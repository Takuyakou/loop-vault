## 1. 拍子とキーの選び方(ボタンと窓)

- `TextMeterSelect` / `TextKeySelect` の中身を、`TextSettingMenu`(1 つのボタン+窓)に置き換えた。ボタンは高さ 32px・左右 10px・角丸 8px・枠 `rgb(150 170 195 / 28%)`・地 `#111b2a`。中は「拍子」/「キー」(11px `#7f90aa`)・値(13px `#f2f6fc`)・▾(10px `#a5b2c6`)、間 6px。ホバーと開いている時は枠 `#42d8c6`。
- 窓はボタンのすぐ下(地 `--lv-surface-raised`・枠 `--lv-border-strong`・角丸 10px・影 `--lv-shadow-overlay`・余白 4px・最大 320px スクロール)。項目は高さ 32px・13px、選んでいる項目は地 `#123b3a`・字 `#42d8c6`。キーの窓は今の `<select>` と同じ順(自動・未設定・推定のキー・すべてのキー)。
- キーボード:Enter/Space(と ↑↓)で開く、↑↓ で選ぶ、Enter で決める、Esc で閉じる、外を押すと閉じる。`aria-label` は今の `<select>` と同じ「拍子」「キー」。
- 外に置いていた太字の「拍子」「キー」の字は消した(ボタンの中)。「BPM」の字も 11px `#7f90aa` にそろえた(`BpmScrubField` に `labelStyle`)。
- `data-testid` はボタンに残し、`data-value` と `${testId}-value` を足した。e2e は `chooseTextSetting(root, testId, value)`(ボタン→項目)に置き換えた(27 spec)。

## 2. 「書き方の早見」を消した

## 3. カードを消す(右クリックと Delete)

- `src/domain/textCardDelete.ts` の `deleteTextCard(input, options, cardStart)`:
  - カードのコードの字と、その小節で続く `=`(のばす)・`%`(もう一度)を消す。小節に残ったコードは今の等分の決まりで読み直される。
  - 小節が空になったら、その小節(`| … |` の 1 つ分)を消す。行が空になったら行を消す。
  - 休符 `_` も読めない字も同じ(読めない字はその語を消す)。
- 右クリック(とメニューキー・Shift+F10)は修正作業場と同じ見た目の小さな窓(`lv-cw-card-menu`)に赤い「削除」1 つ。Esc・外を押すと閉じる。
- Delete/Backspace:ポインタがカードの上にある時はそのカード。ポインタが無い時は、選んでいるカードがあり、カーソルが入力の欄に無い時にそのカード。
- 消したカードの音(`attackVoicing` の発音・`voicingOverrides` の span)も忘れる。
- 消した直後の Ctrl+Z(入力の欄)1 回で前のテキストに戻る(消した時だけ横取りし、それ以外の Ctrl+Z はそのまま)。

### 4. 文字を選べる所を絞る

- `src/styles/shell.css` で `#root { user-select: none }`、`input`・`textarea`・`[contenteditable="true"]`・`[data-selectable]` だけ `user-select: text` に戻した(既存のタイトルバー・BPM・音量・サイドバーの個別指定はそのまま)。
- `data-selectable` を付けた所:
  | 場所 | 要素 |
