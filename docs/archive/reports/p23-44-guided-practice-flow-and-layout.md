## 1. 初回の見本

- Lv1 で確認の記録も途中回答もない場合、コースを開くと「見本を見て弾く」を表示。
- 順序は **C → Cm → F → Fm**（`lv1-n-001` / `lv1-n-004` / `lv1-n-013` / `lv1-n-016`）。
- 各問: 大きいコード名、鍵盤の参照音、音名、「見本を聴く」（何度でも可）。制限時間・成功条件なし。
- 4問目: 「確認を始める」「もう1周」。各見本: 「次の見本」と補助の「確認へ進む」。
- 確認開始時に既存の `startCourseAttempt` で出題・入力処理を開始。見本の段階では `trials` を書き込まない。
- 既存の active attempt / trials がある場合は見本を出さず、従来の再開位置へ戻る。
- 見本は Lv1 初回のみ。Lv2/3、進級、確認問題の構成、翌日条件、保存形式は不変。

確認:
- 4問の順序、進捗「見本 n / 4」、4問目の2操作、途中スキップ、再開時に見本が出ないこと、見本中の trial 0 を E2E/unit で確認。
- 見本の「確認へ進む」/「確認を始める」後は「確認 1 / 30」。

## 2. 誤答後の見直し

- 結果確定後、カード下段に **結果 → 見本を見る／見本を聴く → 次へ** を配置。
- 「見本を見る」で同じ鍵盤に参照音のハイライトと音名を表示。名称は「弾き方の例」。転回・省略も合格になる既存判定に合わせ、その旨を1行添える。
- 「見本を聴く」は参照音を再生。表示・試聴・その場の音では確定 trial を変更しない。
- 未入力は「MIDI入力を確認できませんでした」。不足音/違う音/選択違いは既存の判定理由。自己確認「まだ難しい」でも見本を使える。
- 耳の確認問題で音名・鍵盤強調を出すのは回答確定後、「見本を見る」を選んだときだけ。回答前は出さない。
- invalid は従来どおり「もう一度」で同一問題へ再 arm。見本は出さない。

確認:
- 自己確認の誤答 → 見本表示 → 試聴後も trial 1件・wrong のまま。
- 耳の回答前に「見本の音名」/参照音が出ないこと、回答後に出せることを E2E で確認。

## 3. 画面の配置

- ヘッダー: 戻る、`ガイド練習 · LvN`、課題種別、進捗（`見本 n / 4` / `確認 n / 30`）。
- 1枚の `.gc-card` に、上段=課題、中央=鍵盤、下段=結果・見本・操作を配置。
- カード最大幅 760px。デスクトップ内側 20px、狭幅 12px。コード名 60px / 44〜48px。
- 鍵盤はカード内幅いっぱい。実測:
  - 1440×900: カード 760×493.5、鍵盤 **718×128**、白鍵 **24.76×128**（高さ/幅 5.17）。
  - 768×640: カード 680×444.9、鍵盤 **654×120**、白鍵 **22.55×120**（高さ/幅 5.32）。
- C2〜C6・黒鍵の比率は既存の鍵盤コンポーネントのまま。鍵盤ラベルと鍵盤は課題と同じ中心線。
- 768 は初期表示で課題と鍵盤を優先し、下段と説明は自然な縦スクロールを許容。横 overflow 0。
- 「今やること」を1か所に集約:
  - 耳: 再生中 → 「再生中」、再生後は「メジャーかマイナーを選んでから弾いてください」→ 選択後「弾いてください」。
  - 名前: 「演奏を待っています」。
  - 回答前の「次へ」は主ボタン色を使わず disabled。確定後の「次へ」だけ primary。
  - 自己確認の2択は同じ重み。ヒント説明は試聴ボタン付近、自己確認の注記は回答ボタン付近に1回。
