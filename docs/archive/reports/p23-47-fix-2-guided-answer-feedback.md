## 2. Lv1/Lv3 のメジャー・マイナー三和音に第5音を求める

- 教材（P23-39 v3 の bank/policy）と製品コピーを更新し、Lv1/Lv3 の `maj`/`min` は root+3rd+5th を必須にした。`A-C` だけでは不合格、`A-C-A` の重複でも第5音の代わりにならず、`A-C-E` で合格。転回形は `name` で合格、`ear` は root bass を維持。余分な音は従来どおり不合格。
- 入力の確定条件は item の必須音数（三和音は3音）に追随し、採取中に E を足せば合格、2音のまま窓が閉じれば「E がありません」と照合できる。設計契約の生成器・凍結 JSON・manifest・`bank.test`/`answer.test` を同じ規則に揃えた。
- Lv2 のセブンス（5度任意）、上級のテンション/ルートレス、通常 Dojo の既存ルールは変更していない。保存済みの履歴・合格・中断位置はそのままで、新しい回答から適用する。

## 3. 正解を残し、Enter で次へ

- ガイド練習の基礎・上級の「合いました」を「正解」に統一。自己確認は「弾けた（自己確認）」、ヒント正答は「お手本を使用しました（ヒントあり）」を残す。
- 確定後は離鍵しても、鍵盤に「正解の一例」と音名（C5・E5・A5）を次へ進むまで表示する。転回形でも「別の配置でも合格」と伝える。上級の進行は確定したカードの見本、耳は回答確定までコード名・鍵盤を伏せる。
- 確定後の案内を「鍵盤で正解の一例を確認できます」に切り替えた。
- 「次へ（Enter）」は、結果確定後・保存完了後・ダイアログ/MIDI設定なし・入力/セレクト/日本語変換中でないときだけ有効。他のボタンにフォーカスがあるときはそのボタンの Enter を優先し、キーリピートとボタン発火の重複でも1問だけ進む。

## 4. 「正解したら自動で次へ」

- 「次へ（Enter）」の右にチェックボックスを置いた（初期オフ、ガイド練習内で共通、`localStorage` で再起動後も保持）。
- オンで MIDI 正解のときは「✓ 正解」と正解例を残し、「まもなく次の問題へ（最後は結果へ）」を表示。約1.2秒後、かつ押鍵が離れてから同じ次へ処理で1問進む。押している間は「鍵盤を離すと次の問題へ」で待つ。保存完了前は進まない。
- 誤答・未入力・自己確認は留まる。デモ、譜面のカウント/テンポ、進行の途中カードは対象外。チェックを外す・正解例を聴く・レベル変更/離脱・ダイアログ・MIDI切断で予約を取り消し、再チェックは次の正解から有効。
- 予約中は「この答えを見返す」を出し、押すとその一問の予約だけ取り消して正解例を残したまま「次へ（Enter）」で待つ。チェックはオンのまま。
- 上級の自由練習には「もう一度弾く」を追加し、同じ教材・問番号の回答待ちへ戻す（回数は問題数に数えない）。

## 5. 結果から「間違えた問題だけ練習」

- Lv1〜8・総合確認の結果画面に、対象が1問以上あるときだけ「間違えた問題だけ練習（N問）」を主操作の直後に出した。直前に結果を出した試行の出題順で、確定した誤答・構成音不足・明示的な「わからない」「まだ難しい」を一度ずつ取り出す。未入力・切断などの無効試行、ヒント付き正答は含めない。
- 基礎は専用の練習ランナー（ストアを書かない）で、同じカード・鍵盤・採点を使う。ヘッダーは「間違えた問題の練習 1 / N」「点数には反映されません」、カード下に「元の結果に戻る」。上級は practice attempt（`free`）で同じ項目を出題し、耳の答えは確定まで伏せる。
- 練習終了は「間違えた問題の練習が終わりました」「正解 2 / 3」「2問弾けました。残り1問です」「3問すべて弾けました」「未回答 N問」を出し、「元の結果に戻る」と「まだ間違えた問題を練習（N問）」（残りの誤答数）を提示する。正式の点数・昇級・別日待ち・再開位置には反映しない。
- 自由練習の誤答・構成音不足・「まだ難しい」の後は「もう一度弾く」で同じ一問へ戻り、問番号を増やさない。耳は最初の提示から再開する。
