# 使い方ガイド

このガイドは、Loop Vault の細かい使い方をまとめたものです。まず全体像と始め方は [README](../README.md) を見てください。

## 1. 取り込みと修正

### 1.1 MIDI を取り込む

- 左の「取り込む」で MIDI ファイル(.mid / .midi)を選ぶか、画面へドラッグ&ドロップします。複数ファイルの取り込みに対応しています
- 解析の前に、どのパートをベース・和音・パッド・メロディとして扱うかを確認・変更できます。和音を中心に見たいときは「ハーモニックコア」の寄与設定を使います
- 「解析」を押すと、コードカード・ピアノロール・おすすめの保存範囲が出ます
- 元の MIDI ファイルは書き換えません

### 1.2 修正作業場

- **音を直す**:いらない音を消し、消した跡を残します。音の追加や高さの変更もできます
- **コードを直す**:コード名・ルート・種類・テンションを確認・変更します
- **区切りを直す**:カードの分割・統合や、位置の調整を行います
- **カードを削除**:カードのメニュー、または Delete キーで、いらないコードカードを消します
- **小節を消して詰める**:カードのメニューから、小節ごと消して後ろを詰めます。1 小節ずつ・拍単位の調整もできます
- **聴き比べ**:元の音と修正後の音を比べ、変更をすぐに戻せます
- **元に戻す**:操作は Undo / Redo で戻せます
- **保存する**:範囲を決め、その範囲のコード進行とボイシングを Vault へ保存します

### 1.3 テキストで入力する

`| Dm7 G7 | Cmaj7 | Am7 | F G |` のように、小節線とコード名で入力します。標準の 4/4 では、小節に 1・2・4 セルを置きます。

| 記号 | 意味 |
|---|---|
| `%` | 前のコードを繰り返す |
| `_` | 休符 |
| `=` | 繰り返さず保持 |

- **標準**:拍の頭にコードを置く、かんたんな書き方です
- **拡張**:細かい区切り(裏拍・シンコペーション)を書けます。`Cm(maj7)`・`G7alt`・slash(`G7/D`)などのジャズの表記も読めます
- 入力の上限は 65,536 文字・256 小節・4,096 トークンです
- 解釈できない記号があると、保存の前に理由が出ます。画面の診断を見て直してください

テキストはコード名と時間の情報だけで、**元の MIDI の音の高さ・オクターブ・手の割り当て・細かいタイミングは持ちません**。Voicing Loop では、保存した音・カスタム・自動生成から選びます。

## 2. Voicing Loop

保存した進行を、ループしながら鍵盤で確かめる画面です。

### 2.1 進行を選ぶ

- 上の検索欄で、タイトル・コード・キーから絞れます
- 段は「お気に入り → 最近使った → そのほか(新しく保存した順)」です。同じ進行は 1 つの段にだけ出ます
- 行の星を押すと、**Vault と同じお気に入り**になります。押した瞬間は並びが変わらず、次にこの画面を開いたとき(または検索の文字を変えたとき)に、お気に入りが一番上に並びます
- 練習できない進行は薄く出て、理由が横に出ます(保存データは消えません)
- 行のどこを押しても練習が始まります(星のボタンを除く)

### 2.2 鳴らす音

| 選択肢 | どの音を使うか |
|---|---|
| 保存した音 | Vault でそのコードの生成用に選ばれている保存済みの音。修正した音や、保存時に確認したテキスト・試聴音も含みます |
| 元 MIDI | 取り込んだ MIDI からコードごとに保存された音。修正作業場で排除した楽器は保存対象から外れます |
| カスタム | 鍵盤で登録した音や、音の追加・高さの変更によって保存した手動のボイシング |
| 自動生成 | コード名をもとに、練習用のボイシングを生成した音 |

- 音が保存されていない選択肢は無効になります。一部だけ使える場合は「12/16」のように件数を表示します
- 不足するカードだけ自動生成で補完して印を表示します。保存されているカードの音を、この補完のために再生成することはありません

### 2.3 生成・表示・運指

- **基本 / 骨組み**:自動生成の主な 2 種類。詳しい設定では形・左手・Color・Open を調整できます
- **固定音**を選ぶと、生成タイプと詳しい設定は無効になります
- **覚える / 思い出す**:コードを見ながら確かめる表示と、思い出しながら弾く表示を切り替えます
- **おすすめ運指**:左右の指番号・移動音を表示します。個人の運指を保存し、固定して使うことも可能です
- **次への動き**:現在から次のコードへ向かう手と音の動きを確認できます

### 2.4 再生と区間ループ

- BPM・キー・オクターブ・カウントインを設定し、開始・一時停止・再開・停止・最初からの操作ができます
- 「現在のコードを試聴」やカードのクリックで、1 コードだけを聴くこともできます
- タイムラインのカードや帯をドラッグして A・B を指定すると、コード単位の区間ループになります。Shift+クリックでは 1 コードだけを指定できます。「区間解除」で全体のループへ戻ります
- 区間の指定はその練習の間だけ有効で、保存した進行そのものは変わりません
- 入力欄などに操作していないときは、Space で再生・一時停止を切り替えられます
- MIDI 鍵盤をつなぐと、押している鍵盤を画面で確認できます

## 3. Chord Dojo

コードや進行を、見なくても弾けるように覚える画面です。入口は「今日の練習」です。

- **定番の進行**:J-POP・ジャズ・ボサノバ・ネオソウルなどの進行を、キーを選んで練習します。12 キーのランダムキーにも対応しています
- **Jazz Progressions**:ジャズの定番の進行を 12 キーで。「① 見て弾く」「② 覚えて弾く」の順に進みます。② はヒント無しで通した周だけを記録します
- **保存した進行**:自分の Vault の進行を練習します
- 練習画面は、定番の進行・Jazz・保存した進行で同じ型です。段階を押すとその段階の最初から始まり、「この段階をくり返す」で周の終わりを変えられます
- まちがえても止まらず最後まで進み、まちがいの無い 1 周でクリアです
- MIDI 鍵盤があるときは、正しく弾けたかを自動で判定します。無いときは、答えを見て自分で「弾けた」を押して進めます
- 練習の記録は Chord Dojo 専用の保存場所に置き、Vault やほかの練習の記録とは分けています

## 4. Bass Practice

- **度数・リズム・ベースライン・ルートの動き**を聴いてまねする練習です
- 録音して聴き比べる自己採点(任意)に対応しています
- MIDI で読み込んだベースラインを、正しく弾けたか判定しながら練習できます
- 記録は Bass Practice 専用の保存場所に置きます

## 5. Live MIDI

接続した MIDI 鍵盤の入力とコード判定の履歴を確認する専用画面です。ミニモードでは、常に手前に表示するか・履歴を表示するかを選べます。

## 6. データの置き場所

- Vault・設定: `loopvault/`(デスクトップ版)。バックアップは `loopvault/backups/` に最大 20 個
- テキスト取り込みのジャズ表記: `loopvault/txt-jazz-v3/`(初回に既存の記録をコピーして使います)
- Chord Dojo の記録: `theme-lessons-ranges-v4`
- Original Practice・Jazz Progressions・Bass Practice・耳で弾くの記録: それぞれ専用の保存場所(版 1)

「設定」→「データ」から、保存場所の確認・書き出し・読み込み・バックアップからの復元ができます。

## 7. 現在の制約

- MIDI 解析は完全な自動採譜ではありません。メロディ・装飾音・複雑な和音・転調などは、手で確かめる必要がある場合があります
- 自動生成で扱えるコードや形には範囲があります。代替を使った場合も、選んだ詳細形と同じ音になるとは限りません
- Voicing Loop が対応する拍子は、一定の 1/4〜12/4 です。途中の拍子・テンポの変化、音さやイベント数の上限により利用できない進行があります
- おすすめ運指は練習の目安です。手の大きさ・柔軟性のばらつきを保証するものではありません
- 対応 OS は Windows(x64)です。ブラウザ開発環境のネイティブ機能と保存の確認接続は条件が異なります
- テキスト取り込みは、元の MIDI のボイシング・オクターブ・手の割り当て・正確なタイミングを持ちません
- alt を含む書き出し(`fileVersion: 3`)は、v2.0.0 では開けません
