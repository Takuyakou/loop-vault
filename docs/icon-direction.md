# Loop Vault Icon Direction

## Purpose

Loop Vault stores reusable chord progressions and short music-production loops. The icon should communicate both the **loop** and the **vault** at desktop-icon size.

## Chosen Direction: Vault Door + Loop

- A charcoal or near-black rounded square base.
- A bold circular vault-door / loop motif in the centre.
- A thin neon-cyan ring is the primary visual signal.
- Use only a few abstract MIDI-note blocks or chord cards around the ring.
- Add a small keyhole or restrained `LV` monogram in the centre.
- Optional: a very small off-white or muted-gold highlight to suggest saved musical material.

## Constraints

- Must remain readable at 16px, 32px, and 64px.
- Avoid literal music notes, keyboards, DJ imagery, and dense line work.
- Keep the palette to charcoal, black, neon cyan, off-white, and a minimal gold accent.
- Do not use text labels outside of an optional compact `LV` monogram.

## Production Prompt

Create a desktop icon for a music-production app named Loop Vault. The concept is a vault for reusable chord progressions and 8-bar loops. Use a charcoal rounded-square base with a bold circular vault-door loop in the centre. Add a neon-cyan ring, a few abstract MIDI-note blocks or chord cards, and a tiny keyhole or restrained LV monogram. It should feel like a dark production room: minimal, slightly futuristic, not flashy. Keep the shapes thick and few so it remains readable at small icon sizes. Avoid literal music notes and keyboards.
