README で参照する画像をこのディレクトリに置きます。まだ画像を用意していないため、
README のリンクは現状プレースホルダです。以下のファイル名で書き出すと、README から
そのまま参照されます。

## 用意する画像（推奨 4 枚 + ヒーロー）

| ファイル名 | 内容 | 対応画面 |
| --- | --- | --- |
| `hero.png` | アプリ全体の雰囲気が伝わる 1 枚（トップに掲載） | 任意（例: ホーム or コード進行詳細） |

## 撮影手順

1. 開発ビルドを起動します。

   ```bash
   npm install
   npm run tauri dev
   ```

2. 各画面を開き、OS のスクリーンショット機能（Windows: `Win + Shift + S`）で撮影します。
3. 上表のファイル名で、この `docs/images/` ディレクトリに PNG として保存します。
4. 横幅は 1600px 前後を目安にし、必要に応じて縮小してください（リポジトリ肥大化を避けるため）。

## ⚠️ ダミーデータで撮影してください

スクリーンショットには、以下を **写さない** よう注意してください。

- ライセンスが不明な第三者の MIDI から解析した内容（コード進行・ファイル名・パスなど）
- 個人を特定できる情報（実名・メールアドレス・フォルダの絶対パスなど）
- OpenAI API キーや、Progression Advisor に入力した実際のプロンプト内容

撮影は、**自作またはライセンス上問題のないダミーの MIDI／アイデア**で行い、
「機能が伝わること」だけを目的にしてください。ファイル名やパスが写り込む場合は、
ダミー名（例: `demo-loop.mid`）に置き換えてから撮影します。
