# Reports

One report per stage plus a final report. Each stage report records what was
built, the gates that were run, their results, and the commit hash. Only
committable, non-personal, non-generated evidence belongs here.

Suggested naming:

- `P0.0-00-audit.md`
- `P0.0-01-implementation.md`
- `P0.0-05-final.md`

Never record raw recordings, private MIDI, raw device ids, personal absolute
paths, or `.local-evaluation` artifacts in a report.
