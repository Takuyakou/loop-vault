# P10.0-00 人間用の計測シート（今の取り込み画面）

Phase 10 の新しい画面（P10.0-07）と比べるための基準です。**今の EXE（Phase 10 の前）**で、手元の MIDI を数曲（3〜5曲）取り込み、保存するまでを測ってください。Claude Code は値を書きません。

## 書き方

1. 曲名やファイル名は書かず、「曲1」「曲2」…と番号だけにします（私的な曲の名前を残さないため）。
2. 時計（スマホのストップウォッチなど）を用意し、**MIDI を取り込む画面に入った時**から、**「Vaultに保存」を押して保存が終わった時**までを測ります。解析前のパート選択にかかった時間も含めます。
3. 保存するのは、ふだんと同じく「使いたい範囲」だけで構いません。範囲を2つ保存した時は、2つ目の保存が終わるまでを測り、備考に「2範囲」と書きます。
4. 直した回数は、操作をしたらその場で「正」の字などで数えます。同じ所を何度も直したら、その回数だけ数えます。
5. 元に戻した操作（`Ctrl+Z`・元に戻す）は、直した回数に入れず、下の「戻した」に数えます。

- **分割・結合・挿入・削除**：コードのカードを分ける・つなぐ・足す・消す。
- **名前の変更**：別候補を選ぶ、文字でコード名を入れる。
- **境目・範囲の移動**：手動候補の移動ボタン、範囲のドラッグ、コードの長さの変更。
- **音の変更**：今の画面では音そのものは直せないので、ボイシングの欄で鍵盤から記録した・「元の MIDI／自動生成／カスタム」を選び直した回数を書きます。
- **諦めた所**：今の画面では直せない（例：メロディの音が和音に混ざって消せない、足りない音を足せない）と感じた所の数。何が直したかったかを備考に一言。
