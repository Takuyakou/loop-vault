## P10.0-06（保存）への申し送り

- **直した音の保存**：
  - `edited: true` のカードは、使っている音（`used: true` の断片と足した音の高さ、重複なし）を、そのカードの保存するボイシングとして書く。今の保存の経路では `practiceVoicingOverride` に当たる。
  - 直していないカード（`edited: false`）は、今までどおり解析のボイシング（`timeline[timelineIndex]` のもの）。
  - つなぐ・分ける・境目では `edited` を引き継ぐだけなので、カードの区間が変わったのに `edited: false` のカードの扱い（解析のボイシングで良いか）を決めること。
- **2〜10音の確かめ**：1音以下のカードには `noteWarning`（「2音以上にしてください」）が付いている。保存の時に止める。上限の10音は編集の時点で守っている。
- **人が決めた名前**：`nameSource: "user"` のカードの名前で保存する。名前を変えた時の札の付け直し（`capturedForChordKey`・`Label`）は、保存の時に作る。
- **打ち直しの回数**（`attacks`）は保存しない。
- **カードの区間**：つなぐ・分ける・境目で、`timelineIndex` は最初のカードのまま。保存する進行の拍の位置は、作業データの `start`／`duration` から作る。
- **古い部品で作業場に移したもの**：
  - 移した：分割・結合（分ける・つなぐ）、別候補（名前の候補）、同じ直しの反映、聴き比べ（A／B）、曲全体のコード（タイムライン）、全曲（曲全体の帯）。
  - まだ：挿入・削除、元ベースライン候補（「詳しい設定」）、自動候補カード（「おすすめの範囲」）、試聴音色の切り替えの1か所化、保存の範囲（③）。

## 人間が EXE で確かめること

開発者向けの設定「新しい修正作業場を使う（試作）」を ON にして、手元の曲で：

1. 右クリックで外す、`Ctrl+Z` で戻る、②で空いた所を押して足す、上下のドラッグで高さを直す。これらが手になじむか。
2. メロディの曲で「まとめて選ぶ」→ `Delete` →「同じ音が続く所」の提案（または `Shift+M`）の流れで、カードが期待どおりに減るか。
3. 名前の候補の更新が分かるか（音を変えると自動の名前だけ変わり、`1`〜`4`・`F2` で自分で決めた名前は変わらない）。
4. 長い曲でスクロール・`Ctrl`＋ホイール・追従（`F`、再生中にホイールで止まる）が引っかからないか。
5. 狭い窓（幅 768〜959）でピアノロールが見え、右の欄が1行で下にあるか。開くと下からのパネルになるか。
6. 設定を OFF にすると今の画面だけになり、保存も今までどおりか。

## 人間に決めてほしいこと

1. **カードの挿入・削除**を右の欄のメニューに作るか（今は、分ける＋名前、つなぐで代わりになる）。
2. **追従を止める条件**：再生中だけで良いか（仕様書は条件なし）。
3. **「同じ音が続く所」の提案**を、直した所がある時だけ出すので良いか（取り込んだ直後から出す案もある）。
4. **`Shift`＋ホイール**：ページごと縦に動くので良いか。ピアノロールの中だけ縦に動かす（鍵盤と同期）方が良いか。
