### 作ったもの

- **編集の関数**（`src/domain/correction/edits.ts`、React なし・入力を変えない）：`deleteNotes`（元の音は外す／足した音は消す）・`restoreNotes`・`addNote`（`MANUAL_ADDED`、カードいっぱい、同じ高さは足さない）・`movePitch`（`originalPitch` の付け外し、0〜127 を越える時はしない）、選ぶための `sameShortPitchIds`・`aboveLineIds`・`pitchIds`・`cardNoteIds`。10音の上限は「このカードで鳴らせるのは10音までです」、まとめて戻す時は「N枚のカードは10音を超えるので戻していません」。1音以下は外せて「2音以上にしてください」の印。
- **計算し直し**（`refreshModel`）：触ったカードとその前のカードの要確認、曲全体の提案（メロディの Voice の音が残っているか）、自動の名前（`detectedName`＝3音以上の時の `detectLiveChord`）。名前の更新は音の操作と同じ1回に入るので、`Ctrl+Z` で音と名前が一緒に戻る。
- **履歴**（`history.ts`）：スナップショットと短い文（「Bb4 を足した」「D5 を外した」「3音を外した」「C4 → C#4」）。上限 200。ドラッグ1回は1回分（始めの作業データから計算し、離した時に1回だけ入れる）。
- **ピアノロール**：仕様書 7.2 の表のとおり（右クリック・右ドラッグで外す、外した音の左クリック・ドラッグで戻す、上下ドラッグで高さ、②の空いた所を1回押して足す、ダブルクリックで足す、範囲で選ぶ、`Shift`／`Ctrl`＋クリック、鍵盤を押して鳴らす／`Ctrl`＋クリックでその高さを曲全体で選ぶ）。ブラウザの右クリックのメニューは出さない。②では選んだカード以外を暗くし、メロディの線と「線より上の音を選ぶ（N）」を出す。足した音・高さを直した音（縞と元の高さの紫の破線）・選んでいる音（白い外枠）の見た目を足した。
- **右の欄**：音ごとの「外す／戻す／消す」、「＋ 音を足す」（12の音名、G3〜F#4 に足す）、追加候補を押して足す、要確認の理由ごとのボタン、名前の候補を横1列（押せるのは区切り2）。

### 決めたこと

- **履歴の持ち方**
  - 選んだこと：操作のたびに作業データ全体のスナップショットを持つ。
  - 理由：音と名前・要確認の出し直しを1回分としてそのまま戻せ、逆操作を書く必要がない。作業データは不変なので、変わらない部分は共有されて軽い。
  - 別案：操作ごとの差分と逆操作。メモリは少ないが、カードの操作（区切り2）で逆操作が複雑になる。
- **見えている拍だけを描く処理を区切り1で入れた**
  - 選んだこと：ピアノロールとカードを「見えている範囲＋前後に1画面分」だけ描く（P10.0-05 の要件を先に）。
  - 理由：編集のたびに全部の音を描き直すと長い曲で遅くなるので、編集と一緒に作る方が手戻りが少ない。
  - 別案：区切り3でまとめて入れる。そうすると区切り1〜2の E2E を後で直すことになる。
- **P10.0-02 の E2E「97枚のカード」**
  - 選んだこと：「描いたカードが 0 より多く 97 より少ない」に変えた。
  - 理由：見えている拍だけを描くようになったので、全部のカードが DOM にあることは期待しない。
  - 別案：全部を描く。仕様書 9 章（長い曲）に合わない。
