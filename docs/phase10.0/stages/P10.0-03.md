## 1. 編集の操作（純粋な関数）

`src/domain/correction/` に、`CorrectionModel` を受けて新しい `CorrectionModel` を返す関数として作る（React を使わない。入力は変えない）。

| 操作 | 中身（仕様書 8.3） |
| --- | --- |
| 外す・戻す（元の音） | 断片の `used` を切り替える |
| 足す | `provenance: "MANUAL_ADDED"`・`sourceNoteId: null`・`used: true`。区間はカードいっぱい。同じ高さをそのカードですでに使っていれば足さない |
| 消す（足した音） | 作業データから消す |
| 高さを直す | 元の音：`pitch` を変え、最初の高さを `originalPitch` に残す（元の高さに戻ったら `originalPitch` を消す）。足した音：`pitch` だけ |
| 選ぶための計算 | 同じ高さの短い音（曲全体、`P10-review-thresholds.json` の `shortMaxBeats` 以下だけ）、メロディの線より上で使っている音（曲全体）、鍵盤の高さ（曲全体）、区間の全部の音 |

- **10音の上限（仕様書 7.2）**：足す・戻す・まとめて戻すで、あるカードの使っている音が 11 個以上になる時は、そのカードでは行わず「このカードで鳴らせるのは10音までです」を返す。まとめて戻す時は、上限に当たったカードだけ飛ばし、飛ばした枚数を返す。
- **1音以下**は外せる。そのカードに「2音以上にしてください」の印を付ける（保存の時に止めるのは P10.0-06）。
- 操作のたびに、そのカードの**要確認の理由を計算し直す**（例：メロディの音を外したら「メロディの混ざり」が消える）。曲全体の提案は、対象の音が残っているかで出し直す。
- 操作のたびに**名前の候補を計算し直す**（仕様書 8.4）。名前が「自動」のカードは、表示する名前を新しい候補の先頭にする（人が決めた名前は P10.0-04 で扱い、上書きしない）。
- 元の MIDI（`sourceData`）はどの操作でも変わらないことをテストで確かめる。

## 2. 元に戻す（1本の履歴）

- `src/domain/correction/` に履歴を作る：作業データのスナップショットと「何をしたか」の短い文（「G4 を足した」「D5 を外した」「3音を外した」）を持つ。
- P10.0-04 のカードの操作（つなぐ・分ける・境目・名前・このままでよい）も同じ履歴に入る形にしておく。
- ドラッグ1回（なぞって外す・戻す、上下の移動）は**1回分**にまとめる。再生・スクロール・選択は履歴に入れない。
- 名前の自動の更新は、音の操作と同じ1回に入れる（`Ctrl+Z` で音と名前が一緒に戻る）。
- 履歴の数に上限を置く（例：200。古いものから捨てる）。
- 「直した回数」は、履歴に入った操作の数（元に戻したら減る）。

## 3. ピアノロールの操作（仕様書 7.2）

| 操作 | 結果 |
| --- | --- |
| 左クリック（使っている音） | その音を選び、鳴らす。持ち主のカードも選ぶ |
| 左クリック／ドラッグ（外した音） | 戻す。なぞった音を続けて戻す |
| 右クリック／ドラッグ（元の音） | 外す。なぞった音を続けて外す。ブラウザの右クリックのメニューは出さない |
| 右クリック（足した音） | 消す |
| 空いた所を左クリック | ①：選択を外す。②：その高さの音を足す |
| 空いた所をダブルクリック | ①でも②でも足す |
| 空いた所をドラッグ | ①：範囲で選ぶ。②：`Ctrl`＋ドラッグで範囲で選ぶ。`Shift` で選択に足す |
| `Shift`／`Ctrl`＋クリック | 選択に足す・外す |
| 選んだ音を上下にドラッグ | 半音ずつ。複数なら一緒に。動かしている間は「D4 → E4」 |
| `↑`／`↓`、`Ctrl+↑`／`Ctrl+↓` | 半音、1オクターブ |
| `Delete`／`Backspace` | 元の音は外す、足した音は消す |
| `R` | 選んだ音を戻す |
| `Ctrl+A` | 選んだカードの区間の音を全部選ぶ |
| 鍵盤を押す／`Ctrl`＋クリック | その高さを鳴らす／その高さの音を曲全体で選ぶ |
| `N`／`Enter`／`Esc` | ②へ／直し終わる（②なら①へ）／選択を外す |
| `A`／`B` | 選んだカードの元の音／カードの音を鳴らす |
| `Ctrl+Z`／`Ctrl+Shift+Z`・`Ctrl+Y` | 元に戻す／やり直す |

- 時間方向（横）には動かさない。
- ②では選んだ区間以外を暗くする（仕様書5章）。
- マウスを重ねた音にツールチップ：「D5 · 4拍 · 使っている」「G4 · 手動で足した音」「E4（元は D4）」。
- 見た目（仕様書 6.1）：足した音（薄い塗り＋太い枠）、高さを直した音（縞＋元の高さに紫の破線の枠）、選んでいる音（白い外枠）を足す。
- 入力欄にフォーカスがある時は文字のキーを効かせない。`Ctrl` の組み合わせは作業場の中だけで奪う（仕様書 7.5）。

## 4. 右の欄と曲全体の提案

- **鳴らす音の一覧**：音ごとに「外す」「戻す」「消す」のボタン（右クリックやダブルクリックが使えない人の代わり。仕様書 7.5）。
- **「＋ 音を足す」**：押すと12の音名が並び、選んだ音を和音の音域（G3〜F#4 あたり）に足す。①でも②でも目立つ位置に常に出す（仕様書 6.4）。
- **構成音との違い（参考）**：「追加候補」の音を押すとその音を足す。
- **要確認の操作**：理由ごとのボタン（「D5 を外す」「同じ高さの短い音を選ぶ（40個）」「音を直す」）。「このままでよい」「次とつなぐ」は P10.0-04 で足す。
- **名前の候補**：横1列のボタン（最大4つ）。この区切りでは表示だけ（押せるのは P10.0-04）。
- **メロディの線（②）**：区間の中に点線を出し、「線より上の音を選ぶ（N）」。線の高さはドラッグで変えられる（初期値は区間の一番上の音の少し下）。選んだ後に外すかは人が決める。
- **曲全体の提案**：「まとめて選ぶ」を足す（選ぶまで。外すのは `Delete` か右の欄のボタン）。
- ファイル帯の「直した回数」と、再生の横の「操作 3 · 最後：G4 を足した」を履歴から出す。
