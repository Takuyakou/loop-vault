# P10.0-04 — カードの編集（まとめ A の区切り2）

[P10.0-03.md](P10.0-03.md) の続き。同じブランチ `feat/p10.0-03-editing`。終わったら止まらずに [P10.0-05.md](P10.0-05.md) へ。仕様書 v2.3 の 7.1・7.3・8.3・8.4・6.3・6.5・12章が中心。

## 1. カードの操作（純粋な関数）

`src/domain/correction/` に足す。すべて P10.0-03 の1本の履歴に入る。

| 操作 | 中身 |
| --- | --- |
| つなぐ（`M`、提案のチップ） | 次のカードと1枚に。長さは足し算、打ち直しの回数 `attacks` を足す。名前は前のカードの名前（人が決めた名前があればそれを優先）。音の断片は元の状態を引き継ぎ、同じ元の音で状態も同じ断片は1つにまとめる。足した音は1枚にまとめ、同じ高さは1つにする |
| 一括でつなぐ（`Shift+M`） | 使っている音（音名の集まり＋一番下の音）が**完全に同じ**隣どうしを曲全体から探し、確認のダイアログ（「同じ音が続く所を 7 か所つなぎます」と一覧、`Enter` でつなぐ、`Esc` でやめる）。履歴は1回分。名前が同じでも音が違う所はつながない |
| 分ける（`S`） | 選んだカードを半分に（拍の境目にそろえる）。どちらかが1拍以下になる時は分けない。断片は切り直して元の状態を引き継ぐ。足した音は両方に置く |
| 境目を動かす（取っ手のドラッグ） | 1拍単位、`Alt` の間は ¼拍。隣のカードの長さも変わる。どちらかが ¼拍未満になる所へは動かせない。動かしている間は「5.3」のように位置を出す。断片は切り直して元の状態を引き継ぐ。足した音は持ち主のカードの新しい区間に合わせる。ドラッグ1回で履歴1回 |
| 名前を選ぶ（候補を押す／`1`〜`4`） | 名前だけ変える。`nameSource: "user"` |
| 名前を文字で入れる（`F2`／名前のダブルクリック） | 今の `QuickChordEditor` を使う。読めない名前は入れない（今の検証のまま）。`nameSource: "user"` |
| このままでよい（`Y`） | `reviewed: true`、印を消して次の要確認へ |

- **人が決めた名前は、音を変えても上書きしない**（仕様書 8.4）。右の欄に「あなたが決めた名前」と出し、新しい候補は候補の一覧にだけ出す。自動の名前のカードは「自動の名前（音を変えると候補から更新）」と小さく出す。
- 名前を変えた時の札の付け直し（`capturedForChordKey`・`Label`）は、保存の時に作るもの。ここでは作業データの名前が変わるだけでよい。P10.0-06 の申し送りに書く。
- つなぐ・分ける・境目のあとは、関係するカードの要確認・名前の候補・曲全体の提案を計算し直す。
- カードの「挿入」「削除」（仕様書12章の対応表）は、この段階では作らない（分ける＋名前で挿入、つなぐで削除の代わりになるため）。要るかを報告の「人間に決めてほしいこと」に書く。

## 2. 同じ直しの反映（仕様書12章）

- 名前を変えた時、使っている音（音名の集まり＋一番下の音）が同じで、名前が変える前と同じ他のカードがあれば、右の欄に「同じ音の他の 2 か所にも反映」を出す。押すと確認してから反映（履歴1回）。
- 自動では反映しない。

## 3. 画面

- カードの左右の端に境目の取っ手（仕様書 6.2）。
- コードの段の下 20px に「つなぐ」の提案のチップ（同じ和音の分かれの所）。
- つないだカードに「×2」（打ち直しの回数）。
- 右の欄：名前の候補のボタンを押せるように、「このままでよい」「次とつなぐ」「分ける」、「前とつなぐ」「次とつなぐ」のメニュー、要確認の理由ごとの「次とつなぐ」。
- 曲全体の提案の2つ目：外した結果、同じ音が続く所が出たら「同じ音が続く所が N か所あります」→［確認してつなぐ］（`Shift+M` と同じ確認）。
- 確認のダイアログは今のアプリの確認のダイアログの部品を使う。

## 4. テスト

- 単体（合成だけ）：つなぐ・分ける・境目で断片が元の状態を引き継ぐこと、足した音の扱い、`attacks`、1拍以下は分けない、¼拍未満にならない、`Shift+M` が完全に同じ隣だけを対象にすること、人の名前を上書きしないこと、`Y`、同じ直しの反映、すべて `Ctrl+Z` で戻ること、元の MIDI が変わらないこと。
- E2E：`M` でつなぐ → ×2 → `Ctrl+Z`、`S` で分ける、境目のドラッグ（`Alt` で ¼拍）、候補を `1`〜`4` で選ぶ、`F2` で名前を入れる、`Y` で次の要確認へ、`Shift+M` の確認で `Esc`／`Enter`、曲全体の提案の「確認してつなぐ」。
