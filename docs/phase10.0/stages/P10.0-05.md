# P10.0-05 — 長い曲と狭い画面（まとめ A の区切り3・最後）

[P10.0-04.md](P10.0-04.md) の続き。同じブランチ `feat/p10.0-03-editing`。仕様書 v2.3 の 9章・11章・6.2・7.3・14章が中心。**まとめ A の最後なので、fresh FULL・スクリーンショット・EXE・報告の仕上げまで行い、merge 候補で止まる。**

## 1. 見えている範囲だけ描く

- カード・音・小節の線を、見えている範囲（左右に画面1枚分の余裕）だけ描く。スクロールのたびに描き直す。
- 目安：**300小節・音 5,000 個**でスクロールが引っかからない。重ければピアノロールを canvas に切り替える（見た目と操作は同じにする。音の当たり判定・ツールチップ・ドラッグも動くこと）。
- 合成の曲に「300小節・音 5,000 個」を足す（`src/testing/p10SyntheticSongs.ts`）。
- 測る：横スクロール1回・`→` 1回・拡大縮小1回の時間、作業場の DOM の数。報告に P10.0-02 の数（300小節で DOM 約 3,400、スクロール 約17ms）と並べて書く。

## 2. 倍率・移動・追従（仕様書 9章・7.3）

| 操作 | 結果 |
| --- | --- |
| 「全体」「16小節」「4小節」 | 今のまま。最初は16小節以下なら全体、それより長ければ16小節 |
| `Ctrl`＋ホイール | **マウスの位置を中心に**拡大縮小。最大は8拍が横幅いっぱい |
| ホイール（タイムラインの上） | 横に移動。タイムラインの外ではページが動く |
| `Shift`＋ホイール | 縦（音域）に移動（鍵盤も一緒に） |
| `F`（追従） | 再生位置が右 80% を越えたら左 20% へ。ホイール・帯・キーで動かしたら追従を自動で止める |
| `Home`／`End` | 曲の最初／最後へ |
| `]`／`[`、`←`／`→` | 選んだカードが画面の外なら、画面に入れる |

- OS の「動きを減らす」設定では、なめらかなスクロールを止める（仕様書14章）。

## 3. 狭い画面（仕様書 11章 v2.3）

- 768〜959：**閉じた右の欄はピアノロールに重ねず、タイムラインの下に1行**（「G13・要確認（開く）」）。**768×640 でピアノロールが縦 160px 以上見える**こと。開くと画面の高さの最大 60% の下からのパネル。
- カードの名前が入らない時は根音だけ（「F」）。「F···」のように切らない。全部の名前はツールチップと右の欄（仕様書 6.2 v2.3）。
- 狭い帯の区切りは「×2」。
- どの幅でもページ全体は横スクロールしない。

## 4. テスト

- 単体：見えている範囲の計算（端・拡大縮小・`Home`／`End`）、追従の条件、根音だけの短い名前。
- E2E：300小節・5,000音でスクロール・拡大縮小・`End` が動く（時間の上限は緩く、報告に実測）、`Ctrl`＋ホイールでマウスの位置が中心に残る、追従がホイールで止まる、768×640 でピアノロールが 160px 以上見えて右の欄の1行が重ならない、ページの横のはみ出し 0。

## 報告の仕上げ（`reports/P10.0-03-05-editing.md`）

[reports/README.md](../reports/README.md) の項目に加えて：

- 区切りごとの節（変えたファイル・commit・ゲート・判断ポイント）。
- 仕様書・モックと違えた所と理由。
- 性能の表。
- **P10.0-06 への申し送り**：保存の時に要るもの（直した音の `practiceVoicingOverride` への書き方、札の付け直し、2〜10音の確かめ、人が決めた名前、打ち直しの回数は保存しない）、古い部品で作業場に移したもの・まだのもの、カードの挿入・削除が要るか。
- **人間が EXE で確かめること**（設定を ON にして、手元の曲で）：
  1. 右クリックで外す・`Ctrl+Z` で戻る・②で押して足す・上下のドラッグで高さを直すが、手になじむか
  2. メロディの曲で「まとめて選ぶ」→ `Delete` → `Shift+M` の流れで、カードが期待どおりに減るか
  3. 名前の候補の更新（自動の名前だけ変わり、自分で決めた名前は変わらない）が分かるか
  4. 長い曲でスクロール・拡大縮小・追従が引っかからないか
  5. 狭い窓でピアノロールが見えるか
  6. 設定を OFF にすると今の画面だけになり、保存も今までどおりか
- レビューで見てほしい所（3〜5点）。
