## 区切り1：保存の中身（純粋な関数）

`src/domain/correction/` に、作業データと範囲から、今の保存の経路が受け取る候補（`ProgressionBlockCandidate`）を作る関数を作る（例：`buildSaveCandidate(model, range, analysis)`）。React を使わない。入力を変えない。

| カードの状態 | 書くもの（仕様書 10.2 v2.4） |
| --- | --- |
| 区間も音も変えていない | 解析の時の `ChordTimelineItem` と `voicingMemory` をそのまま |
| 音は直していない（使っている音が元の音だけ・高さもそのまま）が、つなぐ・分ける・境目で区間が変わった | `sourceVoicing` を新しい区間の使っている音から作る（`source: "midi-extracted"`、`representation: "simultaneous-voicing"`、`userVerified: true`、`playbackChoice: "SOURCE"`、`extractorVersion` は解析の時の値のまま、または今の抽出の値。どちらにしたかを報告に書く） |
| 足した音・高さを直した音を含む（`edited`） | `sourceVoicing`：使っている元の音（直す前の高さ）。2音未満なら書かない。`practiceVoicingOverride`：直した後の音（`source: "manual"`、`userVerified: true`、`extractorVersion: "p10-correction:v1"`）。`playbackChoice: "CUSTOM"` |
| 外した音だけ（足していない・高さもそのまま） | 1行目・2行目と同じく `sourceVoicing`（使っている音）。`edited` でも override は書かない |

- **名前**：カードの名前を今の文字の解釈（コードの読み取りの既存の関数）で `ChordSymbol` にする。読めない名前があれば保存できない（理由を返す）。
- **札**：`capturedForChordKey` は `normalizedChordKey(chord)`、`capturedForChordLabel` は `chord.label`。音を書くすべての snapshot で、**保存する名前**から作る（名前を変えたカードの付け直し）。
- **音の数**：2〜10。1音以下のカードがあれば保存できない（「2音以上にしてください：3小節の C」）。音は並べて重複なし（今の検証のまま）。
- **拍の位置**：作業データの `start`／`duration` から `bar`／`beat`／`durationBeats` を作る。範囲の最初のカードが1小節1拍になるように、今の保存の経路と同じ扱いにする（今の `draftToCandidate` などを読んで合わせる）。
- **保存しないもの**：打ち直しの回数、外した音、足した音の出どころ。
- **直した記録**：今の `propagationEvents`・ラベルの直しの記録（`appendLabelCorrectionLogs` など）・解析のフィードバックに、作業場の名前の変更を今の形で渡す。渡し方を報告に書く。

### テスト（区切り1）

- 単体：上の表の4つの状態、名前を変えたカードの札、読めない名前、1音以下、10音、拍の位置（範囲の途中から）、つないだカード・分けたカード。
- **往復**（`src/domain/p89DataRetention.test.ts` に足すか、近くに新しく）：直した音・足した音・高さを直した音を含むカードを保存 → 読み直し → 完全に一致。
- **再生の一致**：保存した進行のカードを、今の `resolveVoicingForUse` に通すと、作業場の「B カードの音」と MIDI の番号まで同じになる（名前を変えたカードも）。合わない時は製品を直さず、報告の「人間に決めてほしいこと」に書く。

commit：`feat(correction): build save candidate from workspace`。

## 区切り2：保存の流れ（画面）

仕様書 10.1 v2.4。

- **範囲（③）**：区切りの帯を押す／右の欄の「おすすめの範囲」（`analysis.result.blockCandidates` を「5〜12小節・Am F C G…」で並べる）／カードを押してから別のカードを `Shift`＋クリック。範囲以外のカードを薄くする。
- **保存フォーム（右の欄）**：範囲、名前の並び、題名、「Vault に保存」「既存のアイデアに追加」（今の `SaveProgressionPopover` などの部品と `useCaptureSave` の `saveNew`・`appendExisting` を使う）。フォームの中に1行「保存すると、外した音は戻せなくなります」。
- **保存できない時**：ボタンは押せる。押すと理由とカードの場所を出し、そのカードへ移れる。
- **保存した後**：同じ画面で次の範囲を選べる。保存した範囲の帯に「保存済み」。
- **離れる時**：保存していない直しがある時に、画面を離れる・別の MIDI を開く時は、今の確認ダイアログ。
- **元ベースライン**：右の欄の「詳しい設定」（閉じておく）に今の `SourceBasslineCapturePanel` を置く。保存できるベースが無い時は出さない。
- **試聴音色**：上のバーの1か所に（今の3か所の切り替えを作業場では1か所に）。
- ファイル帯の「今の画面で保存する」はなくす（2区切り目の入れ替えの後は不要）。

### テスト（区切り2）

- E2E：区切りの帯で範囲 → 保存 → Vault に1件、題名と名前の並び、直した音のカードの試聴の音。おすすめの範囲、`Shift`＋クリック、既存のアイデアに追加、1音以下で保存を押すと理由が出る、保存していない直しがある時に別の MIDI を開くと確認が出る。

commit：`feat(correction): save from workspace`。
