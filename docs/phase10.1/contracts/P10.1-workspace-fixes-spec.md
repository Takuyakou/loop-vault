| グループ | 中身 |
| --- | --- |
| 再生 | `▶ 再生`／`■ 停止`・`追従`・位置（3章）・`BPM [120]`（12章） |
| 表示 | `全体`・`16小節`・`8小節`・`4小節`・☑ `押して鳴らす` |

## 2. 再生の始まる所

- `▶ 再生`・`Space` で曲を鳴らす時、**選んでいるカードの頭から**鳴らし、曲の最後まで鳴らす。**カードを選んでいない時は最初から。**
- **作業場を開いた直後は、カードを選ばない**（v2.5 の「最初の要確認のカードを選んだ状態で開く」を変える）。右の欄は「カードを押すと、ここに音と名前が出ます。」と `要確認 n` へのボタン。
- カードの選択の外し方：`Esc`（6章の順番の最後）、①で何も無い所を押す（音を選んでいない時）。
- 再生中にカードを選んでも、再生は飛ばない（そのまま続ける）。止めてから再生すると、選んだカードから。
- `▶ 再生` の `title`・`aria-label`：「7.1 から再生（Space）」「最初から再生（Space）」。
- **鳴らし方：** transport は変えない。作業場の中で、選んだカードから後ろだけの再生の計画（`createTimelineVoicingPlaybackPlan` に渡す timeline を切り出す）を作り、拍を詰めて鳴らす。音（`explicitMidiNotesByEventId`）の対応は切り出した後も同じ音を指すこと。
- 再生線・位置・追従は、選んだカードの拍（`firstBeat`）から数える。
- まとめ B の「作業場で聴いた音＝保存した音」の確かめ（再生の一致）は、最初からの時にそのまま通ること。途中からの時は、同じカードに同じ音が同じ順で鳴る単体テストを足す。

## 5. `Space`

- **原因（読んだ所）：** キーの処理（`CorrectionWorkspace.tsx` の `onKeyDown`）が、フォーカスがボタン・リンク（`isPressable`）にある時の `Space`、入力欄（`isEditable`。チェックの `<input>` も含む）にある時のキーを、作業場で扱わずに返している。マウスで `16小節` などを押した後は、そのボタンにフォーカスが残るので、`Space` がそのボタンをもう一度押すだけになる。`押して鳴らす` を押した後は、チェックが切り替わる。
- **直し方：** `Space` は、次の所以外では**常に曲の再生／停止**にする。
  - 文字を打つ所（名前の入力、BPM の欄、`textarea`、`contenteditable`）
  - 選択肢（`select`）
  - 作業場の確認ダイアログ・名前の候補の欄が開いている間
- フォーカスのあるボタン・チェックでも `Space` は再生にし、ボタンは押さない・チェックは切り替えない（`keyup` でボタンが押されないことも確かめる）。キーボードでボタンを押すのは `Enter`。
- キーの案内とショートカット一覧：「`Space` 再生・停止（どこでも）」「`Enter` フォーカスのあるボタンを押す」。

---

## 6. `Esc` と枠

- **原因（見込み）：** マウスで押したボタン（例：「線より上の音を選ぶ」）にフォーカスが残り、その後キーを押すと、ブラウザが「キーボードで操作中」と見て、そのボタンにフォーカスの枠（`:focus-visible`）を出す。
- **直し方：**
  - 作業場の入れ物を `tabIndex={-1}` にし、フォーカスの枠を出さない。
  - マウスで押してフォーカスが残ったボタン・チェック・カードがある時、作業場がショートカット（`Tab`・`Enter` 以外）を処理したら、フォーカスを作業場の入れ物へ移す。`Esc` も同じ。
  - `Tab` で移ってきた時の枠（キーボードで使う人のため）は今のまま出す。「マウスで押した」の印は `pointerdown` で付け、`Tab` で消す。
- `Esc` の順番：ショートカット一覧を閉じる → 音の選択を外す → 保存する範囲を外す → **カードの選択を外す（新しい）**。

## 7. 選んだ音の外し方（「線より上の音を選ぶ」の後など）

- ②で音を選んでいる間、ピアノロールの左上（見えている範囲の左端に貼り付く）に**選択の帯**を出す：

  `3音を選択中　［外す Delete］　［戻す R］　［選択をやめる Esc］`

  - 「外す」は使っている音がある時、「戻す」は外した音がある時だけ出す。
  - ①で音を選んでいる時（`Ctrl+A` など）も同じ帯を出す。
- 「線より上の音を選ぶ（n）」は、その線で選んだ音が選ばれている間、「選択をやめる（Esc）」に変わる。押すと選択を外す。
- ②で何も無い所を押すと音を足す（今のまま）。選択は外れない。外し方は帯・`Esc`・このボタン。

## 11. コード名の自動判別

### 11.1 今の動き（読んだ所）

- 音を直した時、名前を変えるのは「自動の名前」のカードで、違う音が3つ以上あり、和音として読めた時だけ（`refreshModel` と `detectedName`）。
- 候補（`1`〜`4`）から選んだ名前・手で打った名前は「あなたが決めた名前」になり、その後に音を直しても変わらない。読めない時は前の名前のまま残り、印も無い。
- つなぐ・分ける・境目を動かした時は、名前を変えない（候補だけ変わる）。

### 11.2 新しい動き

名前の出どころを3つに分ける：**自動**・**候補から選んだ**・**手で打った**。

| 名前の出どころ | 音を直した・境目を動かした・つないだ・分けた後 |
| --- | --- |
| 自動 | 音から判別した名前にする |
| 候補から選んだ | **自動に戻し**、音から判別した名前にする |
| 手で打った | 変えない。右の欄に「音からの判別：Am7 ［この名前にする］」 |

- 「音を直した」は、足す・外す・消す・高さを直す・戻す（`R`）・同じ直しをまとめて。
- つないだカードは、手で打った名前のカードがあればその名前を残す（今の決まり）。無ければ音から判別する。分けた2枚はそれぞれ判別する。
- **読めない時**（違う音が3つ未満、和音として読めない）：名前は前のまま残し、カードの名前を薄くし（色だけにしない：右の欄に文字）、右の欄に「音から名前を決められません（前の名前のまま）」。
- 名前が音から変わった時、知らせに「名前を Am7 にしました（音から）」。
- 右の欄の名前の札：「自動の名前（音を直すと変わる）」「候補から選んだ名前（音を直すと自動に戻る）」「手で打った名前」。
- 元に戻すと名前も戻る（履歴の中なので今のまま）。
- 保存では「候補から選んだ」「手で打った」を、今の `"user"` と同じに扱う（保存の中身は変えない）。
- 判別そのもの（`detectLiveChord`）は変えない。

## 12. BPM

### 12.1 欄

- 操作バーの再生グループに `BPM [120]`（整数 40〜240 の入力欄、幅は4文字ほど）。
- 最初の値：MIDI のテンポ（今の `present.bpm`）。**MIDI にテンポの情報が無い時は、再生が実際に使っている値**（確かめて報告に書く）を出し、`title` に「MIDI にテンポの情報がありません」。
- 確定：`Enter`・欄から出る・`↑`／`↓`（±1、`Shift` で ±10）。範囲の外・空・数字でない時は前の値に戻す。`Esc` で打つ前の値に戻す。
- 欄の中では作業場のショートカットを使わない（5章）。

### 12.2 効く所

- **曲の再生の速さ**と、**再生線・位置・追従**の両方に同じ値を使う。今、再生線は `present.bpm ?? 96`、再生は `present.bpm`（無い時は再生の部品の既定）で、テンポの無い MIDI では食い違うおそれがある。値を1つにまとめる。
- **再生中に変えた時は、今鳴っているカードの頭から、新しいテンポで続けて鳴らす**（2章の仕組みを使う）。
- カードの試聴（A・B、押して鳴らす）は今のまま（テンポに関係しない）。

### 12.3 直す操作としての扱い

- 直す操作として履歴に入れる（「テンポを 120 → 100」）。元に戻す・やり直すで戻る。
- 保存していない変更・閉じる時の確認・計測（種類 `tempo` を足す。数だけ）に数える。

### 12.4 保存

- 保存する進行の BPM（`bpm`）に**この値を入れる**。
- MIDI にテンポが無く、人も変えていない時は、今までどおり入れない（`useCaptureSave` の `SMF_DEFAULT` の扱い）。
- Vault の保存形式は変えない（進行の `bpm` は今もある項目）。

### 12.5 ファイル帯

- 「120BPM」は今の値を出す。変えた時は「100BPM（MIDI 120）」。

## 14. 受け入れ条件

1. 一番上に操作バーがあり、その下に曲全体・小節・区切り・コード・ピアノロールの順に並ぶ。下の再生の列は無い。
2. 再生は選んだカードの頭から、選んでいなければ最初から。開いた直後は何も選んでいない。
3. 再生位置が操作バーと再生線の札で見える。再生線は小節の行からピアノロールまで通る。
4. 再生を始めると追従が ON。
5. どのボタン・チェックを押した後でも `Space` で再生・停止できる。文字の欄では `Space` は文字。
6. マウスで押した後に `Esc` を押しても枠が出ない。`Tab` で移った時は枠が出る。
7. 音を選んでいる時は選択の帯から外せる。線のボタンが「選択をやめる」に変わる。
8. 「範囲を外す」が常にあり、範囲が無い時は押せない。おすすめの範囲を開け閉めでき、覚えている。
9. 表示に 8小節がある。
10. 「押して鳴らす」が最初から ON。
11. 自動・候補から選んだ名前のカードは、音を直すと音から判別した名前になる。手で打った名前は残り、提案が出る。読めない時は文字で分かる。
12. BPM を変えると、再生の速さと再生線が合って変わり、保存した進行の BPM にも入る。元に戻せる。
13. 解析・transport・Vault の保存形式は変わらない。fresh FULL と EXE が通る。
