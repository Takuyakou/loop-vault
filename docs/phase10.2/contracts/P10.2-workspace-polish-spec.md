## 2. 曲の再生で鳴らす音

- **曲の再生は、作業場の音（保存すると鳴る音）で鳴らす。** 各カードで鳴らす音は、カードを押した時の B（`cardAuditionNotes`）と同じ。今は解析の timeline（直す前の音）を鳴らしている。
- 外した音は鳴らない。足した音・高さを直した音は鳴る。カードの境目・つなぐ・分けるも反映する。
- これは**作業場の中での曲の再生の作り方の変更**で、再生の選び方（`resolveVoicing`）・transport・保存の中身は変えない。
- 作り方：作業場のカードから音の並び（`MidiPreviewNote`：音・始まりの拍・長さ）を作り、今ある再生の要求（`type: "notes"`。テキストの取り込みと同じ形）で鳴らす。音色が今と変わる場合は、今の `previewSound` に一番近いものにして報告に書く。`type: "notes"` で作れない事情があれば、今の `type: "timeline"` に各カードの音を明示する形でもよい（その時もメトロノームは 6章のとおり鳴ること）。
- テスト：曲の再生で鳴る各カードの音 = そのカードの `cardAuditionNotes`（全カード、途中からの再生も）。音を外す・足す・高さ・境目・つなぐ・分けるの後も一致する。

## 5. 鳴っているカード

- 再生中、**鳴っているカード**に Voicing Loop の今のカードと同じ見た目を付ける：背景 `--lv-accent-soft`、枠 `--lv-accent`、名前の色 `--lv-accent`。カードの下の端に、カードの中の進み具合の細い帯（任意。重い時はやめて報告）。
- **選んでいるカード**は枠の線（2px の `--lv-accent`）だけにし、今の塗りと影はやめる。両方が同じカードの時は、鳴っている見た目を優先し、枠は2px のまま。

## 6. メトロノーム

- **原因（読んだ所）：** 全体のメトロノームの ON／OFF（`MetronomeProvider`・`useMetronome`・ヘッダーの `GlobalMetronomeButton`）は、テキストの取り込み（`standardTextPlaybackNotes`・`extendedTextPlaybackNotes`）と Voicing Loop は読んでいるが、**修正作業場の曲の再生は読んでいない**。
- **直し方：**
  - 作業場の曲の再生で、全体のメトロノームが ON なら拍ごとにクリックを鳴らす（`textMetronomeNotes` と同じ音・強さ）。
  - クリックは**曲の中の拍**に合わせる。小節の頭を強くする時は、途中から鳴らした時も曲の小節で数える（切り出した所を 0 にしない）。拍子は作業場の `meter`。
  - **作業場にメトロノームの切り替えは置かない。** 切り替えはヘッダーの全体の設定（`GlobalMetronomeButton`）の1つだけ（重複させない）。
  - 再生中にヘッダーで切り替えたら、今鳴っているカードの頭から鳴らし直す（P10.1 のテンポと同じ仕組み）。
  - カウントイン（鳴らす前の1小節）は入れない。入れたい時は報告に案として書く。
- カードの試聴（A・B、押して鳴らす）ではクリックを鳴らさない。

## 7. BPM の欄

P10.1 12章の欄に足す。

- **上下ドラッグ：** 欄の上でマウスを押して上下に動かすと変わる。上で増え、下で減る。4px ごとに ±1。`Shift` を押している間は 12px ごとに ±1（細かく）。カーソルは `ns-resize`。押して動かさずに離した時は何もしない。
- **ホイール：** 欄の上で ±1（`Shift` で ±10）。ページはスクロールしない。
- **ダブルクリック：** 数字を打つ形にする（P10.1 の動き）。キーボードで欄に入った時も打つ形。
- **履歴：** ドラッグ・ホイールの連続した変更は、**離した時・ホイールが 400ms 止まった時に1回だけ**履歴に入れる（「テンポを 106 → 112」）。
- **再生中：** ドラッグ中は数字だけ変え、**離した時に**今鳴っているカードの頭から新しいテンポで鳴らし直す。ホイールは止まった時に。
- **MIDI の値に戻す：** 人が変えた時だけ、欄の右に小さな `↺ MIDI` を出す（`title`「MIDI の値（120）に戻す」）。押すと MIDI の値に戻す（履歴に入る。P10.1 の「MIDI の値に戻したら `tempo` は消える」のまま）。
- 範囲 40〜240 の決まり、保存・再生線・位置への効き方は P10.1 のまま。

## 8. 小節の行を押す

- 小節の行は、**どこを押しても**その位置の小節を指す（番号だけでなく、行の全体。倍率で番号が間引かれていても、押した位置の小節）。
- 押すと、**その小節の1拍目で鳴っているカード**を選ぶ（前の小節から続いているカードなら、そのカード）。1拍目が休み（カードが無い）なら、その小節の中で最初に始まるカード。無ければ何もしない。
- 表示は動かさない（選んだカードが見えている範囲の外なら、今のカードを選んだ時と同じく見える所へ）。
- 再生中に押した時は、選ぶだけで再生は飛ばない（今のカードを押した時の決まりと同じ）。
- 押して鳴らすが ON でも、小節の行を押した時は鳴らさない。
- マウスを乗せると小節の幅で薄く光り、カーソルは指。`title`「n小節の頭のカードを選ぶ」。
- 小節の行は `Shift`＋クリックで範囲を選べる（選んだカードから押した小節まで。今のカードの `Shift`＋クリックと同じ）。

## 9. 右クリックで保存する範囲

Voicing Loop の区間ループ（P11-01。`ProgressionVoicingPracticeView.tsx` の `markRangeCard`・`data-range`）と**同じ操作**にし、見た目もそれに合わせる。下の見た目（黄色の点線・見込みの枠）が Voicing Loop にまだ無い所は、この文書とモックのとおりに作る（Voicing Loop は変えない）。

- カードを右クリック → 「ここから」の印（黄色の点線の枠と「ここから」の札）。
- マウスを動かすと、「ここから」のカードからマウスを乗せたカードまでの**見込みの枠**（黄色の点線。文字「18〜21小節・4コード（右クリックで決める）」）。後ろから前に戻っても同じ。
- 別のカードを右クリック → その範囲を保存する範囲にする（小節の単位：前のカードが始まる小節〜後のカードが終わる小節）。同じカードをもう一度右クリック → そのカードの小節だけ。
- `Shift`＋右クリック：そのカードの小節だけを、すぐ範囲にする。
- キーボード：フォーカスのあるカードで `Shift+F10`・メニューキー（Voicing Loop と同じ）。
- `Esc`：「ここから」だけを消す。`Esc` の順番は「一覧を閉じる → 音の選択 → **ここから** → 保存する範囲 → カードの選択」。
- **ピアノロールの右クリックは今のまま（音を外す）。** 範囲になるのはカードの上の右クリックだけ。
- 区切りの帯・おすすめの範囲・`Shift`＋クリックは今のまま使える。
- 範囲を決めた時の読み上げ：「保存する範囲を 18〜21小節（4コード）にしました」（今の `aria-live`）。
- キーの案内を直す：「右クリック→右クリック：保存する範囲」。

## 10. 画面全体の並び（モックの「案」）

### 10.1 高さを使い切る

- 取り込むの画面は、ウィンドウの高さに合わせる。ヘッダー・ファイル帯の下を、左の作業場と右の欄で分ける（今のまま）。
- **左の作業場：** ピアノロールを残りの高さいっぱいに伸ばす（最低 200px）。凡例はピアノロールのすぐ下に1行。今の「凡例の下の大きな空き」をなくす。
- **右の欄：** 欄の中でスクロールする（ページ全体を長くしない）。下に「保存する範囲」を貼り付ける（10.3）。
- 768×640 などの狭い画面は、今の決まり（右の欄を開け閉めする）のまま。高さが足りない時はピアノロールの最低の高さを守り、ページがスクロールしてよい。

### 10.2 ファイル帯

- 「52小節・106BPM」は操作バー（位置の「／ 52小節」と BPM の欄）と重なるので、ファイル帯から外す。ファイル帯は、ファイル名・拍子・解析の設定の名前・要確認の数・直した回数・パートの設定・別の MIDI。
- P10.1 12.5 の「100BPM（MIDI 120）」の表示は、BPM の欄の `↺ MIDI` の `title` に移す。

### 10.3 右の欄

上から次の順。

1. **選んだカード**：名前（大きく）・「19小節1拍から・4拍」・名前の出どころの札。読めない時の文・手で打った名前の提案（P10.1）。
2. **要確認の理由**（ある時だけ。今の黄色の枠と、その中のボタン）。**問題が無い時の緑の「このカードに要確認の印はありません。」は出さない。**「このままでよい」にしたカードは、名前の下に小さく「このままでよい にしたカード」。
3. **名前の候補**（`1`〜`4`）。
4. **聴き比べ**：`▶ A 元の音`・`▶ B カードの音` の2つのボタンを1行に。説明（「区間に鳴っている音すべて」「保存すると鳴る音」）は `title` へ。
5. **鳴らす音**（今のまま。`＋ 音を足す` は見出しの右）。
6. **構成音との違い（参考）**（今のまま残す。名前の構成音・今の音・追加候補の `＋Bb` などのボタン）。説明の文（「名前の構成音にあって、今の音に無い音です。…」）は短くし、全文は `title` へ。違いが無い時は今のとおり出さない。
7. **カードの操作**：前とつなぐ・次とつなぐ・分ける・名前を入力・元に戻す（P10.0-07 で人間が頼んだ「元に戻す」は残す）。
8. **（下に貼り付け）保存する範囲**：
   - 範囲がある時：「保存する範囲 25〜28小節・4枚」と `範囲を外す`、コード名の1行、`Vaultに保存` と `▾`（詳しい設定）、右に「▸ おすすめの範囲（n）」。
   - 範囲が無い時：押せない `範囲を外す` と `Vaultに保存`、「まだ選んでいません。カードを右クリック→右クリック、区切りの帯、おすすめの範囲で選べます。」
   - 「保存すると、外した音は戻せなくなります」は `Vaultに保存` の `title` と、保存の確認（今の流れ）に残す。
   - 「おすすめの範囲」を開くと、貼り付けた欄の上に一覧が開く（開け閉めを覚えるのは P10.1 のまま）。
   - 保存できない理由（2音未満など）は、この欄の中に出す（今の文のまま）。
- **P10.1 8章の「右の欄の一番上に保存する範囲」を、この「下に貼り付け」に置き換える。** 常に出す・範囲が無い時は押せない、の決まりはそのまま。
- **消すのは、緑の「要確認の印はありません」だけ。** ほかの中身（名前の候補・構成音との違い・鳴らす音など）は場所を移すだけで消さない。
- 画面の下のキーの案内（`←` `→` 前後のカード など）は今のまま残す（P10.2 で変えたキーに合わせて文だけ直す）。
- カードを選んでいない時の欄：「カードを押すと、ここに音と名前が出ます。小節の番号を押すと、その小節の頭のカードを選べます。」

### 10.4 カードの名前を切らない

- **原因（読んだ所）：** `cardLabel`（`workspaceGeometry.ts`）は、名前が幅に入らない時に根の音だけにする。16小節の倍率で「Bmaj9」が「B」になり、右の欄の「Bmaj9」と食い違って、別のコード（B の三和音）に見える。
- **直し方：**
  1. まず字を小さくして全部出す（`16px` → 入らなければ `13px`）。
  2. それでも入らない時は、根の音に「…」を付ける（「B…」）。根の音だけの表示はしない。
  3. もっと狭い（今の `tiny`・`bare`）時は今のまま。
  4. カードの `title` に全部の名前（今の `data-full-name`）。
- 単体テスト：`cardLabel` の幅ごとの結果（全部・小さい字・「B…」）。

## 11. 区切りの端をドラッグする

- **今（読んだ所）：** 区切り（`present.segments`）は解析の後に1回作るだけで、押すと保存する範囲になる。端を動かす操作は無い。
- 区切りの帯の**左端・右端にマウスを乗せると取っ手**（カーソル `ew-resize`、端の 6px）。ドラッグで端を動かす。
  - **小節の線に吸い付く**（区切りは小節の単位）。動かしている間、カードの境目と同じ形の小さな札「23小節から」。
  - **隣の区切りと接している端は、2つの区切りの境目として一緒に動く**（片方が縮み、片方が伸びる。カードの境目と同じ考え方）。
  - 曲の最初（1小節）と最後の端は動かせない。区切りは1小節より短くできない（それ以上は止まる）。区切りを消す・足す操作はこの段階では作らない。
  - 押して動かさずに離した時（4px 未満）は、今までどおり保存する範囲にする。
- 動かした後：
  - 区切りの名前（区切り7 など）はそのまま。「n回出てくる」（`repeatCount`）は区切りの中のコードで数え直す。
  - 曲全体の帯の区切りも同じに変わる。
  - **保存する範囲がその区切りと同じだった時は、範囲も一緒に変える。** 違う範囲の時は変えない。
- 履歴：区切りの変更は履歴に入る（「区切り7 の始まりを 25 → 23小節」）。元に戻す・やり直すで戻る。
  - 区切りは Vault に保存されない（保存するのは範囲の中のコード）ので、**「保存していない変更」・閉じる時の確認・ファイル帯の「直した回数」には数えない。** 計測には種類 `segment` として数だけ残す。
- キーボード：区切りにフォーカスして `Alt`＋`←`／`→` で右端を1小節ずつ、`Alt`＋`Shift`＋`←`／`→` で左端を1小節ずつ。
- テスト：単体（境目を一緒に動かす、1小節より短くならない、曲の端は動かない、範囲が同じ時だけ範囲も変わる、元に戻す、未保存に数えない）、E2E（端をドラッグして区切りと曲全体の帯が変わる、押すだけなら範囲になる）。

## 12. 最初からやり直す

- **今は無い**（作業場には、全部を取り込んだ直後に戻す操作が無い）。
- `⚙` のメニューの一番下に、仕切りの後で「最初からやり直す…」（危険の色の文字）。直した所が何も無い時（取り込んだ直後と同じ時）は押せない。
- 押すと、アプリの中の確認ダイアログ（P10.0-07 で作った `ConfirmDialog` の形）：
  - 見出し「最初からやり直しますか？」
  - 本文「この曲で直した内容をすべて消して、MIDI を取り込んだ直後の状態に戻します。Vault に保存した進行は消えません。」
  - ボタン「最初からやり直す」（危険の色）と「戻る」（既定のフォーカス）。
- やり直すと戻るもの：音・カード（境目・つなぐ・分ける）・名前・「このままでよい」・区切り・テンポ（MIDI の値）・保存する範囲・カードの選択・音の選択・モード（確かめる）。**履歴も空にする**（元に戻すで、やり直す前には戻れない。だから確認を出す）。表示は曲の先頭へ。再生中なら止める。
- 戻さないもの：Vault に保存した進行、「保存済み」の印（Vault に入っているため）、端末の設定（押して鳴らす・凡例・おすすめの開け閉め・倍率・追従）、解析の設定・パートの設定。解析はやり直さない（取り込んだ時の結果を使う）。
- やり直した後は「保存していない変更」が 0 になり、閉じる時の確認も出ない。計測には「やり直した」の印を残す（数だけ）。
- テスト：単体（取り込んだ直後と同じ作業データになる、履歴が空、保存済みの印は残る）、E2E（音を外す・テンポを変える・範囲を選ぶ → 最初からやり直す → 確認で「戻る」なら何も変わらない、「最初からやり直す」で元に戻り、閉じる時の確認が出ない）。

## 14. 受け入れ条件

1. 操作バーが 1280 以上の幅で1行に収まり、要確認 0 の時は移動のボタンが無い。「操作 n」の文字が無い。
2. 曲の再生で、直した音（カードを押した時の B と同じ音）が鳴る。
3. ヘッダーのメトロノームが ON の時、曲の再生でクリックが鳴る。小節の頭が曲の小節と合う。作業場にメトロノームの切り替えは無い。
4. 選んでいない時、見えている一番左のカードから鳴る。そのカードに「▶ ここから」。
5. `⏮` と `Home` で先頭へ。再生中なら先頭から鳴らし直す。
6. 鳴っているカードが Voicing Loop と同じ見た目で、選んでいるカードと見分けられる。その音がピアノロールで明るい。
7. BPM を上下ドラッグ・ホイールで変えられ、履歴は1回だけ入る。`↺ MIDI` で戻せる。
8. 小節の行を押すと、その小節の頭で鳴っているカードが選ばれる。
9. カードの右クリック→右クリックで保存する範囲になり、見込みの枠が出る。ピアノロールの右クリックは音を外すまま。
10. 1小節ちょうどのカードに「4拍」が出ない。押して鳴らす・凡例は `⚙` の中。
11. ピアノロールが残りの高さを使い、凡例の下に大きな空きが無い。右の欄は欄の中でスクロールし、保存する範囲が欄の下に常に見える。緑の「要確認の印はありません」が無い。
12. ファイル帯に小節数と BPM が無い（操作バーにある）。
13. 16小節の倍率でも「Bmaj9」が「B」にならない。
14. 区切りの左端・右端をドラッグで動かせる。隣の区切りとの境目は一緒に動く。元に戻せる。保存していない変更には数えない。
15. `⚙` の「最初からやり直す…」で、確認の後に取り込んだ直後の状態に戻る。Vault に保存した進行と「保存済み」の印は残る。
16. 解析・transport・再生の選び方・Vault の保存形式・保存の中身は変わらない。fresh FULL と EXE が通る。
