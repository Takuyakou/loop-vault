# Reports

段階の報告を置く。報告は日本語で書く。名前：`P10.2-01-fixes.md`。

各報告に書くこと：

1. 計画（段階の最初に書く。承認は待たない）
2. 変えたファイルと commit の一覧
3. 要望の表（1〜9）：直した所・原因（読んだ所）・テストを1行ずつ
4. 書き換えたテスト・基準画像と、その理由
5. ゲートの結果（Test DX の要約行をそのまま貼る）と commit hash
6. スクリーンショットの場所（パスを文字で書く。`/` 区切り）
7. 判断ポイント：選んだこと／理由／別案を1〜2行ずつ
8. 人間に決めてほしいこと（ある場合）
9. 人間が EXE で確かめること
10. レビューで見てほしい所（3〜5点）

生の録音・私的な MIDI・端末の ID・個人の絶対パス・`.local-evaluation` の中身は報告に書かない。
