## 区切り1：再生（仕様 2〜6章）

1. **曲の再生で作業場の音を鳴らす**（2章）：作業場のカードから音の並びを作り、今ある再生の要求で鳴らす。途中からの再生（P10.1 の `timelineFrom`）もこの並びの切り出しにする。テンポの変更・再生線・位置は今のまま合うこと。
2. **メトロノーム**（6章）：`useMetronome` を読み、ヘッダーの全体の設定が ON ならクリックを足す（曲の小節で数える）。**作業場に切り替えは置かない。** 再生中にヘッダーで切り替えたら、今のカードの頭から鳴らし直す。
3. **始まる所**（3章）：選んでいない時は見えている一番左のカード。「▶ ここから」の印、位置の表示のスクロールへの追従。
4. **先頭へ**（4章）：`⏮` と `Home`。
5. **鳴っているカード**（5章）：`data-playing` の付け替え（カードが変わった時だけ）、選んでいるカードの見た目を枠だけに、ピアノロールの音を明るく。
6. テスト：
   - 単体：曲の再生の音の並び（各カードの音 = `cardAuditionNotes`、直した後も、途中から）、クリックの並び（曲の小節で数える、途中から、拍子 3/4・4/4）、一番左のカードの決め方（頭が見えている最初、頭が無い時）。
   - E2E：音を外してから曲を再生した時の音（再生の要求の中身を確かめる）、メトロノーム ON でクリックが入る・OFF で入らない、選ばずに再生した時の位置と「▶ ここから」、`⏮`・`Home`、再生中の鳴っているカードの印と、選んでいるカードとの違い。
   - まとめ B の再生の一致（`saveCandidate.test.ts`）は、曲の再生にも同じ確かめを足す。

commit 例：`feat(correction): play the corrected notes`、`fix(correction): metronome in song playback`、`feat(correction): start from the left card, go to start`、`feat(correction): playing card`。

## 区切り2：選ぶ・範囲・区切り（仕様 8・9・11章）

1. **小節の行**（8章）：行の全体を押せる。1拍目で鳴っているカードを選ぶ。`Shift`＋クリックで範囲。
2. **右クリックで範囲**（9章）：「ここから」・見込みの枠・2回目で決める・`Shift`＋右クリック・`Shift+F10`／メニューキー・`Esc` の順番。ピアノロールの右クリックは今のまま。Voicing Loop の `markRangeCard` の決まりを読み、同じ動きにする（Voicing Loop のコードは変えない。共通にできる純粋な部分があれば、作業場側に同じ形で作る）。
3. **区切りの端のドラッグ**（11章）：取っ手、小節に吸い付く、隣と接する端は一緒に動く、1小節より短くしない、範囲が同じ時は範囲も変える、履歴（未保存・直した回数には数えない）、`Alt`＋矢印。
4. テスト：
   - 単体：小節から選ぶカード（続いているカード・休みの小節・カードの無い小節）、右クリックの範囲（前後・同じカード・逆向き・小節の単位）、区切りの端（11章のテスト）。
   - E2E：小節の行を押して選ぶ、右クリック→見込みの枠→右クリックで保存の欄に範囲が入る、`Esc` で「ここから」だけ消える、ピアノロールの右クリックが音を外すまま、区切りの端をドラッグして区切りと曲全体の帯が変わる・押すだけなら範囲になる。

commit 例：`feat(correction): click a bar to select`、`feat(correction): right-click save range`、`feat(correction): drag section edges`。

## 区切り3：画面全体の並び・操作バー・BPM（仕様 1・7・10章）

1. **操作バー**（1章）：切り替えの形（表示・モード）、要確認 0 の時は出さない、`↶`・`↷`、「操作 n」を消す、`⚙` のメニュー（押して鳴らす・凡例を出す）。1280 以上で1行。
2. **カード**（1.1・10.4）：1小節ちょうどの「4拍」を出さない、コードの行を詰める、名前を切らない（小さい字 → 「B…」）。
3. **画面全体**（10章）：ピアノロールで残りの高さを使い切る、右の欄は欄の中でスクロール、右の欄の並び替え（緑の「要確認の印はありません」を消す、A・B を1行のボタン）、保存する範囲を欄の下に貼り付け、ファイル帯から小節数と BPM を外す。
5. **最初からやり直す**（12章）：`⚙` のメニュー、確認ダイアログ、取り込んだ直後の作業データに戻して履歴を空に、保存済みの印・端末の設定は残す。
6. **BPM**（7章）：上下ドラッグ・ホイール・ダブルクリック、離した時に1回だけ履歴、再生中は離した時に鳴らし直す、`↺ MIDI`。
7. キーの案内・ショートカット一覧（`Home`、右クリック→右クリック、区切りの `Alt`＋矢印）。
8. テスト：
   - E2E：1280 で操作バーが1行（要確認 0 の曲）、要確認がある曲で「◀ 要確認 n / m ▶」、`⚙` の中の切り替えと覚え方、BPM のドラッグで値が変わり履歴が1回、`↺ MIDI` で戻る、「4拍」が出ない。
   - 「操作 n」の `data-testid`（`correction-history`）を使っていた E2E は、`↶` の `title`／`aria-label` を見るように書き直す（理由を報告に）。
   - 単体：`cardLabel` の幅ごとの結果（全部・小さい字・「B…」）、最初からやり直す（12章のテスト）。
   - E2E：最初からやり直す（確認で戻る／やり直す、閉じる時の確認が出ない）。
   - E2E：1440×900 で、ピアノロールの下に大きな空きが無い（ピアノロールの下の端と作業場の下の端が近い）、右の欄をスクロールしても保存する範囲が見える、緑の文が無い、ファイル帯に BPM が無い。
   - 保存する範囲の欄の場所を前提にした P10.1 の E2E は、下に貼り付けた形に合わせて書き直す（理由を報告に）。
   - 基準画像：`capture-analysis-results` を作り直す（差分を見てから）。

commit 例：`feat(correction): tidy control bar`、`feat(correction): full-height layout and inspector order`、`fix(correction): never cut chord names to the root`、`feat(correction): drag to change tempo`。

### 人間が EXE で確かめること（報告に載せる）

1. 操作バーが1行で、要確認 0 の時は移動のボタンが無い。押して鳴らす・凡例は `⚙` の中。作業場にメトロノームのボタンが無い。
2. ピアノロールが画面の下まで伸び、右の欄の下に保存する範囲がいつも見える。16小節の倍率でもカードの名前が「B」のように切れない。
3. 音を外してから ▶ 再生すると、外した音が鳴らない。
4. ヘッダーのメトロノームを ON にして再生すると、クリックが鳴る。途中から鳴らしても小節の頭が合っている。
5. 何も選ばずに少しスクロールしてから ▶ すると、見えている一番左のカード（「▶ ここから」の印）から鳴る。止めてもう一度 ▶ で、止めた少し手前から続く。
6. `⏮`（または `Home`）で先頭に戻る。再生中なら先頭から鳴る。
7. 再生中、鳴っているカードが Voicing Loop と同じ色で光り、選んでいるカードと見分けられる。
8. BPM の欄を上下にドラッグすると変わり、元に戻すは1回で戻る。`↺ MIDI` で元のテンポ。
9. 小節の番号（または小節の行のどこか）を押すと、その小節の頭のカードが選ばれる。
10. カードを右クリック→別のカードを右クリックで、保存する範囲が入る。途中で黄色の点線の見込みが出る。ピアノロールの右クリックは音を外すまま。
11. 区切りの左端・右端をドラッグすると、小節単位で区切りが変わる。隣の区切りとの境目は一緒に動く。`Ctrl+Z` で戻る。
12. いくつか直してから `⚙` →「最初からやり直す…」→ 確認で「最初からやり直す」を押すと、取り込んだ直後の状態に戻る。Vault に保存した進行は残っている。
