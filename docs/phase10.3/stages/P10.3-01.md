## 区切り1：知らせ・歯車・範囲の札（仕様 1〜3章）

1. 範囲を決めた・外した時の文を読み上げだけにする。ほかの知らせは 5 秒で消す（マウスを乗せている間は消さない、`role="alert"` は消さない）。
2. `GearIcon` を足し、作業場のメニューのボタンを歯車に。名前「この画面の設定」。`SettingsIcon` とサイドバーは変えない。
3. 操作バーに範囲の札（`correction-range-chip`、×で外す、文字を押すと範囲の頭へ表示を動かす、狭い時は縮める）。右の欄の下の「範囲を外す」を無くす。
4. テスト：
   - 単体：知らせが 5 秒で消える（時計を進める）、範囲の札の文字（1小節・複数小節、狭い時）。
   - E2E：範囲を決めても操作バーに文が出ない、札の × で外せて札が消える、右の欄に「範囲を外す」が無い、`Esc` でも外れる、歯車のボタンでメニューが開く、サイドバーの「設定」のアイコンが変わっていない。
   - 「範囲を外す」のボタンや知らせの文を前提にしていた P10.1・P10.2 の E2E は、札の形に書き直す（理由を報告に）。

commit 例：`fix(correction): range notices for screen readers only`、`feat(correction): gear icon for the workspace menu`、`feat(correction): range chip in the control bar`。

## 区切り2：区切りの名前・仮の区切り・長い進行（仕様 4〜6章）

1. 区切りごとに保存した進行の `memo` に「区切り3（9〜12小節）」を足す（注意のコードは残す）。`describeBlockMemo` を、注意のコードと区切りの名前が混ざっても読める形に。Vault・進行ページ・Voicing Loop で `memo` が見えるかを確かめて報告に。
2. 仮の区切り（`fallback-8bar`）の端を動かしたら名前を付け直す。解析の区切りの名前は変えない。
3. 長い進行の進行ページで、カードの注意の文字を1行（省略と `title`）に。狭い時は印だけ。対象のコンポーネントを報告に。
4. テスト：
   - 単体：`memo` の組み立て（注意のコードあり・なし）、`describeBlockMemo`（注意のコードだけ・区切りの名前だけ・混ざった時）、仮の区切りの名前の付け直しと元に戻す。
   - データ保持：区切りごとに保存した進行の `memo` の往復。
   - E2E：区切りごとに保存した進行の詳細ページで区切りの名前と注意の文が読める、長い合成の進行（60小節以上）でカードの注意の文字が1行。

commit 例：`feat(correction): keep the section name in the saved memo`、`fix(correction): rename provisional sections after a drag`、`fix(progression): one-line review labels on long progressions`。
