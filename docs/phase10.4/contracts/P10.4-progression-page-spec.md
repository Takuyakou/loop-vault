## 0. 何をするか（一言で）

**進行ページ（進行の詳細。アイデアの詳細も含む）を、取り込むの修正作業場と同じ部品で作り直す。中に入れるのは MIDI ではなく、保存した進行。**

人間がこのページでいちばんやることは、**聴いて、変えたいと思ったコードを替える・消す・足す**こと。「違う」を直すより「この音を変えたい」に近い。保存は「上書き保存」と「別の版として保存」の両方を用意する。

### やってはいけない作り方

- 修正作業場の部品（操作バー・カードの帯・ピアノロール・右の欄・保存の欄・範囲・知らせ）を**コピーして別物を作る**。部品は共有し、違いは props や小さな差し替えで出す。
- 今の進行ページ（`ProgressionDetailView.tsx`）にピアノロールを継ぎ足す。今の画面は置き換える。
- 新しいデータの形を作る、Vault の保存形式（`fileVersion: 2`）を変える。

## 2. 中に入れるもの：保存した進行 ⇄ 作業場のモデル

### 2.1 変換

- 進行（`ProgressionBlock`）を、作業場のモデル（`CorrectionModel` か、その部品が受け取る形）に変える**変換を1つ**作る。逆向き（モデル → 進行）も作る。
  - カード ＝ 進行のコード（名前・始まり・長さ）。名前の出どころは「人が決めた名前」として扱い、音から勝手に付け直さない（`NameSource` の自動の付け直しを止める）。
  - ピアノロールの音 ＝ **そのコードで今の進行ページの再生が鳴らす音**。今の再生の選び方（`resolveVoicing` など）の結果をそのまま使う。選び方は変えない。
  - ベースは今の再生と同じ決め方で、ロールでは作業場のベースの色。
- **変更が無ければ、進行 → モデル → 進行で中身が1つも変わらない**（往復テスト。ID・名前・長さ・音・`voicingMemory`・`memo`・タグ・BPM・キー・ほかの欄すべて）。

### 2.2 手で変えた音をどこに保存するか（手順0で調べて決める）

今の `ChordVoicingMemory`（`sourceVoicing`・`practiceVoicingOverride` など）と `VoicingSource` を読んで、次を全部満たす置き場を決め、報告の判断ポイントに書く：

1. 保存した後、進行ページ・Voicing Loop・Chord Dojo・Bass Practice の再生で、**手で変えた音が鳴る**。
2. 取り込んだ時の元の音（元 MIDI の音）は**消さない**。
3. Vault の保存形式は変えない。今ある `VoicingSource` の値で「手で決めた音（カスタム）」を表せない時は、**値を足さずに止めて報告する**（足すかどうかは人間が決める）。
4. P11-05（名前を変えても保存した音を残す）の決まりと食い違わない。食い違う所は報告に書く。

### 2.3 コードを替えた時の音（「音も合わせる」）

- 右の欄の「コードを替える」に「音も合わせる」の切り替えを置く（既定：ON）。
- **ON：** 名前を替えると、そのコードの音を**今ある自動の音の作り方**（自動生成のボイシング。前のコードに近い高さ）で作り直し、それを手で変えた音として 2.2 の置き場に入れる。作り方のコード（`src/domain/voicing/**`）は**呼ぶだけで変えない**。
- **OFF：** 名前だけ替え、音はそのまま（今の P11-05 と同じ）。
- 切り替えの状態は画面の設定として覚える（Vault には入れない）。

## 3. ピアノロール（音を変える）

作業場の `PianoRoll` をそのまま使う。

| 動き | 確かめる | 音を直す（`N` で切り替え） |
| --- | --- | --- |
| 音を押す | その音だけ鳴る・そのカードを選ぶ | その音を**外す**（外した音は破線で残り、保存すると消える） |
| 外した音（破線）を押す | 鳴る | 戻す |
| 音を上下にドラッグ | — | 半音ずつ高さを変える（横には動かない） |
| 空いた所を押す | その高さが鳴る・そのカードを選ぶ | そのカードにその高さの音を**足す** |
| 囲んで選ぶ | 作業場と同じ | 作業場と同じ |

- 色：鳴る和音の音・ベースは作業場と同じ。**保存してから変えた・足した音は紫**、外した音は破線（凡例に書く）。
- 1つのカードの最後の2音は外せない（「最後の2音は外せません（無音にするなら『消す ▾』）」）。
- メロディの線・要確認の色・使っていない音の決まりは、このページでは使わない（作業場の「使っていない音（破線）」の見た目を「外した音」に使う）。

## 4. カード（替える・消す・足す・長さ）

### 4.1 選ぶ・聴く

- カードを押すと選んで鳴らす（作業場の「押して鳴らす」の設定に従う）。`←` `→` で前後へ、`Home` で先頭。
- ▶ は選んだカードから再生、何も選んでいなければ先頭から。追従・BPM・位置の出し方は作業場と同じ。
- 範囲がある時、▶ は**範囲をくり返し再生**する（4.6）。

### 4.2 替える

- 右の欄の「コードを替える」：候補を最大5つ。先頭4つに `1`〜`4` の番号（キーでも押せる）。候補の出どころは**今の進行ページのコードの候補**（`ChordAlternativeList` が使っているもの）。新しく候補の作り方を作らない。
- 「名前を入力」`F2`・カードのダブルクリック：今ある名前の入力（`QuickChordEditor` など）を開く。
- 構成音との違い：作業場と同じ（名前の構成音にあって今の音に無い音を点線の「＋C#」で出し、押すと足す）。

### 4.3 消す

「消す `Del` ▾」の中に4通り（今の `deleteEditableChordWithMode` を使う）：

| 名前 | 動き |
| --- | --- |
| 消して前を伸ばす（`Del`） | 前のカードがその長さを引き継ぐ。先頭のカードなら次を伸ばす |
| 消して次を伸ばす | 次のカードが引き継ぐ。最後のカードなら前を伸ばす |
| 消して詰める | 後ろを前へ詰める（進行全体が短くなる） |
| 無音（N.C.）にする | 長さを残して無音にする |

最後の1枚は「無音にする」だけ。

### 4.4 足す・分ける・つなぐ

- カードの間にマウスを乗せると「＋」が出る（キーボードでも届く）。押すと**左のカードを半分に分けて、右半分を新しいカードにする**（名前と音は左と同じ。すぐ右の欄で替えられる）。2拍より短いカードは分けない（知らせ）。
- 「分けて足す」`S`：選んだカードを半分に分ける（「＋」と同じ動き）。
- 「前とつなぐ」・「次とつなぐ」`M`：今の `mergeEditableChords`（作業場の `cardEdits` と同じ決まり）。
- 今の `splitEditableChord`・`mergeEditableChords`・`insertSuggestedEditableChordAfter` と作業場の `cardEdits.ts` の、どちらを使うかは手順0で決める。**3つ目の実装は作らない。**

### 4.5 長さ

- カードの境目のつまみを左右にドラッグして、両隣の長さを1拍単位で変える（1拍より短くしない。全体の長さは変わらない）。
- 1回のドラッグ＝履歴1つ。

### 4.6 範囲（右クリック）

- 作業場と同じ：1回目の右クリックで「ここから」、2回目でそこまでの範囲が決まる。両端（A・B）をドラッグで調整。`Esc` か札の × で外す。**見た目は作業場の実装と同じ**にする。
- 操作バーの札：`範囲 27〜29小節・3コード・くり返し ×`（狭い時は「27〜29小節 ×」）。
- 範囲の使い道：(1) ▶ で範囲をくり返し再生、(2) 範囲だけ別の版として保存（5.3）。
- 名前の素早い変更は、右クリックから `F2` とダブルクリックへ移す。

### 4.7 元に戻す・カードの印

- ↶ ↷（`Ctrl+Z`・`Ctrl+Y`）：このページを開いてからの操作すべて（作業場の履歴と同じ作り）。
- 「このカードを元に戻す」：選んだカードだけ保存してある状態へ戻す（履歴に1つ積む）。
- カードの右下の小さな印：保存してから変えたカードは「変更」、足したカードは「追加」。

### 4.8 キー

| キー | 動き |
| --- | --- |
| `Space` | 再生・停止 |
| `←` `→` / `Home` | 前後のカード / 先頭 |
| `1`〜`4` | 候補で替える |
| `F2` | 名前を入力 |
| `Del` | 消して前を伸ばす |
| `S` / `M` | 分けて足す / 次とつなぐ |
| `N` | 確かめる ⇄ 音を直す |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Esc` | メニューを閉じる → 範囲を外す |

入力欄（メモ・名前）にいる時はキーを奪わない。

## 5. 保存

右の欄の下（作業場の保存の欄の場所と部品）。

**ページを開いた時（範囲なし）の保存は進行の全部。** 上書き保存は、範囲があってもいつも進行の全部を保存する（範囲の外を消すことはない）。範囲を選んでいる時の「別の版として保存」は、作業場と同じく範囲を保存する方を先に選んでおく（5.3）。

```
保存　変更 3（まだ保存していない）
C#m9  C#m9  G#m7
[上書き保存]  [別の版として保存]            [▾]
```

- 変更が無い時：「変更はありません」、上書き保存は押せない（別の版として保存は押せる＝複製）。
- 変更の数：変えた・足したカードの数＋消したカードの数。2行目に変えたカードの名前。
- `▾`：「範囲だけ別の版として保存…」（範囲がある時だけ押せる）、区切り線、「変更を捨てる」（赤）。

### 5.1 上書き保存

- この進行（同じ ID）を今の内容にする。**変えていない欄（タグ・BPM 以外の情報・作った日・アイデアとのつながり・`memo` の中の名前と注意のコード・元 MIDI の音など）は1つも落とさない。**
- 保存したら、変更の印・紫・破線が消え、履歴を空にする。知らせ「上書き保存しました」（5秒で消える）。

### 5.2 別の版として保存

- 小さな画面：「別の版として保存」「同じ曲の中にコピーを作ります。元の進行（…）はそのまま残ります。」、名前の入力（初めの値「区切り7（別の版 1）」）、戻る・保存。
- 同じアイデア（曲）の中に新しい進行を作る。元の進行は変えない。保存したら新しい進行を開いた状態になる。
- 名前の置き場：P10.3 で決めた `memo` の名前の部分（P10.3 4章）。形式は変えない。
- タグ・BPM・キーは元からコピーする。

### 5.3 範囲だけ別の版として保存

- 範囲がある時、5.2 の小さな画面に「この進行の全部（25〜32小節）」と「選んだ範囲だけ（27〜29小節）」の2択が出る。**範囲がある時は、開いた時点で「選んだ範囲だけ」が選ばれている**（「別の版として保存」のボタンからでも `▾` の「範囲だけ別の版として保存…」からでも）。全部にしたい時は「この進行の全部」に切り替える。「範囲だけ」の時の名前の初めの値は「区切り7（27〜29小節）」。
- 範囲だけの版は、範囲のカードだけを持ち、小節は元の曲の小節（27〜）で数える。

### 5.4 捨てる・離れる時

- 「変更を捨てる」：「変更 n を捨てて、保存してある状態に戻しますか」と1回確かめてから戻す（↶ では戻せないので履歴は空にする）。歯車のメニューにも「保存した時に戻す…」（同じ動き）。
- 変更があるまま、別の進行へ移る・ほかの画面へ行く・アプリを閉じる時は、**作業場の「閉じる時の確認」と同じ部品**で「保存する／保存しないで移る／戻る」を聞く。

## 6. 進行ページだけのもの

### 6.1 進行の帯

- 進行の名前：`memo` の名前の部分（P10.3）。無ければ「進行（25〜32小節）」のように小節から作る。
- 「この曲の進行（n）▾」：同じアイデアの進行を順に並べ、今の進行に印。別の版もここに並ぶ（名前の右に「別の版」や小節）。押すとその進行へ（5.4 の確認）。
- 曲名・拍子・キー、タグ（`＋ タグ` で足す）。
- メモ：1行の入力。`memo` の**自由に書く部分だけ**を編集する（名前の部分と注意のコードは触らない）。P10.3 の `memo` の組み立てと `describeBlockMemo` を使い、往復で名前と注意のコードが残るテストを足す。メモの変更も「変更」に数えて、保存で入る。
- 練習：Voicing Loop・Chord Dojo・Bass Practice（今の入口と同じ動き。変更がある時は 5.4 の確認）。
- `⋯`：題名を変える（名前の部分を変える）、複製（＝変更なしの別の版）、以前の項目を見る（ジャンル・ムードなど今の画面にある古い欄を読むだけ）、区切り線、この進行を削除…（確認あり）。

### 6.2 アイデアの詳細（`DetailView`）

- アイデアを開いたら、**そのアイデアの最初の進行の進行ページ**を開く（このページの帯と「この曲の進行 ▾」がアイデアの詳細の役をする）。
- 今の `DetailView` にしか無い操作（アイデアの題名の変更・削除など）は、`⋯` の中に「この曲」として残す。**消さない。** 何をどこへ移したかを報告の表に書く。
- 進行が1つも無いアイデアは、今のアイデアの詳細を出す（この phase では作り直さない）。

### 6.3 曲全体の帯

- 同じアイデアの進行を、曲の中の順（`memo` の小節。無ければアイデアの中の順）に横へ並べ、今の進行を作業場の「今見ている所」と同じ枠で光らせる。押すとその進行へ。進行が1つだけの時も1つ出す。

## 8. 変えないもの

- 解析（`src/domain/midi/`）、コード名の判別、再生の選び方（`resolveVoicing` など）、transport の scheduler、自動の音の作り方（`src/domain/voicing/**`。呼ぶだけ）。
- Vault の保存形式（`fileVersion: 2`）。2.2 で値が足りない時は止めて報告。
- 修正作業場（取り込む）の見た目と動き。部品を共有するために props を足すのはよいが、取り込むの画面の結果は変えない（作業場の E2E・基準画像がそのまま通る）。
- Voicing Loop・Chord Dojo・Bass Practice・テキスト取り込みの画面。サイドバーの「設定」のアイコン。
- 新しい依存パッケージ、ライトモード、英語表示。

## 9. 受け入れ条件

1. 進行を開くと、作業場と同じ部品（操作バー・曲全体の帯・小節・カード・ピアノロール・右の欄・右下の保存）で表示され、ロールにその進行で鳴る音が出る。
2. 変更が無ければ、開いて上書き保存しても進行の中身が1つも変わらない（往復テスト）。
3. コードを候補・`1`〜`4`・名前の入力で替えられ、「音も合わせる」ON なら音も作り直され、OFF なら音はそのまま。
4. ピアノロールの「音を直す」で、音を外す・戻す・高さを変える・足すができ、保存するとほかの画面の再生でもその音が鳴る。元 MIDI の音は消えない。
5. カードを4通りで消せる、「＋」と `S` で足せる、つなげる、境目で長さを変えられる。すべて ↶ ↷ で戻せる。
6. 右クリックで範囲を選べ、▶ がくり返し、札の × と `Esc` で外せる。
7. 上書き保存で同じ進行が更新され、別の版として保存で同じ曲に新しい進行ができて元は変わらない。範囲だけの版も作れる。
8. 変更があるまま離れようとすると確かめる。
9. アイデアを開くと最初の進行の進行ページが開き、アイデアにしか無かった操作は `⋯` に残っている。
10. 取り込むの修正作業場の見た目と動きは変わらない。解析・再生の選び方・Vault の保存形式は変わらない。fresh FULL と EXE が通る。
