# Reports

段階の報告を置く。報告は日本語で書く。名前：`P10.4-01-progression-page.md`。

各報告に書くこと：

1. 計画（段階の最初に書く。承認は待たない）。手順0で調べたこと：今の進行ページとアイデアの詳細の操作の行き先の表、部品の共有のしかた、手で変えた音の置き場、分ける・つなぐ・消すに使った関数、`memo` の読み分け
2. 変えたファイルと commit の一覧
3. 仕様の受け入れ条件（9章の 1〜10）：満たした所・テストを1行ずつ
4. 書き換えたテスト・基準画像と、その理由（取り込むの画面の分は 0 のはず）
5. 消した古い部品の一覧
6. ゲートの結果（Test DX の要約行をそのまま貼る）と commit hash
7. スクリーンショットの場所（パスを文字で書く。`/` 区切り）
8. 判断ポイント：選んだこと／理由／別案を1〜2行ずつ
9. 人間に決めてほしいこと（ある場合）
10. 人間が EXE で確かめること
11. レビューで見てほしい所（3〜5点）

生の録音・私的な MIDI・端末の ID・個人の絶対パス・`.local-evaluation` の中身は報告に書かない。
