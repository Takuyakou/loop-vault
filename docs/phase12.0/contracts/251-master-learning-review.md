# 2-5-1 Master — 学習・復習・Mixedと表示の最新変更

2026-10-06のユーザー明示変更。従来のsource MIDI順を使わない規則は復習/Mixedだけに適用し、新規学習と従来Ready全消去を以下で上書きする。Phase12全体の人間受入れとmerge/push禁止は維持。

## 学習

入口に学習/復習/Mixedを示す。学習はForm A/B/C/Dを全て選択可能、推奨順はA→B→C→D。各Formの進捗n/12と続きから/練習するを表示し、初めてでも他Formをロックしない。

キー順は C → B♭ → A♭ → G♭ → E → D → D♭ → B → A → G → F → E♭、pitch classは `[0,10,8,6,4,2,1,11,9,7,5,3]`。canonical内のF#とユーザー表記G♭は同じpc6で、音や運指を移調/生成し直さない。各Formの最初の未完了キーから進み、途中終了やForm往復で未完了を飛ばさない。

見て弾くでは譜面・正解鍵盤・運指・コード名・お手本を利用できる。そのキーのii→V→Iを見て弾けた後、同じキーを答えなしRecallで確認する。独立Recall成功だけが学習完了。Hint使用、Wrong、途中終了、見て弾く成功は完了にしない。Recall速度の段階条件とは分け、遅くても独立Recallを完了すれば学習済み。passed/master/80BPMの既存判定は維持。

## 復習とMixed

学習済みセルだけを候補にする。復習の範囲は全Form/A/B/C/Dを選べる（既定は全Form）。優先順位は直近3回内の失敗、Recallが遅い、80BPM未達、確認期限、長期間未練習。失敗時刻・Recall秒数・tempo進捗・期限・最終練習日を使い、同順位/同値だけseed shuffleする。新規学習順を使わない。

期限は既存Dojo settings.reviewDaysの最初の日数（初期14日）を再利用する。独立成功でnextReviewAtを更新し、Hint成功は延長しない。既存reviewDueも期限優先の根拠として保持。新しい設定画面や日数を増やさない。

Mixedは学習済みForm/Keyを混ぜて確認する仕上げテスト。弱点優先を維持し、同順位/同値では直前と異なるForm/Keyを優先してshuffleする。候補が1Form/1Keyだけなら実在範囲で出題し、範囲が増えれば混ぜる案内を出す。復習全Formとの差は、切替も含めて確認する目的と同率時の切替優先。資格/採点/Hint/80BPMの保護は維持。

復習/Mixedの基本表示はForm/Keyと必要な番号/入力鍵盤。回答の譜面・運指・コード名・音名・ターゲット鍵盤は隠し、Hint/Wrong/明示試聴だけを回答表示として扱う。候補ゼロは学習入口の案内を出し、未学習を混ぜない。

## 保存互換と移行

既存Master version1、Dojo fileVersion4/Vault v2/native namespaceは保持。Masterに任意のlearnedAt/nextReviewAtとversion1のpracticeメタデータ（kind、選択Form、復習scope、Form別学習段階/位置）を追加する。

旧記録はrecent内のok・usedHint false・bpmなし・recallSecありのRecall成功だけを完了根拠にする。真正な根拠をlearnedAtへ保存し、履歴20件が切り詰められても学習完了を失わない。空履歴/Hint/Tempo成功だけ/statusラベルだけでは完了を推定しない。既存passed/master/qualifiedAt/速度/tempo/日時/成否は保持し、移行で昇格や降格しない。根拠が残っていないセルは独立Recallを再確認する。

Form別位置は学習済み集合と照合し、保存された位置だけで未完了を飛ばさない。学習段階もForm別に保存する。正常な保存を壊さず、private Vault/実MIDI/実音内容は調査に使わない。

## 表示・試聴・離鍵待ち

全144canonicalターゲットの共通表示範囲でMaster譜面の倍率・譜表位置・外枠を固定し、音符/臨時記号/運指を切り落とさない。通常GrandStaffの既定表示は変えない。通常3サイズで128px鍵盤/下端8px/縦配置/初期main scroll0を保持。

進行を聞くの直前の表示コードを保存し、自然終了/手動停止時に戻す。試聴で問題番号や採点を進めない。カードへの置換、Form/練習種別/範囲変更、切断、離脱は世代で古い復元/再生をキャンセルする。Recall試聴のHint扱いと、Tempoの明示同セル弾き直し/新時計/全離鍵は維持する。

正解/不正解後に物理鍵を保持している間は、前の回答表示か答えのない必要情報を保持する。Learn/回答確認の譜面・鍵盤・運指を消さず、次の問題/次の回答は全離鍵まで先出ししない。隠すモードでも入力鍵盤・中立譜表・安定した枠を保持する。短い離鍵待ちは控えめに、長い待ちは説明を添える。physical全離鍵ガードとpedalだけでは待たない契約は維持。
