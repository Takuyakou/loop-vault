- 実行可能な1進行を先に選び、最後の進行の時間・共通確認枠を予約する。独立確認→必要な型→同じ範囲の実在する保存音→同じ進行で終了する。新規2件の上限を撤廃し、確認6件／計画900秒を維持。時間経過による強制終了はしない。

- 元進行・範囲・event・出どころ・notes・target ID/revision・productionの手／指を保存する。開始した課題は日付変更や元データの変更／削除でも固定音で続ける。旧活動中計画は現在の練習単位を保持し、旧予定も保存して次の開始からテーマへ移る。
- 同じTargetSnapshotを大譜表と鍵盤に渡す。判定とお手本は固定した同じMIDIを使う。既存の合否規則を指番号で変更しない。Master canonical144・時計・Ready・保持音・P1時刻修正は変更していない。
- 大譜表は鍵盤の直上に置き、「構成音表示・リズム指定なし」と表示する。加線、異名同音、分数、重複音、交差する手、MIDI0〜127を保持する。譜表と手を分け、productionで指が得られない音を明示する。
- Recall／Tempo／Mixed、Ready／pause／exitでは答案用SVG・音名・運指・鍵盤ガイドを渡さない。テーマ名、進行名、memo、過去の解答は中立表示。明示ヒント／確定フィードバックは現在の対象だけを開き、次対象の最初の描画から消す。Tempo途中の外れで自動開示しない。
- スコア枠と操作欄を予約して表示切替時の鍵盤位置を保つ。狭幅・200%では各表示枠をスクロールできる。開始ボタンは長い課題一覧より上に配置する。新しい依存は追加していない。
