# P12.1-01 — Chord Dojo の画面の直し

## 段階の概要

- 仕様：[contracts/P12.1-dojo-ui-fixes.md](../contracts/P12.1-dojo-ui-fixes.md)。数値と受け入れの正。
- モック：zip の `mocks/chord-dojo-fix-mock.html`。見た目と並び順の正。
- 今の画面：zip の `before/`。
- ブランチ：local `master` から `feat/p12.1-dojo-ui-fixes`。

- **docs を含む commit の前には、毎回 `npm run validate:phase-docs` を通す。** 終了コードをパイプで隠さない。

## 迷った時の決め方

- 仕様とモックが食い違う時は、仕様の数値を正とする。
- 仕様に無い細かい見た目（色の濃さ、1〜2px の余白など）は、今の `chord-dojo.css`・`master251.css` の近い部品に合わせる。
- 上の2つに当てはまらない所は、次のように進める。
  1. 「今の見た目と動きを変えない」を選ぶ。
  2. 報告の「仕様と違うことをした所」に書く。
- 止まるのは、`P10-autonomous-run.md` の 3章の条件に当たった時だけ。
