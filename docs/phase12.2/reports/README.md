# Reports

段階の報告を置く。報告は日本語で書く。名前：`P12.2-01-master-fixes.md`。

書くこと：

1. **計画**（段階の最初に書く。承認は待たない）：始めた時の HEAD。
2. **仕様の 1〜12章**：各章を1行ずつ。
   - 満たしたか
   - 確かめたテスト名
   - 1章・2章で確かめた記録の値（`session.cell`・`attempts`・`successes`・`recallSec` の有無・`status`）
3. **仕様と違うことをした所**（あれば）：違い／理由／別案。
4. **変えたファイルと commit の一覧。**
5. **直した今の E2E の行と理由。**
   - Esc で戻っていた所
   - 一時停止の所
   - 「n/4」を見ていた所
   - その他
6. **書き換えた基準画像と理由**（Master の分だけのはず）。
7. **ゲートの結果**：Test DX の要約行をそのまま貼る。commit hash も書く。
8. **スクリーンショットの場所**：パスを文字で書く（`/` 区切り）。
9. **判断ポイント**：選んだこと／理由／別案を1〜2行ずつ。
10. **人間が EXE で確かめること**
    - 実際の MIDI キーボードで、正解の直後の一時停止
    - 途中の一時停止と、その回の記録
    - 一時停止中に音が鳴ること
    - ヒント → お手本を聴く
    - Esc
11. **レビューで見てほしい所**（3〜5点）。

報告に書かないもの：
- 私的な MIDI・Vault の中身
- 端末の ID
- 個人の絶対パス
- `.local-evaluation` の中身
