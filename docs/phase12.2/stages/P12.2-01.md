- **仕様：** [contracts/P12.2-master-fixes.md](../contracts/P12.2-master-fixes.md)。数値と受け入れの正。
- **モック：** zip の `mocks/master251-fix-mock.html`。見た目と並び順の正。

**docs を含む commit の前には、毎回 `npm run validate:phase-docs` を通す。** 終了コードをパイプで隠さない。

## 迷った時の決め方

1. 仕様とモックが食い違う時は、仕様を正とする。
2. 仕様に無い細かい見た目は、今の `master251.css`・`chord-dojo.css` の近い部品に合わせる。
3. 記録に関わる所で迷った時は、次のように決める。
   - 「記録を増やさない」「速さを数えない」の側を選ぶ。
   - `policy.ts`・`model.ts` は変えない。
   - 報告の「仕様と違うことをした所」に書く。
4. 止まるのは、`P10-autonomous-run.md` の3章の条件に当たった時だけ。

主に触る所：`src/views/chord-dojo/Master251View.tsx`・`master251.css`。`engine.ts`・`policy.ts`・`scheduler.ts`・`model.ts` は変えない。

   - 作り方は `p12-master251.spec.ts` の `setup`・`transition` を使う。
