## 3. ベースは上の音より下にする（不具合の直し）

**直すこと：** `builtins.ts` の `rotations()` で、並べた候補ごとに `placeBassBelow()` を通す。

- `placeBassBelow(notes)`：ベース（`notes[0]`）が上の音の一番低い音**以上**なら、1 オクターブずつ下げて、上の音の一番低い音より**下**にする。上の音は動かさない。
- 正しい形は付録 A の `placeBassBelow` と `rotations`。
- これで、同じ音が2つ入る組も無くなる（ベースと上の音が同じ高さだった組）。
- 変わるのは、今の 8つのうち、ベースが上の音以上だった 41 の組だけ。それ以外の組は1音も変わらない（期待データで確かめる）。

**受け入れ：**

- 単体テスト：25 × 12 キーのすべてのコードで、次を満たす。
  - `notes[0] < min(notes.slice(1))`
  - 同じ音が無い
  - `judgeChord({notes, chord, judge, bass:'self'}, notes).ok === true`（答えのとおりに弾けば合う）
- E2E：「定番のキー」A で ii–V–I を練習する。

## 9. ランダムキー：判定・ヒント・クリア・次のキー（D4）

**状態**（`src/domain/chordDojo/endless.ts`。画面の state に持つ。保存しない）：

```ts
interface EndlessResult { key: number; sec?: number; hint: boolean; self: boolean; skipped: boolean }
interface EndlessState {
  builtinId: string; seed: number;
  round: number;   // 1 から
  pos: number;     // この巡で終わったキーの数（0〜11）
  bag: number[]; key: number;
  chordIndex: number; revealed: number[]; hinted: boolean; manual: boolean;
  phase: 'ready' | 'active' | 'clear' | 'paused' | 'summary';
  startedAt?: number; clearedAt?: number; results: EndlessResult[];
}
```

**状態を変える関数**（すべて純粋な関数。時刻は引数 `now`（ms）で受け取る。`performance.now()` は画面の側で呼ぶ）：

| 関数 | 動き |
| --- | --- |
| `createKeyBag(seed, previous?)` | 0〜11 をまぜた配列。1つ目が `previous` なら1つ目と2つ目を入れ替える |
| `startEndless(builtinId, seed, manual)` | `round 1`・`pos 0`・`bag = createKeyBag(seed+1)`・`key = bag[0]`・`phase 'ready'` |
| `activate(state, now)` | `ready` → `active`。`startedAt = now` |
| `revealChord(state, index)` | `revealed` に足す。MIDI のセッションで、`index >= chordIndex` なら `hinted = true` |
| `matchChord(state, eventAt)` | 今のカードを弾けたにする。`chordIndex + 1`。最後のカードなら `phase 'clear'`・`clearedAt = eventAt`、結果を1つ足す（下） |
| `selfJudge(state, ok)` | 自分で判定の Y・N。Y は `matchChord` と同じ（秒は持たない）。N は何も変えない |
| `skipKey(state)` | 結果 `{key, hint:hinted, self:manual, skipped:true}` を足して `nextKey` |
| `nextKey(state, manual)` | `pos + 1`。12 になったら `round + 1`・`pos 0`・`bag = createKeyBag(seed+round, 前のキー)`。`key = bag[pos]`・`chordIndex 0`・`revealed []`・`hinted false`・`manual` を入れ替え・`phase 'ready'` |
| `pause(state)` | `phase 'paused'` |
| `resumeSameKey(state)` | 同じキーを1つ目のカードから：`chordIndex 0`・`phase 'ready'`。`revealed`・`hinted` は残す |
| `switchToSelf(state)` | `manual = true`・`chordIndex 0`・`phase 'active'` |
| `finish(state)` | `phase 'summary'` |
| `summarize(results)` | 10章の数 |

- **結果の秒（`sec`）：** `(eventAt - startedAt) / 1000` を小数1桁に丸める。
  - `eventAt` は、最後のコードを合わせた Note On・Note Off の時刻（判定を待つ `settleMs` は入れない）。今の練習の `lastOnMs - promptAt` と同じ考え方。
  - `hinted` か `manual` の時は `sec` を入れない。
- **結果の `hint`・`self`：** `hint = hinted`、`self = manual`。

**キーの始まり：**

- `phase: 'ready'` で、全部の鍵盤が離れる（`heldNotes` が空）のを待つ。
  - ペダル（サステイン）は見ない。今の練習の `soundingNotes` とは、わざと違う。
- 離れていたら、すぐ `activate(now)`。
- 自分で判定のセッションは待たずに `activate`。

**判定（MIDI）：** `ChordEntry` は使わない（1回しか判定しないため）。`ChordDojoEndlessView` が自分の待ち時間（タイマー）を持ち、`judgeChord` と `requiredCount` だけを使う。`judging.ts` は変えない。

- 対象：今のカード（`chordIndex`）のコード。
  - `judge` は進行の `judge`（`core`。`imaj9-ivmaj9` だけ `shape`）。
  - `bass` は `self`。
- **押さえ直さなくてよい。** 前のコードから押し続けている音を含めて、**今押している全部の音**（`heldNotes`）で判定する。
  - Note On と Note Off のたびに、`settleMs`（今の設定）待ってから見る。
  - 押している音の数が `requiredCount` 以上なら判定する。少ない時は何も出さない。
  - 例：新しい音を先に押し、前の音を後で離す弾き方でも、離した時に合えば進む。
- **合った時：**
  - そのカードを ✓ にして、名前を出す。
  - `chordIndex + 1` にする。次のカードの判定は、その後の Note On・Note Off から。
- **外れた時：**
  - 結果の1行に `✗ {judgeChord のメッセージ}` を出す。
  - そのまま同じカードで、次の Note On・Note Off を待つ（「もう一度」のボタンは無い。離す必要もない）。
  - モック 5 の「· 離して、もう一度」は誤り。この章が正。

- 中央の一番上に `MidiRequiredNotice`（compact）を出す。
  - 見出しは `MidiRequiredNotice` の今の文字（`off` なら「MIDI キーボードがつながっていません」）。
  - 説明：「答えを見て、自分で「弾けた／まだ」を押す形で進みます（秒数は測りません）。」
- コードごとに：
  - 「答えを見る（Space）」で、今のカードの名前と答えを出す（ヒントにしない）。
  - 「弾けた（Y）」：`selfJudge(true)`。✓ にして、次のカード。
  - 「まだ（N）」：答えを出したまま、結果の1行を「答えを見て、もう一度」にする。
  - 「お手本を聴く（L）」・「このキーをとばす」は MIDI の時と同じ。
- 自分で判定のキーは、結果で `self: true`。秒は持たない。

**外れた時**（P14 仕様 5.1 と同じ）：

- 中央に `MidiRequiredNotice` を出す。
  - 説明：「MIDI が外れました。つなぎ直すと、この課題から続けます。」
  - ボタン：「MIDI 設定」「自分で判定に切り替える」
  - 「自分で判定に切り替える」を押した時だけ `switchToSelf`。その後のキーも自分で判定。
- **つながったら：** 全部の鍵盤が離れた後に `resumeSameKey`（同じキーを1つ目のカードから。`startedAt` は新しく）。
  - `clear` の途中で外れた時は、つながった後に次のキーへ進む（結果はもう足してある）。

**キー操作**（`ChordDojoEndlessView` が持つ）：

| キー | 動き |
| --- | --- |
| Space | 答えを見る |
| L | お手本を聴く |
| Y・N | 自分で判定の時だけ。弾けた・まだ |
| Esc | やめる（まとめ） |
| Enter・Esc（まとめの時） | もう一度・定番の進行に戻る |

- `input`・`select`・`textarea`・`button`・`summary` にフォーカスがある時は、今の Chord Dojo と同じく、キーで動かさない。

**受け入れ：**

- `?p12=no-midi` で開く。答えを見る → 弾けた を 4 回押すと、キーがクリアになる。チップは「自分で」。
- MIDI の時、2つ目のカードの途中で `unplug` する。
  - `paused` になり、5.1 の案内が出る。
  - `plug` で戻り、離すと同じキーの1つ目から始まる（`data-endless-key` が同じ、今のカードが1番目）。
- 自分で判定に自動で変わらない。
- ランダムキーの画面で Enter・Esc を押しても、今日の練習の記録が変わらない。
