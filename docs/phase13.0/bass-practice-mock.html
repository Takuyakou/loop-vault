Bass Practice の案（5つの練習を同じ枠に）

起動時の大きさ（1440×900）。上のタブで練習を切り替えます。どの練習も「課題（設定のチップ）→ 段階 → 中身 → 操作」の同じ並びで、右に「録音」と「記録」。新しい「MIDI のベースライン」では、読み込んだ MIDI のベースを本物のベースで弾き、録った音を弾き終わってから判定します（モックでは判定の結果は作りもの）。音は鳴ります（最初の1回はどこかを押してください）。

同じ枠

課題の帯（練習の名前・説明・設定のチップ・BPM）→ 段階の帯（練習ごとの今の段階のまま）→ 中身（練習ごとの図）→ 操作の帯（鳴らす音・ヒント・自己評価・次へ）。右の欄は「録音」（入力のメーター・録って比べる）と「記録」。弦の数・利き手・フレットの範囲は上の ⚙ にまとめて全部の練習で共通。

中身（練習の流れ）は変えない

Degree・Rhythm・Bassline・Root Motion の段階、問題の作り方、ヒント、自己評価（もう一度／難しい／良い／簡単）、移調、保存の形は今のまま。変えるのは並べ方と見た目だけ。

MIDI のベースライン（新しい）

MIDI を読み込む時にベースのトラックを選ぶ（いちばん低いトラックを先に選んでおく）。ほかのトラックは伴奏として鳴らせる。保存した曲は一覧から選んで練習。★ でお気に入り。Vault とは別の置き場で、Bass Practice だけで使う。

弾き終わってから判定

区間（1・2・4・8小節）を選ぶ →「聴く」→「録って弾く」（カウントの後に伴奏と一緒に）→ 録った音の高さとタイミングを解析して、1音ずつ ✓ ／ 音が違う ／ 早い・遅い ／ 抜け ／ 余分な音。自分の演奏とお手本を聴き比べられる。判定は目安。
