## 0. 一言で

1. **今の4つの練習（Degree Echo・Rhythm Echo・Bassline Echo・Root Motion Echo）を、同じ枠にそろえる。** 中身（練習の流れ・問題の作り方・自己評価・保存の形）は変えない。変えるのは並べ方と見た目。
2. **5つ目の練習「MIDI のベースライン」を足す。**
   - 読み込んだ MIDI のベースを、本物のベースで弾く。
   - 録った音を弾き終わってから解析し、1音ずつ正解・不正解を出す。
   - 読み込んだ曲は Vault とは別の置き場に保存し、Bass Practice だけで使う。一覧から選んで練習でき、★ でお気に入りにできる。

### やってはいけない作り方（間違ったものを作らないために）

| してはいけないこと | 理由・正しい形 |
| --- | --- |
| 4つの練習の段階・問題の作り方・ヒント・自己評価・移調・保存の形を変える | 今回は見た目と並べ方だけ。State Machine（`domain/stateMachine.ts` など）と Generator は触らない |
| 4つの練習に自動の判定を足す | 自動の判定は「MIDI のベースライン」だけ。ほかは今のまま自己評価 |
| 弾いている間にその場で判定する（リアルタイム） | 人間の決定は「弾き終わってから判定」。録音中は判定しない |
| MIDI キーボードの入力で判定する | 入力は本物のベースの音（オーディオインターフェース経由の録音）だけ |
| 読み込んだ MIDI を Vault に入れる・Vault の形式を変える | 別の置き場（8章）。Vault の保存形式（`fileVersion: 2`）は変えない |
| 元の MIDI ファイルそのもの・ファイルの場所（パス）を保存する | 保存するのは選んだトラックの音とテンポだけ |
| 録った音を勝手に保存する | 今の Record & Compare と同じ。音は「残す」を押した時だけ |
| 判定を「正確な採点」として見せる | 「判定は目安」と出す。精度は 9章のテストで確かめる |
| 部品をコピーして別物を作る | 録音（`RecordCompareSection` ほか `recording/**`）、指板（`DegreeFretboard`）、ベースの音（`freepatsBass`）、MIDI の読み込み（`parseMidi`）、単音化（`domain/sourceBassline`）は今のものを使う |

## 5. MIDI のベースライン（新しい練習）

### 5.1 一覧の画面（このタブを開いた時）

- 見出し「MIDI のベースライン」と説明1行、右上に「＋ MIDI を読み込む」。
- 曲名で探す欄、「すべて（n）／★ お気に入り（n）」の切り替え。
- 曲のカード（3列）：
  - 曲名・★ の切り替え・ベースの音の小さな図。
  - 小節数・元のテンポ・拍子。
  - いちばん良かった結果（区間と合った数）と、最後に練習した日。
- 並び：★ が先、その中は最近練習した順。
- カードを押すと、その曲の練習の画面（5.3）へ。
- カードの「⋯」に「名前を変える」「削除…」（確かめてから消す）。
- 曲が無い時：「まだ MIDI がありません。『＋ MIDI を読み込む』から、ベースの入った MIDI を選んでください。ベースだけの MIDI でも、コードやメロディ入りでも読めます。」

### 5.2 読み込み（小さな画面）

1. ファイルを選ぶ（`.mid`／`.midi`）。読むのは今の `parseMidi`（`src/domain/midi/parser.ts`）。
2. ファイルの情報：名前・トラック数・小節数・テンポ・拍子。
3. **トラックの表**：

   | 列 | 中身 |
   | --- | --- |
   | ベース | ラジオボタン（1つだけ） |
   | 伴奏で鳴らす | チェック（ベースに選んだトラックとドラムは選べない） |
   | トラック | 番号・名前 |
   | 音の数・音域 | 例：186・E1〜E3 |
   | 見立て | ベースらしい（いちばん低い）／和音／メロディ／ドラム（使わない） |
   | ▶ | そのトラックだけ試しに鳴らす |

4. **ベースの先選び**（自動）。順に見て最初に当たったもの：
   1. トラック名か `roleHint` がベース
   2. General MIDI のベースの音色（program 32〜39）
   3. ドラム以外で、音の高さの中央値がいちばん低いトラック
5. **確かめる項目**（表の下に ✓ か ! で出す）：

   | 項目 | 扱い |
   | --- | --- |
   | 4/4 か | 4/4 以外は読み込めない（「今は 4/4 の MIDI だけ読めます」）。今の元ベースラインと同じ決まり |
   | ベースが単音か | 同時に鳴る音がある時は、今の元ベースラインの単音化（`domain/sourceBassline`）で1音にし、「同時の音を n 個まとめました」と出す |
   | テンポの変化 | 最初のテンポで練習する（「テンポの変化が n か所あります → 最初のテンポ 98 で練習します」） |
   | 音域 | 選んでいる弦の数（4弦は E1、5弦は B0）より低い音がある時は「1オクターブ上げて練習する」のチェックを出す（初めは ON） |
   | 大きさ | ファイル 2MB まで・音 50,000 個まで・ベースの音 5,000 個まで。超えたら読み込まない |

6. 名前（初めはファイル名から拡張子を外したもの）。
7. 「保存して練習する」で保存し（8章）、その曲の練習の画面へ。「やめる」で何も残さない。

**保存しないと明記するもの**：

- 元の MIDI ファイルそのもの
- ファイルの場所
- ベースと伴奏に選ばなかったトラック
- ドラム

### 5.3 練習の画面（3章の枠）

- **課題の帯**：
  - 曲名（大きく）・小節数・元のテンポ・4/4、右に「一覧へ」。
  - チップ：曲（押すと一覧へ）、★ お気に入り、区間（「9〜10小節」）、区間の長さ（1・2・4・8小節・全部）、テンポ（60%・80%・100%と、今の BPM）、「弦とフレットを出す」。
  - 曲全体の帯：小節の番号とベースの音の点。今の区間を青緑の枠、いちばん良かった区間を下に緑の線で出す。押すとその小節から区間が始まる。
- **段階の帯**：① 聴く（お手本を聴いて覚える）→ ② 弾く（録音）（伴奏に合わせて録る）→ ③ 結果（1音ずつ確かめる）。
- **中身**：
  - 小節の段、伴奏の段（伴奏に選んだトラックのコードの名前。名前が出せない時は空）、お手本の段、自分の段。
  - お手本：音名、「弦とフレットを出す」が ON なら弦とフレット（例「A弦 7」。今の指板の割り当て `domain/mapping.ts` と ⚙ の弦の数・フレットの範囲で決める）。
  - 再生中は今の音を光らせ、赤い線で位置を出す。
  - 区間が長い時（8小節より長い・「全部」）は、段を横にスクロールさせ、1拍の幅を 30px より狭くしない。再生中・録音中は位置に合わせて自動で送る。
  - 自分の段は、結果の時に 5.5 の印を出す。
  - 右上に凡例：合った・音が違う／余分・早い／遅い・抜け。
- **操作の帯**：
  - 鳴らす音：お手本・伴奏・クリック。録る時は「お手本」を自動で切る（伴奏とクリックは選んだとおり）。
  - ボタン：
    - ① の時：▶ 聴く（Space）、● 録って弾く（R）。
    - 録音中：■ 止める（Esc）。
    - ③ の時：▶ 自分の演奏、▶ お手本と重ねて、次の区間へ、● もう一度録る（R）。
- **右の欄**：
  - 録音（3章と同じ部品）。
  - この区間の記録（日付と合った数、新しい順に5つ）。
  - 判定の決まり（タイミングの許し・オクターブ違い・音のずれの補正。⚙ で変えられる）。

### 5.4 録る流れ

1. 「● 録って弾く」→ カウントイン1小節（クリック）→ 区間の頭から伴奏とクリックが鳴り、同時に録音が始まる（今の `recording/**` の録り方。入力の機器とチャンネルは設定の画面のまま）。
2. 区間の終わりで自動で止まる。■ か Esc で途中で止めた時は、判定しない。
3. 止まったら「判定しています…（音の高さとタイミング）」と出し、5.5 の判定をする。
4. 録った音は、今と同じく「残す」を押した時だけ保存する。判定の結果（数字）は記録に残す（8章）。

### 5.5 判定（弾き終わってから）

**すべて端末の中で行い、外へは何も送らない。** 解析するのは「MIDI のベースライン」の録音だけ。ほかの4つの練習の録音は今までどおり解析しない。

| 順 | 処理 | 決まり（初めの値。設定で変えられる） |
| --- | --- | --- |
| 1 | 録った音を読み戻す | `decodeAudioData` で PCM に。選んだチャンネル（左・右・モノ）だけ使う |
| 2 | 音の高さを追う | 単音の基本周波数の推定（YIN か McLeod など。新しい依存パッケージは足さずに書く）。範囲 28〜450Hz（5弦の B0 から）。窓 2048・刻み 256（48kHz の時） |
| 3 | 音の始まりを見つける | 音量の立ち上がり＋高さの変わり目で区切り、各音の始まり・終わり・高さ（区間の中の中央値を MIDI の番号に丸める）を出す |
| 4 | 全体のずれを直す | 録音の開始のずれ（`startOffsetMs`）を引いた後、お手本と高さの合う音どうしの始まりの差の中央値を「機器のずれ」として全体を動かす（±250ms まで）。結果に「音のずれの補正 自動（−42ms）」と出す |
| 5 | お手本の音と弾いた音を組にする | 時間の順に、お手本の音の始まりの前後 ±（タイミングの許し×2）の中から1つずつ組にする |
| 6 | 1音ずつ判定 | 下の表 |

| 判定 | 条件 | 自分の段の印 |
| --- | --- | --- |
| 合った | 組になった音の高さが同じ（オクターブ違いも合いにする：初めの値）、始まりのずれがタイミングの許し（初めは ±70ms）の中 | 緑「✓」 |
| 音が違う | 組になったが、高さが違う | 赤「✗ C#3」（弾いた音） |
| 早い・遅い | 高さは合ったが、ずれが許しの外 | 黄「遅い 64ms」 |
| 抜け | 組になる音が無い | 点線「抜け」 |
| 余分な音 | どのお手本とも組にならなかった弾いた音 | 小さな赤「＋D3」（その時間の所） |

- **まとめ**：「9/12 合いました ・ タイミング 平均 +18ms（少し遅め）・ 音が違う 1 ・ 早い・遅い 1 ・ 抜け 1 ・ 余分な音 1 ・ 判定は目安です」。
- 平均は合った音の始まりのずれの平均。+ は遅め、− は早め、±15ms 以内は「ちょうど」。
- **判定できない時**（判定せずに知らせを出し、記録にも残さない）：
  - 音がほとんど入っていない：「音が入っていません。入力の機器とチャンネルを確かめてください」。
  - 音が割れている時間が長い：「音が割れています。入力の音量を下げてください」。
  - 途中で止めた時。
- **設定**（右の欄の「判定の決まり」と ⚙）：
  - タイミングの許し：きびしい ±50ms ／ ふつう ±70ms ／ ゆるい ±100ms。
  - オクターブ違い：合いにする（初めの値）／違いにする。
  - 音のずれの補正：自動（初めの値）／切る。
  - 値は Bass Practice の設定として持つ（8章）。

### 5.6 結果の画面

- 自分の段に 5.5 の印、下にまとめ。
- ▶ 自分の演奏（録った音そのもの）、▶ お手本と重ねて（録った音とお手本のベースを同時に）。今の Record & Compare の再生を使う。
- 「次の区間へ」：区間を長さの分だけ先へ。「● もう一度録る」。
- 記録に残し、曲のカードの「いちばん良かった」と曲全体の帯の緑の線を更新する。

## 8. データと保存

### 8.1 MIDI のベースラインの置き場

- **新しいファイル `loopvault/bass-midi-library-v1.json`**。今の `practice-v1.json` と同じ作りにする：
  - 版つき
  - Zod で検証
  - 一時ファイルに書いてから入れ替える
  - バックアップ 20個
  - 壊れていたら退避して、バックアップから戻す
- 置き場の作り（`infra/repository/` の `practiceStorage.ts`・`practiceRepository.ts`）をまねる。コピーではなく、共通にできる所は共通にする。
- Vault・`practice-v1.json` とは別。Vault の保存形式は変えない。

```ts
interface BassMidiLibraryV1 {
  version: 1;
  songs: BassMidiSong[];          // 最大 200
  settings: {
    timingToleranceMs: 50 | 70 | 100;  // 初めは 70
    octaveCountsAsCorrect: boolean;    // 初めは true
    autoLatencyCorrection: boolean;    // 初めは true
    defaultWindowBars: 1 | 2 | 4 | 8 | "all";
    defaultTempoPercent: 60 | 80 | 100;
  };
}
interface BassMidiSong {
  id: string;                     // アプリが作る（ファイル名・パスから作らない）
  title: string;                  // 人が付けた名前
  favorite: boolean;
  createdAt: string; lastPracticedAt?: string;
  bpm: number;                    // 最初のテンポ
  meter: { numerator: 4; denominator: 4 };
  lengthBeats: number;
  transposeOctaves: 0 | 1;        // 「1オクターブ上げて練習する」
  bass: { pitch: number; startBeat: number; durationBeats: number; velocity: number }[];  // 単音化した後
  accompaniment: { trackLabel: string; notes: { pitch: number; startBeat: number; durationBeats: number; velocity: number }[] }[];
  chordLabels?: { startBeat: number; label: string }[];   // 出せた時だけ（伴奏の段の表示用）
  importFacts: { trackCount: number; mergedSimultaneousNotes: number; tempoChanges: number };
  attempts: BassMidiAttempt[];    // 曲ごとに新しい順、最大 200
}
interface BassMidiAttempt {
  completedAt: string;
  window: { startBar: number; bars: number };  // 「全部」は小節数そのもの
  tempoPercent: number;
  toleranceMs: number;
  counts: { correct: number; wrongPitch: number; timing: number; missed: number; extra: number; total: number };
  meanOffsetMs: number; latencyCorrectionMs: number;
  marks: ("ok" | "pitch" | "early" | "late" | "miss")[];  // お手本の音の順。前回の結果を出すため
}
```

- 録った音は入れない（「残す」を押した時だけ、今の IndexedDB の置き場へ。今の決まりのまま）。
- 曲を消す時は、その曲の記録も消す。残した録音は消さない（今の「残す」の管理画面で消す）。

### 8.2 ほかの画面

## 9. 判定の精度の確かめ（テスト）

Phase 5.16 の決まり（「自動の採点は、決めた音の手本で合格した時だけ入れる」）に従う。

### 9.1 作った音の手本（コミットしてよい・自動テスト）

- リポジトリにある FreePats のベースの音（`assets/freepats-bass-yr`）で、**答えの分かっている録音**を作る。お手本の MIDI どおりに鳴らしたものに、次の違いを入れる：
  - 音を変える（半音・全音・オクターブ）
  - 始まりをずらす（±20・±60・±120ms）
  - 音を抜く
  - 余分な音を足す
  - 全体を遅らせる（0・40・120・240ms）
  - 小さな雑音、音量の大小、指弾きとピック、テンポ 60〜140、4弦と5弦の低い音
- 合格の基準（全部の手本の合計）：

  | 項目 | 基準 |
  | --- | --- |
  | 音の高さ（オクターブ違いを合いにする時） | 95% 以上 |
  | 始まりのずれ | 中央値 20ms 以内、90%点 40ms 以内 |
  | 1音ずつの判定（合った・音が違う・早い遅い・抜け） | 一致率 90% 以上 |
  | 余分な音 | 見つける率 80% 以上、間違って見つける率 10% 以下 |
  | 全体のずれの補正 | 入れたずれとの差 15ms 以内 |
  | 速さ | 8小節（BPM 100）の録音で、判定が 2秒以内（開発の PC で） |

- 基準に届かない項目は、その判定を画面に出さない（例：余分な音が基準に届かなければ、余分な音の印を出さない）。どの項目を出したかを報告に書く。

### 9.2 本物のベースの手本（人間・ローカルだけ）

- 人間が MOTU M4 で録った短い録音（10個前後）で確かめる。**録音と結果はコミットしない**（`.local-evaluation/` の外の、Git 管理外の場所）。
- EXE の受け入れで、人間が「判定がだいたい合っている」と感じるかを確かめる。

### 9.3 そのほかのテスト

- 単体：
  - トラックのベースの先選び。
  - 確かめる項目（4/4 以外・同時の音・テンポの変化・音域・大きさ）。
  - 単音化（今の `sourceBassline` の結果と同じ）。
  - 保存の往復・壊れたファイルからの戻し・200曲の上限。
  - 判定の組み方（5.5 の表の全部の場合）。
- E2E：
  - 読み込み → 保存 → 一覧に出る → ★ → ★ だけの表示。
  - 練習の画面で区間とテンポを変える。
  - 録る（テスト用の録音の入力で作った音の手本を流す）→ 結果の印とまとめ → 記録に残る → 一覧の「いちばん良かった」。
  - 途中で止めると判定しない。
  - 名前を変える・消す。
- 今の4つの練習：今の単体テスト・E2E がそのまま通る（名前を変えた所だけ直す）。録音の解析が4つの練習では動かないこと（テストで確かめる）。

## 11. 受け入れ条件

1. Bass Practice を開くと、5つの練習がタブで並び、どの練習も同じ枠（課題の帯・段階の帯・中身・操作の帯・右の欄）で出る。
2. 4つの練習の流れ・問題・ヒント・自己評価・移調・保存が今と同じ（今のテストが通る）。弦の数・利き手・フレットの範囲は ⚙ で全部の練習に効く。
3. 「＋ MIDI を読み込む」で、ベースのトラックを選んで保存できる（ベースらしいトラックが先に選ばれている）。ほかのトラックを伴奏に選べる。4/4 以外・大きすぎるファイルは読み込まない。
4. 保存した曲が一覧に出て、★ でお気に入りにでき、★ だけを出せる。名前を変える・消すができる。Vault には何も入らない。
5. 曲を選ぶと、区間（1・2・4・8小節・全部）とテンポ（60・80・100%）を選んで、聴く・録って弾くができる。
6. 弾き終わると判定され、1音ずつ「合った・音が違う・早い遅い・抜け（・余分な音）」とまとめが出る。自分の演奏とお手本を聴き比べられる。記録に残る。
7. 判定は 9.1 の基準を満たした項目だけが出る。「判定は目安です」と出る。
8. 録った音は「残す」を押した時だけ保存される。解析は MIDI のベースラインの録音だけで行い、外へ何も送らない。
9. ホームの「今日の練習」に MIDI のベースラインの練習も数えられる。
10. Vault の保存形式・`practice-v1.json` の形（足すのは設定の項目だけ）・Voicing Loop・Chord Dojo・取り込むが変わらない。fresh FULL と EXE が通る。
