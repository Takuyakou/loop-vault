## 0. 守ること（全項目に共通）

1. **判定と記録は変えない。** 次のものは変えない。
   - 判定：`midi/analysis.ts`・`analyzeRecording.ts`・`analysisWorker.ts`・`qualification.ts` の判定、音の高さ・始まり・補正・組み方、資格の基準
   - 記録の形：`bass-midi-library-v1.json`（`library.ts`・`model.ts`）、`practice-v1.json`、Vault `fileVersion: 2`
   - 録音の流れ：カウントイン・自動で止まる・60 秒の上限・`startOffsetMs`・「残す」を押した時だけ保存
   - 読み込みの決まり：4/4 だけ・大きさの上限・単音化・ベースの先選び
2. **今の4つの練習（Degree・Rhythm・Bassline・Root Motion Echo）の流れ・問題・ヒント・自己評価・移調・保存は変えない。** 変えてよいのは次の3つだけ。
   - 6章：入力欄と選択の部品の見た目
   - 12章：⚙ と ⌨ の見た目
   - 9章：段階の帯（3 段の時だけ）
3. **ほかの画面は変えない。** その画面のテストと基準画像も書き換えない。
   - Chord Dojo・Voicing Loop・取り込む・Vault・進行ページ・設定
   - アプリ共通の上の帯・サイドバー
   - アプリ共通の CSS（`src/styles/**`）
4. 新しい依存パッケージは足さない。新しい文言は日本語で書く。
5. 部品はアプリの今の部品を使う（`src/components/ui/controls.tsx`・`primitives.tsx`）。
   - `Button`（主は `variant="primary"`）
   - `SegmentedControl`・`Select`・`Chip`・`IconButton`・`Popover`
   - 同じ形の部品を新しく作らない。

- 枠の下に余った高さは、操作の帯の下に残してよい。

## 5. 1拍の幅と、音の文字の省き方

**今：**
- 段の中の幅は `max(100%, 拍数×30px)`。
- 「全部」（8小節）では 1拍が 30px で、8分音符は 15px になる。
- その結果「C」「4弦 1」のように文字が切れて読めない（`before/practice-all@1440x900.png`）。

**直すこと：**
- **1拍の幅：**
  - 弦とフレット OFF：`max(段の見えている幅 ÷ 拍数, 48px)`
  - 弦とフレット ON：`max(段の見えている幅 ÷ 拍数, 64px)`
  - 段の中の幅は「1拍の幅 × 拍数」。
  - 見えている幅を超える時は、段を横にスクロールする。
  - 小節の見出し・伴奏のコード名・音・再生の位置の線は、同じ px の位置で描く（％で置かない）。
- **音の文字：**
  - 音の箱の幅が 24px 以上の時だけ、音名を出す。
  - 44px 以上で、弦とフレット ON の時だけ、2行目に「4弦 8」を出す。
  - 入らない時は文字を出さない。
  - どの音も `title` と `aria-label` に「C2 4弦 8」の形で全部を入れる。
- 再生中・録音中の自動の送り（今は `beat*30`）も、同じ 1拍の幅で計算する。
- 「自分」の段の印（✓・✗ 音名・抜け・＋音名）にも同じ決まりを使う。✓ は 12px 以上なら出す。

**受け入れ**（1440×900、「全部」8小節）：

| 弦とフレット | 条件 |
| --- | --- |
| OFF | 段の中の幅 ≥ 32×48px |
| ON | 段の中の幅 ≥ 32×64px |

- どの音の箱も、文字が箱からはみ出さない（各要素の `scrollWidth ≤ clientWidth`）。
- 8小節目の見出しまでスクロールで届く。

## 6. 入力欄と選択を、アプリの部品にする

**今：** Bass Practice の入力欄と選択が、ブラウザーの素の見た目（灰色の帯）になっている。

- 理由：`className="lv-input"` を使っているが、アプリの CSS に `.lv-input` の決まりが無い。
- 例：一覧の検索欄・曲名の欄・開始小節・区間の長さ・テンポ・入力チャンネル・Degree Echo の「歌う参考音」
- 読み込みのファイル選びは、英語の「Choose File」のまま。

**直すこと**（`src/features/bass-practice/**` の中だけ）：
- **`<select className="lv-input">`：** `Select`（`controls.tsx`）に置き換える。
- **文字・数字の入力：** Bass Practice の CSS に `.bass-input` を足して使う。
  - 高さ `var(--lv-control-sm)`（36px）
  - 線 `1px solid var(--lv-border-strong)`、角 `var(--lv-radius-sm)`
  - 背景 `var(--lv-bg-subtle)`、文字 `var(--lv-text)`
  - 左右の余白 12px、13px
  - hover / focus は `Select` と同じ
  - 検索欄は左に虫めがねの印（今の Voicing Loop の検索欄の作りと同じ）
- **`<button className="lv-input">`（⚙）：** 12章の `Chip` に置き換える。
- **チェックボックスのトグル**（お手本・伴奏・クリック、弦とフレット）：`Chip`（`aria-pressed`）に置き換える。
- **選択肢を見せる方がよいもの**（区間の長さ・テンポ・一覧の「すべて／★ お気に入り」）：`SegmentedControl` にする。
- アプリ共通の `.lv-input` の決まりは**足さない**（ほかの画面の見た目が変わるため。人間が後で決める）。

**受け入れ：**
- `src/features/bass-practice/**` に `lv-input` の文字列が 0 個。
- Bass Practice の画面のどの `input`（checkbox・radio・file を除く）と `select` も、算出した背景色が `--lv-bg-subtle`、線の色が `--lv-border-strong`。

## 11. 音名を ♭ で出す

**今：** `midi/noteName.ts` が「Eb・Ab・Bb」を返す。結果の印が「✗ Bb1」になる。

**直すこと：**
- 表示に使う音名を「C・D♭・D・E♭・E・F・G♭・G・A♭・A・B♭・B」にする。
  - 対象：段・印・読み込みの音域・一覧
  - `title`・`aria-label` も同じ。
- 記録や判定に音名の文字列を使っている所があれば、そこは変えない（表示の関数を分ける）。

**受け入れ：** MIDI のベースラインの画面のどこにも `\b[A-G]b\d` の表示が無い。

## 12. ⚙ と ⌨ をチップに

**今：** 「⚙ 4弦・右利き・0〜12フレット ▶ ⌨」が、ただの文字の並びに見える。

**直すこと：**
- **⚙：** 「⚙ 4弦・右利き・0〜12フレット」を `Chip`（`aria-expanded`）にする。押した時に開く共通の設定は今の中身のまま。中の select は 6章の `Select` にする。
- **⌨：** `details` を、`Popover`（きっかけは `Chip`「⌨ キー操作」）にする。中の文は今のまま。
- **並び：** 練習のタブの下の行に、⚙・⌨ の順で並べる。

**受け入れ：** 2つが `Chip` の見た目（角丸・線あり）で、押すと開く。

## 13. 一覧の画面

**直すこと：**
- **検索欄：** 6章の `.bass-input`（幅 320px、placeholder「曲名で探す」）。ラベルは `aria-label="曲名で探す"` のまま、見えるラベルは付けない。
- **「すべて（n）／★ お気に入り（n）」：** `SegmentedControl`。
