# Reports

段階の報告を置く。報告は日本語で書く。名前：`P14.0-01-midi-connection.md`。

書くこと：

1. **計画**（段階の最初に書く。承認は待たない）：始めた時の HEAD。
2. **仕様 2〜7章（2.1・5.1 を含む）**：各章を1行ずつ。
   - 満たしたか
   - 確かめたテスト名
   - 2章の受け入れで数えた値（`stats.opens`・`stats.closes`、画面ごとの上部の文字）
   - 2.1 の競合のテスト（7〜9）を 3 回続けて回した結果
   - 7章で数えた値（判定の回数・`notes.held`・`stats.listeners`・モニターの数）
3. **仕様と違うことをした所**（あれば）：違い／理由／別案。
4. **変えたファイルと commit の一覧。**
5. **リースを取らなくした所の一覧**：ファイル・行・置き換えた先。
6. **直した今の E2E の行と理由。**
7. **書き換えた基準画像と理由。**
8. **ゲートの結果**：Test DX の要約行をそのまま貼る。commit hash も書く。
9. **スクリーンショットの場所**（パスを文字で、`/` 区切り）。
10. **判断ポイント**：選んだこと／理由／別案を1〜2行ずつ。
11. **人間が EXE で確かめること**：
    - 実際の機器での起動時の自動接続
    - 画面を移っても切れないこと
    - USB の抜き差し
    - 切断の後に自動でつながないこと（同じ起動の間）。開き直すと自動でつながること
    - 練習の途中で USB を抜いた時に止まり、挿し直すと同じ課題から続くこと
    - Live MIDI（ミニ表示）
12. **レビューで見てほしい所**（3〜5点）。

報告に書かないもの：

- 私的な MIDI・Vault の中身
- 端末の ID（機器名は、合成の入力の名前だけ書く）
- 個人の絶対パス
- `.local-evaluation` の中身
