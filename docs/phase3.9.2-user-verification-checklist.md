# Loop Vault Phase 3.9.2 ユーザー実機確認チェックリスト

確認対象: Style Voicing Practice  
確認EXE: `D:\dev\Loop Vault\src-tauri\target\release\loop-vault.exe`

## 1. 既定動作

- [ ] EXEを起動し、Chord Dojo（コードの練習）を開く
- [ ] 「練習するボイシング」が「保存ボイシング（既定）」になっている
- [ ] 進行を別のものへ変えると「保存ボイシング（既定）」へ戻る
- [ ] アプリを再起動しても「保存ボイシング（既定）」へ戻る
- [ ] 保存ボイシングの出自が「鍵盤で記録」「元MIDI」「元MIDIから推定」「自動生成」のいずれかで正しく表示される

## 2. 4種類の追加ターゲット

同じ進行で次を順に選ぶ。

- [ ] 自動（クローズ）
- [ ] シェル 1-7
- [ ] オープン 1-7
- [ ] ルートレス A/B

各ターゲットで確認する。

- [ ] 「試聴音色」のピアノ／エレピを切り替えると「進行を試聴」の音色が変わる
- [ ] 「進行を試聴」で選択中の形が鳴る
- [ ] 進行全体のコードカードをクリックすると、そのコードだけが選択中の音色で鳴る
- [ ] カードをクリックすると「いま」、現在位置、鍵盤Guideが同じコードへ切り替わる
- [ ] 鳴っているnoteと鍵盤Guideのnoteが一致する
- [ ] ピアノVisualizerが縦に間延びせず、横幅内で確認しやすい
- [ ] L1では左手／右手の推奨note名と色分け鍵盤が見える
- [ ] L2ではnote名とGuide鍵盤が隠れ、Style名と音数だけが見える
- [ ] L3でもnote名とGuide鍵盤が隠れ、度数・Style名・音数だけが見える
- [ ] ルートレスはAまたはBのvariantが表示される
- [ ] fallbackされたイベントは元Styleではなく「自動」と表示される

## 3. 指定音高判定

「判定」を「指定音高」にする。

- [ ] 表示どおりのnoteを押すと通過する
- [ ] 全音をまとめて1オクターブ上へ移しても通過する
- [ ] 全音をまとめて1オクターブ下へ移しても通過する
- [ ] 1音だけ別オクターブへ移すと通過しない
- [ ] 余分なnoteを加えると通過しない
- [ ] pedalで残っているnoteだけでは誤判定しない

「全体のオクターブ移動を許可」をOFFにする。

- [ ] 表示どおりの絶対音高だけが通過する
- [ ] 全音をまとめて1オクターブ移しても通過しない

## 4. ピッチクラス判定

「判定」を「ゆるく（ピッチクラス）」にする。

- [ ] 別の転回形で同じ構成音を押すと通過する
- [ ] 別オクターブで同じ構成音を押すと通過する
- [ ] 余分なpitch classを加えると通過しない
- [ ] ルートレスではRootを追加しなくても通過する

## 5. span

左手、右手を個別に12 / 14 / 16へ変更する。

- [ ] 設定変更で進行全体の形が再生成される
- [ ] 12 semitoneで実際に手が届く
- [ ] 14 / 16で必要に応じて候補が広がる
- [ ] 左右の手が交差した不自然なGuideが出ない
- [ ] アプリ再起動後もspan設定だけは保持される

## 6. 未対応コードとfallback

triad、sus、slash chordを含む進行で「ルートレス A/B」を選ぶ。

- [ ] 未対応の小節とコードが一覧表示される
- [ ] fallback OFFでは練習開始と試聴ができない
- [ ] 「未対応コードだけ自動（クローズ）を使用」を明示的にONにすると開始できる
- [ ] fallbackイベントへ「自動」chipが出る
- [ ] 別の進行を選ぶとfallbackがOFFへ戻る

## 7. Step / Flow

- [ ] Stepで正しい形を100 ms程度保持すると次へ進む
- [ ] 同じコードが連続しても押しっぱなしでは次へ進まない
- [ ] Flowで時計、現在位置、miss、roundが従来どおり動く
- [ ] Style練習中のclean状態は画面内では動く

## 8. 非永続化

確認前に対象進行の現在の段位badgeを覚えておく。

- [ ] Style練習を開始して数コード弾く
- [ ] 終了ボタンで終了する
- [ ] Style練習中にアプリを閉じる
- [ ] 再起動後も段位badge、仮クリア、別日確認が変わっていない
- [ ] Style、A/B結果、fallback選択が復元されない
- [ ] 保存済み進行のコード、Voicing Memory、Vault内容が変わっていない

## 9. 既存試聴の回帰

- [ ] Vault一覧の試聴が従来どおり鳴る
- [ ] 進行詳細の試聴が従来どおり鳴る
- [ ] Homeの試聴が従来どおり鳴る
- [ ] Chord DojoのStyle選択が、他画面の試聴音高へ影響しない

## 10. 音楽的評価メモ

問題があるStyleごとに次を記録する。

```text
進行:
コード:
Style:
A/B:
手が届くか:
前後が滑らかか:
不自然な低音:
不要な重複:
欲しい修正:
```

特にii-V-I、altered dominant、同じコードの反復で、手の移動量と響きの自然さを確認する。
