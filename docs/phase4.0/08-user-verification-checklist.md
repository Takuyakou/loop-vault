# Loop Vault Phase 4.0 実機確認チェックリスト

自動検証で確認できないのは「音」と「実際の操作感」だけである。以下は聴いて / 触って初めて分かる項目に絞ってある。

既定Analyzerが `legacy` から `phase4-v1` に変わっているため、**同じMIDIを読み込んでも以前と違うコードが出ることがある**。

## 1. まず見てほしい変化

3rd（長3度・短3度）が鳴っていないvoicingで、コード名の出方が変わる。

| 状況 | 以前 | 現在 |
|---|---|---|
| E・F#・A・D が鳴っている | `Em11` | `Dadd9/E` |
| 上部にEメジャー、ベースにF# | `F#m11` | `Eadd9/F#` |

**確認したいこと**: この読み替えが、耳で聴いた響きと合っているか。合っていなければ減点係数が強すぎる可能性がある。

## 2. 保存前と保存後で音が変わらないか

Phase 4.0で直した中で、**最も体感しやすい変更**。

1. MIDIを読み込む
2. 候補を再生する（この時点の響きを覚えておく）
3. Vaultへ保存する
4. Progression Detailで同じ進行を再生する

**期待**: 2と4が同じ響きで鳴る。以前は2が生成voicing、4が元MIDIのvoicingで、音が変わっていた。

## 3. 候補の表示

### 1小節に2コードあるMIDI

**期待**: `| F#m11 · C7 |` のように両方出る。以前は片方が消えていた。

### 2小節以上またぐコード

**期待**: `| Gmaj9/A | — |` のように継続が出る。以前は2小節目が `N.C.` になっていた。

### 候補ヘッダー

**期待**: `1-8小節・6コード` のように小節数とコード数が別々に出る。以前は `1-8小節 (8)` で、8が小節数かコード数か分からなかった。

### 短いループ・1コードのVamp

**期待**: 2小節ループや1コードで押し切る箇所も候補に出る。以前はコード数が少ないと順位が下がって消えていた。

## 4. Warning表示

**期待**:

- `要確認` だけでなく理由が出る（例: 「3rdなど和音を決める音が鳴っていない」）
- 日本語UIに英語（`Sparse Evidence` 等）が混ざらない
- 単純なメジャー・マイナーコードに警告が出まくらない

**気になったら**: 明らかに単純なコードに警告が付いていたら、その小節を教えてほしい。

## 5. コード編集

**期待**:

- `C6/9` を入力しても「無効なコード」にならない（以前はなっていた）
- `A13sus` と入力すると `A13sus4` になる（以前は `Asus413` という壊れた表記になっていた）

## 6. 既存データ

**期待**: 保存済みの進行は**何も変わらない**。自動再解析はしない。

Vaultを開いて、以前保存した進行が以前と同じに見えて同じに鳴ることを確認してほしい。

## 7. 元に戻したい場合

コードの出方が気に入らなければ、1行で元に戻せる。

`src/domain/midi/analysis.ts`

```ts
export const defaultAnalyzerMode = "legacy" as const;
export const analyzerVersion = legacyAnalyzerVersion;
```

保存データには影響しない。
