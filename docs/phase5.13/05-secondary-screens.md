# Phase 5.13-05: 副画面の操作状態と復帰導線

## 対象

- Vault
- コード進行詳細
- Live MIDI Mini Mode
- 設定
- コード練習

## 変更

### Vault

- 検索と並び順のラベルを常時表示し、プレースホルダーだけに意味を依存しないようにした。
- 小節数フィルター、並び順、追加フィルターの操作高を揃えた。
- 絞り込み結果件数を polite live region として通知する。
- 0件時に「新しいIdea」へ戻れる共通 Empty State を表示する。
- 試聴、お気に入り、コピー、詳細表示のクリック領域を40pxへ拡張した。

### コード進行詳細

- 戻る、練習、親Idea、複製、削除、変更保存を共通ボタンへ統一した。
- アイコン操作は40pxのクリック領域、ツールチップ、アクセシブル名を持つ。
- 保存可否、再生、編集ロジックは変更していない。

### Live MIDI

- デバイス選択とヘッダー操作を40pxの操作領域へ揃えた。
- 接続状態を live region として明示した。
- 接続エラーを共通 Status Message で表示し、その場からデバイス再読み込みを実行できる。
- 設定の接続テストは処理中を `aria-busy` で示し、成功・失敗を色だけでなく見出しとアイコンで通知する。

### 設定

- 閉じる、保存場所、import/export、バックアップ操作を共通ボタンへ統一した。
- import/export中の二重実行防止を維持した。
- 永続化エラーを assertive live region で通知する。
- データ形式、バックアップ、解析設定の構造と処理は変更していない。

### コード練習

- キューと練習ワークスペースに領域名とキーボードフォーカスを追加した。
- 左右の独立スクロール、選択状態、練習ロジックは変更していない。

## 非変更範囲

- MIDI解析・コード検出
- Live MIDI判定・安定化処理
- 練習判定・進捗
- Vault schema / fileVersion
- Tauri command / Rust
