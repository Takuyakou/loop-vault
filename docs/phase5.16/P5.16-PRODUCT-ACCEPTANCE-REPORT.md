## Cause and reproduction

Bass Practice could not be opened from a normal P5.16 production build because all three shipped mode flags resolved to `false` when no local override existed:

- `enableBassPracticeDegreeEcho` is represented by `loop-vault:bass-practice-degree-echo-enabled:v1`.
- `enableBassPracticeRhythmEcho` is represented by `loop-vault:bass-practice-rhythm-echo-enabled:v1`.
- `enableBassPracticeBasslineEcho` is represented by `loop-vault:bass-practice-bassline-echo-enabled:v1`.

The `App` feature guard derives availability from those flags. Consequently the Home card, Practice sub-navigation and Vault Detail handoff were all absent in a production-default profile. Existing P5.16 E2E setup wrote the Degree flag to local storage before launching, so it did not exercise the actual release default.

A second state defect was found while validating the complete product flow: switching away from an active Degree Echo tab unmounted the view and marked its live Practice session abandoned. Returning to Degree Echo then prevented self-review saving.

## Resolution

- Made Degree Echo, Rhythm Echo and Bassline Echo production defaults `true`.
- Preserved immediate rollback: each mode remains independently disabled by an explicit local `false`; no Vault schema field is used and no history is deleted.
- Added the missing Bassline default constant and covered defaults, invalid stored values and storage denial.
- Kept Degree Echo mounted while changing Bass Practice mode tabs, preventing a tab change from abandoning a live session. Rhythm and Bassline remain mounted only while selected, so their audio/resources are released on mode exit.
- Added a production-default Playwright suite that never writes a feature flag to enable the feature. It verifies Home, Practice, all three modes, Degree self-review save, restart History restoration and the Vault Detail handoff.
- Preserved the old Chord Dojo scenarios by explicitly selecting its tab in their tests. Updated the intentional Home and Practice workspace visual snapshots.
