# P5.17-02 — Session Flow Integration (in progress)

## Determination

**Partially complete — stage still active.** The Record & Compare flow is now
structurally integrated into all three Echo modes and verified non-regressing,
but real Target/My Take audio playback, timed count-in, the force-hear-or-skip
gate before Review, and dedicated Record & Compare E2E scenarios remain. The
stage is intentionally not marked completed in `execution-state.json`.

## What was built

- Shared `RecordCompareSection` (`recording/ui/RecordCompareSection.tsx`) driving
  the flow via `useRecordCompareSession` (`recording/ui/useRecordCompareSession.ts`),
  which owns one `RecordingSessionController`, probes on mount, mirrors recorder
  state into React, and disposes on unmount / mode change (`resetKey`).
- Wired into all three modes, rendered **only** during the play/listen-back
  window (Degree: `thinking`/`playing`/`review`; Rhythm: same; Bassline:
  `review`) so the initial practice screen — and its visual snapshot — is
  unchanged.
- Opt-in and additive: nothing beyond a compact "Record & Compareを使う" prompt
  until the user opts in; microphone permission is requested only on enable.
  Provides channel selection, Play/Record, Stop, Hear Target, Hear My Take,
  Retake, Discard, Keep Take, and "録音せず続ける" (skip). No scoring language.
