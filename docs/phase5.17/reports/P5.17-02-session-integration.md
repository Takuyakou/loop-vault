# P5.17-02 — Session Flow Integration

## Determination

**Stage complete.** The Record & Compare flow is integrated into all three Echo
modes with real Target/My Take playback, timed count-in, the force-hear-or-skip
gate before Review, and dedicated fake-media E2E — all verified non-regressing.

## What was built

- Shared `RecordCompareSection` (`recording/ui/RecordCompareSection.tsx`) driving
  the flow via `useRecordCompareSession` (`recording/ui/useRecordCompareSession.ts`),
  which owns one `RecordingSessionController`, probes on mount, mirrors recorder
  state into React, and disposes on unmount / mode change (`resetKey`).
- Wired into all three modes, rendered **only** during the play/listen-back
  window (Degree: `thinking`/`playing`/`review`; Rhythm: same; Bassline:
  `review`) so the initial practice screen — and its visual snapshot — is
  unchanged.
- Opt-in and additive: nothing beyond a compact "Record & Compareを使う" prompt
  until the user opts in; microphone permission is requested only on enable.
  Provides channel selection, Play/Record, Stop, Hear Target, Hear My Take,
  Retake, Discard, Keep Take, and "録音せず続ける" (skip). No scoring language.

## Completed items (second increment)

1. **Real playback** via injectable `TargetPlayer` / `TakePlayer`
   (`recording/application/playback.ts`): `BrowserTakePlayer` plays the recorded
   Blob through an Audio element with the object URL revoked on stop/end; each
   mode wires its Target through `createTargetPlayer` + the shared
   `previewMidiNotes`/`stopPreview`. The section holds one active playback handle
   and stops the other before starting one, so Target and My Take never overlap.
2. **Timed count-in** via a `countInMs` prop (one bar from each mode's
   tempo/meter), with a Cancel control during count-in; the timer is cleared on
   cancel/retake/skip/unmount.
3. **Force hear-or-skip** before Review: when a take is recorded and unheard, the
   section shows an explicit "My Takeを聴く / 聴き返しをスキップ" choice.
4. **Dedicated E2E** `e2e/phase5.17-record-compare.spec.ts` with Chromium fake
   media device: production-default visibility (no flag injection), full record →
   listen-choice → keep, and explicit-`false` rollback. 3/3 pass.

Added gates: `web-build` (PASS), `playwright-record-compare` (PASS — 3),
`playwright-regression` (PASS — 19: production-activation, degree-echo, visual
with no snapshot diff, accessibility). Full Vitest is now 278 files / 2144 tests.
