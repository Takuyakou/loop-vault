# Contract 02 — Preset Library

## Compatibility

Current default progression must remain addressable by its existing stable identity
or a backward-compatible alias.

No old History or fixture may become unreadable.

## Catalog

Minimum eight learning roles, based on `proposal/PRESET-CATALOG.md`.

If current default is distinct, preserve it as an additional legacy preset.

## Data-driven

No duplicated chord arrays across UI branches.

Catalog entries must be versioned, validated, deterministic and testable.

## Transposition

Same preset + tonal center + section + level + seed yields the same snapshot and exercise.

Borrowed degrees and slash bass are preserved.

## Representability

Never silently replace unsupported chord identities.
