# Contract 05 — Privacy / Safety

## Never commit or report

- personal MIDI
- raw user recordings
- `.local-evaluation`
- personal absolute paths
- source filesystem paths
- raw device IDs

## Protected surfaces

- P5.15
- Vault schema / mutation
- Analyzer
- MIDI Exporter
- Chord Dojo
- Live MIDI
- FreePats assets
- P5.17 RecordingTake storage
- P5.18 chord playback contract

## Git safety

- no reset/stash/discard
- explicit path staging
- no `git add -A`
- no `git add .`
- no automatic master merge
- no push
- no P5.19
- no `docs/CURRENT_STATE.md`
