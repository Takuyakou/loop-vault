# P5.18.1 Design Review

## Conclusion

P5.18.1として分離する判断は妥当。

P5.18はコード伴奏と保存進行の文脈を作るPhaseであり、
P5.18.1は「何を教材にするかをBassline Echo内で明示的に選ぶ」体験を完成させる。

## Why this is needed

現在、Bassline Echoの既定進行が1件だけなら、次の問題がある。

- root motionが固定化する
- chord qualityの経験が偏る
- slash bassやminor進行を練習しにくい
- P5.18のChord Contextを繰り返し使う動機が弱い
- Vaultの保存進行を使える機能が存在しても、Bassline Echo内に入口がなければ発見しづらい

したがって、単なるプリセット追加ではなく、
`Preset / Vault` を同じsource modelで扱う必要がある。

## Important correction

`Generated Progression`という名称は、コード進行そのものを生成していない場合は不正確。

推奨整理:

```text
Progression source
├─ Preset
└─ Vault

Bassline
└─ selected progressionを基に生成
```

将来、進行自体を自動生成する機能を作る場合だけ `Generated Progression` を追加する。

## Current default compatibility

現在の既定進行の内容は、この指示書作成時点ではリポジトリ未監査。

そのため:

- 削除しない
- IDを変えない
- Historyを壊さない
- 8候補と重複するかP5.18.1-00で確認

という契約にする。

## Vault picker opinion

Progression DetailからBass Practiceを開けるだけでは不十分。

ユーザーはBass Practiceを開いた後に教材を変えたい。
したがってBassline Echo内に明示的な `Vaultから選ぶ` が必要。

Pickerは選択を即時commitせず、confirm/cancelを持つべき。
これにより誤クリックでactive sessionや録音contextが破棄される事故を防ぐ。

## Scope control

P5.18.1へ入れない:

- AI recommendation
- weakness-based preset choice
- favorite metadataの新設
- source MIDI bassline
- Root Motion
- auto scoring

まずは「選べる・安全に切り替えられる・履歴に残る」を完成させる。
