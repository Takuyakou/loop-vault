## UI / transaction

Bassline Echo now exposes a visible, accessible `Vaultから選ぶ` action when
Chord Context is enabled.

The picker is a modal transaction:

1. Opening or highlighting a candidate leaves the current practice source and
   active playback unchanged.
2. `キャンセル`, Escape, and closing the modal leave the source unchanged.
3. Only `このセクションを使う` calls the existing `chooseProgression` lifecycle.
   That lifecycle stops legacy playback, Chord Context accompaniment, and
   metronome, clears transient review/hint state, and reconciles the existing
   recording/session facts without deleting retained takes.
4. A confirmed Vault source exposes an explicit return to the generated default.

The previous immediate source-changing select is removed. P5.18.1-03 remains
responsible for the broader preset source selector and source-summary work.

## Search / sections / accessibility

- Candidates are immutable, detached Vault section snapshots.
- Search matches only safe key, safe section label, section range, and chord
  labels; it does not expose Vault titles, source references, files, or raw MIDI.
- The modal provides loading, empty, error, no-match, candidate-preview,
  confirmation, and cancellation states.
- Candidate buttons are keyboard reachable; Up/Down moves the highlighted
  candidate, and the existing modal provides focus trapping, Escape, and focus
  restoration.
- Large lists are deferred while the search text changes and bounded to the
  first 50 matches with an accessible refinement message.
- Each candidate represents an already validated exact 4/4 section. No chord
  clipping, substitution, or section splitting occurs in the picker.

## Read-only / privacy

The picker consumes only `VaultChordContextSnapshot` values created at the
existing App boundary. It does not write to the Vault, mutate the Vault schema,
or re-resolve a candidate against the live Vault at confirmation time.

No private recording, raw audio, raw MIDI, external corpus data, device data,
personal absolute path, or Vault title is introduced in the implementation,
tests, or report. P5.15, Analyzer, MIDI Exporter, Chord Dojo, Live MIDI,
FreePats assets, and the P5.17 recording binary-store contract are unchanged.
