## Source selector and summary

Bassline Echo now provides one visible source control when Chord Context is
enabled:

- `Current default (generated)` keeps the existing generated snapshot and its
  original `bassline-ui:<level>` generator seed unchanged.
- All nine immutable catalog presets are selectable from the same control.
- A preset exposes a same-mode, twelve-tonic key selector. Changing a key
  creates the deterministic catalog snapshot; it never edits a Vault item or
  writes a persisted setting.
- `Choose from Vault` remains the direct, read-only confirmation transaction
  from P5.18.1-02. An active Vault source is explicitly shown in the selector;
  opening, highlighting, cancelling, or closing the dialog does not change
  practice.
- The selected-source summary contains only safe source label/kind, key,
  exact section range, and original BPM. It never renders a Vault title,
  external path, source reference, raw MIDI, or private media.

## Bassline, playback, recording, and History

- Preset and Vault snapshots use the existing generic Chord Context Bassline
  exercise adapter. The generated default deliberately remains on its existing
  P5.16-compatible generator path.
- The selected snapshot drives the Bassline strip, target generation, Chord
  Context chord events, original BPM, and P5.17 Record & Compare reset key.
- A source or key change stops legacy preview and Chord Context playback,
  disposes the prepared session, clears transient review/hint state, and
  invalidates recording facts without altering retained takes or Vault data.
- A full twelve-bar preset reaches the Chord Context engine as all twelve chord
  events; no clipping, implicit splitting, or substitution is introduced.
- Existing factual History uses the already-defined `preset` source metadata
  (`presetId`, catalog version, safe label, snapshot signature, section, BPM,
  and level context). No scoring, raw audio, device data, or source content is
  added.
