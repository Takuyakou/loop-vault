## Vault title

- Entity and field: `SongIdea.title: string`; it belongs to the existing Vault model, not to `SavedProgressionBlock`.
- Schema: required, 1–80 characters. New-idea creation trims whitespace, rejects an empty result, and stores at most 80 characters. The generic update path preserves existing title semantics, so the presentation boundary must still handle legacy whitespace safely.
- Unicode and duplicate titles are allowed; title uniqueness is not a Vault invariant.
- Existing Vault search already includes the parent idea title together with progression fields. This phase adds only picker-local title presentation/search, not a new Vault index or schema field.
- Privacy class: live user-authored Vault data. It is permitted in picker presentation and search only; it is forbidden in snapshots, Practice JSON, History, recording metadata, reports, and logs.
