# P5.18.2 Design Review

## Conclusion
P5.18.1を再オープンせず、P5.18.2として分離するのが適切。
P5.18.1はPreset/Vault source選択のtransactionとHistory互換を完成させた。P5.18.2はprivacy boundaryを保ったまま「見つけやすさ」だけを改善する。

## Primary issue
Vault pickerがタイトルを出さない場合、ユーザーはコード進行を覚えていないと目的の曲由来進行を探しづらい。Loop Vault固有価値はユーザー自身のVaultにあるため優先度が高い。

## Privacy correction
「タイトルを見せない」と「タイトルを保存しない」は別。

```text
UI表示/検索: live Vault title OK
Practice snapshot: titleなし
History: titleなし
Recording metadata: titleなし
Report/log: titleなし
```

## Progression Detail
過去PhaseではVault Detail handoffの証拠があるが、現在状態はauditが必要。
- exists → regression固定
- hidden/broken → minimal fix
- regressed → restore
- never existed → human approval待ち

## Scope discipline
favorite/recent、user preset、Vault statistics、AI recommendation、Chord Dojo integration、Root Motionは混ぜない。
