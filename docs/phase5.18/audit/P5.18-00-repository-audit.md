## Vault progression
- `SavedProgressionBlock` carries a stable block id, optional detected key, BPM, time signature, chord timeline items with bar/beat/duration, and chord symbols including optional slash bass. It also contains source-asset metadata that must not cross the Practice boundary.
- Progression Detail can call `openPractice(ideaId, blockId)`, but the current App handoff only selects the general Bass Practice view; it does not yet construct a P5.18 snapshot.
- Existing Vault preview can resolve meter and voicings. P5.18 must not change its schema, preview behavior, repository, or source-asset lifecycle.
- Practice snapshot construction is therefore a new, read-only P5.18 application boundary. It may use stable logical ids and safe display text, but never source paths, raw MIDI, source bytes, or user metadata.

## Bassline Echo
- The current Bassline generator is deterministic (`bassline-v1`) and accepts only 4/4, 30–240 BPM, 1–8 chord events, and a total duration of at most 8 beats. Target pitches are constrained to MIDI 28–55.
- The current Vault adapter trims to eight chord entries and clips events to the first eight beats; it also assumes 4/4. This is safe for the existing feature but is not a P5.18 section-selection contract and must not be broadened silently.
- P5.18 source sections are locked to one or two complete 4/4 bars (1–8 beats and 1–8 chord events), with each selected boundary on a chord boundary. Unsupported meter, malformed timing, or a longer unselected range is unavailable until a later explicit contract supports it; no hidden truncation or substitution is allowed.
- Current Bassline UI is generated-source-only. P5.18-02, not this stage, is the earliest point for a Vault handoff.

## Audio
- `PlaybackController` centrally replaces the active source and delegates stop/dispose to preview drivers. It is a reuse candidate for route-level exclusivity, not a reason to alter Chord Dojo or other playback in this stage.
- `chordPreview` owns a global scheduled-preview lifecycle and supports FreePats bass preview. P5.18 must use a separately scoped accompaniment abstraction if its timing/layer model cannot be expressed without changing existing Chord Dojo behavior.
- Existing `voiceChordForPreview` includes a low slash/root bass voice (MIDI 43–55). It is unsuitable unchanged for Chord Context accompaniment because Bassline Echo owns MIDI 28–55.
- `RhythmPlaybackController` provides a reusable stop/dispose and metronome lifecycle pattern. FreePats and global master-volume routing already exist and are protected surfaces.

## P5.17 Record & Compare
- P5.17 supplies one `RecordingSessionController`, `RecordCompareSection`, `TargetPlayer`/`TakePlayer`, and an IndexedDB binary take store. Kept binary audio remains outside Vault and Practice JSON.
- Record & Compare already stops Target/My Take mutually exclusively and releases browser playback URLs. P5.18 must reuse that architecture rather than add another recorder, binary store, permission flow, or history store.
- Recording with accompaniment may be offered later, but application output must never be internally mixed into the capture stream. There is no app-side live monitor; headphones guidance is factual only.

## Decisions locked
- **Source snapshot:** immutable `chord-context-snapshot-v1`, canonical-signature based, read-only, and independent of the Vault schema.
- **Section:** one or two complete 4/4 bars; 1–8 beats and 1–8 chord events; explicit start/end chord boundaries; no silent clipping.
- **Voicing:** accompaniment is chord tones only in MIDI 57–76 inclusive. It contains no low root or slash-bass note; slash bass remains harmonic metadata for deterministic upper-structure voicing.
- **Listen default:** `Bass + Chords`.
- **Play default:** `Chords only`; target bass never auto-plays in Play.
- **Default layer gain relative to the existing global master:** target bass 0 dB, chords -12 dB, metronome -9 dB. Per-layer gain must not bypass global master volume.
- **Tempo:** original source BPM is retained; session-effective BPM is manual only and must be 30–240. `+4 BPM` is explicit, never automatic, and is disabled at 240 rather than wrapping or changing Vault data.
- **Rollback:** future `enableBassPracticeChordContext` is production-default true, with the existing local explicit-false feature-flag pattern as the sole rollback. It is independent of Degree, Rhythm, Bassline, and Record & Compare flags; no environment-only enablement or Vault persistence.
- **History:** future P5.18 history is factual only: source type/ref/safe label, snapshot signature, section, original/effective BPM, Listen/Play mode, metronome use, Record & Compare use, and retained-take reference. It excludes scoring, inferred performance content, raw audio, and source paths.
