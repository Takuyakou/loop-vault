## Locked contracts
- Snapshot: immutable `chord-context-snapshot-v1`; canonical deterministic
  signature; no raw MIDI, source path, recordings, or Vault write-back.
- Default Listen: Bass + Chords. Default Play: Chords only; target bass does
  not auto-play during Play.
- Default levels relative to existing global master: bass 0 dB, chords -12 dB,
  metronome -9 dB.
- BPM: original retained; session-only effective BPM 30–240; explicit +4 BPM
  is disabled at 240 and never mutates Vault.
- Rollback: future chord-context flag defaults enabled and uses only the
  established local explicit-false rollback; no environment-only enablement.
- History is factual only and stores no score, inferred performance data, raw
  audio, device information, or source path.
