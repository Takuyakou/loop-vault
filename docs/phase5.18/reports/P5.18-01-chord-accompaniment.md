## Implementation
- Added a source-neutral Chord Context playback plan and driver boundary under `src/features/bass-practice/application/chordContextPlayback.ts`. The future P5.18-02 Vault adapter is responsible for snapshot conversion; this stage does not read or mutate Vault data.
- The deterministic planner validates a 4/4 input, BPM 30-240, a maximum eight-beat section, finite chord/bass timing, normalized bass velocity, and a zero-to-eight-beat count-in before scheduling anything.
- Listen resolves Bass only, Chords only, Bass + Chords, and Bass + Chords + Metronome. Play resolves Chords only, Chords + Metronome, Metronome only, and No accompaniment. Defaults are Bass + Chords for Listen and Chords only for Play; Play never schedules target bass.
- Starts replace the active player safely. Stop, dispose, scheduling failures, creation failures, and natural completion stop and dispose the player. The engine preserves driver failures for diagnostics and does not leave an active plan after cleanup.

## Voicing / register / mix
- Chord voicing is deterministic, chord-tone-only, and constrained to MIDI 57-76 inclusive. No root or slash-bass note is emitted in the bass register. Slash-bass metadata adjusts the deterministic upper-structure center only.
- Target bass stays constrained to MIDI 28-55. This preserves the P5.18 bass-owns-the-low-end contract.
- The global master-volume routing remains a driver requirement. Default mix: bass `0 dB`, chords `-12 dB`, metronome `-9 dB`.
- The implementation does not alter Chord Dojo, Live MIDI, existing preview playback, FreePats assets/mapping, or P5.17 recording/take storage.
