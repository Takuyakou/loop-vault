# P5.18-02 — Vault Source / Section Selection

## Determination
`PASS`

## Implementation

- Added the in-memory, immutable `chord-context-snapshot-v1` boundary for a
  Vault progression handoff. It retains only logical idea/block references, a
  derived safe label, tonal context, original BPM, selected chord section, and
  a deterministic canonical signature.
- A selectable Vault section is complete and contiguous: either four or eight
  beats (one or two 4/4 bars). Unsupported, partial, or invalid sources are
  rejected; they are not clipped, substituted, or silently normalized.
- `ProgressionDetailView` presents the section selector and creates the
  detached snapshot before handing off to Practice. `App` retains that snapshot
  only as transient navigation state; normal navigation does not resume it.
- The P5.18 adapter creates a Vault Bassline exercise only from a validated
  detached snapshot. The legacy Vault adapter remains separate, and generated
  practice remains the compatible fallback.

## Vault lifecycle

- Starting a new practice attempt reads the current Vault progression once and
  produces a fresh snapshot; the Practice handoff does not retain a mutable
  Vault object or perform a later live lookup.
- The signature is recomputed from canonical content and validation rejects a
  malformed or mismatched snapshot. Source edits after handoff therefore do
  not change the active handoff payload.
- This Stage adds no Vault persistence. History retention and deleted-source
  handling remain explicitly deferred to P5.18-04; no source is recreated or
  silently replaced in this Stage.
- No Vault schema, Vault repository behavior, or Vault mutation path changed.

## Contract and protected-surface confirmation

- The implementation conforms to Contract 02: no raw MIDI, source path,
  source-asset metadata, recording, user identity, or mutable source object is
  included in the snapshot.
- The only displayed source label is derived from harmonic key and bar bounds;
  it does not reuse user-entered text or a source file name.
- P5.15, Analyzer, MIDI Exporter, Vault schema/repository, Chord Dojo, Live
  MIDI, FreePats assets/mapping, and P5.17 binary-take storage are unchanged.
- No tracked MIDI, `.local-evaluation` input, recording, private audio, or
  personal absolute path was introduced.
