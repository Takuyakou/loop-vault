# P5.18-03 — Bassline Echo Listen / Play Integration

## Determination

`PASS — Chord Context Listen / Play integration complete`

## Implementation

- Bassline Echo now exposes Chord Context behind its own independent feature
  flag. It consumes either the immutable P5.18-02 Vault snapshot or the
  existing generated-progression fallback; it does not mutate or re-read the
  Vault while a practice session is active.
- The existing bass-only Listen control remains available. Starting Chord
  Context stops that legacy preview first, and starting the legacy preview
  stops Chord Context first, so the two paths cannot overlap.
- The isolated Chord Context Tone driver does not use the shared
  `chordPreview` singleton. Its instruments still route through the existing
  global master-volume destination, leaving Chord Dojo, Vault preview, and
  Live MIDI behavior unchanged.

## Listen modes

The Listen selector provides all four contracted modes:

1. Bass only
2. Chords only
3. Bass + Chords (default)
4. Bass + Chords + Metronome

Listen uses the generated or snapshot-derived target bass only when its
selected layer includes bass. Chord voicings remain in MIDI 57–76 and target
bass remains in MIDI 28–55, preserving the bass-owns-the-low-end contract.

## Play modes

The Play selector provides all four contracted modes:

1. Chords only (default)
2. Chords + Metronome
3. Metronome only
4. No accompaniment

Play never schedules the target bass. The zero-layer No accompaniment choice
does not allocate a playback graph.

## Lifecycle, accessibility, and rollback

- Starting, stopping, changing Listen/Play mode, changing a layer selection,
  changing level, changing a Vault snapshot, opening Review, unmounting, and
  route/tab leave all stop and dispose the active Chord Context session.
- Natural completion clears UI playback state and disposes the driver. The
  engine replaces an existing session before a new one starts, and cleanup
  covers timers, instrument releases, and Tone nodes to prevent stuck notes.
- The controls use labelled radio groups, explicit Start/Stop controls, and a
  polite live status message. Production-default coverage exercises their
  keyboard-reachable surface.
- `enableBassPracticeChordContext` defaults to `true`. Only an explicit local
  storage value of `false` disables it, preserving a non-destructive rollback;
  it is independent of Degree Echo, Rhythm Echo, Bassline Echo, and P5.17
  Record & Compare flags. No flag state is stored in the Vault.
