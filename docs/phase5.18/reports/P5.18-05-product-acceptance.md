## Product feedback remediation

### Unified Echo layout

- Degree, Rhythm, and Bassline now share the same header and progress components.
- Rhythm uses six visible phases: `聴く / 思い出す / 歌う / 考える / 演奏 / レビュー` in Japanese, with phase-specific instructions and actions.
- Bassline uses the same visual hierarchy and a four-stage flow appropriate to its existing behavior.
- Degree keeps the same behavior and now localizes its progress labels consistently: `聴く / 歌う / 考える / 演奏 / レビュー / 移調` in Japanese, while English remains `Listen / Sing / Think / Play / Review / Transfer`.

### Degree progress localization

- Root cause: the selected application language was passed to Rhythm and Bassline views but was not forwarded through the Degree workspace boundary.
- The language is now passed explicitly to Degree Echo and resolved through a static label map; no new state, effect, or persistence was added.
- Unit coverage verifies both Japanese labels and the unchanged English rollback. Production-default Playwright verifies the Japanese labels in the built application.
- The first full Playwright run after this change reported `50/51` because an unrelated Practice-tab keyboard test used state-dependent `ArrowLeft`. Repeated execution reproduced the race. The test now uses the deterministic ARIA `Home` behavior to select the first tab, passed `5/5` in repetition, and that HEAD passed `51/51`; the current selector-enhanced HEAD passes `52/52`.

### Bassline in-screen progression selection

- Bassline Echo now exposes a `コード進行` / `Chord progression` selector in the main challenge header.
- The selector includes the existing deterministic `Dm7 – G7 – Cmaj7` default and every supported complete one- or two-bar 4/4 section from the current Vault.
- App code converts current Vault sources into detached immutable snapshots before they cross into Practice. Unsupported sources are omitted; raw MIDI, source paths, titles, and mutable Vault objects do not cross the boundary.
- Changing progression stops and disposes current bass/chord playback, restores the selected source BPM, resets hints/review and stale recording facts, and never writes to Vault.
- Explicit Chord Context feature-flag `false` hides the selector together with the P5.18 controls and preserves the P5.16 Bassline surface.
- Unit coverage verifies safe catalog construction, default/Vault switching, BPM/chord updates, playback cleanup, and rollback. Production Playwright creates a saved progression and switches Vault → default → Vault inside Bassline Echo.

### Rhythm preparation Stop

- Stop during asynchronous audio preparation returns the session to `ready`.
- Late preparation completion is ignored and cannot restart the stopped session.
- Preparation errors fail safely instead of leaving the UI stuck.
- A deferred-preparation regression test proves that the user can start again after Stop.

### Bassline chord timbre and final click

- Chord Context offers session-only `Electric` and `Piano` chord timbres; Japanese labels are `エレクトリック` and `ピアノ`.
- Electric remains the default and rollback behavior is unchanged.
- Piano is a deterministic offline Tone synth preset; it does not add an external CDN, runtime download, or new audio asset.
- Natural completion retains the audio graph for a 550 ms release tail so the final envelope is not truncated. Manual Stop and route disposal remain immediate and safe.
- Automated tests prove timbre selection and release-tail lifecycle. Musical timbre quality and absence of a perceived click remain human listening checks.

### Single scroll owner

- `html`, `body`, and `#root` are viewport-sized and explicitly non-scrolling.
- `#main-content` is the only vertical app content scroll owner.
- Production Playwright verifies outer overflow is hidden, root equals viewport height, and main is independently scrollable.
- The full Playwright run initially exposed an E2E lazy-load race; the final test waits for Degree Echo before measuring layout. The current exact final HEAD passes 52/52.

## Playback, data, and privacy contracts

- Chord Context remains isolated from shared Chord Preview, Chord Dojo, Live MIDI, Analyzer, and MIDI Exporter.
- Play modes never schedule target bass. No-accompaniment allocates no playback player.
- Replay, natural completion, errors, Stop, Review, route leave, tab leave, and unmount release owned resources.
- Vault input crosses only as a detached immutable snapshot. Vault schema and source content are not mutated.
- History stores factual safe metadata and an optional opaque retained-take reference; raw audio, device IDs, source paths, and private MIDI are not stored.
- Production `enableBassPracticeChordContext` default remains `true`; explicit local `false` rollback remains non-destructive.
