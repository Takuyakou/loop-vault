Flow: Listen→Identify→Sing→Play→Review→Transfer. Objective History and self-rated History are separate. Allowed: 4th up first-answer 8/10. Forbidden: Root Motion skill 80. Legacy History remains readable.
## P5.19-00 contract lock

- Root Motion History is a separate versioned factual collection. It records a safe source kind/reference or snapshot signature, generator and root-path-policy versions, configuration, expected motions, immutable first-answer facts, assistance, replay/attempt counts, separate self-rating, and an optional existing opaque retained-take reference.
- It must not contain a Vault title, raw audio, device identifier, filesystem path, source MIDI, or a derived composite score.
- Existing legacy Practice files stay readable through an optional/defaulted empty Root Motion collection. This additive Practice-data work must retain the current `fileVersion: 1` unless a later stage proves a migration is essential and receives separate approval.
- Objective and self-rated evidence are rendered and queried separately.
