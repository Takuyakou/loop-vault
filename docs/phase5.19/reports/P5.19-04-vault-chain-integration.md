## Implementation / Findings

- Root Motion accepts only a validated, detached Vault chord-context snapshot; it never reads live Vault data while a practice session runs.
- The source extracts pitch classes only. It produces a deterministic, canonical root path rather than an original bassline.
- Level 1–3 use the first two roots; Level 4 uses three roots; Level 5 uses four roots and preserves the existing Transfer contract.
- Repeated roots use `0`; direction uses the locked `-5..+6` signed policy, including `C → G = -5` and tritone `+6`.
- Each selected pitch is represented only by the canonical fingering solver’s legal, in-range position.
- The UI offers Generated Root Motion and a Vault-derived root path only when a safe snapshot is available. It explicitly discloses: “Vault-derived root path — not an original bassline.”
- Source identifiers are safe logical references and snapshot signatures only. No title, source path, raw MIDI, audio, or live Vault mutation crosses into the exercise.
- If the chosen snapshot is removed from the available catalog, the UI safely returns to Generated Root Motion; invalid or unplayable input fails closed with an explicit unavailable result.
