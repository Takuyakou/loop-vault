## CaptureDraft / save

- `src/views/CaptureView.tsx` is the only Capture route and currently offers
  MIDI selection only. P5.20 adds an input mode inside it, not a route.
- `src/domain/midi/manualDraft.ts` exposes a session-only `ManualCandidateDraft`;
  it is the existing Draft authority after an explicit conversion.
- `src/domain/midi/manualDraftEditing.ts`, `CaptureView`, and existing edit
  history supply Quick Editor, timing edits, Undo/Redo, preview, and Save.
- `src/store/vaultStore.ts:createIdeaFromDraft()` is the normal save bridge.
  Text must omit `progressionAnalysis` and `progressionMetadata.sourcePath` so
  no source asset, filename, fingerprint, or MIDI provenance is persisted.
- A P5.20 title must derive from canonical labels and optional confirmed key,
  not a filename or MIDI-oriented capture title helper.

## Parser / identity / timing / key

- `src/domain/chords.ts:parseChordLabel()` and `labelFromSymbol()` are the
  canonical absolute-label parser/formatter. `src/domain/chordIdentity.ts`
  provides spelling-independent identity.
- `src/domain/progressionEditing/fastLabelEntry.ts:parseFastChordEntry()`
  accepts one absolute/Roman/numeric chord with a supplied valid key; it is not
  a progression lexer and needs a transient P5.20 parser wrapper.
- `src/domain/midi/candidateBlock.ts` and existing persisted timeline use numeric
  beat/duration fields. Capture range UI remains whole-beat oriented.
- Grammar v1 is therefore 4/4 only, exact 1/2/4 chords per bar, and rejects
  3-chord bars rather than approximating 4/3 beats. `N.C.` is rejected because
  the existing preview path does not prove silent text-rest playback.
- Existing MIDI `detectedKey` has no confirmation state. P5.20 adds only a
  transient unknown/inferred/confirmed boundary; inferred candidates never
  resolve Roman input or persist as confirmed key.

## ProgressionGrid / cards

- `src/ui/ProgressionGrid.tsx` already provides bar grouping, duration-weighted
  chord segments, selection, playback progress, and responsive grid tokens.
- `src/components/progression-editing/EditableProgressionGrid.tsx` and the
  existing Capture/detail card language are the reuse basis. P5.20 adds a
  compact variant/adapter where necessary; it does not duplicate a large card
  system.

## Voicing

- `src/domain/chordVoicing.ts:voiceChordForPreview()` is deterministic,
  per-chord Auto generation. It is not a progression-aware voice-leading or
  common-tone optimiser.
- Existing `practiceVoicingOverride` supports exact fileVersion 1 Live MIDI
  notes and is compatible with the Draft edit/save bridge. **Custom Voicing is
  AUTHORIZED only through that existing capture path.**
- Text has no source MIDI. `sourceVoicing` extraction/re-extraction and any
  original-MIDI claim are prohibited.

## Capability

- Vault Save, Chord Dojo, and Voicing Memory: supported through existing normal
  block/override paths.
- Bass Practice and Chord Context: conditional on confirmed key, BPM 30–240,
  4/4, exact contiguous complete 1/2/4/8/12-bar timing, and at most 48 events.
- Root Motion: conditional on an eligible Chord Context snapshot and sufficient
  roots; it uses roots/timing only, not Custom Voicing or an alleged bassline.
