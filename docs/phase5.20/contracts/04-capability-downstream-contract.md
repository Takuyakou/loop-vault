# Contract 04 — Capability / Downstream

Each output is evaluated independently as `supported`, `unsupported`, or
`unknown` with a factual reason. A text progression can be valid for Vault Save
while ineligible for a practice feature.

| Consumer | Stage00 contract |
| --- | --- |
| Vault Save | Supported for a valid Draft through the existing normal save path. |
| Chord Dojo | Supported for a normally saved valid block; preserves a compatible practice override. |
| Bass Practice / Chord Context | Conditional: confirmed key, BPM 30–240, 4/4, contiguous complete 1/2/4/8/12-bar section, valid exact timing, and at most 48 chord events. |
| Root Motion | Conditional after an eligible Chord Context snapshot and enough selected roots for the chosen chain. It never treats a text card or Custom Voicing as an original bassline. |
| Voicing Memory | Supported for Auto fallback and compatible Live MIDI practice overrides in normal Vault/Detail/Home/Chord Dojo playback. |

The evaluator must not use a global boolean that hides these distinct outcomes.
