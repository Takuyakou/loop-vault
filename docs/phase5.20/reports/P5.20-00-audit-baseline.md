## Determination

`IN PROGRESS — audit-and-contract commit will be followed by exact-HEAD baseline gates`

## Locked decisions

- P5.20 is a second Capture input mode, not a new route or storage model.
- Text is authoritative only until explicit one-way conversion to the existing
  session-only Draft; Draft is authoritative thereafter.
- Grammar v1 is bounded 4/4 with bar/simple notation, 1/2/4 chords per bar,
  canonical absolute labels, and confirmed-key-only Roman/numeric entries.
- Invalid tokens, `N.C.`, empty/three-chord bars, unsupported repeat syntax,
  and overflow remain diagnostics and block conversion.
- Key is transient unknown/inferred/confirmed. Only confirmed keys support Roman
  input, degree display, or persistence.
- Auto Voicing is existing deterministic per-chord generation. Custom Voicing
  is AUTHORIZED only through existing Live MIDI `practiceVoicingOverride`;
  source-MIDI claims and new persistence are prohibited.
- Vault save remains separate from Bass Practice/Chord Context/Root Motion
  eligibility.
