## Capture UI

- Added the Text Progression entry mode inside the existing Capture route. It
  does not start MIDI analysis, clear a MIDI result, or require a source MIDI
  result to be present.
- The input is bounded by the P5.20 grammar and uses compact, bar-grouped
  cards. Invalid source tokens remain visible with an actionable diagnostic;
  conversion remains unavailable until the complete input is valid.
- The key, BPM, preview, mode exit, and draft conversion paths stop active
  playback before changing state.
- The input-mode selector and invalid-input feedback have keyboard semantics
  and linked error descriptions. Japanese UI wording is supplied for the
  P5.20 diagnostics and capability states.

## Compact cards and Voicing Inspector

- Preview uses the text-entry timeline and explicit preview notes only; it
  does not represent source MIDI analysis.
- Auto voicing is labelled as generated from the text entry. Source-MIDI
  recovery or missing-source claims are suppressed because a text entry has no
  source MIDI by design.
- A compatible, valid Live MIDI simultaneous voicing may be retained as a
  practice-only custom override. Other provenance, incompatible timing, and
  malformed overrides are rejected.
- Confidence `0` remains the no-analysis sentinel and is not presented as a
  review score for this workflow.

## Draft bridge

- Text is authoritative only until explicit conversion. The conversion creates
  a session-only Capture Draft, after which the Draft is authoritative; no
  two-way synchronisation is introduced.
- Text-created drafts use the strict 4/4 timing contract and disable
  structural Quick Editor edits that could create unsupported bar groupings.
- Save uses the existing `SavedProgressionBlock` surface with truthful
  text-parser provenance. It does not add a Vault schema migration, source
  asset/path/fingerprint, raw MIDI, analyzer confidence, or a new persisted
  progression type.
- Initial titles are canonical chord labels with an optional confirmed key;
  the existing explicit save-title edit remains supported.
