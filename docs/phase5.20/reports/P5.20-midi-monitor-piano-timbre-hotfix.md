# P5.20 MIDI Piano Monitor Timbre Hotfix

## Final determination

`PASS — sampled piano monitor accepted on hardware`

The P5.20 Live MIDI voicing-capture monitor previously used a `Tone.Synth`
triangle oscillator with an amplitude envelope. The implementation described it
as piano-like, but it was an electronic synthesizer and therefore did not meet
the product expectation for a piano monitor.

## Fix

- Replaced the oscillator monitor with a `Tone.Sampler` using eight bundled
  Salamander Grand Piano V3 MP3 roots (`A0`, `C1` through `C7`).
- Removed the electronic-synth fallback. If bundled sample decode or preload
  fails, piano monitoring is reported unavailable while MIDI capture remains
  usable.
- Preserved exact note-on, note-off, held-note de-duplication, stop, confirm,
  retry, cancel, card/mode/route change, and unmount disposal behavior.
- Kept routing through the existing global destination/master volume.
- Added CC BY 3.0 license, fixed upstream provenance, SHA-256 manifest, asset
  integrity tests, and About-screen attribution.
- Runtime CDN/download dependency: 0. All eight samples are present in the Web
  production graph and Tauri bundle.
