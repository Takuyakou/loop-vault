Both manifests use `ChordDripCorpusManifest` with `schemaVersion: 1`.
A manifest contains generator/recipe provenance and `files`; each file requires
`caseId`, `midiFile`, `generationRecord`, and an exact `chordTimeline`. Optional
integrity fields are `midiSha256`, byte length, rendered-note count, and clip
length. Dirty-manifest files may additionally contain `sourceCaseId` and
`degradation` (`id`, report category, seed, transforms). The evaluator resolves
each `midiFile` relative to the directory containing that manifest. The
manifests are not inferred, generated, or replaced by placeholders.

## Privacy-safe local ground-truth helper

The support-only command is:

```text
npx vite-node scripts/p521/generateRoleGroundTruthTemplate.ts --midi "<local-midi-file>" --fixture-id fixture-<anonymous-id>
```

It writes a new JSON template under the ignored
`.local-evaluation/p521-role-ground-truth/` directory. The output includes only:

- an anonymous fixture ID;
- deterministic Voice ID/index, track index, and MIDI channel;
- safe program-derived label, dominant program, program list, and program-change flag;
- note count, pitch range, average duration, average polyphony, and drum flag;
- the current product automatic role; and
- empty `expectedRole` plus an optional local human-review note.

Allowed human labels are `bass`, `harmony`, `pad`, `melody`, `percussion`,
`mixed`, and `ambiguous`. The script never derives `expectedRole` from the
classifier: all rows begin with `null`. It does not write raw MIDI, source paths,
source/track titles, raw note events, audio, recordings, or device identifiers.
It refuses output outside `.local-evaluation` and refuses to overwrite an
existing template.
