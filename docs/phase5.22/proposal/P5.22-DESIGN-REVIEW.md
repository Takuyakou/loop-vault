# P5.22 Design Review — B+

## Overall judgment

Source Bassline Practiceは次の大きな機能として価値が高い。
案Aの元MIDI再読込より、案Bのdetached snapshotを採用する。

ただし原提案をそのまま採用せず、B+へ修正する。

## Adopted

- Bassline Echoのsourceとして追加
- user-selected bass Voice
- block/section範囲のみ
- raw MIDI/path/nameを保存しない
- source snapshotをVault exportへ含める
- L1/L2をL3から決定的導出
- existing blocksは遡及生成しない
- Record & Compare reuse

## Changed

### 1. Persist all notes

同時発音を最低音へ潰すのは不可逆。
Snapshotは全note eventを保持する。
Practice engineが単音のみなら、practice時にprojectionして明示する。

### 2. fileVersion is evidence-based

optional fieldだからv1維持、とは決めない。
旧アプリround-tripで消えるならv2が安全。

### 3. Exact timing is audited

三連符等を含む実音価を守るため、float beatで十分か検証する。

### 4. Add independent budgets

12 barsでも悪意あるnote countは作れる。
note/serialized-byte capが必要。

### 5. Explicit user opt-in

Source BasslineはVault exportへ含まれる音楽データ。
保存toggleはdefault OFF、Voiceを人間が確定する。

### 6. Snapshot immutable after edits

コード進行編集でsource notesを書き換えない。
Mismatchを表示し、derivation/Chord Contextを安全に制限する。

### 7. Transfer meaning remains stable

次区間は前/次ボタン。
Transferを別概念にしない。

## Additional design risk

Level1/2にはchord contextが必要。
現在のProgressionBlockが編集可能なため、Stage00で以下のいずれかを固定する。

- captured harmony signature/contextを安全に保持
- current blockとの互換signatureが一致する場合のみ導出
- L1/L2を延期しL3だけ出す

現在の変更後進行を黙って「元ラインの簡略版」の根拠にしない。
