## Scope / Findings

- Bassline Echoへ既存の「生成ベースライン」と明示的な「ソース・ベースライン」選択を追加した。source catalogはcurrent Chord Context catalogから独立し、presentation-onlyのnormalized title、logical idea/block reference、strict detached `SourceBasslineSnapshotV1`を扱う。UI stateはlogical referenceだけを保持してnote arrayを複製せず、Source modeと保存済みsource referenceの両方をユーザーが明示選択する。先頭候補を暗黙選択せず、current chord/key/time-signatureが後からunsupportedになっても選択済みvalid immutable sourceはLevel 3で利用できる。invalid/future local blockは既存store recovery/quarantine境界でcatalogから除外され、Practiceはstrict assetの欠落/利用不可だけを表示し、per-reference corrupt reasonを推測しない。silent fallbackやsilent selectionは行わない。
- snapshotはVault pickerからtransient viewへdetached valueとして渡し、永続snapshotを変更・補完・再保存しない。current progression編集後も同じlogical idea/blockに保持されたsnapshotをsource authorityとし、snapshot自身のchord factsをcurrent chordへ推測変換しない。
- 1小節/2小節window、前/次navigation、最終partial window、empty windowをexact rational timingで実装した。cropを先に行い、その後だけLevel 3のdeterministic monophonic projectionを適用する。同一onsetはlowest pitch、longer clipped duration、higher velocity、canonical source orderでtie-breakし、次の採用onsetでdurationをclipする。
- UIはsource Levelを固定の「Source line (monophonic)」として開示し、cropped source note数、projected target数、boundary clip、simultaneous omission、overlap duration clip、actual bar rangeを表示する。empty windowではlisten/hint/review/recordを無効化し、理由要素を`aria-describedby`で参照する。前/次はedgeでfocusableな`aria-disabled` controlとなり、操作後も呼び出した同じcontrolへfocusを保持する。
- preview/stopとChord Contextは既存audio lifecycleを再利用した。source/progression/window/level変更、Record & Compare再生開始、unmountに加え、外部からのactive/source snapshot削除、store recovery/quarantineによるcatalog除外、replacement、range/signature変更でもstale playbackを停止・破棄し、review/record facts、hint、windowを安全にinvalidate/resetする。
- captured harmonyがstrictかつwindow全体を連続coverageする時だけ、snapshot内のcanonical pitch classesをそのままChord Contextへ渡す。欠落、不完全、conflicting facts、target bass range unsafeではlocalized reason付きでChord Contextだけを無効化し、Record & Compare単体は使用可能なままにする。
- source snapshotはtempoを保持しないため、Source modeのtempoはactive/generated progressionの「original」と主張せず、localizedなsession default 96 BPMとして表示・resetする。generated/preset/Vault progression modeの既存Original semanticsは変更しない。
- source targetをRecord & Compareの既存target playerへ接続し、Record & Compareとretained takesの全copyをJA/ENで揃えた。source modeはHistory保存UIを追加せず、Historyへ書き込まない。
- JA/EN copy、native semantic controls、label、実在要素を参照する`aria-describedby`、`aria-live`、keyboard/focus retentionをcomponent testsで固定した。匿名synthetic fixtureを使うproduction Playwrightで320 CSS pxと200% zoom（effective 320 CSS px）のhorizontal overflowがないことも確認した。
