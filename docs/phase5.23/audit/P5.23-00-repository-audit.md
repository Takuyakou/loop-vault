## Locked grouping
- Relation: `overlapCoefficient >= 0.75` AND `min(startDistance,endDistance,centerDistance) <= 2 bars`. IoU is diagnostic only.
- Anchor order: earlier start → later end → stable ID.
- Add only candidates directly related to the fixed anchor; never transitively expand. Chain result is A+B, then C.
- Preservation: `flatten(groups)` ID multiset equals input, each ID reachable exactly once.
- Representative: longest → higher candidate score → earlier start → earlier end → stable ID.
- Selected variant: finite `selectionScore` (fallback to `confidence` when absent/non-finite) → higher `confidence` → earlier start → shorter length → earlier end → stable ID.
- Nested fixture deliberately displays 16 bars while selecting the higher-scoring 8 bars.
- Exact visible labels: JA `<length>小節 · Bar <start>–<end>`; EN `<length> bars · Bars <start>–<end>`. Exact accessible names: JA `候補グループ <g>、バリアント <v>。<length>小節、Bar <start>–<end>`; EN `Candidate group <g>, variant <v>. <length> bars, Bars <start>–<end>`.
