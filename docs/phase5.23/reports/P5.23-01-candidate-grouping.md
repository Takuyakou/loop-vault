## Grouping
A pure presentation helper applies the locked inclusive interval relation: overlap coefficient at least `.75` and minimum start/end/center distance at most 2 bars. Candidates are processed by earlier start, later end, then stable ID. Membership is direct to the fixed anchor only, so the chain trap does not expand transitively.

Each group exposes a deterministic display representative (longest, higher finite selection score with confidence fallback, earlier start/end, stable ID) and an independently computed selected variant (finite selection score with confidence fallback, higher confidence, earlier start, shorter length, earlier end, stable ID).

## Candidate preservation
The Full Timeline renders one primary bar per group using the representative range. Opening a multi-candidate group exposes every grouped candidate exactly once, with no candidate generation, ranking, count, scoring, or boundary mutation. Focused tests verify deterministic reverse-input output, exact flattened ID preservation, and distinct representative/selected-variant results.

## Variant interaction
Opening, hovering, or focusing a group does not invoke the existing candidate selection callback. The trigger exposes active-group state with `aria-pressed` even while the selector is closed. Opening by pointer or Enter moves focus to the deterministic selected variant; Escape and the explicit close control dismiss without changing the Capture range and restore trigger focus. The analysis identity plus run generation scopes open state, so a replacement dataset invalidates the selector even when the same anchor ID reappears. A commit-synchronous callback-ref lifecycle tracks the committed dataset key and mounted state, preventing a pending pointer activation from firing after a committed dataset replacement or unmount without allowing speculative/aborted renders to suppress a valid activation. Keyboard Enter activates exactly once and restores trigger focus. Pointer single activation is committed after the double-click transaction window and restores trigger focus; a double click cancels the pending single activation, closes first, then invokes the existing reveal/focus callback exactly once so candidate-card focus remains final. The active variant also carries a visible non-color check marker while preserving the exact visible label.
