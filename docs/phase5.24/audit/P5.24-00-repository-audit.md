## Fragment contract

## Metrics
- Fragmentation Ratio: detected harmonic states / ground-truth harmonic states.
- Change Precision: one-to-one matched predicted changes / predicted changes.
- Change Recall: one-to-one matched predicted changes / expected changes.
- False Merge Rate: unmatched expected changes / expected changes.
- Over-segmentation Rate: max(0, detected states - expected states) / expected states.
- Identity Error Rate: unmatched semantic state identities / ground-truth states; identity is exact label plus normalized PC set.
- Bass Lane failures: non-equivalent fixture count plus unsupported stable/transient evidence violations.
- cardinality lock: A1/B1/C2/D2/E4/F2/G2/H1/I1/J2/K6 ground-truth states; expected changes are exactly states minus one.
- boundary tolerance: inclusive `0.25` quarter-note beat, with sorted two-pointer maximum-cardinality one-to-one matching.
- J timing: any stable predicted boundary before the synthetic ground-truth boundary is independently counted and rejected, even within tolerance.
- zero-denominator policy: no expected changes gives recall 1; precision is 1 only when predicted changes are also empty, otherwise 0. Extra predicted boundaries fail through Over-segmentation.
