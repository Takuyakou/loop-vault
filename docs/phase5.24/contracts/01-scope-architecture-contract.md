- derived Harmonic State layer
- Harmonic Rhythm evidence
- Voice-internal Bass Lane
- Fragment Consolidator
- Shadow evaluation

- Product Acceptance

Must not:
- mutate raw/display MIDI
- quantize notes
- rewrite tempo map
- implement Local harmonic rhythm
- change chord vocabulary
- change candidate scoring/ranking formula
- change Vault schema/fileVersion
- implement candidate diversification
