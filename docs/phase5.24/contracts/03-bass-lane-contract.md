# Contract 03 — Voice-internal Bass Lane

Do not use minimum pitch per attack.

Bass State evidence may include:
- low-register rank
- duration
- strong-beat presence
- temporal continuity
- repeated/stepwise relation
- upper-texture separation
- compatible role prior

Bass PC movement alone is not a harmonic-change signal.

A strong Bass State transition requires persistence and contextual support.

Every A-K expected and predicted Bass Lane result must:
- be explicitly present
- cover the full fixture with finite contiguous states
- use stable/transient pitch classes in 0..11 without duplicates or stable/transient collision
- relate every stable Bass State to Bass Lane note evidence in its interval
- exactly match the locked synthetic Bass Lane truth for promotion
- report zero unsupported stable/transient evidence safety violations
- use a deterministic pitch-class interval index/sweep; never scan every note for every Bass State

Missing, corrupt, incomplete, non-equivalent, or unsupported Bass Lane evidence fails
promotion.

Protect:
- walking bass
- passing bass
- pedal bass
- inversion
- upper-texture minimum trap
