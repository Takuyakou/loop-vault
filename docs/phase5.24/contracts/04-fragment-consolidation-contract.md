# Contract 04 — Performance Fragment Consolidation

PC subset/superset is supporting evidence only.
Never merge solely because A is a subset of B.

Same-state evidence may include:
- same harmonic-rhythm cell
- stable Bass State
- PC compatibility
- temporal continuity
- repeated support

Strong-change evidence may include:
- persistent new PC
- persistent Bass State transition
- stable new texture
- HR cell boundary
- strong metric boundary + subsequent persistence

Persistent structural C→Cmaj7 and C→Am7 remain true changes.
Transient tension flutter must not automatically create a stable state.
Conflicts fail conservatively.
