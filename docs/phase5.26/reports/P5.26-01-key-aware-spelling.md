# P5.26-01 — Key-aware Spelling

## Determination
`PASS — COMPLETE AT EXACT IMPLEMENTATION COMMIT`

## Target cases
- Added runtime-only `enableKeyAwareChordSpelling?: boolean`; omission, `false`, and non-literal values preserve exact legacy analysis output. There is no user-facing setting.
- In E major, diatonic roots use `E F# G# A B C# D#`; `Ab7` identity renders `G#7`.
- Slash bass resolves generic degrees from the existing `ChordQuality` plus tensions. It respells only when the bass pitch class matches one unique generic degree; zero matches, multiple degrees, and unsupported runtime qualities retain the legacy bass spelling.
- Quality-sensitive locks include `E/Ab` -> `E/G#`, `G#aug/E` -> `G#aug/D##`, `G#dim7/F` unchanged, and `Caug/Ab` -> `Caug/G#`. The non-member tritone remains `E/Bb`.
- `Amaj7/B` and `E6/9` remain unchanged. `b9` and `b13` tokens remain unchanged.
- Non-diatonic E-major roots retain the legacy surface; focused negatives lock `C` and `Bb`, preventing a global sharp-key rewrite.
- The adapter runs after analyzer selection, accuracy candidate union, and P5.24 consolidation version selection.
- A version suffix, `+p526-key-aware-spelling-v1`, is appended only when at least one label changes.

## PC identity invariance
The adapter changes only `ChordSymbol.label`, derived candidate summaries, and `analyzerVersion` when a spelling actually changes. The test deep-compares the complete analysis after normalizing only those fields, so timing/duration, confidence, raw match evidence, warnings, candidate stats/quality/ranges, occurrence timing/stats/transpose/sections, identities, signatures, and recommendation data are all automatically protected.

All runtime display surfaces are covered:
- `fullTimeline` primary and alternatives
- `blockCandidates` chords, event chords, event sources, and `summaryText`
- `candidatePatterns` occurrence event chords and sources
- `candidateCatalog` pattern occurrence event chords and sources

The layered synthetic surface-spelling metric improves from `9/10` to `10/10` eligible slots. Other metric axes are not changed by this stage.

## Unknown-key fallback
Missing, `unknown`, and unsupported-mode keys return the original analysis object and identical JSON. A recognized key with no spelling change also returns the original object and does not alter `analyzerVersion`.

## Persistence impact
The adapter is analysis-runtime-only. A focused integration executes the existing `createVaultStore` -> `appendBlockToIdea` -> save-projection path from an enabled analysis and verifies the persisted candidate contains `E/G#` and the spelling analyzer suffix. An existing `SavedProgressionBlock` object and its serialized value remain deep-equal. The written Vault stays `fileVersion = 2`; schemas and migrations are unchanged.
