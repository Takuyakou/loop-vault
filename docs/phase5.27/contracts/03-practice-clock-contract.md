# Contract 03 — Single Practice Clock

One musical transport drives:
- current chord
- next chord
- beat
- progression progress
- loop count
- playback timing

No independent UI timers.

Must support:
- count-in
- BPM change
- pause/resume
- restart
- 1/2/4 chords per bar
- mixed durations
- last→first loop
- long-running deterministic operation
