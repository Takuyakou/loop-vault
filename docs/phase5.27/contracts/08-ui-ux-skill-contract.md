# Contract 08 — UI / UX Skill

Production user-facing UI work must use:

`$emil-design-eng`

Install reference:
`npx skills@latest add emilkowalski/skills`

Optional:
- `$prototype` only for materially different UI alternatives
- `$review-animations` only when meaningful motion is added

Existing Loop Vault product/accessibility contracts override generic skill advice.
