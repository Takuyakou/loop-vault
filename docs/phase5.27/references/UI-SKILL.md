# Codex UI Skill Reference

Source:
Emil Kowalski — `emilkowalski/skills`

Install:

```bash
npx skills@latest add emilkowalski/skills
```

P5.27 required Skill:

```text
$emil-design-eng
```

Use for:
- hierarchy
- control polish
- interaction details
- restrained motion
- UI review

Optional:

```text
$prototype
```

only when multiple materially different UI alternatives are required.

```text
$review-animations
```

only after meaningful animation implementation.

P5.27 principle:
frequent practice UI should feel immediate and calm.
Do not animate merely because the Skill discusses animation.
