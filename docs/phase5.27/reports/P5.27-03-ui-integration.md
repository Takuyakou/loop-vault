## MY / LESSON selector

- MY: Source MIDI and Custom.
- LESSON: Basic Shell 1–7, Basic Full 1–7–3, and Left-hand.
- The component accepts detached snapshots keyed by explicit selection. A
  missing selection renders an unavailable entry state; it never resolves a
  different family.
- Current-event resolution preserves all Stage02 status distinctions and
  disables Start unless every event is playable. Every unresolved event is
  listed before playback.
- When one MY snapshot proves a progression is loaded, switching to a missing
  Source MIDI or Custom snapshot shows explicit unavailable rather than the
  no-progression entry state.

## Current / Next

- Both derive from `projectProgressionPracticeClock` using the same absolute
  Tone Transport beat used to schedule audio. Audio, click, and Draw projection
  all convert the callback time with `getTicksAtTime(time) / PPQ`; UI lookahead
  never advances the visible chord early.
- Current is the dominant heading and Next is secondary.
- The progression strip marks Current with `aria-current="step"` and is not a
  second seek/timer mechanism.

## Beat / Progress / Loop

- Beat number and text are visible; color is never the only state signal.
- Chord progress, progression progress, Current/Next, count-in, and Loop count
  are one domain projection from one Transport callback.
- Count-in is an initial Start/Restart offset. Audio event repeats use only the
  progression length, so last-to-first loops do not repeat count-in.
- Pause retains Transport position and disposes scheduled-ahead instruments;
  Resume recreates instruments without rebuilding the Transport schedule. BPM
  ramps the same Transport; Restart seeks that same schedule to zero.
- Pending Start/audition promises carry a generation token. Pause, Stop,
  Restart, source/rule changes, and unmount invalidate stale continuations.
- Reference audition cannot supersede a pending full-session Start.
- BPM and metronome changes made while `Tone.start()` is pending are retained as
  desired state and applied before the Transport begins.
- An instance stops/cancels the shared Tone Transport only while it owns that
  Transport. Mount and unowned cleanup cannot interrupt another practice mode.
- All MIDI lease callers consume `ready` rejection. Voicing Loop remains
  non-blocking because monitoring is optional; Chord Dojo exposes localized
  failure and explicit Reconnect retry; capture and mini mode safely unwind.

## Learn / Recall

- Learn shows exact pitch/octave and degree facts plus keyboard guide notes.
- Recall shows the chord identity while hiding note names and guide notes.
- Neither state scores, gates, advances, or stores performance.

## Keyboard

- Reuses `PianoKeyboardVisualizer` and the existing adaptive practice range.
- Live MIDI held/sustained notes are optional visual monitoring only.
- Neutral-monitor mode omits correct/missing/foreign scoring copy and scoring
  ARIA while leaving the Chord Dojo default unchanged.
- MIDI is activated opportunistically through the shared serialized lease used
  by Chord Dojo, App mini mode, and voicing capture; no device connection is
  required to enable Start. Pre-active sessions remain owned by their original
  consumer, and manager-owned partial activation is cleaned up after failure.

## Accessibility

- Practice tabs implement roving focus with ArrowLeft/ArrowRight/Home/End over
  two or three available modes.
- Selector and Learn/Recall states expose `aria-pressed`; progress meters expose
  labels and numeric values; status changes use existing live-region
  primitives; transport icons have adjacent text.
- Learn/Recall is a localized control group. A dedicated polite live region
  announces the current chord only when the chord boundary changes.
- The horizontally scrollable keyboard region is focusable without turning its
  individual decorative keys into tab stops.
- Focused Playwright proves keyboard navigation, no viewport overflow at 320px,
  effective 200% scale, and zero serious/critical axe violations on the routed
  Stage03 entry surface.
