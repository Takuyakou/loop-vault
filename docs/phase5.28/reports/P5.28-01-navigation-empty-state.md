## Adopted implementation

- Sidebar remains flat. A native `SidebarItem` named `Voicing Loop` sits immediately after
  `Practice` and reuses the existing icon size, 40 px minimum height, focus-visible behavior,
  collapsed accessible label/title, color transition, and active indicator.
- `Practice` is not `aria-current` while `Voicing Loop` is active. Chord Dojo and Bass Practice
  continue to use the generic `Practice` destination.
- The direct handler passes through `requestProgressionLeave`. Only its permitted callback clears
  `voicingPracticeHandoff`, `practiceTarget`, and `chordContextSnapshot`, then selects
  `practiceMode = voicing-loop` and `view = practice`. Reselecting the direct item therefore
  replaces a loaded session with the empty key rather than reviving stale state.
- Source-less Voicing Loop renders the existing `SectionHeading` and `EmptyState` with localized
  `My Vaultから選ぶ` and `Textで進行を入力` buttons. Source badge, MY/LESSON selectors,
  transport, and error/warning UI are absent until a progression exists. The CTA row wraps.
- My Vault routes through the existing Vault row → Progression Detail → Voicing Loop handoff.
  Text uses a mount-only `initialInputMode` seam. Normal Chord Capture still mounts in MIDI mode.
- Live MIDI acquisition is guarded by `progressionLoaded`. Empty mount acquires zero leases;
  loaded → empty releases the old lease once and does not reacquire.
- Existing P5.27 handoff builders/resolvers were not changed. Saved duration, key, BPM, exact
  Source MIDI / Custom pitch and octave, explicit unavailable, and no-silent-fallback contracts
  continue through the same path.

## `$emil-design-eng` review

| Before | After | Why |
| --- | --- | --- |
| Generic `Practice` was the only sidebar route into all practice modes | One flat `Voicing Loop` item follows `Practice` | Matches the existing navigation language without introducing hierarchy for one shortcut |
| Source-less view exposed a Source badge and MY/LESSON controls | Heading plus actionable existing `EmptyState`; source controls appear only after load | Removes misleading affordances and keeps the next action obvious |
| Empty guidance described Vault but offered no action | Primary My Vault CTA and secondary Text CTA use existing `Button` variants | Makes both supported paths immediately keyboard-operable |
| A loaded same-route session could remain when the shortcut was selected | Direct event handler clears all transient Practice sources inside the leave guard callback | Invisible lifecycle correctness prevents accidental stale practice |
| Empty view acquired Live MIDI | Lease acquisition now requires a loaded progression | The source-less screen owns no practice resource and cleanup stays deterministic |
| A new shortcut could add decorative motion | No new animation, token, keyframe, spring, or CSS rule | Frequent keyboard navigation should feel immediate and honor the existing reduced-motion contract |
