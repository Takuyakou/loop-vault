# P5.28-04 — Inline Vault Selection Implementation

## Outcome

COMPLETE — FOCUSED GATES PASS

The source-less Voicing Loop now presents eligible saved Vault progressions in
the practice screen itself. A native row button performs the existing P5.27
Vault handoff immediately, reducing the saved-progression path from three
clicks to one without changing the loaded practice workspace.

## UI review

| Before | After | Why |
| --- | --- | --- |
| Open the Vault picker, find a progression, open its detail, then start Voicing Loop | Search or choose a compact progression row directly in Voicing Loop | Removes the modal/page detour from a frequent practice flow |
| Large primary Vault and Text actions | Saved progressions are primary; Text is a quiet secondary action | Matches the requested task hierarchy |
| No direct recency signal | Up to five recently practiced logical references appear first | Makes repeated practice fast without creating Practice History |
| Source-less copy only | Title, Key, BPM, and compact chord preview use existing tokens and primitives | Preserves Loop Vault's visual language and avoids exposing memo or source data |

The list uses native buttons, explicit focus styling, no interaction animation,
wrapping content, and existing responsive tokens. The optional previous-session
resume card was intentionally omitted because reconstructing session preferences
would expand persistence scope.

## Data and lifecycle

- Candidate eligibility and click-time validation both use
  buildProgressionVoicingPracticeHandoffFromVault.
- Search reuses the existing Vault query normalizer and searches only title,
  chord labels, and Key.
- Recent progressions are stored under
  loop-vault:voicing-loop-recents:v1 as at most five ideaId/blockId references.
  No Vault schema or fileVersion changes were made.
- Duplicate references are moved to the front rather than added again.
- Deleted or invalid recent references are pruned against the current eligible
  candidate set.
- A failed click-time validation does not update recent state.
- Existing view cleanup stops the prior transport before the source-less
  selector is rendered. No new asynchronous source-loading path was introduced.
- The existing Vault picker remains unchanged for the Bass Practice workflow.

## P5.27 regression

The loaded P5.27 practice workspace remains unchanged, including Source MIDI,
Custom, Basic Shell, Basic Full, Left-hand, clock, transport, loop, metronome,
count-in, keyboard visualization, and no-scoring behavior. Existing Vault and
Text handoffs continue through the same handoff builder.
