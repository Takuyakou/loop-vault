# P5.29-01 — Harmonic Rhythm Strengthening

## Outcome

The existing Text, Vault, detached snapshot, single Practice Clock and Tone
Transport pipeline already retained variable durations. No clock, timer,
playback engine, voicing generator, schema or migration change was required.

The canonical `| Cmaj9 | Am9 Dm9 | G13 | Cmaj9 |` fixture now locks:

- Text events: 4, 2, 2, 4, 4 beats
- saved and reloaded Vault events: 4, 2, 2, 4, 4 beats
- Source MIDI, Custom, Basic Shell, Basic Full and Left-hand snapshots: identical
  starts `[0, 4, 6, 8, 12]` and durations `[4, 2, 2, 4, 4]`
- Current, Next, Beat, progression position and last-to-first Loop projection
- reference playback boundaries on the same 192 PPQ grid

## UI review

| Before | After | Why |
| --- | --- | --- |
| Progression chip showed only index and chord | Chip also shows practice bar, onset beat and duration | Half-bar and one-beat changes are visible before Start |
| Timing could have been copied into view state | Label derives directly from the detached snapshot | Prevents UI/clock drift and adds no timer |
| High-frequency practice surface | No animation added | Keeps keyboard and repeated practice interaction immediate |

At 320px the chips wrap within the existing flex strip. The compact metadata
uses existing colors, spacing and focus semantics; no design system or motion
was added.
