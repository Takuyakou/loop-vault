# UI Skill Requirement

P5.30 changes user-facing Voicing Loop UI.

Use the installed Emil Kowalski design-engineering skill as `$emil-design-eng` when available. The skill is advisory: repository product contracts, existing Loop Vault visual language, accessibility requirements, and the user-approved mock take precedence.

Do not use the skill as justification for a broad redesign. The user explicitly prefers Loop Vault's current compact/slim density.

Hard visual rule: **active/current timeline cards never grow**. Keep fixed geometry and communicate state with border/background/playhead instead.

`$prototype` is unnecessary unless a materially different UI alternative must be compared. `$review-animations` is unnecessary unless new nontrivial animation is introduced beyond the transport playhead projection.
