# P5.30-03 — Audio interactions

## Outcome

PASS. Timeline cards now audition their own currently selected resolved voicing,
and the transport exposes a session-local `お手本音` checkbox. Both paths reuse
the existing resolver, synth ownership and Tone Transport; no clock, generator,
schema or persisted preference was added.

## Card audition

- Each playable 92 × 46 timeline card is a native button with visible keyboard
  focus and an accessible name containing position, chord, duration and audition
  intent.
- Click/Enter auditions the selected mode's resolved MIDI pitches through the
  same transport preview method as the current-code button.
- Audition does not seek, start or stop transport, change current/next/loop, or
  mutate Vault data.
- Unavailable Source/Custom and unsupported generated states remain disabled and
  fail closed; no fallback was introduced.
- The last auditioned state changes only border/background and preserves fixed
  geometry.

## Reference sound

- New sessions default ON in React session state and do not write storage.
- ON uses the already scheduled harmonic boundaries and attacks exactly one
  selected resolved voicing at each boundary after count-in.
- OFF suppresses every automatic voicing attack while metronome and visual
  projection continue normally; manual audition remains available while idle.
- Turning OFF releases the currently owned voicing immediately.
- Pause disposes owned instruments, Resume re-articulates at most once only when
  ON, and Stop/exit/source switch invalidate schedules and dispose resources.

## Regression and lifecycle evidence

- Source MIDI, Custom, Basic Shell, Basic Full and Left-hand resolver suites use
  unchanged timing and exact/no-fallback semantics.
- Pending Start, Pause/Resume, Restart, stale draw callbacks, 30 musical-minute
  projection and 20 rapid lifecycle cycles remain covered.
- Focused browser coverage confirms keyboard card audition, clock position
  invariance, audition geometry, default ON, OFF visual progression, 128-event
  scrolling and accessibility.
