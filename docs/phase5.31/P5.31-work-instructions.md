## P5.31-02 — Re-strike / Rest / Hold

Implement `%`, `_`, `=` through the existing timing model.

Requirements:

- `%` generates a new attack of previous chord;
- `_` produces a silent time span;
- `=` extends previous sounding chord with no attack;
- only 1/2/4 cells per 4/4 bar;
- no 3-cell invented duration;
- timing remains exact after save/reload;
- reference sound:
  - attack/re-strike => sounds,
  - hold => does not re-trigger,
  - rest => silence;
- card audition remains independent of transport;
- playhead remains coherent through rest/hold;
- no resource leak/stuck notes.

Use a single timing source. Do not add a second timer.

Tests:
- `E 7%_A m7|=G`;
- hold across bar boundary;
- invalid leading `%`;
- invalid leading `=`;
- `=` after rest => explicit invalid;
- repeated same chord via ordinary text vs `%` preserves attack distinction;
- route leave / restart / BPM / loop lifecycle.
