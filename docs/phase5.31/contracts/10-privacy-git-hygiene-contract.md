# Contract 10 — Privacy / Git Hygiene

- no private MIDI/audio fixture in Git;
- no real ReChord user account/session data;
- only synthetic/user-supplied text fixture in this package;
- no absolute personal paths in reports;
- `.local-evaluation` remains ignored;
- generated test/build output not staged;
- do not restore `docs/CURRENT_STATE.md`;
- no reset/stash/discard;
- explicit-path staging;
- no `git add -A` or `git add .`;
- no merge/push/tag/release without separate authorization.
