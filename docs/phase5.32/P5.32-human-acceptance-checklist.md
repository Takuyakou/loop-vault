# P5.32 Human Acceptance Checklist

After P5.32-04 automated PASS:

1. Open Voicing Loop with a saved progression.
2. Confirm all six Voicing buttons remain available, including Full Shell:
   - Source MIDI
   - Custom
   - Basic Shell
   - Basic Full
   - Full Shell
   - Left-hand
3. In Source/Custom/Basic Full/Full Shell, switch RH/LH and confirm:
   - pitches do not change merely because fingering display changes hand unless
     the underlying product mode itself resolves a different hand-specific target;
   - finger labels update R/L correctly.
4. Confirm Left-hand locks LH.
   Confirm Basic Shell also uses its left-hand-only target.
5. Confirm CURRENT shows:
   - chord
   - pitch
   - degree
   - suggested/personal finger numbers.
6. Confirm NEXT previews its fingering.
7. Confirm keyboard shows note + `R1/L5` style finger labels.
8. Toggle `おすすめ運指` OFF/ON.
9. Use `この運指を保存` if persistence is enabled.
10. Restart the app and confirm personal fingering reloads.
11. Reset the personal fingering and confirm Suggested returns.
12. Try Dm9→G13:
    - fingering remains stable/useful rather than visibly random;
    - common-tone connection is understandable.
13. Check a chord with black-key thumb candidate; confirm it is not rejected merely
    because the thumb is on a black key.
14. Check >5 one-hand keys:
    - exact voicing remains;
    - fingering honestly reports unavailable.
15. If P5.31 is integrated, verify:
    - `%` reuses fingering,
    - `_` clears fingering,
    - `=` holds/inherits.
16. Pause/Restart/Stop/route leave:
    - no stuck audio;
    - no clock desync.
17. 320px / 200% / keyboard-only / reduced motion remain usable.

Human acceptance does not authorize merge/push/release.
