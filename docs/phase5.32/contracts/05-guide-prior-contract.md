# Contract 05 — Guide-derived Priors

Use as first-choice priors, not truth:

- triad root: RH 1-3-5 / LH 5-3-1
- triad first inversion: RH 1-2-5 / LH 5-3-1
- triad second inversion: RH 1-3-5 / LH 5-2-1
- two-note guide tones: RH 1-5 / LH 5-1
- four-note jazz/rootless start: RH 1-2-3-5 / LH 5-3-2-1
- three-note LH shell: 5-3-1

Do not label a candidate wrong merely because it differs from these priors.
