# Contract 09 — P5.31 Integration

If P5.31 is integrated:

- `%` re-strike => same fingering as prior resolved chord;
- `=` hold => inherits; no new decision;
- `_` rest => no fingering target;
- slash identity remains intact.

For approved `Upper Structure + Separate Slash Bass` Left-hand policy:
- finger numbers apply only to actual LH target notes;
- separate Bass reference is not assigned a fake LH finger.

For Source MIDI / Custom, an exact saved slash Bass that is part of the selected
voicing remains an L target with its own finger while the chord identity stays
X/Y. This does not change the special Left-hand Lesson policy above.
