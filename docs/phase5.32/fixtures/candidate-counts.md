# Candidate Count Expectations

For one hand with N distinct simultaneous keys:

| N | candidates |
|---:|---:|
| 1 | 5 |
| 2 | 10 |
| 3 | 10 |
| 4 | 5 |
| 5 | 1 |
| >5 | unsupported suggestion |

RH candidates are ascending low→high.
LH candidates are descending low→high.

Do not generate permutations.
