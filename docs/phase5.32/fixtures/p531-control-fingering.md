# P5.31 Control-cell Fingering Fixture

If P5.31 control tokens are integrated, create a fixture equivalent to:

```text
E7 % _ Am7 | = G
```

Fingering facts:

- first E7 attack gets a normal suggestion;
- `%` reuses the exact same E7 fingering;
- `_` has no fingering target;
- Am7 gets a suggestion;
- `=` inherits the Am7 fingering with no new decision;
- G gets a new suggestion.

The fingering layer must not alter the control-token timeline.
