the integrated Full Shell mode; canonical P5.32 documents now protect all six.

| Mode | Exact resolved pitches | R valid | L valid | Suggestion input |

  boundary. Fingering consumes its `SUPPORTED` output only.
- `ProgressionVoicingPracticeView` owns the single clock projection and the
  Current/Next and slim timeline composition.

  are metadata passed into it and must not change its range or active pitches.
- `ProgressionVoicingTransport` remains the only playback clock/transport.

### Persistence determination

Persistence is authorized without a breaking migration. `SavedProgressionBlock.practice`
would mutate Vault and is therefore not used. The existing versioned app-local
Voicing Practice preference repository pattern provides a safe extension point:
a new dedicated optional/defaulted and bounded v1 collection may store only
hand, sorted unique absolute MIDI pitches, finger array, and optional timestamps.
It must not change Vault schema/fileVersion or the existing strict three-field
Voicing Practice preference payload. Corrupt/future data fails to defaults.
