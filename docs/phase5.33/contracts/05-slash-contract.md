# Contract 05 — Slash Chords

For `X/Y`:

- upper/root remains X;
- specified bass remains Y;
- degree labels use X unless explicitly analysis-only metadata says otherwise;
- do not add a lower X root under Y;
- do not automatically rename to a bass-root interpretation.

First-wave golden cases:
- C/E
- Eadd9/F#
- Dadd9/E
- Am9/C
- Am11/B
- Gmaj9/A
- D/C
- C6/9 parser distinction
