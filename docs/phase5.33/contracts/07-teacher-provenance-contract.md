# Contract 07 — Teacher Provenance

Teacher evidence, external theory, and analysis proposal are separate.

If a teacher source says `RH = 3 + Melody` but the current progression has no
Melody layer:

- do not invent a note and call it teacher Melody;
- if the app proposes a top note, call it `Top Candidate`;
- preserve provenance in rule metadata/report.

Concrete octaves/fingers from the research pack are proposals unless directly
supported by teacher evidence.
