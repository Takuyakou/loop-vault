- rule family;
- coverage;
- candidate n/N;
- LEFT HAND;
- RIGHT HAND;
- RULE;
- OMIT;
- TOP.

- `なし` when none;
- explicit degree(s) for Reduction.

`TOP` role must distinguish:
- fixed Melody;
- app Top Candidate;
- normal voicing top.
