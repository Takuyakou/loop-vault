1. compact SOURCE/STUDY/DISPLAY toolbar;

- PROGRESSION timeline geometry/behavior.

The full HTML research mock remains an interaction/reference artifact. Its lower
PROGRESSION/KEYBOARD/TRANSPORT styling is not adopted wholesale.

- same 88-key geometry everywhere;
- no mode-specific zoom/crop/size;
- Start row becomes easier to operate;
