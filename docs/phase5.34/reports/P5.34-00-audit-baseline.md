## 1. Where time signature enters

CONFIRMED.

- `src/domain/midi/rawSmf.ts` collects time-signature meta events and defaults to `[4,4]` when absent (`orderedTimeSignatures[0]?.value ?? [4, 4]`).
- `src/domain/midi/parser.ts` computes `barLengthBeats = beatsPerBar(timeSignature)` and `totalBars = max(1, ceil(totalBeats / barLengthBeats))`.
- `src/domain/midi/timing.ts` `beatsPerBar` = `numerator * 4 / denominator`, default `[4,4]` → 4, invalid input → 4.

Meter drives the window grid and bar/beat labels. It is **not** a direct
authority for harmony boundaries in the default `phase4-v1`/`legacy` lane, except
that the P5.24/P5.26 consolidation paths require `"4/4"` and reject anything
else with `reason: "unsupported-meter"` (`harmonicStateConsolidation.ts`,
`localHarmonicStateIntegration.ts`).

## 2. Whether meter creates cells before harmonic inference

CONFIRMED — yes.

- `src/domain/midi/legacy.ts` `buildWeightedWindows` builds a fixed `beatsPerWindow` (default `2`) grid over `totalBeats = totalBars * barLengthBeats`.
- Cells (windows) are built **before** chord identity is assigned; `matchWindowWithRankingScore` runs afterwards per window, then `smoothTimelineWithRankingScores`.
- `AnalyzeMidiOptions.beatsPerWindow?: 1 | 2 | 4` is the only grid knob.

## 3. Where empty `—` cells arise

CONFIRMED.

- `src/domain/progressionText.ts` `formatBar` returns `"-"` when a bar has zero timeline items.
- This is **label-absence**, not "segmentation covered bars with no notes": a note-less window still yields a `C` maj fallback with `confidence: 0.2` and a `sparse-evidence` warning (`legacy.ts` empty-histogram fallback).
- `-` cells therefore appear when the item array passed to the text formatter has no entry for a bar (empty `fullTimeline`, a block candidate that omits a bar, or a manual/draft range).

## 4. Where boundaries are created

CONFIRMED.

- Default/`phase4-v1` lane: the window grid itself (`legacy.ts`), then `smoothTimelineWithRankingScores` — an A-B-A smoother (low-confidence middle chord overwritten) plus adjacent same-label merge.
- P5.24 (`harmonicStateConsolidation.ts` → `fragmentConsolidatorCore.ts`): cell boundaries at an estimated global harmonic-rhythm period (1/2/4/8), per-cell state identity, `merge-same-state` vs `split-strong-change`.
- P5.26 (`localHarmonicStateIntegration.ts` → `localHarmonicStateShadow.ts`): one cell per beat, `decideBoundary` with `merge-same-state` vs `split-structural-change`.
- `src/domain/timelineHarmonicActivity.ts` is a downstream **reporter** (per-bar activity levels), not a boundary engine.

## 5. What counts as simultaneous / active

CONFIRMED.

- A note is "active" in a window if any part of its duration overlaps it: `note.startTick < endTick && note.startTick + note.durationTick > startTick` (`legacy.ts` `overlaps`).
- Weight is proportional to overlap duration (`overlapBeats`) times role/range/velocity/beat-position factors; a `simultaneityBonus` (1.2) applies when 3+ notes overlap.

## 6. Whether onsets are clustered

CONFIRMED — no.

- There is **no onset clustering / tolerance / quantization** in the analyzer. Onset grouping uses exact `toFixed(6)` beats (`segmentation.ts` `groupOnsets`) or exact `startBeat` keys (`shadowEvidence.ts`).
- Grid-alignment checks exist only as ratios/flags (`metricAlignmentSupport`, `metricStrength`), not as clustering.
- Consequence for experiment D: there is **no existing tolerance seam**; D requires either pre-clustering/re-timing notes into `preparedData` or a new option.

## 7. Structural bass assignment

CONFIRMED.

- Voice/track role: `inferTrackRoles` (`legacy.ts`) — bass when `avgPitch < 52 && avgDuration >= 0.7`; channel 9 forced percussion.
- Legacy bass pitch class: `bassPc = maxIndex(window.bassHistogram)`; slash bass only when `bassPc !== root && pcs.includes(bassPc)`.
- Hybrid/reranker: `bassPc = maxIndex(profile.bassPcs)` with `bassCompatibilityScore` / `slashCompatibilityScore`.
- P5.24/P5.26 keep explicit structural-bass estimation (`estimateP524BassLane`, `retainedBassAfterMerge`).

## 8. Re-strike representation

CONFIRMED.

- `rawSmf.ts` pairs noteOn/noteOff via a FIFO queue keyed by `(trackIndex, channel, pitch)`; repeated same-pitch onsets stack and are paired in order.
- A re-strike of the same chord does **not** create a boundary in the default lane (boundaries are grid-fixed), nor in P5.24/P5.26 (re-strikes only feed attack counts / onset slots).

## 9. P5.24 / P5.26 suppression paths

CONFIRMED.

- `ornaments.ts` flags passing/neighbor/chromatic-approach/short-upper-voice notes with weight penalties, but is applied **only** in `hybrid` / `legacy-boundary-rerank` / `voice-aware-rerank` lanes — not in the default `phase4-v1`/`legacy` lane.
- P5.24 `fragmentConsolidator.ts` merges a boundary for a "locally supported non-persistent" added pitch class (transient bass + low coverage + single attack), reason `local-transient-partial-voicing`. Fires only when `enableHarmonicStateConsolidation` is literal-true and meter is `4/4`.
- P5.26 `localHarmonicStateShadow.ts` retains only structural bass (`retainedBassAfterMerge`), dropping weak transient/approach bass (`bassPersistence < 0.5`).
- Both record a `reason` / `fallbackReason` when they do not fire.

## 10. Fallback conditions

CONFIRMED.

- Closed 21-quality vocabulary (`ChordQuality`). `parseChordLabel` / `parseQuality` return `null` on unparseable tokens.
- Empty histogram → `previous ?? makeChordSymbol(0, "maj")` with `confidence: 0.2`.
- `candidates.ts` `scoreStructuredChordCandidate` **throws** on an unsupported quality.
- `chordFactorization.ts` `symbolFromFactorized` returns `undefined` when the closed vocabulary cannot express the parts (explicit no-silent-rounding seam).
- P5.24 `identifyP524HarmonicState` returns `undefined` on unrepresentable/ambiguous state → `unsupported-harmonic-identity`.

## 11. Canonical identity / representability utilities

CONFIRMED.

- `chords.ts` — `parseChordLabel` / `makeChordSymbol` / `labelFromSymbol` (canonical parse↔render).
- `chordIdentity.ts` — spelling-independent `NormalizedChordIdentity`, `chordIdentityKey`, `chordIdentitiesEqual`.
- `chordFactorization.ts` — factorize + `symbolFromFactorized` (unrepresentable → `undefined`).
- `chordAlternatives.ts` — dedup/rank alternatives; `canonicalChordAlternative`.
- `voicing/normalizeVoicing.ts` — `normalizeMidiNotes`, `normalizedChordKey`.
- `voicingRules/goldenCorpus.ts` — S01–S16 with `representable` + `deferredReason`.
- `midi/candidates.ts` `canonicalChord` (hybrid/reranker dedup); `harmonicState/harmonicIdentity.ts` (P5.24 identity).

## 12. How A/B/C/D can run with production behavior unchanged

CONFIRMED.

- **A** — `analyzeMidi(bytes)` (default `phase4-v1`) or `{ mode: "legacy" }`.
- **B** — pass a `preparedData` whose `timeSignature` is forced `"4/4"` (and `totalBars`/`ticksPerBeat` accordingly); or enable `enableHarmonicStateConsolidation` (which itself enforces `4/4`). No product change.
- **C** — `beatsPerWindow` + a synthesized `preparedData` that decouples the grid from the real meter (`buildWeightedWindows` reads only `timeSignature`/`totalBars`/`ticksPerBeat`).
- **D** — **no existing seam** for onset tolerance. Requires either pre-clustering/re-timing notes into `preparedData`, or a new diagnostic option (shadow-only).

The existing shadow pattern (`run-shadow-diagnostics.ts`, `shadowEvidence.ts`, `shadowTension.ts`, `walkingBassShadow.ts`) runs a side estimator and records differences without changing `analyzeMidi` output — the intended pattern for P5.34.
