## Executive conclusion

LF-MIDI-001 is **two independent problems**, not one:

1. **Meter-driven downstream fragmentation** (bar/block/text), CONFIRMED. The
   harmonic segmentation is stable; only the meter-derived bar indexing,
   block sliding, and formatted text fragment.
2. **Contextual chord-identity failure** (slash-chord mislabeling), driven by
   window contamination and candidate ranking under mixed evidence. This is
   unrelated to meter and unrelated to vocabulary.

The refined causal mechanism for (2) is:

```text
2-beat window (duration-overlap note inclusion)
  → sustained/overlapping notes from adjacent harmonies contaminate the histogram
  → broad templates (min11 / dom13 / slash) "cover" more of the smeared pitch classes
  → the correct narrow chord (Bm7) is generated but loses on ranking
  → the structural bass is assigned as a slash bass on the wrong root
```

## CONFIRMED

- **Meter-driven downstream fragmentation.** A(1/4)=bar 65/dash 46 vs B(4/4)=bar 17/dash 1,
  with identical `smoothedTimelineItemCount=19` and `boundaryCount=18`.
- **Window/context contamination.** Slash-chord windows have 7–10 distinct
  histogram pitch classes vs 5–6 in clean windows (local `diagnoseLegacyWindowCandidates`),
  i.e. sustained/overlapping notes from adjacent harmonies smear the window.
- **Candidate ranking under mixed evidence.** The correct narrow chord is
  generated (minor-7-family candidate present in every window) but loses to the
  broad slash chord when the histogram is contaminated.

## SUPPORTED-HYPOTHESIS

- **Structural bass association.** In the slash mislabels the bass pitch class is
  often the "correct" root (e.g. B), but is assigned as a slash bass on the wrong
  root (Am11/B instead of Bm7). Consistent with bass-as-slash rather than
  bass-as-root, but the bass signal alone does not uniquely explain the ranking.
- **Representability / closed vocabulary (altered-dominant family only).**
  S02 `G7(#9,b13,no5)` is only partially representable; the real `G7`/`Eb…/G`
  states are this limit surfacing in context, not a ranking defect.

## REJECTED-HYPOTHESIS

- **Meter/harmony segmentation coupling.** Harmonic boundaries (bnd=18) are
  identical under 1/4 and 4/4.
- **Onset jitter.** D tolerance sweep (1–12 ticks) changes nothing.
- **Candidate generation.** All real identities are representable and generated;
  generation is not the failure point.
- **Representability as the primary failure.** 12/12 distinct identities parse;
  the dominant failure is ranking under contamination, not vocabulary (altered
  dominant is the sole representability-limited family).
- **Bass re-strike as a boundary primitive.** Synthetic T05 shows no boundary
  effect; not isolated on the real file (see UNRESOLVED).

## UNRESOLVED

- Whether the slash mislabels are better fixed at segmentation (note weighting /
  windowing) or ranking (over-coverage penalty / narrowest-consistent-chord
  preference) — the diagnostic shows both contribute; their relative weight is
  not yet isolated.
- Bass re-strike effect on the real file (not separately measured).
- Fallback quality when an exact identity is unavailable (e.g. altered dominant).
