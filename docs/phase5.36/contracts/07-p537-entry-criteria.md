# Contract 07 — P5.37 Entry Criteria

P5.37 is intended as the final production-fix/integration phase candidate.

P5.36 may recommend P5.37 only if it can state an exact implementation target supported by evidence, such as:

```text
A. meter-normalized harmonic-grid fix
B. attack/sub-state evidence partition
C. root/slash ranking fix under mixed current attacks
D. another explicitly demonstrated mechanism
```

Proposal must identify:
- exact production seam;
- what changes / does not change;
- shadow/prototype evidence;
- hard regression gates;
- rollback path;
- private fixture acceptance;
- synthetic corpus acceptance.

Do not recommend a vague "improve analyzer" phase. If causal target remains ambiguous, P5.37 is not ready.
