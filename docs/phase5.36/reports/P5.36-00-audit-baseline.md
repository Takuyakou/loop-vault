## Audit answers (seams; all read-only)

1. **2-beat window creation:** `buildWeightedWindows(data, roles, durationBeats=2)`
   — `src/domain/midi/legacy.ts:353`. Iterates `startBeat` in steps of
   `durationBeats` over `totalBars × beatsPerBar(timeSignature)`.
2. **Attack accumulation:** the same function sums a per-note weight
   (`overlapBeats × beatPositionFactor × rangeFactor × velocityFactor × roleFactor
   × simultaneityBonus`) into `histogram[pc]` for **every overlapping note**, with
   no attack-vs-sustain and no sub-state distinction. Attack detection itself is
   available shadow-side from `classifyWindow` (`scripts/p535/temporalEvidence.ts`).
3. **1/4 meter effect:** `beatsPerBar("1/4") = 1` (`src/domain/midi/timing.ts`), so
   `barLengthBeats = 1`; a 2-beat window spans **2 source bars**, and `bar =
   floor(startBeat/1)+1`. Many source sub-bars collapse into one wide histogram.
4. **Same notes under diagnostic 4/4 (no mutation):** `withMeterView(data, num,
   den)` (`scripts/p534/isolationCore.ts:75`) returns a copy with
   `timeSignature`/`totalBars` changed and **notes untouched**; `matchWindow`
   (exported) scores the resulting windows. A/B is possible with pitch/start/dur/
   velocity/PPQ/tempo/order/mode/options held identical (work-instr §6).
5. **Top-N candidate scoring read-only:** `diagnoseLegacyWindowCandidates(bytes,
   scoring)` (`legacy.ts:240`) → per window `{bar, beat, durationBeats, totalWeight,
   noteCount, histogram?, bassHistogram?, candidates:[{chord, rawScore,
   qualityCoverage}]}`. No production change.
6. **Root/bass/slash components:** `chord.bass` on each candidate `ChordSymbol`;
   `bassPc = maxIndex(bassHistogram)`; slash set when `bassPc ≠ root ∧ pcs.includes
   (bassPc)` (`scoreTemplates`, `legacy.ts:677`). All readable via the diagnostic.
7. **1-beat buckets (no production change):** `buildWeightedWindows(data, roles,
   1)` or `buildMeterIndependentWindows(data, roles, 1)`
   (`scripts/p534/isolationCore.ts:118`) — shadow only.
8. **Deterministic attack clusters:** `snapOnsets(data, toleranceTicks)`
   (`isolationCore.ts:188`) + the P5.35 attack-set logic — diagnostic only.
9. **Reusable fixtures:** `scripts/p534/fixtures.ts` (`chordFixture`,
   `progressionFixture`, `timingFixtures` T01–T08), `scripts/p534/isolationCore.ts`
   (`instrument`, `withMeterView`, `buildMeterIndependentWindows`, `snapOnsets`),
   `scripts/p535/fixtures.ts` (contamination / held / common-tone / slash / etc.),
   `scripts/p535/{temporalEvidence,shadowRanking}.ts` (classifier + shadow ranking).
10. **LF-MIDI-001 availability:** available via the approved ignored-local
