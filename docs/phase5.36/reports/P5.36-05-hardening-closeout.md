## Critical existing blocker (frozen)

The existing local-harmonic-state path is **hard-gated to 4/4**:
`prepareLocalHarmonicStateAnalyzerOptions` returns
`{applied:false, reason:"unsupported-meter"}` when `timeSignature !== "4/4"`, and
the input builder hardcodes `meter:[4,4]` / `totalBeats = totalBars * 4`. This is
why it cannot currently address the 1/4 private fixture. P5.37's job is to
**remove/generalize this restriction safely** — **not** to rewrite 1/4 MIDI into
4/4. The source meter fact must remain intact.

## Legacy rollback semantics (frozen)

`enableLocalHarmonicStateConsolidation = OFF → exact legacy behavior`; every
`unsupported-*` / `legacy-fallback` reason returns legacy output. P5.37 must
preserve this OFF = legacy fallback through integration and the promotion period;
flipping the default is a P5.37-acceptance decision only.
