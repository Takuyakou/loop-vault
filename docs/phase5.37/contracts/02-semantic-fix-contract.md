# Contract 02 — Semantic Fix Contract

## Confirmed cause

```text
fixed 2-beat aggregate
+ multiple distinct local harmonic states
→ chimera evidence
→ wrong-root/broad-slash winner
```

## Desired behavior
When a strong local harmonic-state change exists inside the legacy evidence region, partition/consolidate into coherent local states and rank each coherent state with existing harmonic identity machinery.
When no meaningful change exists, preserve one harmonic state.

## Mandatory safety
Do not over-split same-chord re-attack, rolled chord, arpeggiated chord, layered extended harmony, genuine slash/inversion, syncopated chord attack, held/pad/legato harmony, or common-tone transitions.

## Meter independence
Eligibility must not depend on exact 4/4 unless a concrete algorithmic requirement is demonstrated. Source time-signature metadata remains unchanged.

## Candidate/scorer reuse
Preferred target: state segmentation changes; candidate vocabulary/scorer/bass extraction unchanged. If insufficient, stop and document rather than silently changing ranking.
