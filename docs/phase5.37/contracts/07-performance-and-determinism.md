# Contract 07 — Performance / Determinism

Correctness > modest runtime increase > raw speed.
The algorithm must have a documented bound in terms of notes/windows/boundary candidates/harmonic states/candidate evaluations. No combinatorial explosion.

Stress tests should cover long progressions, dense repeated attacks, sustained harmony, many safe re-attacks, alternating true changes.
Tie handling must be explicit and stable; no clock/random dependence.
