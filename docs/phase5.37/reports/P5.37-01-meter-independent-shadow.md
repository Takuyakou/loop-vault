## New shadow architecture

`scripts/p537/unionChimera.ts` — `analyzeUnionChimera(data, roles, {minBucketPcs})`.
It reuses, unchanged, the P5.36-03 parity-guarded scorer replica
(`../p536/shadowScore`) and the W2/B0/B1 decomposition (`../p536/subwindow`) — the
**same candidate set and the same scorer** production uses, with candidate
generation vs ranking already separated. It adds only a bounded **trigger** and, for
triggered windows, a local-evidence **partition** into the two beats' coherent
candidates. It changes no candidate vocabulary, scorer, or bass extraction, and no
production behavior. It is **not** a global 1-beat split — untriggered windows keep
the exact legacy W2 result.

## Oracle-independence

The trigger reads only runtime observations: W2/B0/B1 candidate rankings (from the
parity replica), the W2-winner's per-beat candidate support, and per-beat pitch-class
evidence counts. No expected/known chord, and no private truth, enters the trigger,
partition, candidate generation, scoring, or bucket selection. `root wins neither
beat` is recorded as *runtime* evidence (compared candidate rankings), never as an
oracle rule.

## Candidate parity

on 21/21 fixture and 98/98 LF windows; the parity guard is test-locked by

is introduced.

## Frozen policy (frozen before the private evaluation)

- **Policy version:** union-chimera v1.
- **Trigger** = all of: (A) W2 winner is top-1 in neither non-empty beat; (B) — folded
  into A via label inequality with both beat winners; (C) the two beats' top-1 roots
  are materially different identities; (D) the W2 winner's defining support spans
  BOTH beats; (F) each beat carries ≥ `minBucketPcs` distinct pitch classes
  (`minBucketPcs = 3`, a triad's worth — the coherence / analyzable requirement).
- **Support-spans-both:** the winner's matched chord tones are distributed across B0
  and B1 (not merely "notes exist in both beats").
- **Coherence rule:** a beat with `< 3` distinct pitch classes is not treated as a
  harmony (`insufficient-bucket-evidence`).
- **Fallback:** any condition unmet → `legacy-coherent` / `same-state-reattack` /
  `buckets-same-identity` / `support-not-spanning` / `insufficient-bucket-evidence`,
  all keep the exact legacy W2 result.
- **Boundary:** baseline B0/B1 at the integer mid-beat (attack-cluster boundary
  refinement deferred — no algorithm proliferation).
- **Reason codes:** `legacy-coherent`, `union-chimera-detected`,
  `insufficient-bucket-evidence`, `same-state-reattack`, `buckets-same-identity`,
  `support-not-spanning`. Deterministic.

The threshold (`minBucketPcs = 3`) was frozen on synthetic + hard-negative evidence
**before** any LF-MIDI-001 inspection.

## Determinism / boundedness / source immutability

- Deterministic: identical output across runs (test-locked); no clock/random; fixed

- Bounded: per window, W2 + B0 + B1 over the fixed candidate set (reused

  attack-cluster fallback added (deferred).
- Source-immutable: `data` (incl. pitch/onset/duration/velocity/PPQ/tempo/meter) is
  never mutated (test-locked).
