## Evaluated policy (frozen, not retuned)

Union-chimera policy **v1**, `minBucketPcs = 3` (P5.37-01). Trigger = W2 winner wins
top-1 in **neither** beat **AND** B0/B1 are materially different coherent identities
**AND** the winner's support spans **both** beats **AND** each beat has ≥3 distinct
PCs. TRUE → partition into the two beats' coherent candidates; FALSE → exact legacy
W2. No threshold / trigger / scorer / partition change was made in Stage-02.

analyzer flow using only read-only seams: `diagnoseLegacyWindowCandidates(bytes,
phase4-quality-scoring)` for the pre-smoothing per-window items + the exported

FINAL timeline after downstream smoothing/consolidation.
