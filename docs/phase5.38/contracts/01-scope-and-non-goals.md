# Contract 01 — Scope / Non-Goals

## In scope

Family A downstream representation/grouping:
- bar count used by progression rendering;
- block grouping;
- formatted progression text;
- dash / placeholder emission caused by meter-derived fragmentation;
- explicit separation of source-bar truth from presentation grouping if required.

## Protected / out of scope

Do not alter:
- union-chimera policy v1;
- candidate vocabulary;
- candidate generation;
- scoreTemplates / matchWindow semantics;
- bass extraction;
- source notes;
- source time signature;
- Vault schema/fileVersion unless unavoidable and explicitly authorized;
- Source Voicing / Source Bassline;
- playback;
- UI redesign;
- Family C vocabulary/representability.

## Success is not cosmetic

A fix that only deletes `-` from text but leaves incorrect block/group topology is insufficient.
