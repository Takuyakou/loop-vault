## Placeholder and block semantics

The meanings remain independent:

- `-`: no event starts in a formatted cell;
- `—`: a true carry-in sustain across a block cell boundary;
- `N.C.`: no event overlaps the block cell.

The synthetic dash reduction comes from fewer event-derived presentation cells,
not marker substitution.

Applied and fallback block audits confirm monotonic boundaries, original item
order, positive range-bounded relative timing, exact structured signatures,
cell/summary agreement, and source-object provenance. This safety evidence does
not compensate for Gate A failure.

## Failure interpretation

This result does **not** mean source/presentation separation is invalid. The
Stage01 architecture is viable and its safety properties hold.

The precise result is:

```text
runtime-only presentation projection architecture is viable

BUT

frozen fragmentation-detection policy v1 is too conservative for LF-MIDI-001
and fails the required private improvement gate
```

The 0.44 result must not be converted into a lower numeric cutoff merely to pass
the fixture.

## Next shadow research questions (proposal only)

No new policy is implemented in this stage. A separately authorized shadow
redesign should investigate:

1. Is multi-source-group harmonic-span ratio actually necessary to recognize
   Family-A fragmentation?
2. Can occupied-start ratio, dash ratio, event-start topology, and
   source-group/event-span mismatch form a structural relation without a brittle
   single threshold?
3. Can the trigger distinguish genuine one-beat meter through topology rather
   than requiring one fixture-sensitive duration proportion?
4. Can the already-proven event-derived projection remain unchanged while only
   trigger evidence is redesigned against public-safe positive and hard-negative
   controls before any private evaluation?

This is a research direction, not authorization to implement Shadow v2.
