## Counterfactual guards

Before v2 can apply, it builds the same pure projection counterfactually and
requires both:

```text
candidate formatted groups < legacy formatted groups
candidate dash cells      < legacy dash cells
```

An input that does not structurally improve never receives the candidate
projection. The counterfactual neither mutates source data nor writes a runtime
result.

## Placeholder and block semantics

Meanings remain independent:

- `-`: no event starts in a presentation/source cell;
- `—`: an event truly sustains across the cell boundary;
- `N.C.`: no event overlaps the cell.

The LF reduction from 40 to 0 dash cells comes only from fewer
event-start-oriented presentation cells. No marker is replaced or hidden.

Projected blocks are accepted only with monotonic group/absolute-beat bounds,
positive range-bounded relative timing, original item order, matching
structured signatures, matching cell summaries, and original source-object
provenance.

## PresentationGroup semantics

```text
PresentationGroup != source bar
PresentationGroup != rewritten meter bar
```

## P5.38-03 production integration proposal

This proposal is documentation only. It is not implementation authorization.

### Exact module seam

Move the shared pure projection architecture and promoted v2 trigger from the
P5.38 research scripts into one downstream domain module that consumes the
already-resolved post-P5.37 `fullTimeline`, truthful source grouping metadata,
and already-selected legacy block candidates. It must not be called from MIDI
parsing, candidate generation, ranking, smoothing, or Family-B partitioning.

### Shared pure projection strategy

Maintain one pure implementation for:

```text
fragmentation evidence
-> frozen v2 applicability
-> PresentationGroup[]
-> formatted cells/text
-> projected presentation blocks
```

Research and production tests should exercise identical policy semantics. Do
not fork a UI-specific trigger or rebuild projection logic per consumer.

### Feature flag and fallback

Use a reversible Family-A presentation-grouping seam:

```text
enabled  -> frozen promoted v2 policy
disabled -> exact legacy source-group presentation
```

The flag must affect presentation consumers only. Unsupported meters, weak
evidence, hard negatives, failed counterfactual guards, or explicit OFF all
return exact legacy behavior.

### Initial presentation consumers

Limit initial integration to:

- formatted progression text;
- candidate-card presentation summaries;
- downstream presentation block topology.

### Source-truth consumers

Continue using source coordinates for:

- source meter/bar metadata;
- saved chord events and block coordinates;
- source timing and provenance;
- persistence and export.

### UI consumers requiring separate care

`SongMiniMap` and `ProgressionGrid` must not replace source bars with
`PresentationGroup` objects. Their integration should be excluded from the
initial text/block seam unless a separate UI contract explicitly represents
variable-duration harmonic spans without calling them bars.

### Save and persistence invariants

Persist no `PresentationGroup`. Save original source-coordinate timeline and
block data under the existing schema and `fileVersion`. No migration.

### Family B invariants

Keep `enableUnionChimeraPartition` default-on, explicit-off rollback, trigger,
`minBucketPcs`, scorer, vocabulary, bass handling, and final identities
unchanged. The Family-A module consumes only its output.

### Required production tests

- v2 positive and hard-negative topology matrix;
- exact legacy OFF fallback;
- exact 4/4, 3/4, and 2/4 parity;
- genuine 1/4 fail closed;
- source-coordinate and persistence round-trip;
- placeholder and block semantics;
- Family B exact regression;
- deterministic/bounded projection;
- focused downstream text/card/block consumers;
- official regression and privacy checks.

### Rollback

Disable the Family-A presentation seam to restore exact legacy downstream
grouping. Rollback must require no schema migration or saved-data rewrite.

### Production contract

```text
PresentationGroup is not a bar.
```

No production consumer may relabel it as source meter truth.
