## Consumer Effectiveness

PASS. Stage03 exposed a runtime projection but Capture candidate presentation
still used the legacy catalog/shortlist. Stage04 adds a presentation-only
consumer adapter and uses it for:

- formatted progression text used by candidate copy;
- candidate-card presentation summaries;
- the visible candidate-card block topology and count.

Each presentation card retains a direct reference to its original source
candidate. Edit, preview, save, voicing, export, source coordinates, and draft
selection continue to use that source candidate. Invalid projected provenance
fails closed and does not guess a source candidate.

`SongMiniMap` and `ProgressionGrid` were not changed and continue to consume
source bars/timeline coordinates. The UI does not label PresentationGroups as
bars.
