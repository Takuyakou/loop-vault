## Frozen v2 policy and design provenance

Application requires all of:

```text
source meter = 1/4
source beats/group = 1
source groups >= 8
timeline items >= 4
occupied-start source groups >= 4
empty-start source groups >= 4
source groups <= occupied-start source groups * 3
all 4 contiguous source-extent partitions contain a harmonic start
counterfactual formatted groups < legacy formatted groups
counterfactual dash cells < legacy dash cells
```

Provenance for each structural condition:

- `8 source groups` rejects the generated short-file negative before topology
  statistics become meaningful.
- `4 timeline/occupied groups` ensures the relation is not inferred from a
  single long-held event or a tiny sample.
- `4 empty groups` separates genuine one-start-per-bar 1/4 from materially
  finer source topology.
- `source groups <= occupied groups * 3` is the integer relation represented
  by the synthetic 1/2/3-group positive family; it rejects sparse/long-held
  topologies. It is not derived from LF-MIDI-001.
- four-part extent coverage rejects activity concentrated into a burst or
  alternating dense/silent regions.
- strict counterfactual reductions prove the unchanged projection removes both
  group fragmentation and legacy dash fragmentation before it is applied.

There is no private-derived floating cutoff and no compound score.
