# Contract 05 — Anti-overlabel / Hard Negatives

Family C must not improve coverage by labeling ordinary chords as complicated
extended/altered/omission symbols.

Mandatory hard-negative families include current supported examples of:
- major / minor triad;
- major7 / minor7 / dominant7;
- sus;
- dim / half-diminished where supported;
- aug;
- 6 / 6/9 where supported;
- 9 / maj9 / m9;
- representable 11/sus and 13 families;
- genuine slash/inversion;
- sparse shell/guide-tone evidence;
- power/fifth-like ambiguity if present in current corpus.

## Preference rule

If a simpler existing identity explains the same represented pitch-class identity
without unsupported assumptions, the richer new descriptor must not win merely
because the vocabulary can express it.

Do not implement a global "fewer notes is always better" rule. Protect legitimate
rich harmony.
