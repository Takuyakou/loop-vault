## Required audit answers

1. **Current vocabulary and count.** `ChordQuality` contains exactly 21 values:
   major/minor/dim/aug triads; maj7/min7/dom7/min7b5/dim7; maj9/min9/dom9;
   min11/dom13; sus2/sus4/dom7sus4; add9; 6/min6/6-9. Both analyzer template
   tables and the evaluation list repeat this closed set. Candidate enumeration
   is exactly `12 x 21 = 252` per analyzed window.
2. **Identity versus surface notation.** `domain/chordIdentity.ts` owns normalized
   comparison identity and canonical keys. `domain/chords.ts` owns parsing,
   canonical display spelling, tension ordering, and quality aliases.
3. **Alterations/extensions/omissions.** `ChordSymbol.tensions` can carry `9`,
   `b9`, `#9`, `11`, `#11`, `13`, `b13`, and `#5`. Normalized identity separates
   numeric extensions from string alterations. There is no omission field in
   `ChordSymbol`, its schema, normalized identity, or factorized descriptor.
4. **Impossible versus never generated.** Explicit `no3`/`no5` is impossible by
   current type/schema/parser. Several altered/extended combinations are legal
   in `ChordSymbol` and parseable, but the base detector never emits them because
   its 252 templates use empty tension arrays. The observed-b9 rule is a bounded
   opt-in augmentation; historical tension shadows are not the base vocabulary.
5. **Slash bass/inversions.** Slash bass is the optional `bass` pitch class,
   normalized and formatted separately from upper identity. The parser protects
   `6/9` and treats only a trailing note token as bass. Current generation adds a
   slash only where the structural bass satisfies its bounded chord-tone rule.
6. **Round-trip surface.** `parseChordLabel` and `formatChordSymbol` round-trip
   current supported symbols with deterministic tension ordering and accidental
   spelling. They do not round-trip omission notation.
7. **Candidate enumeration.** Both `domain/midi/legacy.ts` and
   `domain/midi/candidates.ts` enumerate fixed quality templates. The current
   production diagnostic exposes all 252 pre-display candidates.
8. **Closed-set scoring assumptions.** Legacy scoring iterates its fixed template
   table; structured scoring looks up a fixed template by `quality`; evaluation
   representability enumerates the same 21 qualities. A target outside that set
   cannot be ranked because it is absent before ranking.
9. **Canonical comparison seam.** `normalizeChordSymbol`, `normalizeChordLabel`,
   and `chordIdentityKey` compare semantic identity independently of display
   spelling. `chordFactorization` already supplies a reversible root/triad/
   seventh/tension/bass decomposition for the existing vocabulary.
10. **Fixed-enum consumers.** Persistence schema, text progression family logic,
    candidate templates, evaluation reachability, label tests, and factorization
    tests assume the current enum. Expanding `ChordQuality` directly would be a
    cross-cutting schema/runtime change, not a Stage01 shadow.
11. **No-migration descriptor.** A runtime/test-only descriptor can extend the
    existing factorized identity with bounded omissions without changing saved
    `ChordSymbol`, Vault schema, or file version. Persistence remains explicitly
    out of scope until promotion proves a safe integration seam.
12. **Smallest reversible shadow seam.** Add a parallel root-relative identity
    descriptor/oracle beside `chordFactorization`, then compare it through
    canonical evaluation keys. Do not widen `ChordQuality`, schema, parser, or
    production candidate enumeration in P5.39-01.
