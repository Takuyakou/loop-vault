# P5.39-01 — Root-Relative Identity Grammar / Representability Oracle

## Goal

Build a shadow-only bounded identity model/oracle that can express target Family-C
structures for all roots without private/root-specific logic.

## Required properties

- root-relative pitch-class intervals;
- 12-root transposition invariant;
- octave/voicing/doubling invariant;
- slash bass separate;
- bounded modifier grammar;
- deterministic canonical identity;
- explicit alterations/omissions;
- no ambiguous canonical `alt`;
- no production behavior change.

## Required target-family corpus

Do not limit to two literal symbols. Build family-level generated cases around:
- altered dominant with explicit altered tensions and omission-sensitive fifth;
- 11th-family with omitted fifth;
- neighboring existing 9/11/13 families;
- alterations currently supported individually but not in combination;
- omission-sensitive variants justified by pitch-class identity.

The exact supported combinations must come from the Stage00 audit and bounded grammar.

## Metamorphic tests

For every new family:

```text
12 roots × >= 4 voicing transforms
```

plus slash/inversion variants where meaningful.

## Deliverable

`reports/P5.39-01-root-relative-identity-oracle.md`

If no bounded safe grammar can be defined, STOP rather than create arbitrary symbols.
