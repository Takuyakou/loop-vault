# P5.40-02c — Safe Activation Certificate Design Lock

Frozen before Stage02c code and before its one-time private whole-file run.
The prior Stage02b implementation and its FAIL remain historical facts. This
is an opt-in Shadow arbitration layer, not a candidate/scorer retune or a
production change. No private identity, note set, location, rank or score was
used to select the rules below.

## One bounded candidate evaluation

For each W2, one-beat or optional half-beat evidence bucket, call the frozen
Stage02b ranker once. Recover the baseline winner from its unchanged first
276 scored rows using the frozen numeric-score, label, enumeration ordering.
The enriched winner is that same result's current Stage02b top candidate.
No second candidate universe, re-scoring or additional modifier enumeration
is allowed. Prefix winner parity with the frozen 276 ranker is a test gate.
Each call remains at most 300 candidate visits.

## Identity activation certificate

If the two identities are equal, retain the common winner. Otherwise adopt
the enriched identity only when every following source-derived condition
holds; a failed or unavailable fact returns the baseline identity.

1. Every pitch class in the enriched score template is material under the
   existing scorer presence threshold. The enriched root is material and the
   observed structural bass equals the identity's root or explicit slash
   bass. This includes the third/seventh or altered structural tones implied
   by the fixed template, without a root-specific exception.
2. The enriched row has no missing expected tone, no unsupported explicit
   modifier, and no omission conflict. Its missing-expected, conflicting-
   present and omission-conflict sets are each subsets of the corresponding
   baseline sets. A more verbose label never justifies worse evidence.
3. There is at least one strict semantic improvement: fewer source-present
   pitch classes outside the candidate template, fewer missing expected
   tones, or (with identical root/bass and pitch-class template) an additional
   explicitly named, materially present modifier absent from the baseline
   descriptor. Score, label order and enumeration order alone cannot satisfy
   this condition. Same-pitch-class enharmonic naming without a new supported
   semantic fact does not activate.

For a root or slash-bass change, the material-root and exact observed-bass
checks above are mandatory independently of score. The existing root/quality
evidence in the scorer is not retuned. Ordinary and omission-sensitive
negative controls must not activate solely because an enriched candidate is
available.

## Temporal certificate and fail-closed partition

Feed the selected W2/B0/B1 winners to the *unchanged* production Family B
predicate. The frozen 276-prefix winners and the same predicate determine
the baseline partition. A changed partition is accepted only when the source
has an actual boundary onset, a formerly material pitch class ends, both
local states have at least three material pitch classes and complete supported
templates with no material outsider/missing/omission conflict, and neighboring
upper templates differ by at least two pitch classes. Otherwise use the
baseline partition and baseline winners for that window.

Where the accepted path is unsplit, the existing Stage02b half-beat probe is
permitted only for a source-articulated transition with at least one off-beat
boundary. All four half-beat states must meet the same complete-support
certificate, and each enriched half-beat winner must independently pass the
identity activation certificate against that bucket's 276-prefix winner.
Every proposed boundary must satisfy the existing onset, ended-pitch-class
and distinct-upper-template checks. Otherwise retain the coarse baseline or
certified W2 span. This avoids treating re-strikes, bass-only motion, sparse
or partially overlapping notes as a new harmonic state.

The normal production smoother is used unchanged after arbitration. The
evaluation must report W2, local, Family B, micro-partition, smoothing and
final-state differences separately so a remaining failure can be classified
without retuning.

## Positive, negative and stop contracts

The protected source-first local classifications, confirmed regions and
temporal cases are acceptance checks only; no runtime ID lookup is allowed.
Synthetic all-root/compatible-bass positives, unsupported-modifier/omission
negatives, ordinary major/minor/dominant/suspended/slash controls, source
order/register/octave/doubling invariants, re-strikes, boundary crossing and
same-root sub-beat changes precede private evaluation. Family A/B regression,
determinism, source fidelity, and the 300-visit bound are mandatory.

After code and public tests, run exactly one private whole-file evaluation.
Any newly changed unreviewed region, reviewed divergence, lost required
local match or temporal split, non-determinism, source mutation or bound
breach means `SHADOW SAFETY = FAIL`. There is no post-result threshold or
condition retune in Stage02c. PASS permits only a separately authorized
Stage03; FAIL stops with a generalized certificate/failure classification.
