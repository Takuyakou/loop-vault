# P5.40-01 — Generalized Shadow Correction Design

## Authorization status

NOT AUTHORIZED by package creation or P5.40-00 completion alone.

## Entry gate

Begin only if P5.40-00 ends with a sufficiently evidenced generalizable cause and a human separately authorizes Stage01.

## Intended scope

Design and implement the smallest bounded Shadow-only correction that addresses the diagnosed general mechanism.

Before coding, freeze:

- exact proposed rule;
- affected evidence terms;
- negative controls;
- protected cases;
- performance bound;
- deterministic tie behavior;
- rollback/isolation condition.

## Forbidden

- target-ID fixes;
- production integration;
- private-result retuning after evaluation;
- broad candidate explosion;
- changing unrelated Family A/B/smoothing behavior.

## Stop

Stop after focused Shadow validation. Do not run private Promotion evaluation without separate authorization.
