# P7.0-02 — Local source-only annotation workflow

The independent full-timeline Gold has not been authored. This workflow creates a local review pack from one raw SMF file without running the Analyzer or importing prior Family A/B/C, FC-REAL, or FC-SAFETY labels. It does not classify a note, boundary, passing chord, role, or chord identity from timing or product output.

## Generate the ignored-local pack

From this branch's repository root:

```powershell
npx vite-node scripts/p7/buildLocalReview.ts --source "<local-midi-path>" --id local-witness-01
```

The default output is under the current checkout’s `.local-evaluation/phase7/local-witness-01/`, which Git ignores. To write directly into another checkout’s ignored-local directory, pass `--local-root "<absolute-path-to-.local-evaluation>"` to generation and validation. `source-facts.json` contains raw observations and a local-only source checksum. `review.json` starts in draft with every semantic decision unknown. `source-only-review.html` contains the same source observations and editable controls. No source MIDI is copied into the pack or modified.

The extractor retains exact PPQ ticks, MIDI note numbers, paired onset/offset/duration, tempo and time-signature events, track/channel, controller events, and simultaneous-onset clusters. A source 1/4 time signature is retained as 1/4. One-beat and half-beat states remain visible as observations; duration never assigns ornament or passing-chord truth. Unpaired notes and overlapping same-pitch note events are rejected because an offset cannot be unambiguously paired and reported as observed truth.

## Human review

Open `source-only-review.html` locally. Review harmonic and voicing boundaries independently, including any boundary that falls between onset clusters. Review passing-chord status, note role and note-event kind, and enter continuous harmonic and voicing spans. Voicing targets use source note IDs; the checked Gold derives exact MIDI numbers from those human-selected IDs. Chord identity is entered by the reviewer. The page displays no Analyzer prediction, candidate, score, rank, or old Gold. Save the downloaded JSON into the ignored-local directory; do not add it to Git.

Validate the local result with:

```powershell
npx vite-node scripts/p7/buildLocalReview.ts --source "<local-midi-path>" --id local-witness-01 --check "<saved-review-json-path>"
```

A `draft` can pass structural checks but is never Gold. Only a complete `reviewed` file with source checksum, all onset review decisions, continuous spans, selected observed target instances, and no unknown labels can produce ignored-local `accepted-gold.json`. That file uses the anonymous ID and source checksum for evaluator linkage. Source bytes are re-read and compared during extraction. Gold remains local-only.
