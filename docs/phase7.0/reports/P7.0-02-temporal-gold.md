# P7.0-02 — Temporal Gold v1 and Boundary Taxonomy

## Evaluation-only contract

`scripts/p7/temporalGold.ts` defines `p7-temporal-gold-v1`. Each case has independent source notes, continuous harmonic spans, continuous voicing spans with exact target MIDI note numbers, and optional note events for ornaments, re-strikes, arpeggios, and residuals. Gold is authored before analyzer output and is never inferred from product boundaries. Harmonic and voicing spans may differ. Note events do not automatically introduce either boundary.

The validator checks version, category, full span coverage, continuous/non-overlapping spans, sorted unique valid target notes, observed target pitches, valid source notes, and bounded note events. MIDI is encoded in memory from public-safe synthetic source notes; no generated MIDI binary is tracked. A focused roundtrip test confirms parsed source pitches and deterministic encoding.

## Synthetic taxonomy

| Category | Harmonic boundaries | Voicing boundaries | Note event |
| --- | --- | --- | --- |
| ordinary sustained chord | none | none | none |
| single-voice passing note | none | none | passing |
| neighbor note | none | none | neighbor |
| appoggiatura-like note | none | none | appoggiatura |
| same-voicing re-strike | none | none | re-strike |
| same-voicing arpeggio | none | none | arpeggio |
| voicing-only change | 0 | 1 | none |
| one-beat passing chord | 2 | 2 | none |
| half-beat passing chord | 2 | 2 | none |
| true harmonic change | 1 | 1 | none |
| sustained pedal residual | 1 | 1 | residual |
| bass pedal point | 1 | 1 | none |
| syncopated harmonic change | 1 | 1 | none |

The one-beat and half-beat passing chords preserve both changes as Gold. A sustained pedal residual is excluded from the later stable target voicing, while a structural bass pedal remains in both voicing targets. These distinctions prevent a duration-only rule or a blanket one-voice ornament rule from satisfying the contract.
