# P7.0-04 — Versioned harmonic truth and equivalence contract

## Frozen evaluation model

`scripts/p7/harmonicTruth.ts` defines `p7-harmonic-truth-v1`. Each independent Gold item specifies source MIDI notes, an explicit audible pitch-class set plus bass pitch class, a primary label, and one or more accepted semantic identities. Identity stores root, quality, bass, and factor tokens independently of label spelling. The accepted identities and audible signatures are authored as Gold; they are never inferred from product candidates, score, rank, renderer output, or prior evaluation.

Tier 2 playback equivalence requires exact pitch-class content and bass pitch class against an allowed Gold audible signature. Octave/register differences are deliberately outside this test and remain Tier 1 errors. An accepted alternate identity can be playback-equivalent without becoming the same semantic identity as the primary interpretation. `canonicalExact` is a diagnostic label-string check only. `namingOnly` requires the primary semantic identity and playback equivalence with a different label. `rendererOnlyMismatch` requires an accepted identity whose actually played notes fail the audible signature; the wrong audible result is not excused by a correct chord name.

The contract explicitly covers multiple valid C6/Am7-over-C interpretations, rootless dominant, omitted fifth, altered dominant, extension, and slash/inversion synthetic examples. These examples are public-safe authored fixtures, not a relabeling of an existing corpus. Product parser representability and candidate recall are separate measurements in P7.0-07. Unsupported label syntax cannot be silently rewritten into Gold. Any source voicing omissions/alterations are explicit factor tokens; a missing root or fifth is not automatically treated as the absence of a harmonic root/fifth in the interpretation.

## Verification and use

Focused Vitest passed 3 cases: fixture validity; playback-equivalent alternate identity versus primary-identity naming-only; and renderer-only mismatch versus octave-insensitive Tier 2 signature. Strict TypeScript and ESLint passed. The examples are evaluation-only and have no production connection. Later candidate experiments must report playback-equivalent, identity accepted, canonicalExact, naming-only, and renderer-only outcomes separately. No private human Gold is used.
