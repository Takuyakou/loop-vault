- Development: 13 authored temporal categories, six authored Tier 2 harmonic categories, and Harmony Support Gold dev (20 files / 160 events). The temporal fixtures and harmonic examples are separate evaluation tasks.
- Validation: Harmony Support Gold validation (6 files / 48 events), inspected only through aggregate outputs.
- Regression: versioned Chord Drip, Harmony Support, and existing repository regression suites; prior historical holdouts are not the Phase 7 final sealed holdout.
- Final sealed synthetic: 26 ignored-local examples, two fresh transpositions for each of the 13 temporal categories. SHA-256 of sealed JSON: `dbc0a91cf56a5280ff3e6cccebdfa03ea9231cf2ec220330e33edcff9fc15975`. Generated once with exclusive-create (`wx`), before any candidate tournament. The local file and answer rows are untracked and were not opened for selection. Its structure is derived from public-safe authored fixture families, so it is a category generalization check, not independent human real-MIDI Gold. Final evaluator may return aggregates only. If the sealed file is missing or its hash changes, final evaluation must stop rather than regenerate it.
- Local real MIDI witness: no independent semantic Gold; excluded from quantitative ranking. `PENDING_HUMAN_REVIEW / NON_BLOCKING`.

## Frozen controls

`Copy-Oracle` uses Gold boundaries and target note sets, without chord inference. `Copy-Simple` segments the source at integer beats, collects all raw MIDI note numbers with any positive overlap with each segment, without chord inference or track filtering. `Copy-ProductBoundary` uses current product boundary starts with the same raw note collection. Source duration is computed from raw MIDI, not Gold end time. The arm is scored by the segment covering each Gold event midpoint; the Gold event is used only for scoring. No model output contributes notes to either simple copy arm. This deliberately exposes melody contamination and fragmentary source attacks rather than hiding them with Gold role filters. The controls are frozen here before the tournament.

They are a causal control, not an optimized extraction candidate. `P7.0-06-copy-dev.jsonl` and `P7.0-06-copy-validation.jsonl` contain aggregate-only counts; synthetic appears in both as the same control.
