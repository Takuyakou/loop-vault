# P8.8.1-01 — Exact Extended subdivision timing

## Change

The Extended structural parser uses 960 integer source ticks per beat.
1, 2, 3, 4, 5, 6, 8, 12 and 16 equal slots in supported n/4 meters
divide the per-bar tick count exactly. Slot, harmonic-span and attack
objects retain integer tick positions/durations as parser truth. Numeric
beat values remain compatibility projections derived from those ticks.
No parser rounding is performed. The shared segmenter accepts a bounded
16-token compact search only when called by Extended; Standard keeps its
four-token search.

Within a span, percent creates an attack and equals extends duration with
no attack. Repeated written chords retain attacks. Rests reset the active
span. Tick arithmetic determines adjacency and accumulated duration, so
floating-point addition cannot silently merge or split an interval.

## Frozen PRE erratum

EV1-087 is authored synthetic text with a three-slot 4/4 bar. PRE marked it
negative under the former integer-beat-only contract. The new approved
subdivision contract makes it valid. The tracked fixture is unchanged; the
parser regression test has an explicit one-ID exact-timing erratum. The
separate semantic errata EV1-070–077 remain unchanged.
