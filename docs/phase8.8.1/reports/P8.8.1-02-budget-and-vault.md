# P8.8.1-02 — Independent budget and Vault v2 preservation

## Change

Extended Text now has an independent source-document budget: 65,536 UTF-16
code units, 256 bars, 4,096 score slots, 2,400 harmonic spans, 4,096 attacks,
400 comments, 512 sections and 16 slots per bar. Standard Text retains its
existing 32-bar/128-token limits. These are resource bounds, not an assertion
that every accepted chart is directly playable in every practice mode.

The strict optional `textSource` member of Vault fileVersion 2 accepts the
same bounded Extended source and fractional beat projections. The save
adapter validates the complete source by reparsing raw text and checking every
saved harmonic event. It keeps the original raw text; no schema version or
fileVersion migration is made. The source model's integer 960-PPQ ticks remain
authoritative. The optional Vault source does not persist the parser's internal
tick field; it is reconstructed from the unchanged raw text when validating.

Voicing Loop retains its existing 192-tick practice grid and independent
capacity limits. An authored subdivision that cannot land exactly on that
grid (for example five equal 4/4 slots) remains valid source/Vault data but
returns `invalid-timing` at the practice boundary, rather than being silently
rounded. Eight-slot 4/4 bars are representable.
