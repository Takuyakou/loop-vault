# P8.8.1-03 — Extended aliases and written spelling

## Change

The Extended-only chord grammar accepts signed alterations in a parsed chord
context: F7-5, Fm7-5, F7+5, F7+9 and F7+11. The unsuffixed C+ quality keeps
its existing augmented meaning. Malformed signed forms remain invalid.
The Product MIDI chord parser and Standard Text grammar are unchanged.

Preview-facing and saved chord labels retain the written root and slash-bass
spelling, including G#m7 and G#m7/C#. The saved optional text source retains
the original raw text and writtenChord. Save validates every label against
the reparsed source so a caller cannot inject an unrelated display label.

F7-5 has a flat-fifth semantic marker in the Extended harmonic span and
optional Vault text source. Its existing ChordSymbol playback projection is
natural-fifth omission plus enharmonic #11. This gives the correct pitch-class
set without changing the global Product/MIDI chord vocabulary. Consumers
that need the written alteration must read textSource.semanticAlterations;
the generic factorized ChordSymbol still expresses this pitch as #11. This
boundary is explicit rather than silently claiming those spellings are
identical.
