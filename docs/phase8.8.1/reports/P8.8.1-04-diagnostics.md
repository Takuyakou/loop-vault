# P8.8.1-04 — Reason-specific diagnostics

## Change

Extended diagnostics now include a machine-readable reasonCode for unknown
tokens, unknown chord labels, ambiguous tokenization, invalid structure,
unsupported subdivision, resource excess, unsupported meter and invalid
metadata. The previous code remains for the frozen PRE corpus; reasonCode is
the new product-facing cause. A generic segmented-bar message has been
replaced with cause-specific English source diagnostics and Japanese UI copy.

The Capture preview displays the original malformed bar text in its original
bar position with an error state. The diagnostic renders line, column and
source span. ERROR continues to block Save; input stays editable and intact.

## Verification

Public synthetic cases cover all required causes, legacy PRE code
compatibility and raw bar retention. Japanese Capture UI verifies the visible
cause, source span, original erroneous bar and disabled Save. Frozen PRE
99/99, focused diagnostics/UI 10/10, TypeScript and changed-scope ESLint:
PASS.
