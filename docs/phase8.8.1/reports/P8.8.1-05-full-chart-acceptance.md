## Public synthetic acceptance

A deterministic authored-pattern generator composes 1-slot and 8-slot bars
with comments, section markers, slash bass, augmented/diminished chords,
signed altered aliases, percent reattacks, equals holds, rests and repeated
written-chord attacks. It creates the chart at test runtime; no copied chart
is tracked. The UI test pastes/previews/submits all 150 bars. The integration
test then saves through the public text adapter, serializes and reloads Vault
fileVersion 2, and builds the Voicing Loop handoff without missing slots,
harmonic spans or attacks.

The independent parser budget permits these lengths. Over-budget 257 bars,
4,096-slot dense spans above the harmonic-span cap, oversized raw input and
excess comments fail closed with no partial save. The 150-bar UI rendered
every slot and enabled Save.

Parser-only warm median on this host over seven runs: 70 bars 1.31 ms,
150 bars 2.61 ms, 200 bars 2.81 ms. This is a trend observation, not a
portable latency limit.
