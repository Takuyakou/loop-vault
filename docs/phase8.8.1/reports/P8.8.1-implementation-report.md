## Root cause and scope

The observed compound-chart failures had multiple independent causes.
The shared compact segmenter searched at most four tokens, so adjacent
eight-slot bars often failed before timing. Spaced eight-slot bars reached
an Extended-only integer-beat divisibility check and failed there.
Extended inherited Standard's 8,192-code-unit, 32-bar and 128-token caps;
the Vault save adapter and strict optional source schema independently
repeated small-chart/int-only assumptions. Confirmed signed chord aliases
also failed in isolation; those are semantic failures, not subdivision
failures. G-sharp spelling was lost through canonical display. Generic
diagnostics obscured these distinctions.

## Implemented contracts

- Extended source timing uses integer 960 ticks per beat. A 4/4 eight-slot
  bar has 480 ticks (half a beat) per slot. One, two, three, four, five, six,
  eight, twelve and sixteen equal slots have exact parser positions where
  the bar tick count divides the slot count. Parser source truth is never
  rounded. Percent produces a reattack, equals extends without an attack,
  rest ends the active span, and repeated written chords retain attacks.
- Extended owns separate bounds: 65,536 UTF-16 code units; 256 bars; 4,096
  score slots; 2,400 harmonic spans; 4,096 attacks; 400 comments; 512
  sections; 16 slots per bar. Standard retains its historical limits.
- Optional Vault v2 textSource and the text save adapter accept the bounded
  chart and fractional beat projections. Raw source is reparsed on save and
  compared to saved timing/identity. Vault fileVersion remains 2.
- Voicing Loop retains its independent 192-tick practice grid and resource
  limits. A valid source fifth-subdivision that cannot be represented exactly
  there stays in Vault but returns invalid-timing at the practice boundary.
  No rounding or silent shortening occurs. Eight-slot bars hand off exactly.
- Extended-only grammar accepts F7-5, Fm7-5, F7+5, F7+9 and F7+11 while C+
  remains augmented. Original G#m7, slash-bass and signed spelling survive
  preview, save and reload. The Product MIDI chord parser remains unchanged.
- F7-5 preserves a machine-readable flat-fifth source semantic marker.
  The existing generic ChordSymbol playback representation uses omitted
  natural fifth plus enharmonic sharp-eleventh pitch. The actual pitch-class
  set is correct; generic factorized identity cannot express the written
  flat-fifth degree. Consumers requiring that spelling use textSource.
- Diagnostics add cause-specific reasonCode values for unknown token,
  unknown chord, ambiguous tokenization, invalid structure, unsupported
  subdivision, input-limit excess and unsupported meter. The Japanese
  Capture UI displays the cause and line/column/span and retains the raw
  erroneous bar in place. Existing PRE diagnostic codes remain stable.
