# P8.8.3 Product theory and audition contract

Policy: `p8.8.3-product-defining-v1`. Corpus: `p8.8.3-product-supported-r-v1`.

Accepted written labels must retain root, written third or suspended replacement, written sixth/seventh, altered fifth, and every explicit tension/alteration. An ordinary dominant 13 retains the 13 but need not include natural 11. Natural fifth, implied ninth in 11/13, and duplicate root may be omitted when identity survives. Explicit #5/b5 replaces an unwritten natural fifth. Explicit #11 replaces an unwritten natural 11. Slash bass is the lowest sounded note for deterministic text confirmation audition.

Text Preview and saved text-card audition use `text-chord-tones-v1`: deterministic, context-free, compact mid-register, no fixed upper-tone cap. It is neither SOURCE nor CUSTOM nor Generated practice. Text-derived Voicing Loop basic-full retains its Generated voice-leading purpose but must include every defining pitch class. MIDI-derived Generated behavior remains unchanged.

Unsupported labels must diagnose/reject rather than silently approximate. The frozen 98 PRE fixtures are not rewritten. P8.8.4 UI/transport work is excluded.
