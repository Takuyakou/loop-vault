# P8.8.4-01 — Shared Text Capture shell

Both Standard and Extended now render through one `TextCaptureShell` with the same product heading, concise description, syntax switch and compact mode legend. Extended no longer introduces a second large page heading or a separate switch inside its transport toolbar. `CaptureView` keeps MIDI/Text selection at the existing top placement and removes only the Text audition timbre selector. Text card and Extended auditions use a fixed electric-piano timbre while retaining the P8.8.3 note resolver; unrelated global MIDI sound settings are unchanged.

Fresh checks: shared shell regression plus Standard/Capture tests 19/19 PASS; Extended panel 8/8 and P8.8.3 audition 2/2 PASS; app TypeScript and repository lint PASS. No parser, Vault, MIDI or semantic policy changed.
