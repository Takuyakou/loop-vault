# P8.8.4-03 — Text transport state machine

Added a Text-only state machine over the existing PlaybackController. It freezes a note snapshot on Play, tracks musical-beat position, captures a play anchor, supports Pause/Resume/Stop, exact seek and Beginning, whole progression loop, and BPM rescheduling from the current beat. It does not change shared MIDI/Vault playback behavior. Future notes are trimmed in beat space; held notes resume on seek and pause, while already-fired attacks are skipped on live BPM updates. The Stage 04/05 UI will connect this state machine to both syntaxes.
