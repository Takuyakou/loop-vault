# P8.8.5-02 — Global audition timbre and metronome

The app header now owns one persisted metronome ON/OFF preference, default OFF, with an accessible icon button, focus/hover tooltip, aria-label and aria-pressed. The setting crosses navigation/restart. Voicing Loop and Rhythm Practice read it; their screen-level ON/OFF toggles were removed. Voicing Loop still owns its BPM, count-in and transport; the global toggle updates its active runtime. Rhythm Practice retains its own tempo and lesson playback mode. Bass Practice chord-context accompaniment radio choices remain task-specific mode selections rather than a second general ON/OFF switch.

Text Capture now uses the existing global Piano/EP setting for Standard whole transport, Extended whole transport, Extended chord-band audition and Capture event audition. There is no Text-only hardcoded EP default. A shared source-only click-note primitive is beat-aligned, and each Text transport provides its own BPM. The underlying parsers, exact note timing, Voicing Loop sound behavior and P8.8.3 chord semantics are unchanged.

Gates: app TypeScript, repository lint, focused Text/Voicing Loop/Rhythm regression (66/66), provider persistence and actual audio-driver path tests (3/3), and product Playwright (2/2 including global toggle persistence) passed.
