# P8.8.5 Final UI Correction — Implementation Report

## Decision

The corrected Capture UI is a candidate on `feat/phase8.8.5-final-ui-correction`. The canonical mock's layout hierarchy is implemented while the existing application sidebar and global header controls remain visible. This stage does not merge, push, tag, release, or create an EXE.

## Baseline and audit

The candidate branched from local `master` at `373d43f`. The phase README and execution state describe the preceding P8.8.5 candidate; Git reality for this final correction is the branch above. The pre-change code audit is in [P8.8.5-final-ui-audit.md](P8.8.5-final-ui-audit.md). The unrelated root checkout was not changed.

## UI correction

- `コード採集`, its subtitle, and the one persistent MIDI/Text selector now share the application header. The selector retains one DOM node and geometry when moving among MIDI, Standard, and Extended states.
- The existing global playback meter, volume, timbre, save status, and metronome remain. The metronome has a visible label and accessible ON/OFF state backed by the existing persisted preference. Loop ON and playback use teal; inactive controls are neutral.
- Standard and Extended retain the same source text while switching. Their control row now contains syntax, meter, key, BPM, transport, position, Name and Save. Play/Pause/Resume reserves a fixed width. The Name/Input/Save group wraps together when space is limited.
- Editor and parser-backed preview use one flat shared surface and dividing line. Pristine empty input has a neutral no-errors state and a clear disabled Save reason. Unset BPM is displayed as `—`, while audition fallback remains 120. Explicit 120 is represented separately.
- Legacy Standard key/BPM sections, large yellow diagnostic panel, duplicate status rows and local Text metronome are removed. Card, voicing and availability detail remain reachable from compact disclosure controls above the single bottom status line. Parser, transport, Vault schema and SOURCE/CUSTOM behavior were not changed.

## Fonts

IBM Plex Sans JP 400/600 and IBM Plex Mono 400/600 are bundled as local WOFF2 assets with their OFL license texts next to the assets. The six WOFF2 files add 1,911,800 bytes before compression. CSS uses `font-display: swap` and Latin/Japanese unicode ranges. App UI uses the sans family; chord names, BPM, positions, numerical labels and source text use mono with tabular numerals. A browser test blocks external HTTP and confirms both fonts load.
