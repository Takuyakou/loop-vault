# P8.8.6-00 baseline audit

At base `feb2b51`, the app shell supplies a fixed viewport height, but Capture's main region adds vertical padding while the Text Capture root independently requests a calculated minimum height. At 1920x1080 this produced 20 px of main-content scrolling. Standard placed its toolbar outside the intake shell while Extended placed it inside. Standard omitted the annotation count in its status line. Both readers already preserved the same raw text when switching modes.

The correction will use the app-shell content height directly, place Standard's toolbar/workspace/footer under one shell, and derive both status lines from one presentation model. No parser or persistence change is needed.
