# Phase 8.8 — Extended Text Intake handoff

## Product state

Extended Text is an explicit second Text Capture dialect. Standard mode
remains the initial mode; the UI may suggest Extended but never switches
automatically. Extended supports the approved source syntax, bounded
diagnostics, live preview, opt-in Key/BPM comment hints, and a one-click Vault
save. Raw text, sections, slots, harmonic spans, attack positions, and parser
policy provenance are retained in an optional strict Vault v2 textSource
member. Existing Vault v2 records and fileVersion remain unchanged.

Voicing Loop uses the saved text timing to rearticulate written and percent
attacks. A hold adds no attack and an explicit rest is silent. Voicings are
generated by the existing product policy; the text path does not claim exact
source-MIDI notes or adopt an external reference voicing.

## Gates and limits

The frozen PRE corpus has 98 authored synthetic fixtures, manifest SHA-256
f6dd1f79e2a91ffb7b385cb8054b23f197963b316f75b78ebd787d23a31b2d12.
EV1-070 through EV1-077 use the explicit semantic erratum; the frozen fixture
file was not rewritten. Fixed-seed mutation, persistence, generated playback,
normal/extended UI and responsive accessibility checks passed. The candidate
full suite passed 3656/3656 with bounded worker count and timeout; related
Playwright passed 7/7.

Meter is limited to constant 1/4 through 12/4. Text cannot reconstruct a
specific performance voicing, octave, doubling or microtiming. Unsupported
syntax stays diagnostic and cannot be saved as a guessed chord. The score
document is limited to 8192 UTF-16 units, 32 bars, 128 score tokens and 128
comment/playback marker sections. No Vault v3, Phase 8.9 or Phase 9 behavior
is included.

## Resume / acceptance

After the local master merge and Windows EXE gate, human product acceptance
is a short local check: paste representative public text, inspect
preview/diagnostics, save to Vault, open Voicing Loop and listen for attacks,
holds and rests. No public or copyrighted raw text is required in Git.
