# P8.8-01 — Frozen PRE fixture erratum

The `extended-v1-canonical-v1` JSON and its SHA-256 manifest digest are not
modified. The PRE corpus intentionally recorded unimplemented semantic forms
as negative `SEMANTIC_GAP`. Phase 8.8 implements the following meanings, so a
new parser should treat these cases as positive in a versioned overlay rather
than rewriting the research oracle.

| PRE IDs | PRE expectation | Phase 8.8 accepted meaning |
| --- | --- | --- |
| EV1-070 | semantic gap | `E7(b9,#11,b13)` retains all three written alterations |
| EV1-071 | semantic gap | `CmMaj7` is minor triad with major seventh |
| EV1-072 | semantic gap | `G13` retains dominant 13 identity; optional 11 voicing is separate |
| EV1-073 | semantic gap | `D11` is dominant seventh with 9 and 11 |
| EV1-074 | semantic gap | `C(omit3)` retains omitted third |
| EV1-075 | semantic gap | `F7(no5)` retains omitted fifth |
| EV1-076 | semantic gap | `A5` is a root-and-fifth power chord |
| EV1-077 | semantic gap | `Dm11(omit3)` retains the omission and extension |

`EV1-095` with two parenthesized groups remains unsupported. Other frozen
negative and ambiguous cases remain unchanged. A Phase 8.8 fixture runner will
identify this overlay explicitly by policy ID and never report the original
negative cases as though the frozen PRE file were changed.
