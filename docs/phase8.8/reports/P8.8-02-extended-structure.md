# P8.8-02 — Extended structural and timing adapter

## Implementation

`extended-v1` now has a separate structural adapter over the shared chord
semantics and score segmenter. It retains exact raw text and UTF-16 source
ranges, line/column diagnostics, comments, playback markers, bars, grid slots,
harmonic spans, and attack events. Equal divisions of supported n/4 bars yield
deterministic whole-beat timing. Unknown or ambiguous text blocks conversion.

`%` adds a reattack to the active harmonic span, `=` extends it without
an attack, `_` and `N.C.` make explicit rests, and repeated written chords
retain attacks. The span model keeps articulation distinct from harmonic
identity. No MIDI source path was changed.

Whitespace-separated bare chord lists use the frozen implicit-bar convention;
compact adjacent tokens remain within one bar. The PRE fixture corpus stays
immutable. Semantic-gap cases EV1-070 through EV1-077 use the recorded
P8.8-01 erratum.
