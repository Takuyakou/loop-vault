# P8.8-03 — Text intake UI and live preview

## Implementation

Capture text entry now has an explicit Standard / Extended selector. Standard is
still the initial mode. A likely extended score produces a suggestion and an
actionable switch; the editor never switches automatically. The same editable
source text survives mode changes.

The Extended view places raw input beside live bars, source sections, slot
timings and line:column ERROR diagnostics. Empty input stays idle. Key and BPM
hints from source comments require separate “Use” actions; selecting a meter is
also explicit. One Save to Vault action sends a complete harmonic-span timeline
through the existing store adapter. It never saves a partial parse. The Vault
adapter now accepts the extended n/4 whole-beat grid without changing
fileVersion 2. The previous Standard 4/4 behavior remains the default.

Stage 04 adds strict raw-source/attack persistence to the saved block. The
Stage 03 save path already keeps the editor open on failure and does not
fabricate MIDI-source fields.
