# P8.8-05 — Saved text to Voicing Loop

## Product path

Extended Capture saves one harmonic card per harmonic span. The Vault v2
textSource keeps every written/percent attack separately. On the existing
Vault handoff, each practice event receives detached attack beats. The current
Generated Voicing resolver is unchanged. Both V2 rolling transport and the
legacy rollback scheduler now schedule those beats, with durations ending at
the next attack or chord/rest boundary. Holds add no attack; explicit rests
remain silent spans. A repeated written same chord remains an audible new
attack while the card count stays tied to harmonic spans.

The text path never claims SOURCE MIDI. Saved slash bass, source meter, exact
score length and section-independent timing survive the strict Vault reload.
No external concrete-note policy or reference voicing was added.
