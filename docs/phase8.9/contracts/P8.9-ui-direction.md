# P8.9 — 見た目と画面の方針

人間との事前打ち合わせ（2026-09-27）で決まったこと。モックは段階の zip で `mocks/` に追加され、モックがある画面はモックを正とする。

## 1. テーマ

- 使いやすさ・モダン・おしゃれ・使っていてモチベーションが上がる。毎日開きたくなる「練習スタジオ」。
- 1画面ごとに「やること」を1つにしぼる。
- やる気の仕掛けは控えめに入れる：進み具合の帯、連続日数、クリア時の小さな演出まで。レベルや称号は入れない。数字で急かさない。
- ライトモードは作らない。ロゴとアプリ名は変えない。

## 2. 色（`src/styles/tokens.css` を土台にする。変数名は変えず、足りないものだけ足す）

| 役割 | 変数 | 使う所 |
| --- | --- | --- |
| 地 | `--lv-bg` #0a1019 | 画面全体 |
| サイドバー | `--lv-sidebar` #0d1522 | サイドバーとタイトルバー |
| 面 | `--lv-surface` #111b2a / `--lv-surface-raised` #162338 | カード・浮いた面 |
| 主役 | `--lv-accent` #42d8c6 | 主役ボタン・選択中・フォーカス枠 |
| 状態 | `--lv-accent-secondary` #746df4 | ループ ON だけ |
| 練習の記録 | ロゴの黄色（変数を追加） | 連続日数・練習のリング |
| 注意 | `--lv-warning` #f2c14e | 要確認の印・注意のトースト |
| エラー | `--lv-danger` #ee6b73 | エラーと、ウィンドウの閉じるボタンのホバーだけ |
| 文字 | #f2f6fc / #a5b2c6 / #7f90aa | 本文 / 補足 / 控えめ |

## 3. 文字・余白・動き

- フォント：本文 IBM Plex Sans JP、コード名・数字・BPM は IBM Plex Mono（同梱済み。CDN は使わない）。
- 大きさ：11 / 12 / 13 / 14 / 16 / 20 / 28px。本文 13px。
- 余白：4px 刻み（4 / 8 / 12 / 16 / 20 / 24 / 32）。
- 角の丸み：小さい部品 8px、カード 12px、大きいカード 16px、チップは丸。
- 動き：ホバーなど 0.12 秒、出入り 0.18 秒。OS の「動きを減らす」設定の時は止める。

## 4. ボタン

| 段階 | 見た目 | 決まり |
| --- | --- | --- |
| 主役 | 青緑の塗り | 1画面に1つだけ |
| 無彩色 | 枠線か塗りなし | それ以外すべて。停止・最初からもここ |
| 状態 | 紫 | ループ ON など、オンの状態を示す時だけ |

赤と黄は操作ボタンに使わない。押せない時は理由をツールチップで出す。

## 5. 共通レイアウト

| 部分 | 大きさ | 中身 |
| --- | --- | --- |
| タイトルバー | 高さ 36px | ロゴとアプリ名、検索（Ctrl+K）、最小化・最大化（最大化中は「元に戻す」）・閉じる。空いている所のドラッグで移動、ダブルクリックで最大化 |
| サイドバー | 幅 232px、狭い時は 64px（アイコンだけ） | 日本語の画面名と自作アイコン。境目は 1200px を案とし、手で切り替えた状態は記憶する |
| ヘッダー | 高さ 56px | 左：画面名とその画面の操作。右：MIDI の状態・試聴音色・メトロノーム（ON/OFF）・音量（小さくまとめる） |
| 中身の欄 | 残り全部 | ここだけがスクロールする。二重のスクロールはなくす |

- 一体型タイトルバーは Tauri の `decorations: false` と、ウィンドウ操作の権限の追加で作る。Windows 11 のスナップレイアウトは標準では出ないので、Win+←/→ と画面端へのドラッグが使えることを実機で確かめる。うまくいかない時に標準のタイトルバーへ戻せる設定を1つ残す。
- 起動時のウィンドウは 1440×900（画面がそれより小さい時は収まる大きさ）。最小は 768×640 のまま。
- 2列の画面（Vault・進行ページ）は、中身が 900px を切ったら右の欄を折りたたむ。

## 6. トースト

今の2種類（右上の `Toast` と左下の `UndoToast`）を右下の1つにまとめる。

- 位置：右下。下の帯や再生ボタンに重ならない。最大3件まで重ねる。
- 出方：下から少しスライドしてフェードイン（約 0.18 秒）。約4秒で消え、マウスを乗せている間は止まる。
- 種類：成功・お知らせ・注意・エラー。アイコンと細い色の線で見分ける。エラーだけ自動で消えない。
- 中身：1行の文。必要な時だけ操作を1つ（「開く」「元に戻す」）。
- `aria-live` で読み上げソフトにも伝える。
- 「✓ 保存済み」など一時的なお知らせはトーストへ。「未保存の変更がある」のように常に見える必要がある状態は、画面の中の決まった場所に小さく出す。

## 7. 画面名（日本語に統一。固有名はそのまま）

ホーム・取り込む（コード採集）・Vault・練習（Chord Dojo・Voicing Loop・Bass Practice）・Live MIDI・設定。

## 8. 画面ごとの扱い

| 画面 | 扱い |
| --- | --- |
| ホーム | 作り直す（続きから・取り込む・今日のループ・今日の練習・最近の進行） |
| Vault | 作り直す。左の絞り込みは残す。一覧は「進行」だけ |
| 進行ページ | 作り直す。Idea 詳細を吸収する |
| Chord Dojo | 8.9 では作り直さない（後日、練習画面のリニューアルで）。外枠と共通部品に馴染ませ、表示を日本語にするだけ |
| Bass Practice | 8.9 では作り直さない（後日、練習画面のリニューアルで）。外枠と共通部品に馴染ませ、表示を日本語にするだけ |
| 設定 | ダイアログから画面へ。開発者向けの欄は奥に折りたたむ |
| Live MIDI | 見た目を揃えるだけ |
| 起動・復旧・空の状態 | 次にやることが分かる案内にする |
| コード採集・Voicing Loop | 微修正だけ。共通部分に馴染ませる程度で、並びと操作は変えない |

## 9. 承認済みの削除（画面から外すだけ。保存データはそのまま）

| 外すもの | 移し先・代わり |
| --- | --- |
| 制作ステータス（Idea〜完成・保留・没）と切り替え | なし |
| 月間ゴールと「今月の完成」 | なし |
| 次の一手・停滞中の一覧・「保留にする」 | なし |
| 「＋ Idea」と空の Idea を作るダイアログ | 「取り込む」に置き換える |
| 参考曲・参照、関連ファイル | なし |
| ジャンル・ムード、コード進行メモ | 進行ページで「以前の項目」として読むだけ（[データ保持の契約](P8.9-data-retention.md)） |
| Idea 一覧・Idea 詳細の画面 | 進行ページと Vault に吸収。Idea は保存の入れ物として残す |
| 英語表示と言語の切り替え | 日本語だけ。`i18n.ts` の仕組みは日本語固定で残し、英語の文言だけ消す |
| 履歴画面 | ホームの「最近」と練習の記録に吸収 |
| AI で展開案（LLM 設定を含む） | なし |
| Chord Dojo のミックス練習 | 後日、Dojo の作り直しと一緒に外す（8.9 では外さない） |

残すもの：設定の「解析（開発用）」は設定の奥の「開発者向け」へ移す。音量メーターと音量つまみは小さくまとめる。
