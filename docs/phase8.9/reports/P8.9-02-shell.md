### 段階1の申し送り（手順6）

1. **下の帯の高さの申告**：`useReserveBottomSpace(ref)`（`src/components/notifications/bottomReservations.ts`）が、下の端にある要素の高さを ResizeObserver とウィンドウの大きさの変化で測り、通知の重なりの下の余白に足す。使う所は、Voicing Loop の下の操作欄、テキスト採集の下の帯、ブラウザ版 Live MIDI の小窓。`:root:has(…)` と固定の高さ（64・112・288px）はなくした。採集と Voicing Loop の変更は、それぞれ ref と呼び出しの数行だけ。採集の検査欄（768〜1279px で下に出る）は、既存の `--lv-sticky-inspector-height` をそのまま足している。
2. **部品の見本が本番に入らない検査**：見本の側に `P89_GALLERY_MARKER` を1つ置き、描画にも出す。FULL の本番ビルドのすぐあとに `scripts/test-dx/check-gallery-excluded.mjs` が `dist/` を探す。本番のビルドでは通り、`VITE_P89_GALLERY=1` のビルドでは落ちることを両方確かめた。

   - 最初の撮影で、トーストがダイアログの「解析（開発用）」の開閉ボタンに重なった。**ダイアログが開いている間は、通知の重なりを上の中央に移す**ように直した（`Modal` に `useAnyModalOpen()` を足した）。直したあとの重なりは 0 件。

- **サイドバーの幅の動き**：幅を 0.18 秒で動かすと、その間に中身の欄の幅が変わり続け、採集のタブの位置のテスト（1024px で 146px ずれ）が落ちた。幅は動かさず、すぐ切り替えるようにした。
- **狭い時のタイトルバー**：モックの狭い版（`RHomeCompact`）に合わせ、サイドバーがアイコンだけの時はタイトルバーの左もアイコンだけ（64px）にした。
- **ダイアログとトースト**：768×640 の設定のダイアログは画面のほとんどを覆い、右下のトーストがダイアログのボタンに重なった。ダイアログが開いている間は上の中央に移した（見出しの文字には少しかかることがあるが、ボタンには重ならない）。別案：ダイアログの下の余白を空ける → ダイアログの高さを削ることになるので採らなかった。
- **保存の状態の失敗の印**：Vault の `error` は保存以外の理由（読み取り専用の間の操作など）でも出る。そこで、`error` があり、かつ未保存のまま、の時だけヘッダーを「保存できません」にした。エラーのトーストは、`error` が変わった時に1回出す。
- **画面名**：サイドバーと同じ日本語の名前にそろえた（取り込む・履歴など）。`#main-content` の読み上げ名（`aria-label`）は E2E が確かめているので、今の名前のまま残した。
- **E2E の「Practice」**：サイドバーの「練習」は見出しになり押せないので、Chord Dojo の項目に置き換えた。

## 8. 残った課題と申し送り

- 各画面の中の「Voicing Loop」などのボタンや、画面の中の英語は、画面を作り直す段階で扱う。
- 試聴音色とメトロノームの部品は、今の見た目のまま。モックの形（塗りのセグメント・アイコンだけのボタン）は、共通の部品として後で直すとよい。
- `#main-content` の読み上げ名は古い名前（例：`Vault`）のまま。E2E と合わせて、段階3の日本語化で直すとよい。
- 設定のダイアログは段階8で画面にする。そのとき、ダイアログの間のトーストの位置（上の中央）は不要になる。

## レビューで見てほしい所

1. **閉じるの経路**：`windowControls.ts` の `requestWindowClose()` が `close()`（閉じる要求）で、`destroy()` や終了の命令を直接呼ばないこと。`TitleBar.test.tsx` の closeGuard を通すテストの組み方。
2. **権限の追加**：`capabilities/default.json` の7つ（特に `allow-internal-toggle-maximize` と `allow-set-decorations`）が必要十分か。
3. **保存の状態**：成功で何も出さない・失敗の条件（`error` かつ未保存）・エラーのトーストの出し方（`App.tsx`）。
4. **ダイアログの間のトーストの位置**（`Modal.tsx` の `useAnyModalOpen` と `components.css`）。
5. **E2E の置き換え**：`data-nav` への機械的な置き換えで、画面の中の同じ名前のボタン（例：進行ページの「Voicing Loop」）を巻き込んでいないこと（`nav` に絞ったものだけを置き換えた）。
