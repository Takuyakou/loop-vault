### ホーム（モック `RHome.dc.html`／狭い時 `RHomeCompact.dc.html`）

順と形はモックどおり：**続きから（8列）・取り込む（4列）／今日のループ（7列）・今日の練習（5列）／最近の進行（12列）**。主役の青緑のボタンは「続きをやる」の1つだけ。

| カード | 中身 | データ |
|---|---|---|
| ヘッダー | 「ホーム」と今日の日付（例：9月28日（月））。外枠のヘッダーに小さな副題の欄（`pageSubtitle`）を足した | 端末の時計 |
| 続きから | 名前・キー・BPM・小節数、1小節1マスの帯（8.8 の帯の見た目：左の太線＝発音、斜線＝保持）、「試聴」（無彩色）と「続きをやる」 | 練習の記録で最新のもの（Chord Dojo・Bass Practice のうち進行を指すもの）。無ければ最後に取り込んだ・更新した進行。どちらも無ければ出さない |
| 取り込む | 「MIDI から取り込む」と「コード譜のテキストを貼り付け」 | 取り込むを MIDI／テキストのモードで開く |
| 今日のループ | 再生（今のコードが光る）・お気に入り・「詳しく見る」（進行ページ）・「他のループ」（入れ替え、元に戻すのトースト）・コードの札（押すとそのコードを試聴、度数表示が ON なら度数） | 下の決まり。お気に入りは進行の `pinned` |
| 今日の練習 | 直近5日の点（`--lv-record`）と「n日連続」、Chord Dojo と Bass Practice の行（今日の数と輪） | 今ある記録だけ（下） |
| 最近の進行 | 最大5行。試聴・名前とキー/BPM/小節数・コードの札・取り込み元・いつ・「練習」（Voicing Loop）。行を押すと進行ページ | 進行の `capturedAt` と Idea の `updatedAt` の新しい方 |

- 大きさ：中身の欄の幅で切り替える（container query）。1400px 以上＝モックの 8/4・7/5・帯16マス。1440×900（中身 約1160px）＝同じ順で 7/5・帯12マス。1200px 未満の窓（サイドバーがアイコンだけ）＝`RHomeCompact` の形（帯8マス・札6つ・余白を詰める）。768×640 は1列に積み、横にはみ出さない（`p89:screens` で確認）。
- 進行が1つも無い時は「最初の進行を取り込む」の空の状態だけを出す（主役ボタン「取り込む」）。

- トーストは `useNotify()`：お気に入り＝成功、入れ替え＝お知らせ（「元に戻す」付き）、試聴の失敗＝エラー。お気に入りボタンは `IconButton` の `tooltip="styled"`。

**今日のループ**（`src/views/home/todayLoop.ts`。人間が決めた決まりどおり）：

1. 候補は表示中の Idea（隔離中は Vault の読み込みで外れている・削除待ちも除く）のすべての進行。
2. 端末の日付（`YYYY-MM-DD`）を種にした重み付きの決まった選び方。同じ日は開き直しても同じ（端末ローカルの `picks` に残す）。
3. 直近7日（前日〜7日前）に出た進行は除く。全部が除かれる時はこの条件を外す。
4. お気に入りは重み3。
5. 入れ替えは「今の進行・その日に出たもの・直近7日」を除いて選ぶ（無ければ今の進行以外）。結果はその日のうち保たれ、「元に戻す」で前の進行に戻り、入れ替えた方は「出た記録」から消す。候補が1つだけの時は「ほかに入れ替えられる進行がありません」と出す。
6. 記録は `localStorage` の `loop-vault:today-loop:v1`（2週間分だけ残す）。Vault には書かない。
7. 単体テスト（日付固定）：同じ日は同じ・7日の除外・全部除外の時・お気に入りの重み（3000日で約50%＝3/(3+3)）・入れ替えと元に戻す・2つだけ/1つだけ・消えた進行・壊れた保存値。

**練習の記録の集め方**（`src/views/home/practiceActivity.ts`、読むだけ。新しい保存先・項目は作っていない）：

| 練習 | 読むもの | 日付 |
|---|---|---|
| Chord Dojo | 進行の `practice` | `lastPracticedAt`（無ければ `provisional.clearedAt`、次に `transposition.updatedAt`） |
| Bass Practice | 練習ファイルの `attempts`（評価済み）・`rhythmAttempts`・`chordContextHistory`・`rootMotionHistory`・`sourceBasslineHistory` | それぞれの `completedAt` |
| Voicing Loop | 調べた結果、日付の付いた練習の記録は無い（`loop-vault:voicing-loop-recents:v1` は最近開いた進行の並びだけで日付なし） | 数えない |

- 日付の無い記録は数えない：Chord Dojo の `practice` で上の3つの日付がどれも無いもの（古いデータで `confirmedLevel` だけのもの）と、評価済みで `completedAt` の無い Degree Echo の試行。数は内部で `undatedCount` に数えるが画面には出さない。
- 日付は端末の日付で数える（既存の `derivePracticeHomeSummary` は UTC の日付で数えていた。ホームでは使っていない）。
- 連続日数：1日に1つでも記録があればその日を数える。今日にまだ記録が無い時は昨日から数える（今日の途中で0に見えないように）。
- 限界：Chord Dojo は進行ごとに最後の日付しか残さないので、同じ進行を何日も続けた日は最後の日しか数えられない。連続日数は実感より短く出ることがある（EXE で確かめてほしい項目 3）。
- 今日の数：Chord Dojo は「今日練習した進行の数」、Bass Practice は「今日の問題・セッションの数」。目標の数は決め打ちせず、輪は今日の数が1以上なら一周、0なら空。

### Vault（新しいモックなし。`Vault.dc.html` の中身の並び＋デザインシステム）

- **一覧は進行だけ**。Idea のカードの格子と「ライブラリ／一覧／Idea」の切り替えを外した。一覧の件数は段階3と同じ（どちらも表示中の Idea のすべての進行）。
- **進行のない Idea**：一覧の最後に「進行のない Idea（n件）」のまとまり（最初は閉じている）。開いて押すと今の Idea 詳細。絞り込み中は出さず、検索の文字は Idea の名前にも当てる。合成データ（スクリーンショット・E2E）では0件。いつもの Vault の件数は EXE で確かめてほしい（項目 5）。
- **左の絞り込み**（幅256px、件数付き）：お気に入り・取り込み元（MIDI・テキスト・Live MIDI）・キー（4列の格子、`C`・`Am` の短い名前、ツールチップは「Cメジャー」）・長さ（〜4／5〜8／9〜16／17小節〜）・タグ（自分で付けたタグと Smart Library の自動のタグ、多い順に8つ、「ほか n件を表示」）。欄の中は「または」、欄どうしは「かつ」。件数はその欄の選択を除いた条件で数え、0件で選んでいない項目は押せない。「すべて解除」は左の見出しと、一覧の上の条件の札の列の2か所。中身の欄が 900px 未満の時は「絞り込み n」ボタンから左の引き出しで出す（Esc と外側で閉じる）。
- **検索**（`#vault-search`、タイトルバーの検索がここに来る）：入力欄の説明は「コード名か度数（2-5-1）で探す」。
  - 度数の流れ：`2-5-1`・`2 5 1`・`251`・`b7-1`・`ii-V-I`。進行のキーから `degreeOf` で度数を出し、同じ度数が続くところは1つにまとめて連続で一致を探す。キーの無い進行は出さない。一致した行には「度数で一致：ii7 → V7 → Imaj7（2〜4番目のコード）」と出し、該当のコードの札を黄色の枠で示す。
  - コード名：前方一致（`Dm7` は Dm7・Dm7(9) に当たる）。空白や `-` で区切ると連続した並び（`Dm7 G7`）。大文字小文字は区別しない。
  - それ以外の文字：名前・ファイル名・タグ・まとめの文字・コード名の中を探す（今までの文字検索を残した）。
- **並び順**：新しい順（取り込んだ日）・名前順・長さ順（短い順）・最近練習した順（Chord Dojo の `lastPracticedAt`、無いものは後ろ）。
- **行**：試聴・名前（押すと進行ページ）・キー/BPM/小節数/日付/取り込み元・タグ（4つまで）か度数の一致・練習の札（今までの `PracticeProgressBadge`）・コードの札（8つまで＋「…」、試聴中は今のコードが光る、度数表示が ON なら度数）・お気に入り・コピー・開く（`進行を開く`）。行の余白を押すと選択、ダブルクリックと Enter で開く。
- 仮想スクロール（50件超、1行96px）とキー操作（↑↓・Space・Enter・C・S・/・Esc）は今のまま。
- 「要確認あり」の絞り込みと度数表示の切り替えは Vault に置いていない（設定の度数表示はそのまま効く）。
