# Reports

段階ごとに1つの報告と、最後に最終報告を置く。報告は日本語で書く。

名前の付け方：

- `P8.9-00-setup.md`
- `P8.9-01-foundation.md`
- `P8.9-08-final.md`

各報告に書くこと：

1. 計画（段階の最初に書く。承認は待たない）
2. 変えたファイルと commit の一覧
3. 外した機能とその移し先（該当する段階）
4. 書き換えたテスト・基準画像と、その理由。機能削除に伴って消したテストは1件ずつ
5. ゲートの結果（Test DX の要約行をそのまま貼る）と commit hash
6. スクリーンショットの場所（`p89-generated/<段階>/`。リンクにはせず、パスを文字で書く）
7. 判断ポイント：1項目ごとに「選んだこと／理由／別案」を1〜2行ずつ。結論だけを短く書き、途中の考えは書かない
8. 残った課題と、次の段階への申し送り

生の録音・私的な MIDI・端末の ID・個人の絶対パス・`.local-evaluation` の中身は報告に書かない。
