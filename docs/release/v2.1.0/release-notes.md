# Loop Vault v2.1.0

Version: 2.1.0. 公開日: 2026-11-08 (Asia/Tokyo)。

## 練習

- **Chord Dojo の作り直し**:「定番の進行」を 12 キー・ランダムキーで練習できます。Original Practice(保存した進行)、2-5-1 Master、長い進行、保存した進行の一覧も同じ画面にまとまりました。判定は 1 回答で 1 つだけ進みます。
- **Jazz Progressions**:ジャズの定番 21 進行・56 カードを 12 キーで。「① 見て弾く」「② 覚えて弾く」の順に進み、② ではヒントを見たかを周ごとに数えます。オクターブ +1・BPM の変更・通して聴く・ランダムキーにも対応しました。
- **練習画面の共通の型**:定番の進行の練習画面を 1 つの型にそろえました。①②のくり返しと「この段階をくり返す」があります。
- **Bass Practice**:度数・リズム・ベースライン・ルートの動きを聴いてまねる練習、録音して聴き比べる自己採点、MIDI で読み込んだベースラインの判定。練習の記録は専用の保存場所に置きます。
- **耳で弾く**と、アプリ全体の **MIDI 接続の共通化**。

## 取り込み

- コードカードを**削除**できます(カードのメニュー・Delete キー)。
- 小節ごと**消して詰める**ことができます。
- プレビューのフェードを滑らかにしました。
- テキスト取り込みで **`minMaj7` と `alt`** を読み、保存しても分類が保たれます。alt を含む進行は専用の保存場所(`loopvault/txt-jazz-v3/`)に置きます。

## Voicing Loop

- MIDI 鍵盤の音が鳴り、ナビゲータの塗りが再生位置に追従します(VL-13)。
- 再開したときに再生位置がガタつかないよう、音の時計から描くようにしました(VL-14)。
- **進行の選び方を作り直しました**(VL-15):「お気に入り → 最近使った → そのほか」の 3 段、2 行のコンパクトな行、数字だけの BPM、コード名の 1 行表示。お気に入りは **Vault と同じ**で、押すと次の画面から一番上に並びます。
- 下の余白を 6 つの大きさ(表示倍率 125%・150%・200% 相当を含む)で確かめました(VL-07/R-02)。

## Vault とデータ

- バックアップの回転が実バックアップだけを数え、`legacy-import.json` の置き場所を正しく扱い、後片付けに失敗しても読み込みを続けます。
- **データの形は変わりません(Vault の `fileVersion` は 2 のまま)。変わるのは保存するフォルダで、初回起動でこれまでの記録を写して使います。**
  - Vault:旧 `loopvault/data.json` → **`loopvault/txt-jazz-v3/data.json`**。元のバイトは `loopvault/txt-jazz-v3/legacy-import.json` として残り、旧ファイルとそのバックアップは変わりません。書き出すときは、alt を含まなければ `fileVersion: 2`、含めば **`fileVersion: 3`** です。
  - Chord Dojo:以前の場所から **`theme-lessons-txt-jazz-v4`** へ一度だけ読み取り専用で写します。
- 練習の記録は目的ごとの保存場所(`original-practice-v1`・`jazz-progressions-v1`・`ear-practice` など)に分かれます。
- 写す仕組みは合成データのテスト(`jazzVaultStorage.test.ts`・`txtJazzWorkflow.test.ts`・Chord Dojo の Rust テスト)で確かめており、これもリリースの検証に含まれています。

## v2.0.0 から上げるとき(重要)

- **初回起動で、これまでの記録を新しいフォルダへ写して使います。元のデータは残ります。** Vault は `loopvault/data.json` から `loopvault/txt-jazz-v3/` へ(元は `loopvault/txt-jazz-v3/legacy-import.json` に残る)、Chord Dojo は `theme-lessons-txt-jazz-v4` へ写ります。
- **移ったあとは v2.0.0 を使わないでください。** v2.1.0 で付けた変更は v2.0.0 に反映されず、v2.0.0 で付けた変更も v2.1.0 には反映されません。
- **alt を含む書き出しは v2.0.0 で開けません**(`fileVersion: 3`)。v2.0.0 に戻す必要があるときは、上げる前に Vault を書き出しておいてください。
- 上げる前に、**設定 → データ**から Vault を書き出すか、バックアップを取っておくと安心です。

## 信頼性

- テストの片付け(R-01)、Rust の安全情報の更新(R-02)、残る npm の注意 1 件(本番の zod、理由をつけて受け入れ)をしました。
- 詳しくは [release-validation](release-validation.md) を見てください。

## Windows の配布物

- 直接起動する EXE・NSIS セットアップ・MSI を、これまでと同じ決まりで作ります(署名なし)。
- WebView2 Runtime が必要です(Windows 11 には入っています)。
- 配布物の大きさと SHA-256 は [release-assets](release-assets.md) に書きます。
- 利用者の Vault・私的な録音・評価用のデータは含みません。
