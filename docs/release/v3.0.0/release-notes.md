# Loop Vault v3.0.0

Version: 3.0.0。公開日: 2026-11-22 準備(公開の日時は GitHub のリリースに従います)。

v2.1.0 のあと、画面を全部作り直し、Chord Dojo のガイド練習と Bass Practice の新しい練習画面を加えました。**v2.1.0 のデータはそのまま使えます。**

## 新しいこと

- **画面の作り直し**:字・色・面の作り、ホーム(今日のループ・続きから・練習の記録)、取り込む(MIDI とテキストの入口・取り込み前の確認)、Vault の一覧とプレビュー、進行のページの上の行、修正作業場、設定、左のメニューとお知らせの形を新しくしました。**Ctrl+K** でどこからでも探せます。
- **コード名と度数**:♯ ♭ の書き方と、ローマ数字の度数(Ⅱm7 など)で表示します。取り込むときにキーが未設定なら、自動で付けます。
- **共通の BPM**:上の帯の BPM を、Voicing Loop・Jazz の「通して聴く」・Bass Practice で共有します。
- **Voicing Loop**:練習画面と進行の選び方を作り直しました。区間は黄色で示し、区間の中を右クリックすると外せます。
- **Chord Dojo**:
  - ホームを 2 列にしました。
  - **ガイド練習**(Lv1〜Lv8 と総合確認)を加えました。見本を見て弾き、段を進めます。コースの地図・やり直しの確認・結果の画面があります。
  - **耳で弾く**(選ぶ・記録・判定・結果)、**ボイシングドリル**、2-5-1 Master の上の行を新しくしました。
- **Bass Practice**:練習を 3 段の舞台にし、弾いたベースラインを自動で判定します。ホームも整えました。

## v2.1.0 から上げるとき

- **データの形は変わりません**(Vault の `fileVersion` は 2 のまま。alt を含む書き出しだけ 3)。保存するフォルダの名前も変わらず、v2.1.0 の Vault・練習の記録は、そのまま開きます。
- 新しく足した記録(ガイド練習 `guided-course-v1`・`guided-course-advanced-v1`、ボイシングドリル `voicing-drill-v1`)は、**初めて使うときに、それぞれ別のファイルとして作られます**。これまでの記録のファイルは書き換えません。
- v2.0.0 から上げるときも、v2.1.0 と同じに、初回起動でこれまでの記録を新しいフォルダへ写して使います(元のファイルは残ります)。移ったあとは v2.0.0 を使わないでください。
- 上げる前に、**設定 → データ**から Vault を書き出すか、バックアップを取っておくと安心です。

## 気をつけること

- **Bass Practice の自動の判定は、単音の演奏を対象にした目安です**。和音や速いフレーズでは、まちがって判定することがあります。
- **配布物に署名はありません**。ダウンロードしたとき、Windows が確認の画面を出すことがあります。`SHA256SUMS` と照らして確かめてください。
- **WebView2 Runtime** が必要です(Windows 11 には入っています)。
- 対応 OS は Windows(x64)です。

## 信頼性

- `npm audit` は **0 件**(全部・本番のどちらも)、Rust の安全情報は脆弱性 **0 件** です(警告の扱いは [release-validation](release-validation.md) の §2)。
- 使うライブラリを新しくしました(zod 4・vitest 4・vite 7.3.8 と Rust の 4 つ)。
- 検証の記録は [release-validation](release-validation.md)、含めたものの確認は [release-inclusion-audit](release-inclusion-audit.md) にあります。
