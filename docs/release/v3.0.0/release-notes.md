# Loop Vault v3.0.0

公開日:2026-11-22

画面をすべて作り直した大きな更新です。Chord Dojo にガイド練習が加わりました。Bass Practice では、5 つの練習すべてで、弾いた音を自動で判定するようになりました。**v2.1.0 のデータは、そのまま使えます。**

## ダウンロード

ふつうは **`Loop.Vault_3.0.0_x64-setup.exe`** を選んでください。

| ファイル | 中身 |
|---|---|
| `Loop.Vault_3.0.0_x64-setup.exe` | インストーラー(おすすめ) |
| `Loop.Vault_3.0.0_x64_en-US.msi` | MSI 形式のインストーラー |
| `loop-vault.exe` | インストールせずに使える版 |
| `SHA256SUMS` | ダウンロードしたファイルが壊れていないかを確かめる値 |

Windows(x64)用です。WebView2 Runtime が必要です(Windows 11 には最初から入っています)。

## 新しくなったこと

### 画面をすべて作り直しました

- ホーム・取り込む・Vault・設定まで、字・色・配置を新しくしました。
- ホームの「今日のループ」では、進行を小さなピアノロールで見ながら、すぐに聴けます。「続きから」で、前の練習や編集に戻れます。
- **Ctrl+K** で、どの画面からでも探せます。
- コード名に加えて、Ⅱm7 のようなローマ数字の度数でも表示します。取り込む時にキーが決まっていなければ、自動で付けます。

### Chord Dojo:ガイド練習

- Lv1〜Lv8 と総合確認の 9 段階で、見本を見て弾きながら、順番に進めます。
- コースの地図で、今どこまで来たかが分かります。
- 「ボイシングドリル」を加え、「耳で弾く」も作り直しました。

### Bass Practice:弾いた音を自動で判定

- 度数・リズム・ルートの動き・コード進行のベース・MIDI のベースラインの 5 つの練習を、「聴く → 弾く → 結果」の同じ流れにしました。
- 録音しながら弾くと、合った音・違う音・早い/遅いを、その場で示します。
- 録音せずに弾いて、自分で評価することもできます。

### Voicing Loop

- 練習の画面と、進行の選び方を作り直しました。
- くり返す区間を黄色で示します。区間の中を右クリックすると外せます。

### BPM を共通に

- 画面の上の BPM を、Voicing Loop・Chord Dojo の Jazz の「通して聴く」・Bass Practice で共有します。

## v2.1.0 から上げる方へ

- 新しい版をインストールするだけで、Vault と練習の記録はそのまま開きます。
- 念のため、上げる前に「設定 → データ」から Vault を書き出しておくと安心です。
- v2.0.0 から上げる場合は、初めて起動した時に、これまでの記録を新しい場所へ写して使います(元のファイルは残ります)。そのあとは v2.0.0 を使わないでください。

## 気をつけること

- 配布ファイルには署名がありません。そのため、起動の時に Windows が「Windows によって PC が保護されました」と出すことがあります。「詳細情報」を押すと「実行」が出ます。気になる時は、`SHA256SUMS` の値と照らして確かめてください。
- Bass Practice の自動の判定は、1 音ずつ弾いた時の目安です。和音や速いフレーズでは、正しく判定できないことがあります。
- データはすべて手元の PC に保存します。配布ファイルに、個人の Vault や録音は入っていません。
