# v3.1.0 の配布物

Windows x64。配布物はテストを行ったリリースと同じツリーから `npx tauri build` で作成します。

| ファイル | 形式 |
|---|---|
| `Loop.Vault_3.1.0_x64-setup.exe` | NSIS インストーラー |
| `Loop.Vault_3.1.0_x64_en-US.msi` | Windows Installer |
| `loop-vault.exe` | 単体起動版 |
| `SHA256SUMS` | 配布物3ファイルの SHA-256 |

ハッシュは [SHA256SUMS](https://github.com/Takuyakou/loop-vault/releases/download/v3.1.0/SHA256SUMS) で確認できます。配布物のバイト数・ハッシュ・作成時刻はビルド後の公開前確認に記録します。成果物を確定した後もテスト済みのGitツリーを保つため、実測値は配布物側で管理します。
