# Loop Vault v3.1.0

公開日:2026-11-23

テキスト取り込みを 1 つの入力にまとめ、MIDI 鍵盤で 1 コードずつ入れられるようにした更新です。初めての方向けのサンプル進行と、ガイド練習の「ひとこと」も良くしました。**v3.0.0 のデータは、そのまま使えます。**

## ダウンロード

ふつうは **`Loop.Vault_3.1.0_x64-setup.exe`** を選んでください。

| ファイル | 中身 |
|---|---|
| `Loop.Vault_3.1.0_x64-setup.exe` | インストーラー(おすすめ) |
| `Loop.Vault_3.1.0_x64_en-US.msi` | MSI 形式のインストーラー |
| `loop-vault.exe` | インストールせずに使える版 |
| `SHA256SUMS` | ダウンロードしたファイルが壊れていないかを確かめる値 |

Windows(x64)用です。WebView2 Runtime が必要です(Windows 11 には最初から入っています)。

## 新しくなったこと

### テキスト取り込み

- 「標準」「拡張」の読み方の切り替えを無くし、1 つの入力にしました。今までのどちらの書き方も、そのまま読めます。
- コード譜をそのまま貼り付けられます。歌詞の行は読み飛ばし、全角の記号などはそろえて読みます。何をしたかは 1 行で知らせ、「整えたテキストに置き換える」で入力を整えられます。
- `[Aメロ]` などの見出しで、プレビューを区切ります。
- 読めない所には波線を引き、「直す所」の一覧からその場所へ移れます。`Hm7` のような書き方は「Bm7 に直す」で直せます。
- カードを押すと入力の同じコードが、入力のコードを押すとカードが選ばれます。カードは右クリックか Delete で消せます。
- 拍子とキーの選び方を新しくしました。拍子は 1/4〜12/4 から選べます。

### 鍵盤で入れる

- テキスト取り込みの「鍵盤で入れる」を押すと、MIDI 鍵盤で和音を押さえて離すたびに、コードが足されます。押した音が、そのカードの音として残ります。
- 長さ(1 小節・2 拍・1 拍)・休符・「1 つ戻す」が使えます。

### サンプル進行

- Vault が空の時に「サンプル進行を 3 件入れて試す」を押すと、王道進行・丸サ進行・循環進行が入り、すぐに聴いたり練習したりできます。タグ「サンプル」が付き、ふつうの進行と同じように消せます。

### Chord Dojo のガイド練習

- Lv1・Lv2 の耳の問題で、転回形でも正解になりました(ルートが合っていれば、配置は自由です)。
- Lv4〜総合確認の 5 問ごとの「ひとこと」が、間違え方に合わせて具体的になりました。お手本と弾いた音を聴き比べることもできます。
- 結果の鍵盤で、足りなかった音も緑で示し、点線の輪を見やすくしました。

### Voicing Loop

- 「思い出す」では、次のコードの鍵盤を出さないようにしました。
- 再生中・一時停止中にオクターブや詳しい設定を変えても、音に反映されなかった不具合を直しました。
- 一時停止すると、そのカードの頭に戻ります(停止は今までどおり最初へ)。止める時のプツッという音を無くしました。

### そのほか

- Bass Practice・Chord Dojo・Voicing Loop のホームの「続きから」と「続ける」の形をそろえました。
- 画面の文字がドラッグで選択されないようにしました。入力の欄や曲名、コードの並びなどは今までどおり選べます。

## v3.0.0 から上げる方へ

- 新しい版をインストールするだけで、Vault と練習の記録はそのまま開きます。
- テキストで保存した進行も、今までどおり開けます。これから保存する進行では、同じコードを続けて書いた所(`| C | C |` や `| C % |`)も、弾き直しとして残ります。
- 念のため、上げる前に「設定 → データ」から Vault を書き出しておくと安心です。

## 気をつけること

- 配布ファイルには署名がありません。そのため、起動の時に Windows が「Windows によって PC が保護されました」と出すことがあります。「詳細情報」を押すと「実行」が出ます。気になる時は、`SHA256SUMS` の値と照らして確かめてください。
- 「鍵盤で入れる」には MIDI 鍵盤が要ります。
- データはすべて手元の PC に保存します。配布ファイルに、個人の Vault や録音は入っていません。
