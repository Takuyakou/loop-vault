# Loop Vault v3.2.0

公開日:2026-11-27

テキスト取り込みで、カードの音(重ね方と高さ)をその場で直せるようにし、Voicing Loop で MIDI 鍵盤を弾き合わせられるようにした更新です。自動で作るボイシングを、分かりやすい 4 つの形に作り直しました。「修正作業場」は「進行エディタ」という名前に変わりました。**v3.1.0 のデータは、そのまま使えます。**

## ダウンロード

ふつうは **`Loop.Vault_3.2.0_x64-setup.exe`** を選んでください。

| ファイル | 中身 |
|---|---|
| `Loop.Vault_3.2.0_x64-setup.exe` | インストーラー(おすすめ) |
| `Loop.Vault_3.2.0_x64_en-US.msi` | MSI 形式のインストーラー |
| `loop-vault.exe` | インストールせずに使える版 |
| `SHA256SUMS` | ダウンロードしたファイルが壊れていないかを確かめる値 |

Windows(x64)用です。WebView2 Runtime が必要です(Windows 11 には最初から入っています)。

## 新しくなったこと

### ボイシングの形を 4 つに

- 自動で作るボイシングの形を作り直しました。最初は今までどおりの「**基本**」(音も今までと同じ)で、練習したい形として **シェル・ルートレス A/B・シェル+上の三和音・4 度積み** の 4 つを選べます。シェルとルートレスには **テンションを足す・広げる** の 2 つの部品を付けられます。Voicing Loop では基本にも付けられます(今までの「Colorを加える」「Open配置」の代わり)。
- Voicing Loop の基本で、今まで音を作れなかったコード(7alt など)にも音が付くようになりました。テキスト取り込みで試聴した時と同じ音で、カードに「代わり」が付きます。今まで鳴っていたカードの音は変わりません。今までは、テキスト取り込みと Voicing Loop に、別の名前の形が合わせて 11 個ありました。
- テキスト取り込みと Voicing Loop で、同じ形・同じ名前を使います。
- 「テンションを足す」は、そのコードに何が足されるか(たとえば Cmaj7 なら「+9(D)」)をボタンに出します。
- その形で作れないコードは、近い形で鳴らし、カードに「代わり」が付きます。
- 低い所で音が濁らないよう、編曲の本でよく使われる間隔の基準で置きます。左手と右手は 1 オクターブより離れないので、どのキーでも形の見え方がそろいます。
- Voicing Loop の上の段では、「基本」と「詳しい設定」を「形 ▼」1 つにまとめました。「最適化」は「なめらかにつなぐ」という名前に変えて、「形 ▼」の中に入れました(中身は同じです)。
- Voicing Loop の今のコードの下の行から、中の決まりの名前(Teacher Style・Literal など)を外し、「ほかの押さえ方」「省いた音」だけを日本語で出すようにしました。「MIDI 未接続」は上の行の小節数の右に出ます。
- 音を直す帯・メニュー・運指や弾き合わせの切り替えが、一瞬ではなく、なめらかに出たり消えたりするようになりました。切り替えても、ほかの物の位置は動きません(動きを減らす設定の時は、今までどおりすぐ切り替わります)。
- Voicing Loop:ボタンやカードを選んでいる時でも、Space で開始・一時停止できるようにしました(文字を打つ欄の中は除きます)。
- 音を直す帯の音名を、コードの度数で綴るようにしました(C メジャーの Em7 の 9 度は G♭ ではなく F♯)。
- テキスト取り込みの試聴の段から「1 / 8 小節」の表示をなくしました。
- テキスト取り込みで保存した後の知らせを、右下のお知らせ 1 つにまとめました。お知らせの「Voicing Loopで練習」から、すぐ練習を始められます(プレビューの下に出ていた「保存した進行を練習できます」の面は無くしました)。
- 分数コード(C/E など)で、ベースのすぐ上に半音でぶつかる音や、ベースと近すぎる短 9 度を置かないようにしました(たとえば Cmaj7/B・F♯m9/G♯)。どの形・部品でも同じ決まりです。よく使う分数コードの音は今までと同じです。
- テキストで書いた分数コードのベースが、別の字で出ていたのを直しました(F♯m9/G♯ が F♯m9/A♭ と出ていた)。書いたとおりの字で出ます。
- Voicing Loop で自動生成やほかの形を選んでいる時、カードを押すと元MIDI の音が鳴ることがあったのを直しました。今ループで鳴っている音が鳴ります。
- 前の版で保存した進行の音は、そのまま鳴ります(作り直しません)。

### テキスト取り込み:カードの音をその場で直す

- プレビューのカードを選ぶと、下に鍵盤の付いた帯が出ます。鳴らす音が光り、キーにはコードの中での役割(R・3・5・7・9 など)が出ます。
- 鍵盤を押すと、音を足したり外したりできます。まだ鳴らしていないコードの音には小さな輪が、前のカードの音には紫の線が付くので、つながりを見ながら直せます。
- 「形」を、音の並びの絵から選べます(上の 4 つの形と 2 つの部品)。
- 「転回」「高さ(1 オクターブ)」「前のコードに近づける」(1 つ前のカードから一番動きの少ない転回と高さにする)が使えます。
- 「直す範囲」で、このカードだけ・同じコードのカード全部・進行ぜんぶ、を選べます。たとえば「ぜんぶ」にして高さを下げると、進行全体が 1 オクターブ下がります。
- 「MIDI 鍵盤で弾いて入れる」を押すと、和音を弾くたびにそのカードに入って次のカードへ進みます。進行を頭から順に弾き直せます。
- 帯の上の行の「↶」の右に「最初から」があり、そのカードを選んだ時の音に戻せます。
- 音を変えてコードが変わった時は、入力のコード名も書き換わります(たとえば Em7 から D を外すと Em)。
- キーボードだけで直せます:← → でカードを移り、↑ ↓ で転回、Shift+↑ ↓ で高さ、1〜5 で形。一覧は右上の「?」にあります。
- 各カードの下に、音の高さを示す点が出ます。どのカードが高いか・低いかが、進行全体で一目で分かります。
- カードにマウスを乗せると(キーボードで移った時も)、Voicing Loop のカードと同じように少し浮き上がります。
- これに合わせて「音を細かく直す」は無くなりました。カードの長さや分け方を直したい時は、保存した後に Vault で進行を開いてください(進行エディタで直せます)。

### Voicing Loop:弾き合わせ

- 下の操作の帯の「弾き合わせ」を ON にすると、進行を流しながら MIDI 鍵盤で一緒に弾けます(最初は OFF です)。
- 鍵盤で、合っている音は緑に ●、違う音は赤に × が出ます。弾きながら、その場で指を直せます。「思い出す」の時は、目安を隠したまま、押した音だけが答え合わせされます。
- カードを通り過ぎると、そろったカードに ✓、そろわなかったカードに ✖ が付きます。進行の行に、この周の「達成 6/8」が出ます。
- 判定は 2 つから選べます。「コード一致」(最初はこちら)はコードの音がそろえば押さえ方は自由です(ルートと 5 度は省いてよい)。「押さえ方どおり」はカードに出ている押さえ方と同じ音(全体が 1〜2 オクターブずれていても可)。
- 少し早めに弾いた和音、前のコードから指が離れ遅れた音、ペダルで残っている音は、間違いにしません。
- 「この進行を元MIDIに」を「この進行を元の音に」にし、ほかのボタンと同じ見た目にしました。テキストから取り込んだ進行でも、取り込んだ時の音にまとめて戻せます(自分で直した音はそのままです)。

### 鍵盤で入れる

- MIDI 鍵盤を弾きながら、PC のキーで長さ(1・2・3)・休符(0)・1 つ戻す(Backspace)を切り替えられます。
- 「もう一度(R)」で、前のコードを今の長さでもう一度入れられます(`%` と同じ)。
- プレビューの最後の「＋」を押す(右クリックでも)と、次のコードのパレットが開きます。今の進行とキーに合う候補 5 個(定番・展開・なめらか・あなたの Vault の好み)と、そのキーの 7 つのコードから、押して試聴し、「＋」で末尾に足せます。長さは 1 小節・2 拍・1 拍から選べます。続けて足せて、Ctrl+Z で戻せます。外との通信はしません。
- 鍵盤を 3 オクターブにし、押さえている鍵を分かりやすくしました。右に、押さえている和音の名前と音名が出ます。右上の「×」で閉じられます。

### コード譜の貼り付け

- `[C]きょうも[G]あるく` のように、歌詞の中にコードを書いた形も読めるようになりました。長さは 1 コード 1 小節で入ります。
- `C, G, Am, F`・`C-G-Am-F` のように、カンマやダッシュで区切った書き方も読めるようになりました(DAW のコード進行の欄に打つ書き方)。`.` は前のコードのくり返しです。
- コード譜の「Key: D minor」「BPM: 108」「Time Signature: 4/4」のような行を読み、キー・BPM・拍子に入れます(行には「設定」の札が付きます)。「--- A Section ---」のような行は見出しとして読みます。
- BPM の欄が空の時は、試聴で使う上の帯の BPM を欄の中にうすく出します(「試聴 120」の字は無くしました)。
- コード名のすぐ後ろに `{C3 G3 E4 B4 D5}` のように音を書くと、そのカードはその音で鳴り、その音で保存されます(C4 が真ん中のド)。

### 名前の変更

- 「修正作業場」を「進行エディタ」に改めました。中身は同じです。

### そのほか

- プルダウンを開いた時の一覧を、アプリの見た目(暗い面、選んでいる物が青緑)にそろえました。キーボードでも、今までどおり選べます。
- 形のメニューの項目に、マウスを乗せた時の色を付けました。プルダウンの一覧が、すっと出てすっと消えるようにしました。MIDI から取り込む画面の「落とす」を「ドロップ」にそろえました。
- コードからキーを自動で決める時、5.5 割のコードがそのキーに合えば決めるようにしました(今までは 7.5 割)。同じ音の長調と短調(C メジャーと A マイナーなど)は、最初のコードで決めます。
- 覚える/思い出すを切り替えた時の動きを、行きと帰りで向きがそろうようにしました。
- テキスト取り込みの鍵盤が「つながっていません」と出ていた所を、Voicing Loop と同じ「MIDI 未接続」にしました。
- テキスト取り込みの「?」を右上に移し、書き方とキー操作を短い表にまとめました。
- 各モードのホームの「続きから」の帯を、高さはそのままで見やすくしました。
- Chord Dojo:練習の中の「MIDI 未接続」の知らせを、結果が変わる所だけ小さい 1 行にしました(つながっているかは上の帯で分かります)。耳で弾くのカードの「押すと鳴ります」の字と「何度でも。印は付きません」を外し、選ぶ画面の右の列のズレを直しました。
- ボタンの字が縦に折れないようにしました。
- 窓の幅が狭い時・広い時の、進行エディタの並びを整えました。
- 前に画面から外した AI のアドバイザーの、使われていなかった仕組みを取り除きました。設定の画面から、前に保存した API キーを確かめて消すことは、今までどおりできます。
- ソースコードのドキュメントを整理し、README に技術の説明と短いデモを足しました。

## v3.1.0 から上げる方へ

- 新しい版をインストールするだけで、Vault と練習の記録はそのまま開きます。前の版で選んだ形の音も、そのまま鳴ります。
- Voicing Loop の自動生成で選んでいた形は、近い新しい形に読み替えて開きます(「基本」はそのまま基本、「骨組み」はシェル、「ルートレスシェル」「左手 Rootless」はルートレス)。「基本」に付けていた「Colorを加える」「Open配置」は、基本の「テンションを足す」「広げる」として開きます。
- 念のため、上げる前に「設定 → データ」から Vault を書き出しておくと安心です。

## 気をつけること

- 配布ファイルには署名がありません。そのため、起動の時に Windows が「Windows によって PC が保護されました」と出すことがあります。「詳細情報」を押すと「実行」が出ます。気になる時は、`SHA256SUMS` の値と照らして確かめてください。
- 「MIDI 鍵盤で弾いて入れる」「鍵盤で入れる」「弾き合わせ」には MIDI 鍵盤が要ります。
- データはすべて手元の PC に保存します。配布ファイルに、個人の Vault や録音は入っていません。
