# P15-04 再生中の縦線を滑らかにし、鳴っている音を分かりやすくする

ブランチ `feat/p15-import-check`（P15-03 の追加の手直しの後）。対象は取り込み前の確認画面の再生だけ。
`src/domain/midi/**` は変えていない（`sessionPreviewNotes` は読むだけ）。音の鳴らし方（`previewMidiNotes`）も変えていない。解析に渡す内容も変わらない。

## 1. 原因（着手前に自分でも確かめた）

`PreAnalysisWorkspace.tsx` の旧 `playSession` は、`setInterval` の 50ms（1秒に20回）ごとに `setPlayheadBeat` を呼んでいた。

- 縦線は1秒に20回しか進まないので、60Hz の画面でカクつく。
- そのたびに約1100行の画面全体が描き直され、ピアノロールの canvas も全部の音と格子を描き直していた（縦線1本のために）。

修正作業場（`CorrectionWorkspace.tsx`、spec v2.5 §7.3）は同じ問題を既に解いている。同じ作り方にそろえた。

## 2. 変えたこと

| 内容 | 場所 |
| --- | --- |
| 再生中は `requestAnimationFrame` で毎フレーム動かす。位置は ref に持ち、`playheadBeat`（状態）は**停止したときに1回だけ**書く | `PreAnalysisWorkspace.tsx`（`startFrames` / `endFrames`） |
| ピアノロールを2層にした。下の層＝格子と音（表示範囲・役割・線・選択が変わったときだけ描く）。上の層＝縦線と鳴っている音の光（再生中は毎フレーム、マウス操作は下に通す） | `PreAnalysisPianoRoll.tsx`（`drawPianoRoll` から縦線を除いた、新しい `drawPlaybackOverlay`） |
| 「再生位置を追う」のページめくりのときだけ、下の層を描き直す（めくり方は今のまま） | 同上 |
| 全体の帯（`TimelineNavigator`）の再生位置も、同じフレームで直接動かす。ページをめくっても古い位置に戻らない | `OverviewBand` |
| 小節番号は、小節が変わったときだけ書き換える | `barRef` |
| 縦線の色はアプリの強調色（ティール `#42d8c6`）。動きを減らす設定でも動かす（位置の情報なので） | `PLAYHEAD_COLOR` |
| 鳴っている音を光らせる（役割の色を明るくして白い縁）。左の鍵盤の欄で、鳴っている高さの段を役割の色で塗る | `drawPlaybackOverlay` |
| 再生の行に「鳴っている音 C2 C3 E3 G3」を低い順に出す。変わったときだけ書き換える。停止で消す。1023px 以下では出さない | `lv-pa-sounding`（`playbackView.ts` の `soundingText`） |
| 鳴っている音は、始まり順に並べた音から、今の位置の前後だけを二分探索で探す。長く伸ばした音（16拍超）は別の小さな一覧に分けてある。組が変わったときだけ参照が変わる | `playbackView.ts` |

**光らせる音は、実際に鳴らす音と同じ。** `audibleNotes` は `sessionPreviewNotes` と同じ規則（使うパート・重複でない・ファイルが消音でない・ソロ／消音）で、同じ集合になることをテストで確かめている。表示を隠した（目のアイコン）パートの音は鳴るが描かれていないので、光は出さない（音名には出す）。

## 3. 再生中は凡例の場所に「鳴っている音」を出す（承認後の追加の手直し）

最初の版では、幅 1440px で凡例が幅を取り、音名が「鳴っている音 C2 …」と省略されていた。そこで、**再生中は色の凡例を隠し、その場所に「鳴っている音」を出す**ようにした。停止すると凡例に戻る。

- 再生の行（`lv-pa-transport`）に、再生中だけ `data-sounding` が付く（フレームの動きが始まったとき・終わったときに1回ずつ）。CSS で `.lv-pa-transport[data-sounding] .lv-pa-legend { display: none; }`。
- 音名の欄は、凡例の分の幅まで使える。何も鳴っていない間は「鳴っている音 なし」と出す（空のままにしない）。ツールチップに全部の音名も入れてある。
- 1023px 以下では、これまでどおり音名も凡例も出さない。
- 再生していないときの見た目は変わらない。視覚ベースラインも変わっていない（`git status` で画像の変更なし）。
- 1440×900 で6音の和音（C3 E3 G3 B3 D4 F4）が省略されない。再生の行の高さも変わらない。画面写真: `docs/reports/P15-04-assets/six-notes.png`。

## 4. テスト（`PreAnalysisPlayback.test.tsx`、13件）

| # | 内容 |
