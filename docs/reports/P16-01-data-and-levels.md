# P16-01 出題用の進行・キー・レベル・出題の選び方(追加の進行 304 個を含む)

ブランチ `feat/p16-ear-practice`。`P16-00-decisions.md` と `P16-01-extra.md` に従って、画面を作らずに
「問題を1つ作って、鳴らす音と判定を出す」ところまでを `src/domain/earPractice/` に作った。
**今の Chord Dojo のコード(`judging.ts`・`chords.ts`・`chordVoicing.ts`)と `src/domain/midi/**` は変えていない。**

## 1. 作ったもの

| ファイル | 内容 |
|---|---|
| `earProgressions.json` / `earProgressionsExtra.json` / `earDisplayNumbers.json` | 出題用の進行 60 個、追加の進行 304 個、表示用の番号 364 個(データのまま。元の MIDI の押さえ方・素材の出どころが分かる言葉は入っていない) |
| `degrees.ts` | 度数の書き方(`bVIImaj7`・`I/III`・`I6/9/II` など)を読む。`/` の後ろが度数のときだけベース(`6/9` の `/9` はベースではない) |
| `keys.ts` | 12のキーの名前(メジャー C・D♭…B、マイナー Cm・C♯m…Bm)と、♭/♯ の決まり |
| `spelling.ts` | 度数とキーからコード(`ChordSymbol`)を作る。度数が ♭ ならフラット、♯ ならシャープ、付かなければキーに合わせる。マイナーキーは平行長調で決める(D・G マイナーはフラット、E♭ マイナーもフラット) |
| `chordTones.ts` / `voicing.ts` | 鳴らす音。**ベースを C2〜B2(36〜47)に置き、上の音はそれより1オクターブ以上上**から積む。分数コードは書かれたベースが一番下で、ルートを上の音に鳴らす。7(♯11)・7(♭13)・7alt は完全5度を除く。7alt は 3度・♭7・♭9・♭13(例 G7alt = G2 \| B3 F4 A♭4 E♭5) |
| `judge.ts` | `earJudge`: `core`(`judgeChord` をそのまま使い、mMaj7 は合格のあとに長7度を確かめる)/ `pitchset`(7alt。音名の組がそろい、余分な音が無く、一番下がベース)/ `sounded`(自分の進行の曲の音。音名の組と一番下の音名が同じ) |
| `levels.ts` | `earChordLevel` / `earLevelOf`。**ラベルの文字列でなく `ChordSymbol` で**判定する |
| `bank.ts` / `question.ts` / `select.ts` | 出題用の進行の読み込み(60+304)、`EarQuestion`、出題の選び方(直近10問を避ける・ランダムのキーは直前と違う・腕試しの問題は腕試しのキーで出さない・「追加の進行も出す」の入り切り)、腕試しの固定の問題 |
| `builtinSource.ts` | 定番の進行(`buildBuiltin(id, key)` で12キーに移調し、この練習の鳴らし方で鳴らす。長いものは小節の頭で切り出す) |
| `collection.ts` | 自分の進行。`x/4`(x が 2〜12)と拍子なしだけ対象。小節の頭から4・8・16小節を切り出す。保存した音は保存のまま鳴らし、`core` に通らないコードは `sounded`。キーを変えるときは、保存した音も同じ量だけ平行移動する |

## 4. 数字(参考)

- 鳴らす音: 出題用の進行・追加で のべ 36,468 コード。最低音 36、最高音 85(MIDI)。上の音の 95% は 74 以下。84 を超えるのは1コードだけ(音は最大6つ)。定番の進行は 2,448 コード、最高 80。
- `pitchset`(7alt)は 660 コード(12キー分)。
- 定番の進行 43 個は、12のキーすべてで、この練習の鳴らし方で判定に通る。

## 5. 気づいたこと・お願い

- **追加の進行の名前**(「ii–V–I・セカンダリードミナント」など)は答えの説明なので、**練習中は出さない**(「耳の課題 037」)。データには残してあり、`EarQuestion.name` は結果の画面でだけ使う。表示は Stage 02。26個は名前が空。
- **自分の進行の名前**は問題に入れていない(内部の id と小節だけ)。選ぶ画面の一覧に出す名前は `CollectionSegment.displayName` にあり、記録には入れない。
- 自分の進行で、この Stage ではレベルを「キーが分かる(`keyContext` がある)ときだけ」三和音の基本形をレベル1にする。分からないときは2(指示書どおり)。
- 腕試しは今の60個だけを使う(追加には入っていない)。
- 保存データ・元の素材のファイル名などは、コード・テスト・報告・コミットメッセージに書いていない。
