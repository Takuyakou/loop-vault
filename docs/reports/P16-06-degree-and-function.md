## 2. 度数と機能(§2・§3)

- 出題用の進行: `Ⅰ…Ⅶ`(全角)・`♭`・`♯`、種類の部分はそのまま。マイナーの曲も、主音のメジャースケールからの度数(`Ⅰm`・`♭Ⅲ`・`♭Ⅵ`・`♭Ⅶ`)。
- 機能の規則は、§3 の順(1.〜6.)・2つの表をそのまま実装した。最後のコードは次を見ない。
- **定番の進行・自分の進行**は、コード名の根音の文字が主音の文字から何番目かで数字を決め、高さの差で ♭/♯ を付ける。**私が足したこと**: Dojo の定番の進行の名前は、キーによって綴りが違う(LF-DOJO-003)。たとえば D♭ の定番で、Ⅳ のコードが F♯maj7 と綴られる。文字で数えると `♯Ⅲ` になってしまうので、**長音階の半音の2か所(Ⅲ–Ⅳ、Ⅶ–Ⅰ)にまたがる読み**(♯Ⅲ・♭Ⅳ・♯Ⅶ・♭Ⅰ)は、同じ高さの自然な度数(Ⅳ・Ⅲ・Ⅰ・Ⅶ)に直す。これで C の定番と D♭ に移調した定番の度数と機能が一致する(テスト6)。

## 3. カードの出し方(§1)

- まだ合っていないカードには、**名前も度数も機能も出ない**(DOM にも無い)。1つ目(名前が最初から見える)は最初から出る。合ったカードと結果の画面のカードに出る。「度数と機能を見せる」をオンにすると、全部のカードに出る(名前は「?」のまま)。
- **私が足したこと**: 画面の切り替え「度数と機能を見せる」(「1周聴く / 1コードずつ弾く / 結果」の並びの右)。指示書のテスト3(途中でオフにしても…)を確かめるには、練習の途中で切り替える手段が要るため。腕試しには出さない。
- **カードの高さは変えていない。** 実測で、1440×900 は 108px、1280×800 は 76px、768×640 は 68px のまま(度数と機能が付いても、結果の画面でも、e2e が同じ値であることを確かめる)。そのために、度数・機能が付いたカードは行の高さ・余白・「合った」印の大きさを少し詰め、768px では秒数をカードの一番上の行(番号の横)に移した。度数は 12px 以上(下の §8a)。
- 長い表記(`♭Ⅱ7(♯11)`・`D→♭Ⅲ`)は、カードの幅からはみ出さない(e2e が各行の位置を測る。はみ出したら「…」で省く)。
- 結果の画面に「機能はコードの並びから自動で推定したものです。」を出した。

## 4. 記録(§5)

- 答える前に度数・機能が**実際に表示された**カードは、記録に `degreeShown: true`。設定の「今の値」ではなく、見えた事実で決める(途中でオフにしても、オフにする前に見えていたカードは `true` のまま。途中でオンにしたら、オンにした後にまだ答えていなかったカードだけが `true`)。
- `degreeShown` のコードは、主な成績(一発・秒数・ヒントなし・聴き直し・レベルの目安・苦手・コードの動き)から外れ、耳の記録の画面の小さな欄に「度数と機能を見てから弾いたコード n ・ 一発 x%」と出る。
- 1つ目のカードは今までどおり `given` として外れる(`degreeShown` が付くのは、設定がオンのときだけ)。腕試しでは設定に関係なく出さないので、付かない。

## 5. カードを押すと鳴る(§7)

- 「1コードずつ弾く」の段階のカードと結果の画面のカードが押せる。「1周聴く」の間は押せない(見た目は押せない状態で、押しても何も起きない)。
- 鳴るのは問題の音(「今のコードを聴く」と同じ長さ・テンポ。何か鳴っていれば止めて鳴らし直す)。鳴っている間は薄い青の枠で光る(今のカードの印とは別の色)。
- **押しても動かないもの**: 今のカード・答えの判定・鍵盤の表示・楽譜・ヒントの段・秒数。カードはフォーカスを取らない(マウスを押した時点の既定の動作を止めている)ので、押した直後の Space・L などは今までどおり働く。MIDI 鍵盤で押さえている途中でも、判定は途中のまま変わらない。
- 「?」のカードを押しても、名前・度数・機能は出ない。
- 聴き直しの数え方(§7.4): 今のカード=L と同じ(`replays` +1)/ もう合ったカード=数えない / まだのカード=そのカードの `replays` +1(今のカードの秒数には影響しない)/ 結果の画面=数えない。腕試しでも押せて、同じ数え方で「聴き直しの合計」に入る。
- 見た目: 押せるカードはマウスを乗せると指の形になり、「押すと鳴ります」と出る。読み上げ用の名前は「3つ目のコードを鳴らす」。

## 8a. 承認後の直し(度数の読みやすさ)

度数は「この機能でいちばん大事な情報」なので、見た目を直した(写真は §7 の6枚を直したあとのものに差し替えた)。

- **大きさ・色**: 度数は **12px 以上**(窓の高さが 860px 以上のときは 14px)・**太字**・**通常の文字色**(灰色をやめた)。機能(T・SD・SDm・D)は 11px(高い窓で 12px)の太字の色付きで、**度数のほうが目立つ**。
- **カードの高さは変えていない**(108px・76px・68px のまま。e2e が、度数と機能が付いたカード・付かないカード・結果のカードで同じ高さであることを確かめる)。入れるために、高さが 860px 未満または幅が 1023px 以下のときは、秒数などを番号の横(カードの一番上の行)に移した。コード名は 15〜16px(度数の 12px より小さくならない)。
- **「Ⅰ m」の隙間**: 全角のローマ数字は 1em の幅で、字の左右に空きがある。使っているフォントで測ると、右側の空きは **Ⅰ が 1/3em、Ⅱ が 1/4em**、Ⅲ〜Ⅶ は 1/12em 以下だった。そこで、**Ⅰ と Ⅱ だけ**、字の前後を詰めた(`Ⅰm`・`♭Ⅰ`・`Ⅱm7` が詰まって見える)。ほかの数字は変えていない。
- 写真: `play-mixed-768x640.png`・`play-mixed-1440x900.png`(練習中)、`result-768x640.png`・`result-1440x900.png`(結果)、`play-…`(全表示)。
