# Dojo: 和音を1回弾いて2枚進む不具合の修正

ブランチ `fix/dojo-double-advance`(master `03e1ac1e` から)。master へのマージ・push はしていません。

## 1. 何が起きていたか
負荷の高いとき(遅い PC を含む)、和音を1回弾いただけで、カーソルが2枚進むことがあった。`p12-4-long`(5本)・`dojo-display-judge` の66小節などが、負荷の高い実行で落ちていた原因。

- 和音の答えが出ると、一定時間のあとに自動で次のカードへ進むタイマー(20ms ごとに見る)が `next()` を呼ぶ(`ChordDojoView.tsx`)
- `next()` が終わって `automaticTransition` が戻ってから、画面が描き直されてタイマーが止まるまでの間に、タイマーがもう一度働くことがある。そのとき `next()` は、**古い画面の答えと位置**を持ったまま `advance(latest.current)` を呼び、すでに進んだ位置からさらにもう1枚進めていた
- 記録した経過(負荷をかけた実行):`submit(位置2)` → `next(位置2)` → カーソル 3 → **同じ瞬間にもう一度 `next(位置2)`** → カーソル 4。2回目の呼び出しの前に、弾いた操作はない
- 負荷が高いほど、描き直しがタイマーより遅れて起きやすい。変更前の master でも起きる(今日の Jazz の変更とは無関係)

## 2. 直し(`next()`、5行)
- 同じ答え(`result` のオブジェクト)で、すでに進めたものは、2回目の呼び出しを捨てる(`consumedResult`)
- 答えを出したときの位置(課題・段階・キー・和音)と、いまの位置(`latest.current`)が違う呼び出しも捨てる
- 保存に失敗したときは、印を戻して、やり直せるようにする
