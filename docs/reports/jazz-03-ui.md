## 2. 作ったもの

### 2.1 共通部品(Original と Jazz の両方が使う)
`OriginalPracticeView` の中の、練習の中身を3つに分けました。

| ファイル | 中身 |
|---|---|
| `useHeldCardRun.ts` | MIDI または自分で判定・切断/再接続の停止・押さえている鍵盤と「新しく押した」音(`HeldCardJudge`)・今のカード・この画面の周回・完奏の記録・お手本・キー(L / Y / Esc) |
| `HeldCardParts.tsx` | 入力と記録の注意の表示・ヒントの1行・譜面と鍵盤 |
| `OriginalPracticeView.tsx` | 上を使う Original の画面(見た目と DOM はそのまま) |

Original の見た目・動き・既存テストの期待は変えていません。`p12-5-original.spec.ts`・`p12-5-no-restart.spec.ts` ほかは、画面の中身については何も書き換えずに通りました。**書き換えた既存の期待は2か所だけ**(下 §5)。

### 2.2 一覧(定番の進行)
- **Original Practice のあとに Jazz Progressions のまとまり**(別の `<section>`。`BUILTINS` には入れない)。「まとまりへ移る」にも `Jazz Progressions 12`
- 項目ごとに1枚:番号・題・度数の並び・キーとコード名の並び(`display`)・完奏の数(その項目の全部の版の合計。無ければ「まだ」)
- 派生がある項目は、カードの中で版を選べる(例:「半音階版(主) / 通常版」)。選ばないときは主の進行。「これを練習する」は選んだ版を開く
- 今の定番の進行・Original Practice のまとまりの並びと見た目は変えていない(カードの数 45・グループの件数は元のまま)

### 2.3 練習の画面(`JazzPracticeView.tsx`)
Original と同じ流れ(カードの音をすべて押さえると次へ、最後の後は1枚目に戻って完奏)。違うところ:
1. **キーの選択・ランダムキー・12キーの完奏の欄・大きなキー表示はありません。** キーは「キー E♭」と小さく見せるだけ
2. 上:`Jazz Progressions N`・題・度数の並び(009 は後半だけ「♭Ⅲmaj7 · Em」と、どのキーの度数かを添える)。「推奨ボイシング(元の演奏の書き起こしではない)」を小さく
3. カード:度数・コード名(`display`。`Dm6/9`・`D♯7(♯9)`)・左手と右手の音を**データの綴りで**、指番号を添えて(`F2(5) E♭3(1)`)
4. 鍵盤と譜面:このカードの音に指番号(データの指)。**譜面はデータの綴りどおり**(`jazzCardSnapshot`):009 の `F𝄪3`・`E𝄪4`、010 の `C♭4`、008 の `F4`
5. 押さえたままの案内(「A♭3 C4 G4 は押さえたままで構いません。ほかの音は弾き直します」)を、データの綴りの音名で
6. 版の切り替え:画面の上のボタン。切り替えると1枚目から、この画面の周回の数えも新しくなる
7. **「通して聴く」**:`jazzPlaybackNotes`(カードの `struck` と開始拍)を `{type:'notes'}` で、進行のテンポ 72 で鳴らす。もう一度押す(「止める」)で止まる。カード1枚(`L`・カードを押す)は今のまま
8. 戻る:Esc・「← 定番の進行」で、一覧の Jazz のカードに戻る(フォーカスも)
9. 完奏:記録は Jazz 専用の置き場所(`jazz-progressions`)。Dojo の「クリア」の記録・Original の記録には書かない。画面は「完奏」と書き、「クリア」とは書かない

### 2.4 𝄪(ダブルシャープ)
フォントの 𝄪 は小さく高い位置に出て読みにくかったので、**文字(`𝄪`)は文字のまま残し(コピー・読み上げ可)、その上に描く印**にしました:カードの音名ではマスクで、譜面では `GrandStaff` に小さな図形(Jazz の画面でだけ見える)。`GrandStaff` の変更は、ダブルシャープの音にだけ図形と属性を足すもので、ほかの画面の見た目は変わりません(耳で弾くの譜面の e2e も通過)。
