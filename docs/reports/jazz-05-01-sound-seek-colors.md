## 1. 「通して聴く」の音(案C)

- `jazzListenNotes(progression)`(`jazzProgressions.ts`):**各カードの全部の音(`expected`。押さえたままの音も)を、カードの開始拍に、長さ = カードの拍数 × 0.9、強さ 0.72**(カード1枚を鳴らす `previewChord` と同じ)で並べる。`{type:'notes'}` の経路は今と同じ。弾く練習の判定(押さえたまま/押し直し)は変えていない
- 強さ・長さの値は `JAZZ_LISTEN_VELOCITY`・`JAZZ_LISTEN_LENGTH_RATIO` として名前を付け、テストで固定
- 選んでいる楽器(ピアノ/エレピ)は、これまでどおり `run.sound` で渡している
- `jazzPlaybackNotes`(`struck` から作る)は**使う所が無くなったので、削除**した(使う所は `JazzPracticeView` と自分のテストだけだった)

Stage 00 で測ったとおり、この鳴らし方はカード1枚と音量がほぼ一致します(ピアノ 001 の RMS:カード1枚 0.0916 / 0.1023 / 0.1000 に対し 0.0916 / 0.1026 / 0.1001)。今回のコードでは音の測定は走らせていません(鳴らす音の指示をテストで確かめています)。**実機の確かめをお願いします。**

## 2. シークバー(位置が見えるだけ)

- 通して聴いている間、**カードの並びの下に細い棒**が出て、左から右へ進む。**カードの区切りに小さな目盛り**。止める・別のカードを鳴らす・画面を出ると消える(場所は取ったまま。出し入れで画面が動かない)。**クリックで飛ぶ機能は作っていない**
- **位置は音の時計から**:`onStarted` で拍 0 の音の時間(`Tone.now()`)を取り、描画のたびに `getOutputTimestamp().contextTime`(今スピーカーから出ている音の時間)を読み、`(今 − 拍0) × テンポ / 60` で拍にする。使えないときは `currentTime − outputLatency`。**画面の側で時間を数えない**(耳で弾くと同じ方法)。計算は純粋な関数(`listenPosition.ts`:`listenBeat`・`listenProgress`・`listenCardIndex`・`heardContextTime`)で、単体テストあり。棒は DOM を直接書き(React をフレームごとに再描画しない)、`aria-valuenow` は整数の % が変わるときだけ更新
- **今鳴っているカードを光らせる**:金色の輪(`data-listening`)。今の「練習中のカード」(緑の枠・`data-state=current`)とは別。通して聴く中も練習中のカードの緑の枠はそのまま
- **譜面と鍵盤は、鳴っているカードの音を見せる**(`listeningIndex` を表示に使う。今の `playingIndex` の動きを、通して聴くにも効かせた)。譜面の見出しは「B♭13 を聴いています」

## 3. 鍵盤の○の色

- `HeldCardParts` で `PracticeKeyboard` に `colorGuideHands` を渡した:**左手 = 橙・右手 = 水色**(譜面と同じ)。指の印も手の色。**変わるのは `HeldCardParts` を使う Original Practice と Jazz だけ**。見て弾く・ランダムキー・Master 2-5-1 の鍵盤は変えていない(`PianoKey` も変えていない)
- **色だけに頼らない**:Jazz は印が「左5」「右1」。**Original は指が無いので、印に「左」「右」だけ**を出した(`fingerLabels` に手の字を渡す)
- 鍵盤の上の凡例に「左手」(橙)・「右手」(水色)を足した
