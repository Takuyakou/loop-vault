## 4. ランダムキー(動き)

- **一覧**:Jazz の各項目に「**ランダムキーで練習**」(ほかの定番の進行と同じ言葉・同じ並び。「これを練習する」は元のキー)
- **練習の画面**:
  - 「キー」の選択(12キー。元のキーに「(元のキー)」)と「**ランダムキー**」の切り替え(押すと印が付く)。**版の切り替えでも、選んだキーとランダムキーの状態は保つ**(1枚目から)。今の版のキーが項目のキーと違うときは「この版のキー Em」を出す
  - ランダムキーが入っていると、**完奏と同時に次のキーへ**(鍵盤を離すのを待たない。次のカードは押し直さないと通らないので誤判定にならない)。順は **`createKeyBag`(12キーを1巡ずつ)**:`jazzRandomKey.ts`(`endless.ts` と同じ式)。表示は「n巡目 k/12」。「完奏！ C → 次は F · 1周 · 続けて、次のキーで弾けます」
  - ランダムキーが入ったまま手でキーを選ぶと、そのキーから新しい巡(最初は別のキー)。切ると、完奏してもキーは変わらない
  - **12キーの完奏の欄**:鍵盤の上の行(「完奏したキー:」)に、弾き終えたキーの印と回数・今のキーの輪
  - 「通して聴く」・カード1枚の再生・譜面・鍵盤・カードの音名・押さえたままの案内は、**今のキーの音と綴り**
- **指はデータのまま**(移調で動かすだけ。直していない)
- 「注記」(推奨ボイシング(元の演奏の書き起こしではない))は、キー・ランダムキーの部品が増えて操作の行に入らなくなったので、**ヒントの行の右**に移した(1280×720 の収まりを保つため)

## 8. 気づいた点
- 低い音(C2 より下まで)になるキーが34の「進行 × キー」にある。鍵盤は自動で C1 まで広がる(今のところ画面の幅に収まっている。Stage 03 の写真で改めて確かめる)
