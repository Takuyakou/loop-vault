## 2. 最後に直した3点

1. **カードの音名が途中で折り返さない**:音1つ(`E𝄪4(5)` など)を `white-space:nowrap` の1まとまりにし、折り返すのは音と音の間だけ。009 の 1660×1035・1280×720・1920×1080 で確認
2. **譜面の指の番号の線が交差しない**(`fingerLayout='aligned'`):手ごとに指の印を音の高さの順に並べ、間隔は 23(文字の枠が重ならない最小)。線は音から短く水平。右手の線は 75〜90px 未満。2度の音は、同じ譜表だけでなく**高音部と低音部をまたぐときも**横にずらす(002 の B3/C♯4)。001 の右1・右2、009 の右5 は写真で確認
3. **鍵盤の指の印**:印は1.4倍以上(1280×720 は 1.4 倍、高い画面は 1.6 倍まで)。白鍵の「左5」「右2」が黒鍵に隠れていたので、白鍵の印を少し下げ、ラベルを黒鍵の下端より下に置いた(e2e:白鍵のラベルの上端 ≥ 黒鍵の下端 − 4px)

その他:高音部と低音部の間は **28px**(Jazz・Original。音の高さのまま。A♭3 と C4 は重ならない)。譜面は音の高さで高音部・低音部を決める(MIDI 60 以上が高音部)。

## 5. 気づいた点
- 同じ譜表の3度は頭が少し触れる(従来の描き方)。e2e は「頭の大部分が重なる」ものだけを不合格にしている
- compact(1280×720)は余裕が小さい。譜面の下の音符・鍵盤の印の行を詰めて収めた。これ以上小さい窓では compact のまま縦に収まらず、ページがスクロールする(768×640 はもともとそう)
- 指の印が多い和音(5音)では、印の列が譜面の縦をほぼ使う。2音までの手は影響なし
