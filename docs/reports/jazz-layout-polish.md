# Jazz / 定番の進行: 大きい画面の縦1列・題の色・一覧のスクロール位置

ブランチ `feat/jazz-layout-polish`(master `1311860c` から)。master へのマージ・push はしていません。

## 1. 練習画面:大きい画面は縦1列
- 1500px 以上の wide(左右2列)をやめた。`jazzLayout` の段階は `compact`(1280×720・1366×768・768×640)と `stacked`(1440×900 以上の縦1列)の2つ。stacked は上から 操作の行 → カード → シークバー → ヒントと注記 → この進行で学ぶこと
- 文字・カードの拡大は今までどおり最大 1.4 倍(カード・コード名・音名・学ぶことの文字)。操作の行だけは拡大を 1.15 倍で止め(`JAZZ_BAR_SCALE_MAX`)、1660×1035 と 1920×1080 でも、009 の長い行(版・キー・ランダムキー・最初から・BPM・オクターブ・通して聴く・お手本)が **1行に収まる**(+1 のときも)
- 中身の幅の上限と中央寄せは、stacked の既存の指定(カードの幅 216px × 拡大、シークバー 720px × 拡大、学ぶこと 980px × 拡大)がそのまま効く
- 1280×720(compact)と 1440×900(stacked)の見た目は変えていない
- 写真:`p89-generated/jazz-layout-polish/practice-<001|009>-<1280x720|1440x900|1660x1035|1920x1080>.png`(Git 管理外)

## 2. 題の色
- 今までのまとまりと Original の題(h2)は、見出し共通の薄い灰色を引き継いでいた。`.dojo-builtin-title h2,h3` に `color:#f2f6fc`(Jazz の題と同じ)を指定。並び・大きさ・太さ(15px・700)・ほかの見た目は変えていない

## 3. 練習から戻ったとき、一覧のスクロール位置
- 一覧(定番の進行)のボタンを押した時の、一覧のスクロール位置を、ボタンのフォーカスキーごとに覚え(`ChordDojoView.tsx`)、「← 定番の進行」や Esc で戻ると、その位置に戻して、押したボタンにフォーカスを戻す。窓の大きさが変わって同じ位置にできないときは、押したボタンが見える位置にする(`scrollRestore.ts`)
- 全部のまとまり(今までの定番の進行・Original・Jazz)と全部の入口(「これを練習する」「ランダムキーで練習」)で同じ。フォーカスの印がなかった Original と Jazz の「ランダムキーで練習」に印を足した
- 一覧以外の入口(2-5-1 Master など)は、今までどおり先頭で開く(最初の実装で、これも戻してしまい `p12-vertical-layout` が落ちたので、一覧のボタンだけに限った)
