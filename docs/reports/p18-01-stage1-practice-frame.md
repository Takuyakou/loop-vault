## 1. 変えたもの

**共通の型(上から)**:1 上の行 / 2 設定の行 / 3 カード / 4 知らせ+操作の行 / 5 譜面 / 6 鍵盤 / 7 下の余白。A・B・C・D は同じ行で並びます。

- **`practiceLayout.ts`**(旧 `jazzLayout.ts`):D の compact/stacked を A〜D 共通の並べ方に。名前を `practiceLayout`・`PracticeLayout`・`usePracticeLayout`、CSS の変数を `--pf-*`、属性を `data-practice-layout` に。**下の余白**(`safe`:compact 16px・stacked 24px)を足し、**譜面の行から取りました**(stacked の譜面は `高さ×0.26`(最小 210)。コード名・指番号・鍵盤の高さは変えていません)。測るのは `usePracticeLayout`(コールバック ref。A は一覧から入ったときだけ画面に出るため)
- **`PracticeFrame.tsx`(新)**:`PracticeHead`(戻る・種類・題・度数・段階・進み具合・MIDI 設定・やめる(Esc))/ `StageIndicator`(①②③。この段階では表示だけ)/ `PracticeCard`(度数・コード名・左右の音名・印・札)/ `PracticeSafeArea`
- **D(Jazz)**:共通の上の行に。「通して聴く」「お手本を聴く(L)」を設定の行から**操作の行**(カードの下)へ。段階は「① 見て弾く」(① だけ)。進み具合は「① n周目 · k/m · 完奏 n」。**D の記録・判定・オクターブ・BPM・通して聴くの動きは変えていません**
- **C(Original)**:共通の上の行・共通のカード。**大きな「キー E♭」の文字をやめ**、設定の行(キー・ランダムキー・最初から)に。「完奏したキー:」の印は鍵盤の上の行(D と同じ位置)へ。段階は ① だけ
- **B(ランダムキー)**:共通の上の行(種類「ランダムキー」、段階は ② が光り ①③ は薄く押せない:「ランダムキーは ② で弾きます」)。**大きな「キー F」をやめ**、設定の行に「キー B♭(ランダム)」と判定の方針。カードは度数+名前(隠す間は「?」)。「このセッション:」の印は鍵盤の上の行へ(最後の6つ、結果が無いときは出さない)。クリアの知らせは知らせの行の頭に
- **A(定番「これを練習する」)**:**一覧から入ったときだけ**(`practiceFrom==='builtin-progressions'`)、共通の型に。中央の大きな題と「復習 → 型を覚える → …」の流れ・「今日 合った…」・「課題と練習の記録」は出さず、上の行に集約(種類=グループ名「J-POP」など)。段階 ①②③(③ は押せない:「③ は覚えた次の日の復習で出ます」)。設定の行は「キー C」(表示だけ)/ 判定の方針 / ☆使いたい / 歯車(BPM)。カードは D と同じ大きさ(今の小さな 92×50 をやめ)。**② では名前を「?」に、番号を上の小さな行に**(今どおり度数は ① だけ)。「前回ヒント」の札は小さなカードの中で重ならず読めます。操作の行の並びは お手本を聴く(L)/ 答えを見る(Space)/ とばす(今あるものだけ)。**今日の練習から入った A は一切変えていません**(`!fromList` のときの今の JSX がそのまま)
- **CSS**(`chord-dojo.css`):D だけだった compact/stacked の規則を `[data-practice-frame]`(A=a・B=b・C=c・D=d)の共通の規則に書き直し、末尾に「共通の型」の節を足しました。狭いとき(コンテナ幅 900px 以下)は、種類・度数・押せない段階の名前・進み具合の2つ目以降を畳み、上の行は1行のまま

## 3. 最大化とタスクバー(§1.2)
実機(exe、起動して CDP で窓の外形を測り、自分の「最大化」ボタンで最大化)で確認しました。

- 最大化前:1440×900。最大化後:**1920×1079、画面の作業領域(`screen.availHeight`)は 1080**。窓の下端 1079 ≦ 作業領域の下端 1080。**窓はタスクバーの下に潜り込んでいません**(差 −1)。
- ただし、この PC では3つのモニターとも作業領域が画面と同じ大きさ(1920×1080)で、**タスクバーが作業領域を取っていません**(自動で隠れる設定のように見えます)。そのため「タスクバーが表示されたまま最大化」の状態は、ここでは再現できていません。表示される設定のときに重なるかは、実機(タスクバーを常に表示にした状態)で確かめてください。重なるようなら、止まって報告します(Tauri の設定・`windowControls.ts`)。
- この確認で、アプリが起動時に作るバックアップ(`txt-jazz-v3/backups`)が1つ増えています(通常の動作)。
