## 1. 変えたもの(§2 対応)

### 1.1 段階の表示(§2.1)

- D の上の行の段階は「① 見て弾く ② 覚えて弾く」の2つに。**押せる**(A と同じ形・同じ動き:押すとその段階の1枚目から)。③ はまだ出しません(P18-03)
- 進み具合:「① n周目 · k/m · 完奏 n」の頭に今の段階を付けた形(今の ① と同じ周回の数え方:そのキーの完奏の数 +1)。**② のときは「② ヒントなし n」も表示**(この画面を開いてからの、ヒントなしで通せた ② の周の数。保存しない)

### 1.2 ② のときの見え方(§2.2)

- **カード**:度数とコード名は出したまま、左右の音名・指は「?」(音の数だけ ? を並べる)。**弾き終えたカード(今のカードより前)と、答えを見せたカード(今のカードが動くまで)は音名を出す**
- **ヒントの印**は A の ② と同じく **カードの角の小さな札**(「ヒント」。カードの高さは変わらない。E2E で高さが同じことを確かめる)
- **譜面**:見せるまで空(GrandStaff の既存の隠し表示。A・B と同じ言葉)。**鍵盤**:押している音は今どおり、このカードの音・左右の色・指の印は見せるまで出さない。凡例は「押している音 / 答え(弾いた後かヒントで出る)」に替わる(`HeldCardBoard` の `concealed`)
- **知らせの一行**:「ボイシングを思い出して弾いてください。止まると、そのカードだけ音が出ます」。押さえたままでよい音があるときは「前のカードから押さえたままの音は、離さなくて構いません」(**音の名前を言わない**。`heldCardHint` に ② 用の言い方を足した)
- ①(見て弾く)は今どおり全部見える

### 1.3 ヒント(§2.3)

- A・B の ② と同じ3入口で **今のカードだけ**の答え(カードの音名・指、譜面、鍵盤の答え)を見せる:
  1. 「答えを見る(Space)」ボタン・Space キー(② にだけ出る)/ 2. 「お手本を聴く(L)」(音も出す)/ 3. 止まり:`settings.hintSec`(Dojo の設定の値、A と同じ)を押さえずに超えると自動で見せる
- 見せたカードに「ヒント」の印(A と同じ)。**その周はヒントあり**。次のカードへ進むと答えは閉じる(そのカードは弾き終えたカードとして音名は出たまま)
- **「通して聴く」**:② の途中でも押せて、押したらその周はヒントあり + 知らせ「通して聴いたので、この周はヒントありです」
- 判定は未変更。自分で判定(Y)も今どおり

### 1.4 周の終わり(§2.4)

| | くり返す **入**(D の最初の値) | くり返す **切** |
|---|---|---|
| ① の終わり | 今どおり次の周(ランダムキーなら次のキー) | 止まる:「もう一度 ① を弾く(R)」+ **「② 覚えて弾くへ(Enter)」**(A と同じ。Enter は同じキーの ② の1枚目から) |
| ② ヒントなし | 知らせ「② をヒントなしで通しました」で次の周(ランダムキーなら次のキー) | 止まる:「② をヒントなしで通しました」+「もう一度 ② を弾く(R)」(R でランダムキーなら次のキー) |
| ② ヒントあり | **同じキーでもう1周**(ヒントの印を消して1枚目から)。止める選択は出さない | 同じ |

- 段階・キー・版・オクターブを変えたらその段階の1枚目から。**段階を変えてもキー・版・オクターブ・ランダムキー・くり返す、くり返す** は保つ(見本どおり。E2E で確認)
- この決まり(bundle)は `src/views/chord-dojo/heldCardRecall.ts`: `jazzLapOutcome(段階,ヒントあり,くり返す)` → `{数えるか(complete+laps+次のランダムキー), 止まるか}`。`useHeldCardRun` が `lap` オプションでこれに従う(C は `lap` を渡さないので今どおり)

### 1.5 記録(§2.5)

- **完奏(`laps`)は ① の周(今どおり)と ② のヒントなしの周で数える**。② のヒントありの周は数えない(記録もランダムキーの移動もしない)。「完奏したキー」の印も ② をヒントなしで通したキーに付く
- 画面の中の「② ヒントなし n」は保存しない
- ランダムキーの丸ごとの周回(巡目)の数え方は今どおり:周が終わって次のキーに進むときのみ進む

### 1.6 「この進行で学ぶこと」の音名(§2.2 の報告)

**「この進行で学ぶこと」(focus)には 21 の進行のうち 20 に元のキーの音名が入っているため、② の間は畳みました**:

- **②(演奏中)**:focus の文を畳み、**「この進行で学ぶこと(開くと答えが分かります)」のボタン**を出す。譜面の見出し(1280×720 の caption)の中に出しているときも同じ
- **開くと**:その周はヒントあり(通して聴くと同じ扱い)+ 知らせ「**学ぶことを開いたので、この周はヒントありです**」。開いた文章は「畳む」ボタンで閉じられる(印はその周の間残る)
- **① と、② の周の終わり(止まったとき)**:今どおり文章を出す
