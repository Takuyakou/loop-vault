## 1. できたこと

Chord Dojo のホームを、練習へ入るための画面として作り直した。

- 上部に「続きから」を置き、直近の練習を最大 3 件表示する。
- よく使う練習を 4 枚の大きいカード(定番の進行 / 2-5-1 Master / 耳で弾く / ボイシングドリル)にした。
- そのほかを 4 枚の小さいカード(自分の進行 / 登録した音 / コードの型 / 今日のおまかせ)にした。
- MIDI がつながっていないときだけ、細い MIDI 帯を 1 つ出す。
- ホームは既存の記録を**読むだけ**。新しく保存するのは「続きから」の小さな設定(`loop-vault:dojo-recent:v1`)だけ。
- 練習の中身・記録の形式・押した先の画面は変えていない。練習画面には「最初の入力で続きからを更新する」フックと、再開用の初期位置だけを足した。

## 2. 仕様への対応

### 2.1 続きから

- 保存する種類は 10 種類: 定番の進行 / Jazz Progressions / Original Practice / 2-5-1 Master / 耳で弾く / ボイシングドリル / 自分の進行 / 登録した音 / コードの型 / 今日のおまかせ。
- 識別は「種類 + 安定 ID」。表示名は今のデータから引くので、名前を変えても続けられる。消えた項目はデータ読み込み後に出さない。
- 最大 3 件。同じ種類+ID は上書き。1 件ずつ zod で検証し、壊れた 1 件だけを外す。保存に失敗してもホームは表示される。
- 記録するのは「その条件の最初のカードを実際に始めたとき」だけ。開いてすぐ戻っただけでは記録しない。
- 再開は項目・モード・段階・キーだけを復元し、周の先頭から始める。カード位置・時間・ランダムの袋は復元しない。「n 周目」も出さない。
- 記録する場所:
  - 定番の進行(固定キー)/ 自分の進行 / 登録した音 / コードの型 / 今日のおまかせ: 最初の回答
  - 定番の進行(ランダムキー): そのキーの最初の入力
  - Jazz / Original: 最初の鍵盤入力(手動判定では「弾けた」)
  - 2-5-1 Master: その Form・モードの最初の鍵盤入力
  - 耳で弾く: 問題を始めたとき
  - ボイシングドリル: その組・段階・キーの最初の入力
- 読み込み中は「続きから」を仮表示にして押せない。読めないときは「今は開けません」と薄く出し、記録は消さない。

### 2.2 カードの数字

- 定番の進行: Jazz Progressions は**今の一覧の ID** のうち、どれかのキーで 1 回以上完奏した数 / 今の一覧の数。Original Practice も同じ。廃止された進行の lap は数えない。分母は固定値ではなく一覧から取る。
- 2-5-1 Master: 既存の `Master251Card` の数(MASTER・Form ごとの x/12)をそのまま使う。
- 耳で弾く: 既存の記録から、1 問ごとの「測れたコードの一発正解率」を 0〜100 の点にして、最新を「前回」、最高を「ベスト」にした。記録が無い/読めないときは数字を出さない。
- ボイシングドリル: 最後に練習した組・段階・キーの、**今の内容版**の best だけ。前の版や長さの違う組は比べない。まだ一周していなければ「まだ記録はありません」。
- 読み込み中・読めない・0 件を内部で分け、読めないときは「—」と小さな「記録を読めませんでした」を出して 0 と表示しない。

### 2.3 大きさ

- 1440×900・標準文字・「中身を見る」を閉じた最初の状態で、縦スクロールなし。
- 1280×720 / 1366×768 は縦スクロール可。どの大きさも横はみ出しなし。
- 列はホームに実際に使える幅のコンテナクエリで、1100px 未満は大きいカード・小さいカードとも 2 列。
- 主なボタンは 44px 以上。文字は切らず、長い名前は折り返してスクロールを許す。
- 下にタスクバー用の余白を取った。

### 2.4 Enter とフォーカス

- ホームで何もフォーカスされていないときだけ、Enter で「続ける」と同じ動作。続きが無ければ何もしない。
- 入力中・IME 変換中・ダイアログ/パネル・キーリピートでは動かない。ボタン/リンクにフォーカスがあるときは、そのボタンの動作を優先する。
- 練習から戻ると、実際に押したボタン(`data-focus-key`)へフォーカスを戻す。無くなっていたら同じカードのボタン → 「続きから」→ 最初のカード、の順に落とす。

### 2.5 MIDI

- つながっていないときだけ細い帯を 1 つ。MIDI 設定を開ける。
- 接続エラー時は `role="alert"` でエラーを表示する(ホームの帯とは別)。
- 既存の練習画面の MIDI の注意はそのまま。

## 3. 見本と違えた所

- 2-5-1 Master のカードは、既存の `Master251Card` をそのまま大きいカードとして使った(Form A〜D の枠・学習順・MASTER 数・新規学習/復習/Mixed Test の動きを変えないため)。見本の独自カードには置き換えていない。
- 「耳で弾く」の「点」は既存記録に点数が無いため、1 問の「測れたコードの一発正解率 × 100」と定義した。画面には前回・ベスト・前回の日だけを出し、定義はこの報告に残す。
- 「今日のおまかせ」は、見本の大きな今日カードを小さいカードに縮め、テーマ・今日の課題・練習の量は「中身を見る」で開く形にした。
- 見本の「NEW」などの印は付けていない。
- ボイシングドリルの 4 段階は、カード内の 2×2 の枠。押すと選ぶ画面のその段階へスクロールする。
- 登録した音の「使いたい」は、ホームでは件数と先頭 2 件。全部は「選ぶ」で開く登録した音の画面の先頭「使いたい」一覧に移した。

## 7. 注意・残したこと

- 練習画面・記録の形式・押した先の画面は変えていない。ホームは記録を書き換えない(テストで前後の localStorage を比較)。
- 実際の Vault・記録・音声は使っていない。e2e は合成データだけ。
- P19 で修復したワークスペースの ACL はそのまま。P20 で新しい権限変更はしていない。
- 仕様の「全種類の続きからの記録」e2e を追加した(定番の進行・Jazz・Original・2-5-1・耳で弾く・ボイシングドリル・自分の進行・登録した音・コードの型・今日のおまかせ)。段階/キーの変更、名前変更、削除、読み込み中/失敗、保存失敗、長い名前も確認している。
- 「今日のおまかせ」の再開は、計画の**今のカーソル**から。カードの「始める/続きから始める」と同じ動きで、先頭には戻さない。カーソル・課題の記録は巻き戻さない。先頭に戻していたコードは削除した。
- 「今日のおまかせ」の 1 枚目が型でも、続きからは「今日のおまかせ」として記録する。
- e2e の「読み込みが遅い」は、テストが `sessionStorage` の `p20-home-read-delay` を設定したときだけ遅らせる。本番の既定は 0。
- `p104=renamed` / `p104=none` は合成 Vault の fixture で、実際の Vault は使っていない。
