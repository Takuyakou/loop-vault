## 直した 3 つ

1. **MIDI の結果ヘッドの縦並び揃え**
   - [src/features/bass-practice/ui/bassPractice.css](../../src/features/bass-practice/ui/bassPractice.css#L112) の `.bass-midi-result-head` を `width:100%; display:flex; flex-direction:column; align-items:center; gap:18px;` に変更。
   - [e2e/p23-62-bass-stage.spec.ts](../../e2e/p23-62-bass-stage.spec.ts#L730-L737) の `expectStageShape`(S7)へ、5 つの練習すべての段 3(`1440×900`・`1280×720`)で `bp-result-big` と `bp-result-facts` の中心 X 差が `4px` 以内かつ `facts.y > big.y + big.height` であることの検証を追加。
2. **自分の段で「抜け」と近くの「余分な音」を 1 箱にまとめる**
   - [src/features/bass-practice/stage/useJudgedTake.tsx](../../src/features/bass-practice/stage/useJudgedTake.tsx#L234-L287) の `takeNotes` で、`!mark.played` ごとに `result.extras` から開始拍が `[expected.startBeat - 0.5, expected.startBeat + expected.durationBeats)` にある最も近い未使用の余分な音を探し、見つかった場合は点線の「抜け」と「＋」の箱を出さず、`kind: "late" | "early"`・`text: "大きく遅い" | "大きく早い"`・`sub: noteName(...)`・`label: "自分 {n} 音目 {word} {name}(判定の幅の外)"` の 1 箱へ統合(判定件数 `result.counts` は不変)。見つからない場合のみ従来の「抜け」・「＋」を維持。
   - [src/features/bass-practice/stage/useJudgedTake.test.ts](../../src/features/bass-practice/stage/useJudgedTake.test.ts#L26-L61) へ単体テスト 3 本を追加(2.3 拍の余分な音で 1 箱 `late`/`大きく遅い`・1.7 拍で 1 箱 `early`/`大きく早い`・3.6 拍の離れた余分な音で `抜け`/`＋` の 2 箱)。
3. **コード進行のベースの条件チップから「既定の生成進行」を外す**
   - [src/features/bass-practice/ui/BasslinePracticeView.tsx](../../src/features/bass-practice/ui/BasslinePracticeView.tsx#L920-L1410) で `progressionSourceLabel` のフォールバックを `"おまかせの進行"` に、`progressionName` のフォールバックを新設ヘルパー `formatProgressionChords(activeSnapshot?.section.chords)`(コード名を `–` 連結、4 つ超なら先頭 3 つ + `…`、空時は `"おまかせの進行"`)に変更。
   - [src/features/bass-practice/ui/BasslinePracticeView.chordContext.test.tsx](../../src/features/bass-practice/ui/BasslinePracticeView.chordContext.test.tsx#L153-L297) の 2 箇所を `"Dm7–G7–Cmaj7"` 期待・`"既定の生成進行"` 非含有へ更新。
