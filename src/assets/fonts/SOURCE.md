# 字のファイルの出どころ

| ファイル | 元 | 版 | ライセンス |
|---|---|---|---|
| `inter-latin-*.woff2`・`inter-latin-ext-*.woff2` | Fontsource の `@fontsource/inter`(Inter。The Inter Project Authors) | 5.3.0 | SIL Open Font License 1.1(`OFL-Inter.txt`) |
| `noto-sans-jp-japanese-*.woff2` | Fontsource の `@fontsource/noto-sans-jp`(Noto Sans JP) | 5.3.1 | SIL Open Font License 1.1(`OFL-Noto-Sans-JP.txt`) |
| `lv-symbols-*.woff2` | ♭ ♮ ♯(U+266D〜266F)は Fontsource の @fontsource/noto-sans-symbols(Noto Sans Symbols。The Noto Project Authors)5.3.0 から切り出した物。Ⅰ〜Ⅻ(U+2160〜216B)は、同じ太さの Inter(@fontsource/inter 5.3.0)の I・V・X の形を並べて作った物 | 5.3.0 | SIL Open Font License 1.1(`OFL-Noto-Sans-Symbols.txt`・`OFL-Inter.txt`) |

太さは 400・600・700。Inter と Noto Sans JP のファイルの中身は変えていない。`lv-symbols` は、記号 3 字を切り出し、ローマ数字 12 字を Inter の形から作った物(字の名前は元の字と別の「LV Symbols」)。
